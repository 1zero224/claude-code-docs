# 我在 Amazon Bedrock 中使用 Claude。我应该联系谁进行客户支持咨询?

[联系 AWS 支持](https://aws.amazon.com/contact-us/)以获取 Claude in Amazon Bedrock 支持咨询，或联系您的 AWS 账户经理。如需社区支持，请访问 [AWS re:Post](https://repost.aws/)。

# 我如何获得通过 Amazon Bedrock 使用的退款？

如果您通过 AWS Bedrock 使用 Claude，您的使用费用不可退款。如果您是与 Anthropic 签订私人协议和直接合同以用于 Bedrock 使用的客户，您可以联系您的 Anthropic 关系经理以获取额外帮助。

---

**注意：**对于使用 Bedrock 的日本客户，  Anthropic 将在成为日本消费税纳税人后注册日本消费税，即在超过法定阈值时（最早从 2026 财年开始）。
