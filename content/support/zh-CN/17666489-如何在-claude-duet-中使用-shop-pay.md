# 如何在 Claude Duet 中使用 Shop Pay

连接 Shop Pay（Shopify 的钱包）到 Claude Duet，这样它就可以为您批准的购买付款。

Shop Pay 在 Claude Duet 中可用，这是美国 Pro、Max 和 Ultra 计划的研究预览版。目前在 Claude、Cowork 或 Claude Code 中不可用。

Shop Pay 与 Shopify 连接器分开，后者让 Claude 在您的 Shopify 商店中工作。您可以单独使用其中任何一个。

## 您可以做什么

- **批准每次购买。**Claude Duet 的设计目的是在每次购买前询问。

- **使用一次性卡付款。**每次购买都使用一张一次性卡，该卡仅适用于该购买。

## 如何连接

Shop Pay 未在连接器目录中列出。您在 Claude Duet 中连接它。

1. 在 Claude Duet 中选择您的头像。

2. 选择连接付款的选项，然后选择 Shop Pay，或在移动设备上从推荐的连接器列表中选择。

3. 登录您的 Shop Pay 账户并批准访问。

当您要求需要付款的东西时，Claude Duet 也会建议连接 Shop Pay。

Claude Duet 可以看到您保存的付款方式的最后四位数字和到期日期，以及您的账单地址。它无法访问您的完整卡号或银行账户号码。

## 如何使用 Shop Pay 付款

1. 向 Claude Duet 要求您需要的东西，例如"订购更多运输标签，与上次相同。"

2. Claude Duet 找到该商品并要求您批准购买。

3. 点击"在 Shop Pay 中审核"，然后批准购买。

4. Claude Duet 使用一张一次性卡通过 Shop Pay 付款，该卡的范围限制在批准的金额内。

## 当前限制

- Shop Pay 仅在美国的 Claude Duet 中的 Pro、Max 和 Ultra 计划中可用。

- 某些网站可能会阻止 Claude Duet 付款。如果发生这种情况，您可能需要自己完成购买。

## 常见问题

### Claude Duet 可以在不问我的情况下购买东西吗？

不可以，Claude Duet 的设计目的是在每次购买前询问。

### 为什么我在连接器目录中找不到 Shop Pay？

Shop Pay 内置于 Claude Duet 中，因此您在那里连接它。

### Shop Pay 与 Shopify 连接器相同吗？

不是。Shopify 连接器让 Claude 在您的 Shopify 商店中工作，例如管理产品和订单。Shop Pay 为购买付款。您单独连接它们。

### 我应该联系谁了解费用、退款或购买问题？

您购买的商店处理退款、退货和订单问题。直接联系商店。如有关于您的 Shop Pay 账户或费用的问题，请联系 **[Shop 支持](https://help.shop.app/en/shop/report-issue/contact-the-shop-support-team)**。如有关于 Claude Duet 本身的问题，请在聊天中告诉 Claude Duet 发生了什么，它会将您的报告转发给我们的团队。

### 我如何断开 Shop Pay 的连接？

1. 在 Claude Duet 中，选择您的 Claude Duet 头像。

2. 选择付款，然后选择 Shop Pay。

3. 选择"断开连接"。
