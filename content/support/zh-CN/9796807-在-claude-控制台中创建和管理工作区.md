# 在 Claude 控制台中创建和管理工作区

本指南将引导您完成在 Claude 控制台组织中创建、编辑和管理工作区的过程。

## 什么是工作区？

工作区是控制台组织内的协作空间，团队可以按用例分离 API 资源。

如果您需要创建一个完全独立的组织，具有自己的成员、账单和工作区，请参阅下面的**[创建独立的控制台组织](#h_816b6c2559)**。

## 如何创建新工作区

**注意：**只有组织管理员可以创建新工作区。

1. 登录您的**[Claude 控制台账户](https://platform.claude.com/login)**。

2. 转到**工作区**页面 (platform.claude.com/settings/workspaces)。

3. 点击"创建工作区"。**创建工作区**页面打开 (platform.claude.com/settings/workspaces/new)。

4. 为您的新工作区输入名称，并选择颜色。颜色可帮助您在 Claude 控制台中识别您的工作区。

5. 点击"创建工作区"以完成新工作区的创建。

您的新工作区现在将出现在工作区列表中。

**注意：**每个组织限制为 100 个工作区。

## 编辑工作区设置

1. 从**工作区**列表中，点击要编辑的工作区旁边的省略号。

2. 选择"编辑详情"。

3. 您可以修改以下设置：

  - 工作区名称

  - 颜色

4. 进行更改后，点击"保存"以应用更改。

**注意：**您无法重命名默认工作区或更改其颜色，也无法存档或删除它。

## 向工作区添加成员

**注意：**您必须按照**[这些说明](https://support.claude.com/en/articles/13443764-inviting-members-to-the-claude-console)**将成员添加到您的控制台组织，然后才能将他们添加到工作区。

1. 转到**成员**页面 (platform.claude.com/settings/members)。

2. 点击"添加到工作区"。

3. 选择工作区、要添加的组织成员及其工作区角色。

4. 点击"添加到工作区"以确认。

**注意：**组织管理员会自动添加为每个工作区的工作区管理员。组织账单角色持有者会自动获得查看所有工作区的成本、使用情况和限制值的能力，但可以升级为组织管理员角色。

## 从工作区删除成员

1. 转到**成员**页面 (platform.claude.com/settings/members) 并从**工作区**下拉菜单中选择工作区。如果菜单显示"全部"，删除成员会将其从您的组织中删除。

2. 在成员行的末尾，打开"更多操作"菜单（三个点）并选择"删除成员"。

3. 点击"删除"以确认。

**注意：**具有管理员和账单角色的组织成员会自动获得所有工作区的权限，无法从工作区中删除。

## 在工作区中管理 API 密钥

1. 转到**API 密钥**页面 (platform.claude.com/settings/keys)。

2. 从**工作区**下拉菜单中选择工作区以仅列出其密钥。

3. 要为此工作区创建新 API 密钥：

  - 点击"创建密钥"

  - 为密钥提供描述性名称

  - 点击"创建密钥"

4. 要撤销现有 API 密钥：

  - 在列表中查找密钥

  - 点击其旁边的省略号

  - 选择"禁用 API 密钥"或"删除 API 密钥"

    - **注意：**删除 API 密钥是永久操作，无法撤销。

  - 确认操作

**注意：**API 密钥与创建它们的工作区相关联，无法在工作区之间移动。

## 设置工作区速率限制

1. 转到**速率限制**页面 (platform.claude.com/usage/limits) 并从**工作区**下拉菜单中选择工作区。

2. 点击模型旁边的"编辑"以设置其限制。

3. 通过点击每个选项旁边的"编辑"为每个模型层级和限制类型设置限制。

4. 工作区限制可以通过选择模型、在**编辑工作区速率限制**模态框中将所有字段留空，然后点击"保存"来重置为组织速率限制。

**注意：**Anthropic 始终为每个请求评估所有适用的限制器——在工作区和组织级别。换句话说，如果工作区限制未设置，组织限制仍然适用。

## 设置工作区支出限制或通知

1. 转到**工作区**页面 (platform.claude.com/settings/workspaces) 并选择工作区。

2. 在打开的面板中，点击"支出限制"。

3. 选择以下选项之一：

  - 在**月度限制**下选择"更改限制"以为此工作区设置特定的支出限制。

    - **注意：**您只能设置低于组织限制的支出限制。如果未设置，您的支出限制默认为组织的限制。您无法为默认工作区设置支出限制。

  - 在**电子邮件通知**下选择"+ 添加通知"以设置当工作区支出达到特定金额时的电子邮件通知。

## 查看工作区使用情况和成本

转到**使用情况**页面 (platform.claude.com/usage) 或**成本**页面 (platform.claude.com/cost)。

## 存档工作区

如果您不再需要工作区但想保留其历史数据：

1. 导航到**工作区**页面。

2. 点击要存档的工作区旁边的省略号。

3. 确认您要存档工作区。

**注意：**存档工作区将存档工作区中的所有 API 密钥。此操作无法撤销。

## 管理默认工作区

转到**API 密钥**页面 (platform.claude.com/settings/keys) 并从**工作区**下拉菜单中选择"默认"。

## 创建独立的控制台组织

单个电子邮件地址只能创建一个控制台组织。如果您已经使用您的电子邮件创建了一个组织，再次注册会将您路由回该组织，而不是启动新组织。您仍然可以被邀请加入其他组织并在同一电子邮件上的组织之间切换，但您只能自己创建一个。

### 何时需要独立组织

您可能需要为不同的法律实体或单独的账单创建完全独立的组织。独立组织独立于您现有的组织，具有自己的成员、账单和工作区。

要创建新组织，请使用尚未在 Anthropic 注册的工作电子邮件地址注册。

### 如何创建新组织

将拥有新组织的人应完成这些步骤。注册的人将成为组织的主要所有者。

1. 转到**[Claude 控制台](https://platform.claude.com/)**。

2. 使用 Google 或 Microsoft 单点登录 (SSO) 或电子邮件和密码通过工作电子邮件地址注册。

3. 使用发送到该收件箱的链接验证电子邮件地址。

4. 完成组织详情表单，包括组织名称、实体类型、国家/地区和预期用途，然后选择"完成设置"。

新组织会自动创建，带有默认工作区，注册的人会被带到该组织的控制台。

### 设置后

主要所有者可以：

- 在**成员**页面 (platform.claude.com/settings/members) 上邀请成员并分配角色（如管理员、账单和开发者）。

- 在**账单**页面 (platform.claude.com/settings/billing) 上添加付款方式。
