# Claude Cowork 和聊天合二为一

我们推出了一种使用 Claude Cowork 和聊天的新方式，消除了这两个产品之间的区别：在新体验中，它们合并为一个对话，因此您无需在开始前决定哪个选项更适合您的任务。向 Claude 询问您需要什么，它可以决定使用哪个工具。Claude 可以回答快速问题，也可以处理更复杂的工作，如研究、报告、电子表格和演示文稿，并将其作为您可以编辑的完成文件返回。使用新的 Claude 体验，您可以在同一对话中要求所有内容，无需选择模式。您之前只能在 Claude Cowork 中执行的操作现在可以从任何对话中使用。

新的 Claude 体验正在逐步推出，首先在网络、桌面和移动设备上的 Pro、Max 和 Ultra 计划中推出。在团队计划（测试版）和企业计划中，当**聊天和 Cowork 统一**打开时可用。

## 您可能还没有获得的原因

我们分阶段推出这个新体验，因此即使是同一计划上的账户也会在不同时间看到变化。您无需执行任何操作来启用新体验。如果您使用的是 Pro、Max 或 Ultra 计划，且您的消息框仍显示"聊天"和"Cowork"选项，则您还没有获得。在此之前，请继续像今天一样使用聊天和 Claude Cowork，您可以执行本文中的大部分操作。您的聊天、任务、项目和设置会在您的账户转移时随之转移。一旦您的账户获得新体验，您将无法切换回单独的"聊天"和"Cowork"选项。

## Claude 可以做什么

### 将整个任务交给 Claude

描述您想要的结果，Claude 会自行完成各个步骤：搜索网络、阅读您的文件、运行代码并汇总结果。您无需将工作分解为步骤或先选择模式。快速问题仍会得到快速答案，您可以同时运行多个任务。

*尝试："浏览这五份面试笔记，提取主要主题，每个主题配一条引用。"*

### 在 Claude 工作时离开

更复杂的任务即使在您关闭笔记本电脑或离开页面后，也会继续在云中运行。任务完成后返回，结果会在对话中等待您。使用您计算机上的文件或应用的任务需要 Claude Desktop 打开。

*尝试："研究小团队的顶级项目管理工具并撰写比较。我稍后会回来查看。"*

### 获取完成的文件

Claude 可以创建文档、带有工作公式的电子表格和可在 PowerPoint 中打开的演示文稿。下载它们并在任何地方使用，或要求 Claude 继续完善它们。

*尝试："将此分析转换为我周一可以演示的 10 张幻灯片。"*

### 创建设计、演示文稿和文档

Claude 可以直接在对话中构建图表、图表和交互式视觉效果。在**[聊天和 Cowork 中的自定义视觉效果](https://support.claude.com/en/articles/13979539)**中了解更多信息。在付费计划中，您还可以要求为您将在他人面前展示的工作设计、演示文稿或文档。Claude Design 制作品牌视觉效果和模型，Claude Slides 制作演示文稿，Claude Docs 制作您与 Claude 和您的团队一起编写的实时文档（Claude Design、Claude Slides 和 Claude Docs 处于测试版）。自己编辑结果或告诉 Claude 要更改什么，然后通过链接共享或导出。在**[什么是工件以及如何使用它们？](https://support.claude.com/en/articles/9487310)**中了解更多信息。

*尝试："制作此发布计划的一页视觉摘要。"*

### 使用您已连接的应用

您连接到 Claude 的应用（如 Google Drive、Gmail、Microsoft 365 或 Slack）在 Claude 执行任务时工作，因此它可以在进行过程中提取所需的内容。在**[自定义 > 连接器](https://claude.ai/customize/connectors)**中连接应用。

*尝试："在我的 Drive 中查找上个季度的董事会演示文稿，并总结自那以后发生了什么变化。"*

### 在网络和您的计算机上工作

- **文件和文件夹：**在 Claude Desktop 中，授予 Claude 访问您计算机上的文件夹的权限，以便它可以读取、组织和创建文件。

- **浏览：**Claude 可以打开网站、阅读页面、点击和填写表单，使用 Claude Desktop 中的内置浏览器或通过 Chrome 中的 Claude 使用您自己的 Chrome 浏览器。在**[使用 Claude Cowork 中的内置浏览器](https://support.claude.com/en/articles/16607400)**中了解更多信息。

- **计算机使用：**在 Pro、Max 和 Ultra 计划的测试版中，Claude 可以通过点击、输入和导航您的屏幕直接使用您计算机上的应用。在**让 Claude 在 Cowork 中使用您的计算机**中了解更多信息。

Claude 仅在 Claude Desktop 打开时才能访问您的本地文件、内置浏览器和计算机使用，默认情况下在永久删除任何文件前会询问。

*尝试："按文件类型和日期组织我的下载文件夹。"*

### 安排定期工作

要求 Claude 按计划运行任务，例如每周一早上的收件箱摘要。计划的任务可以在云中运行，因此当您的计算机关闭时它们会继续运行。在**[在 Claude Cowork 中安排定期任务](https://support.claude.com/en/articles/13854387)**中了解更多信息。

*尝试："每个工作日上午 8 点，总结我的团队 Slack 频道中的新消息。"*

### 从您的手机查看

您在办公桌上启动的任务也会显示在 Claude Mobile 中，因此您可以查看其进度、回答 Claude 的问题并从任何地方重定向工作。您也可以从手机启动任务，Claude 会继续在云中工作。

### 让 Claude 成为您自己的

- **技能：**教 Claude 您喜欢如何完成任务，它会在任务出现时遵循这些步骤。在**[在 Claude 中使用技能](https://support.claude.com/en/articles/12512180)**中了解更多信息。

- **插件：**添加为您的角色捆绑技能和连接器的插件。在**[在 Claude 中使用插件](https://support.claude.com/en/articles/13837440)**中了解更多信息。

### 选择 Claude 与您协商的程度

消息框中的权限设置控制 Claude 的独立工作程度：

- **自动（Pro、Max、Ultra 和团队计划的默认设置）：**Claude 继续工作而不停止询问每个步骤，自动化安全检查在采取行动前运行。

- **手动（企业计划的默认设置）：**Claude 在采取行动前询问，您选择是否允许每个行动。

您可以随时更改设置，并可以在 Claude 工作时停止或重定向它。该设置适用于整个对话。对于有真实后果的工作，如发送消息或更改重要文件，请保持接近并审查 Claude 的操作。在**[安全使用 Claude Cowork](https://support.claude.com/en/articles/13364135)**中了解更多信息。

## 从您离开的地方继续

- **一个对话列表：**您的快速问题和更长的任务一起存在于**[最近](https://claude.ai/chats)**中。

- **记忆：**Claude 在为您执行的任务中使用它从您的聊天中记住的内容。

- **项目：**为相关工作保持文件、说明和上下文在一起。项目在每个对话中工作。

- **Claude 的说明：**在**设置 > 您的 Claude**中设置适用于每个对话的偏好（或在较旧的设置布局中**设置 > 账户**）。

## Claude Cowork 发生了什么？

在新体验中，Claude Cowork 所做的一切都可以从任何对话中使用。您现有的 Cowork 任务、项目、连接器、技能、工件和文件会转移，这些 Cowork 任务会像以前一样打开，因此您可以继续它们。模型选择器和"代码"选项卡在它们之前的位置。

## 什么在新的地方

- **Cowork 任务：**与您的聊天一起在**[最近](https://claude.ai/chats)**中。

- **全局说明：**Cowork **全局说明**设置现在是**设置 > 您的 Claude**中**Claude 的说明**的一部分（或在较旧的设置布局中**设置 > 账户**）。检查您的说明是否符合您的要求。

- **网络搜索：**没有网络搜索切换。当有帮助时，Claude 会搜索网络。

- **研究：**输入 /deep-research，或点击聊天输入下方的"+"按钮，然后选择"研究"。

- **文件：**Claude 创建的文件与对话一起显示。在 Claude Desktop 中，Cowork 保存其工作的文件夹仍然存在。在**设置**中查找**存储文件夹**。您授予 Cowork 访问权限的文件夹列在**受信任的文件夹**下。

- **来自本地任务的记忆：**来自仅在您计算机上运行的 Cowork 任务的记忆会随这些任务一起保留。

## 当前限制

- **从 GitHub 添加**不受支持。

- **从较早的点分支对话**不可用。

- **隐身聊天**仍然有效，但它们在以前的体验中打开，因此 Claude 无法在其中创建文件或运行代码。

- **搜索**不包括较旧的 Cowork 任务。它涵盖您的聊天和新对话，您仍然可以在**[最近](https://claude.ai/chats)**中按名称查找较旧的任务。

- **调度**对新用户不可用。如果您已经使用调度，您现在可以继续使用它。在**[从 Claude Cowork 中的任何地方分配任务](https://support.claude.com/en/articles/13947068)**中了解更多信息。

## 使用如何工作

您使用 Claude 所做的一切都计入您的计划的使用限制。搜索网络、运行代码或创建文件的较长代理任务通常比快速问题使用更多。在新体验推出期间，对于拥有它的账户和没有它的账户，使用情况的测量方式可能略有不同。在**[设置 > 使用](https://claude.ai/settings/usage)**中检查您当前的使用情况，并在**[使用限制最佳实践](https://support.claude.com/en/articles/9797557)**中了解更多信息。

## 开始

打开 Claude 并描述您需要什么，就像您向同事简报一样。当您包括以下内容时，您会获得更好的结果：

- **您想要的结果：**您想要最终得到什么，例如"一页摘要"或"一个电子表格，每个地区有一个选项卡"。

- **格式：**您希望如何交付结果，例如 Word 文档、幻灯片演示或可以粘贴到 Slack 中的消息。

- **Claude 需要的输入：**Claude 应该使用的文件、链接或应用。

不确定从哪里开始？询问 Claude 它可以帮助什么。
