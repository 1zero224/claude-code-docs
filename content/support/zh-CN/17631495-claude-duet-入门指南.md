# Claude Duet 入门指南

**[Claude Duet](https://claude.com/product/claude-duet)** 是 Claude 的研究预览版，你可以像给人发消息一样与它交互。告诉它你需要什么（文字或语音），它会在你连接的应用中工作，在需要你时通知你，并且在发送消息、进行支付、签署文件或删除任何内容之前会先征求你的同意。本文介绍了 Claude Duet 的功能、谁可以获得访问权限、如何加入等待列表，以及它目前还不能做什么。

Claude Duet 作为研究预览版向美国 Pro、Max 和 Ultra 计划的用户提供，通过等待列表获取。它使用你的 Claude 账户设置和你的计划使用限制。目前在 Team 或 Enterprise 计划上不可用，我们计划稍后将其引入这些计划。访问权限分阶段开放，功能在研究预览期间可能会变化。

## 谁可以获得访问权限

要使用 Claude Duet，你需要：

- Pro、Max 或 Ultra 计划

- 美国的 Claude 账户

- 来自等待列表或 Claude Duet 用户的邀请

## 你可能还没有访问权限的原因

- 邀请分阶段发送，所以加入等待列表不能保证具体日期。

- 在研究预览期间，Claude Duet 仅在美国可用。

- Claude Duet 目前在 Team 或 Enterprise 计划上不可用。

- 你在等待列表上使用的电子邮件地址与你的 Claude 账户或手机上的 Google 或 Apple 账户不匹配。访问权限与你提供给我们的电子邮件地址相关联。

## Claude Duet 如何工作

Claude Duet 在你的 Claude 账户上运行，所以你在 Claude 中设置的记忆、技能和连接器从第一条消息开始就已经存在。它在云中的自己的计算机上运行，所以即使你关闭应用后它也能继续工作。

- **像给人发消息一样与它交互。**输入消息或录制语音消息。你的主线程保持在一个地方，所以 Claude Duet 会从你上次停止的地方继续。你也可以为不同的主题开始单独的频道，它们共享相同的记忆。

- **用简报开始新的一天。**每天早上，它会查看你的电子邮件和日历，选出最需要你关注的内容，并可以开始第一步，比如为你起草回复供审阅。在一天中，它会发送关于它正在进行的工作的更新，并跟进已经沉寂的线程。

- **交给它更大的任务。**描述你需要什么，它会确定使用哪些应用以及任务需要多少工作量。更大的结果会以文件形式返回供你审阅和编辑，例如研究简报、财务模型、幻灯片或仪表板。完成的工作会出现在**制作**标签中。

- **添加插件。**Claude Duet 支持插件，例如小企业插件，并可以建议适合你工作的插件。

- **使用没有连接器的网站。**对于没有连接器的网站，Claude Duet 使用其自己的云浏览器。

### 示例请求

- "清除我收件箱中任何我不需要阅读的内容。"

- "检查 Stripe 中的未支付发票，并为我起草提醒电子邮件以供批准。"

- "在我下午 2 点的会议前汇总关于这家公司的简报。"

### 跟踪任务

**任务**标签显示 Claude Duet 正在处理的内容，并突出显示需要你输入的任务。你的主线程保持更安静：Claude Duet 在任务完成或需要你做出决定时在那里发布。它可能会建议任务看起来已完成，但只有你可以将任务标记为已完成。

## 加入等待列表并获取应用

1. 转到**[Claude Duet 产品页面](https://claude.com/product/claude-duet)**并选择

2. 输入你的名字和电子邮件地址。如果你已经使用 Claude，请输入你的 Claude 账户上的电子邮件地址。

3. 选择你的 Claude 计划和你的手机类型（iPhone 或 Android）。你也可以告诉我们你做什么以及你想首先交给 Claude Duet 什么。

4. 选择"提交"。我们会逐步添加人员，当轮到你时你会收到一封电子邮件。

5. 当轮到你时，在你的手机上打开邀请电子邮件，并按照 iPhone 或 Android 的设置步骤进行操作。使用与你提供给我们的电子邮件地址相关联的 Apple 或 Google 账户，因为访问权限与该地址相关联。

6. 打开 Claude Duet 并使用你的 Claude 账户登录。接受邀请后，应用可能需要几分钟才能可用。

## 连接你的应用

Claude Duet 可以使用你已在 Claude 中连接的应用。你可以在 Claude 设置中管理访问权限。它适用于你在 Claude 中连接的连接器，例如 Gmail、Google Calendar、Google Drive、Slack、QuickBooks、HubSpot、Docusign 和 Calendly。你自己启动每个连接，并且可以随时断开任何应用。断开应用会阻止 Claude Duet 从该点开始访问它，但会保留来自早期对话的过去信息的记忆。

了解更多关于**[使用连接器](https://support.claude.com/en/articles/11176164)**的信息。

### 合作伙伴集成

Claude Duet 也适用于一些合作伙伴服务：

- **Stripe：**检查你的 Stripe 账户中的未支付发票，并为你起草提醒电子邮件以供批准。这使用 Stripe 连接器，与 Link 分开。

- **Link：**使用 Link（Stripe 的数字钱包）支付你批准的购买。了解更多关于**[如何在 Claude Duet 中使用 Link by Stripe](https://support.claude.com/en/articles/17666484)**的信息。

- **Shop Pay：**使用 Shop Pay（Shopify 的钱包）支付你批准的购买。了解更多关于**[如何在 Claude Duet 中使用 Shop Pay](https://support.claude.com/en/articles/17666489)**的信息。

Claude Duet 被设计为在每次购买前询问，每次购买都使用一张一次性卡，仅适用于该购买。Link 和 Shop Pay 目前仅在 Claude Duet 中可用，你在 Claude Duet 中连接它们，而不是在连接器目录中。

### 搜索你的过去聊天

Claude Duet 可以搜索你的过去聊天以从早期工作中获取上下文，所以你不必重复自己。它搜索你的 Claude Duet 聊天和你在项目外的 Claude 中的聊天。当你删除聊天时，它会从搜索中删除。

这使用与 Claude 相同的**[搜索和参考聊天](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context#h_a11816bb20)**设置。要阻止 Claude Duet 搜索你的过去聊天，请在**设置 > 你的 Claude**（或旧设置布局中的**设置 > 记忆**）中关闭**搜索和参考聊天**。

## 限制

在研究预览期间，请记住这些限制：

- 你不能选择模型。Claude Duet 在 Claude Opus 5.5 上运行，并决定任务需要多少工作量。

- 你不能观看 Claude Duet 在其浏览器中的工作或接管浏览器。

- 它按设定的时间间隔检查你的账户，所以紧急的事情可能在检查之间到达。

- 它看不到你的所有项目或计算机上的文件，它可以读取你在 Claude 中的工作但不能更改它。

- 它不会给其他人打电话或发送短信。经过你的批准，它可以从你连接的账户发送电子邮件。

- 即使经过你的批准，某些操作也是禁止的，例如交易证券、在账户之间转移资金或访问他人的账户。

- 某些连接器（例如 Slack）在 Claude Duet 中有限制。Microsoft 365 目前不可用。

- 个人财务在 Claude Duet 中不可用。

Claude Duet 也可能犯错误，例如误读线程或误判什么是紧急的。在确认草稿和批准请求之前先审阅它们。

## 定价和使用限制

**定价。**在研究预览期间，Claude Duet 包含在 Pro、Max 和 Ultra 计划中，无需额外费用。

**使用限制。**Claude Duet 使用你的计划的使用限制，包括任何五小时会话限制和你的每周限制，与 Claude 中的聊天速率相同。它在后台进行的工作，如早晨简报和检查，也计入其中，所以你可能比仅聊天更快达到限制。了解更多关于**[使用限制](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work#h_673be3815f)**的信息。

**限制重置。**在研究预览期间，我们向你的账户添加完整的限制重置，以便你有空间尝试 Claude Duet。每个重置都会在你在网络上的**[设置 > 使用](https://claude.ai/settings/usage)**或 Claude Desktop 中选择使用时重新填充你的五小时会话和每周限制。你获得的数量取决于你的计划：

- Pro：三次限制重置

- Max 和 Ultra：一次限制重置

未使用的限制重置将在 2026 年 12 月 15 日过期。了解更多关于**[限制重置](https://support.claude.com/en/articles/17007452-what-is-a-limit-reset)**的信息。

## 隐私、安全和控制

Claude Duet 被设计为在发送消息、进行支付、签署文件或删除任何内容之前向你显示它将要做什么并等待你的批准。如果你不能立即批准，Claude Duet 会完成任务的其余部分，并稍后将批准带回给你。当它给你一个数字或摘要时，它会告诉你它来自哪封电子邮件、文件或电子表格。

Claude Duet 读取其他人写的内容，例如电子邮件和网页，该内容可能包含旨在误导它的指令。这称为*提示注入*。Claude Duet 被构建为将其读取的内容视为信息，并根据你的要求行动，但没有完美的防御，这是为什么需要你批准的后果行动的原因之一。

在其浏览器中，Claude Duet 旨在遵循网站为代理设置的规则。当网站要求输入密码时，你将其输入到你设备上的单独表单中。该表单将其直接发送到浏览器，该浏览器旨在将其保留在你与 Claude Duet 的聊天之外。
