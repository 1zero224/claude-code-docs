# Claude Cowork 入门指南

本文介绍如何使用 **[Claude Cowork](https://claude.com/product/cowork)**，它将 Claude Code 的智能体功能扩展到编码之外的知识工作领域。

## 可用性

Claude Cowork 在付费计划上可用（Pro、Max、Ultra、Team 和 Enterprise）：

- **Claude Desktop for macOS、Windows 和 Linux（测试版）**：  在所有付费计划上可用。在 **[claude.com/download](https://claude.com/download)** 下载或更新。

- **Web 和 Claude Mobile：**Pro、Max、Ultra 和 Team 计划（Team 上处于测试版），以及 Enterprise 计划（当所有者启用时）。

- **Chrome 侧边栏中的 Claude：**所有付费计划。在 Enterprise 计划上，所有者需要启用 Chrome 中的 Claude 和云中的 Cowork。有关更多信息，请参阅 **[Chrome 中的 Claude 入门](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome)**。

新的 Claude 体验结合了聊天和 Cowork，正在向 Pro、Max 和 Ultra 计划推出。在 Team 计划（测试版）和 Enterprise 计划上，当启用 **聊天和 Cowork 统一** 时可用。如果您的消息框不再显示 “聊天” 和 “Cowork” 选项，说明您已拥有新体验，本文中的某些步骤可能看起来不同。在 **[Claude Cowork 和聊天合为一体](https://support.claude.com/en/articles/16761823)** 中了解更多信息。

在桌面、Web 和移动设备上，聊天和 Cowork 共享一个主页，因此您可以从同一位置启动两者。找到消息框并选择 “Cowork，” 然后描述您的任务。要返回常规对话，请选择 “聊天。” 在 Chrome 侧边栏中，打开侧边栏会直接启动 Cowork 会话。

## 什么是 Claude Cowork？

Claude Cowork 使用与 Claude Code 相同的智能体架构，无需终端。Claude 不是一次响应一个提示，而是可以承担复杂的多步骤任务并代表您执行。

使用 Cowork，您可以描述一个结果，然后离开，之后回来查看完成的工作——格式化的文档、组织的文件、综合的研究等。Cowork 在云中远程运行您的会话，因此您的会话和文件与您的 Claude 账户一起保存，并跟随您在桌面、Web 和移动设备之间移动。聊天和 Cowork 现在共享一个主页，因此将任务交给 Claude 与进行对话从同一消息框开始。通过计划任务，Claude 可以自动为您完成工作。通过项目，您可以将相关任务组织到具有自己的文件、链接、说明和记忆的持久工作区中。

**重要提示：**

- 由于 Cowork 的智能体性质和互联网访问，它具有独特的风险。

- Cowork 遵守您当前的网络出口权限。

  - **重要提示：**网络出口权限不适用于网页获取或 **[网页搜索](https://support.claude.com/en/articles/10684626-enabling-and-using-web-search)** 工具或 MCP，包括 Chrome 中的 Claude。网页获取在服务器端运行，仅限于搜索结果和您共享的 URL。

  - Team 或 Enterprise 计划所有者可以在 **[组织设置 > 功能](https://claude.ai/admin-settings/capabilities)** 中为 Cowork 和聊天关闭网页搜索，或通过 **[组织设置 > Chrome 中的 Claude](https://claude.ai/admin-settings/browser-extension)** 为 Chrome 中的 Claude 关闭。

- 您可以控制您的 Cowork 任务，并可以随时使用 “删除” 选项删除任务（单击任务旁的 “⋮”，或从您的任务列表中选择任务并单击垃圾箱图标）。您的 Cowork 任务将立即从您的任务历史记录中删除，并根据我们的 **[数据保留期](https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data)** 在 30 天内从我们的后端存储系统中删除。

- 有关更多信息，请查看 **[安全使用 Cowork](https://support.claude.com/en/articles/13364135-using-cowork-safely)**。

有关 Team 和 Enterprise 组织使用 Cowork 的重要限制和注意事项，请参阅 **[Team 和 Enterprise 计划的 Cowork](https://support.claude.com/en/articles/13455879-cowork-for-team-and-enterprise-plans)**。

### 主要功能

- **随处工作：**云中的会话跟随您的 Claude 账户。在一个平台上启动任务，从另一个平台上控制它，并在任何地方获取完成的输出。请参阅 **[在 Web、桌面和移动设备上使用 Claude Cowork](https://support.claude.com/en/articles/15520349)**。

- **无需您参与的持续工作：**在云中的会话中，当您关闭笔记本电脑或离开时，Claude 会继续工作。

- **与聊天共享的记忆：**在云中的会话中，Claude 从它已经从您的聊天中记住的内容开始，Cowork 任务中出现的内容会回到聊天中。要运行单个任务而不使用记忆，请在发送第一条消息之前在 “+” 菜单中关闭 “记忆”。这在任务启动时设置，之后无法更改。了解更多关于 **[Claude 的记忆](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context#h_82126ebcc9)**。

- **直接本地文件访问：**在桌面上，Claude 可以读取和写入您的本地文件，无需手动上传或下载。

- **子智能体协调：**Claude 将复杂工作分解为较小的任务，并协调并行工作流来完成它们。

- **专业输出：**生成精美的可交付成果，如具有工作公式的 Excel 电子表格、PowerPoint 演示文稿和格式化文档。

- **就地编辑草稿：**当 Claude 起草 Markdown 文档时，突出显示您想要更改的文本，单击 “使用 Claude 编辑，” 并输入您的请求。Claude 在您标记的位置进行编辑，无需在任务线程中描述该部分。

- **长期运行的任务：**在长时间内处理复杂任务，不会因对话超时或上下文限制而中断您的进度。

- **计划任务：**创建并保存任务，您可以让 Claude 按需运行或按您选择的频率自动运行。计划任务在云中运行，无需设备在线。

- **电子表格和演示文稿：**Cowork 可以生成电子表格和幻灯片，可以使用 Claude for Excel 和 PowerPoint 进一步编辑。

- **项目：**将相关任务分组到具有自己的文件、上下文、说明和记忆的工作区中。请参阅 **[在 Cowork 中使用项目组织您的任务](https://support.claude.com/en/articles/14116274-organize-your-tasks-with-projects-in-cowork)**。

- **浏览器操作：**对于涉及网站的任务，Claude 可以打开网站、阅读页面、点击、输入和填充表单。在桌面上，Claude 默认使用内置于 Claude Desktop 应用中的浏览器，无需安装任何内容。如果您已经使用 Claude in Chrome，Claude 会在您自己的浏览器中工作，您可以随时在 **[设置 > Cowork](https://claude.ai/settings/cowork)** 中更改您的首选浏览器。您也可以直接在 Chrome 侧边栏中运行 Cowork 会话。在 **[在 Claude Cowork 中使用内置浏览器](https://support.claude.com/en/articles/16607400)** 和 **[Chrome 中的 Claude 入门](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome)** 中了解更多信息。

## Claude Cowork 如何运行您的任务

Cowork 在云中运行您的任务。Claude 的工作在 Anthropic 的服务器上以隔离环境运行，您的会话和文件保存到您的 Claude 账户。当您关闭笔记本电脑时工作会继续，您可以从任何平台打开同一会话。

当任务需要您计算机上的内容（如本地文件或您的浏览器）时，Claude 通过该计算机上的 Claude Desktop 应用访问它。当您在 Cowork 中启动任务时，Claude：

1. 分析您的请求并创建计划。

2. 在需要时将复杂工作分解为子任务。

3. 在 Anthropic 服务器上的隔离环境中运行代码和 shell 命令。

4. 在适当时并行协调多个工作流。

5. 将完成的输出交付到您的会话，您可以在其中预览和下载它们。

您在整个过程中保持对 Claude 正在规划和执行的操作的可见性，因此您可以在重要时进行控制，或让 Claude 独立运行。

## 入门

### 要求

- **付费 Claude 订阅：**Cowork 仅适用于付费 Claude 计划（Pro、Max、Ultra、Team、Enterprise）。

- **对于本地文件访问、浏览器使用和计算机使用：**macOS 或 Windows 的 **[Claude Desktop 应用](https://support.claude.com/en/articles/10065433-installing-claude-desktop)**，已打开并连接。这些功能访问您计算机上的内容，因此即使您的会话在云中运行，它们也需要该应用。

- **活跃的互联网连接：**在整个会话期间需要。

## 启动 Cowork 会话

**注意：**如果您的消息框不显示 “聊天” 和 “Cowork” 选项，说明您拥有新的 Claude 体验。跳过第 2 步，因为每个对话都可以承担 Cowork 任务。

聊天和 Cowork 共享一个主页。要在任何平台上启动会话：

1. 在 claude.ai、Claude 桌面应用或 Claude 移动应用中打开 Claude。

2. 在消息框中，选择“协作。”

3. 描述您希望 Claude 完成的任务。

4. 查看 Claude 的方法，然后让它运行。

**注意：**即使桌面应用关闭或计算机处于睡眠状态，会话也会继续运行。如果您的任务使用本地文件、浏览器或计算机，请保持桌面应用打开，以便 Claude 可以访问它们。

## 任务期间的预期情况

当 Claude 在协作中处理任务时：

- **进度指示器**显示 Claude 在每一步所做的工作。

- **透明度：**Claude 展示其推理和方法，以便您可以跟进。

- **引导：**您可以随时介入以纠正方向或在任务中途提供额外指导。

- **随处检查：**在另一个设备上打开同一会话以监控进度、回答 Claude 的问题或重定向工作。

- **并行工作：**对于复杂任务，Claude 可能会协调多个子代理同时工作。

- **删除保护：**使用协作时，Claude 需要您的明确许可才能永久删除任何文件。您将看到权限提示，需要选择“允许”才能让 Claude 执行删除任务。

任务可以根据复杂性运行较长时间。您可以监控进度或离开，在 Claude 完成时返回。

## 选择 Claude 如何与您联系

协作有三种模式，用于控制 Claude 在采取行动（如使用您的连接器）前何时请求您的许可。您可以随时从聊天框中的模式选择器更改模式。

**注意：**如果您使用新的 Claude 体验，消息框中的权限设置提供**自动**（在 Pro、Max、Ultra 和 Team 计划中作为默认推出）和**手动**（Enterprise 计划的默认设置，Chrome 中的协作侧面板除外）。如果您之前在浏览器或应用中选择了手动，该处的新对话将继续以手动开始。如果您尚未选择模式，新对话将以默认模式开始。

| ---------- | ------------------------------------------------------------------- | --------------------------- | ------------------ | ----------------- |
| **“手动”模式** | 已批准                                                                 | 请求权限                        | 请求权限               | 已拒绝               |
| **“自动”模式** | 无需询问您即可运行，无需自动检查。例外是连接器标记为破坏性的工具，例如删除数据的工具：该工具仍会被检查，或 Claude 会先询问您。 | 无需询问您即可运行，除非自动检查将该操作标记为有风险。 | 请求权限（**见下文**）      | 已拒绝               |

在自动模式中，自动检查会在操作运行前进行审查，除了表中注明的情况。它可能会遗漏有风险的操作。要自己批准每个“需要批准”的操作，请使用手动。提醒一下，您可以通过聊天框中的“+”菜单或**[自定义 > 连接器](https://claude.ai/customize/connectors)**页面控制 Claude 可以使用哪些连接器。

**注意：**在 Team 和 Enterprise 计划中，您的管理员控制“自动批准”是否可供您的组织使用，以及新任务是否以此开始。如果您的管理员关闭它，该模式不会出现在您的模式选择器中。您的组织也可能需要对具有写入功能的连接器工具进行按任务批准，因此“始终允许”偏好设置可能不适用。请参阅**[在 Team 和 Enterprise 计划中使用 Claude 协作](https://support.claude.com/en/articles/13455879-use-claude-cowork-on-team-and-enterprise-plans#h_1bd1fa754d)**。

**手动批准（手动）**，以前称为“采取行动前询问。”Claude 暂停并请求批准操作。您审查每个请求并选择允许或拒绝。

**自动批准（自动）。**Claude 继续工作，无需停下来询问每一步。相反，Claude 审查每个操作的安全性（例如检查数据外泄或**[提示注入](https://support.claude.com/en/articles/13364135-use-claude-cowork-safely)**），并自动阻止它认为不安全的任何内容。您设置为“始终允许”的连接器工具是例外：请参阅上表。当操作被阻止时，Claude 会寻找更安全的方式来完成任务或暂停并直接询问您。如果 Claude 不断遇到阻止，它会切换回为每一步请求您的权限。当 Claude 使用浏览器或您的计算机时，审查其操作的自动检查可以看到最新的屏幕截图，Anthropic 可以在其检查记录中保留该屏幕截图的副本。

在将自动模式设为 Claude Code 中的默认值之前，我们在内部和第三方红队测试中进行了测试。我们使用这些发现来加强自动模式在所有产品中的工作方式。它为您提供让 Claude 无中断工作的速度，同时具有“跳过所有批准”没有的保护层：操作在发生前会被审查，除了您设置为“始终允许”的连接器工具。*当然，没有防御是完美的，没有模式可以替代您的判断。对于有真实后果的工作——金钱、以您的名义发送的消息、重要文件——请保持密切关注并审查 Claude 所做的工作，或考虑切换回“手动批准。”*

自动模式适用于您所有现有的连接器、插件、内置浏览器、Chrome 中的 Claude 和一些协作操作（如获取网站）。

**跳过所有批准（跳过）**，以前称为“无需询问即可操作。”Claude 不会暂停询问，也不会自动检查其操作。例外是您设置为“始终询问”的连接器工具。Claude 的设计是在每次使用该工具前询问，即使在跳过中也是如此。计划任务可能会在没有它的情况下完成。仅当您完全信任任务中涉及的每个操作、连接器、文件、应用等时，才使用“跳过”。

### 让 Claude 始终在使用连接器工具前询问

“始终询问”正在 Pro、Max、Ultra、Team 和 Enterprise 计划中逐步推出。在 Team 和 Enterprise 计划中，您的组织设置优先，因此您可能看不到此选项。

要自己批准特定的连接器工具（例如发送电子邮件的工具），请将其设置为“始终询问。”Claude 的设计是在每次使用该工具前询问，在聊天和协作中，在每种模式中都是如此。它在 Dispatch 或研究中尚未完全支持。

1. 在网络或 Claude 桌面上，导航到**[自定义 > 连接器](https://claude.ai/customize/connectors)**。

2. 选择连接器。

3. 选择**权限**选项卡以查看**工具权限**。

4. 在工具的行上，选择“始终询问。”

Claude 会暂停，直到您选择“仅允许一次”或拒绝。您的选择会替代自动模式对此工具的自动检查，因此请在允许前审查每个请求。如果您为该工具或其组选择“始终允许”（包括在聊天或手机上），它会覆盖此设置。

“始终询问”仅适用于您选择的工具。Claude 可能能够通过不同的工具（在此连接器或其他连接器中）获取相同信息，而无需询问您。如果其他工具可以访问该信息，如果它们有此选项，也请将其设置为“始终询问”。

计划任务可能会等待您的答复或在不使用该工具的情况下完成。要让一个任务在不询问的情况下使用该工具，请在网页或 Claude Desktop 的左侧边栏中点击“已计划”，然后打开该任务并编辑它。将其批准模式设置为手动，当 Claude 询问时选择“对所有计划运行允许”。

## Claude Cowork 插件

插件自定义 Claude 如何为您的角色、团队和公司工作。每个插件将技能、连接器和子代理捆绑到单个包中。您添加的插件会保存到您的账户，因此它在聊天和 Claude Code 以及 Cowork 中都可以使用。有关查找、添加和自定义插件的详细信息，请参阅**[在 Claude 中使用插件](https://support.claude.com/en/articles/13837440-use-plugins-in-cowork)**。

## 计划定期任务

您可以设置 Claude 自动或按需运行的任务。要计划任务，请在任何 Cowork 任务中输入 `/schedule`。您也可以点击左侧边栏中的“已计划”来查看、创建和管理您的计划任务。

计划任务在云中运行，因此不需要您的计算机处于唤醒状态或桌面应用打开。

有关更多深入详情，请参阅**[在 Cowork 中计划定期任务](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-cowork)**。

---

## 使用限制

多步骤任务（如运行代码、创建文件或使用您连接的应用和浏览器的任务）比快速提问使用更多的使用配额。Claude 采取的每一步都会使用令牌。

如果您经常达到使用限制，请尝试：

- 将相关工作分组到一个任务中，而不是多个任务。

- 为不相关的工作开始新对话，这样 Claude 就不会携带额外的上下文。

- 告诉 Claude 您只需要快速答复，而不是文件或完成的可交付成果。

- 在**[设置 > 使用情况](https://claude.ai/settings/usage)**中检查您的使用情况。

有关更多信息，请参阅**[使用限制最佳实践](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)**。

## 权限和安全

Cowork 采用分层保护运行：

- **会话隔离：**Claude 的工作在 Anthropic 服务器上的隔离环境中运行，与您的计算机和网络分离。Claude 编写的 Shell 命令和代码在该环境内运行。隔离保护您的计算机；它不会改变 Claude 通过您授予的访问权限可以读取或执行的操作。

- **受控文件和网络访问：**Claude 只能读取和写入您连接的文件夹中的文件，网络访问遵循您配置的出站设置。

**重要：**Claude 可以访问您授予其权限访问的本地文件，并可以代表您采取真实操作。在允许 Claude 继续之前，请审查其计划的操作，特别是在处理敏感文件时。

权限的工作方式与聊天相同。您可以控制：

1. 您**[连接到 Claude 的 MCP](https://claude.ai/settings/connectors)**以及它们要求权限的频率。在自动模式下，设置为“需要批准”的工具可以在不询问您的情况下运行。请参阅**[选择 Claude 如何与您联系](#h_c274f6c9b5)**。

2. **[Claude 的互联网访问](https://claude.ai/settings/capabilities)**

在扩展对 MCP 或网站的访问权限超过 Claude 的默认设置之前，请仔细评估您对其的信任程度。

## 示例用例

Cowork 专为受益于文件访问和扩展执行时间的复杂多步骤工作而设计。以下是一些示例：

### 文件和文档管理

- **组织文件：**“按类型和日期组织我的下载文件夹” — Claude 可以将数百个文件分类到分类文件夹中。

- **处理收据：**将收据放在文件夹中，并要求 Claude 创建格式化的费用报告。

- **批量重命名：**使用一致的模式（如 YYYY-MM-DD 格式）重命名文件。

### 研究和分析

- **研究综合：**将网络搜索、文章、论文和笔记中的信息合并为连贯的报告或摘要。

- **成绩单分析：**从会议记录、访谈或讲座录音中提取主题、要点和行动项。

- **个人知识综合：**分析您的笔记、日志或研究文件，以发现您可能遗漏的模式、主题和联系。

### 文档创建

- **带公式的电子表格：**生成具有有效 VLOOKUP、条件格式和多个选项卡的 Excel 文件，而不仅仅是需要修复的 CSV。

- **演示文稿：**从粗略笔记或会议记录创建幻灯片。

- **来自混乱输入的报告：**将语音备忘录和零散笔记转换为精美文档。

### 数据和分析

- **统计分析：**对数据文件进行异常值检测、交叉制表和时间序列分析。

- **数据可视化：**使用您的数据生成图表。

- **数据转换：**清理、转换和处理数据集。

如需更详细的示例，请参阅我们的**[用例](https://claude.com/resources/use-cases)**并按“Cowork”类别筛选。

## 当前限制

某些 Cowork 功能尚不可用：

- **不支持会话共享：**会话无法与他人共享，但您可以共享在会话期间创建的单个工件。详细了解**[在 Claude Cowork 中使用工件](https://support.claude.com/en/articles/14729249)**。

- **某些功能仅限桌面版：**2026 年 8 月 19 日之前创建的实时工件和包含本地 MCP 服务器的插件仅可通过桌面应用使用。

我们根据反馈不断改进 Cowork。如果您使用免费版、专业版、最大版或超级版计划，请使用应用中的反馈按钮分享反馈。如果您使用团队版或企业版计划，应用中不会显示反馈按钮，请联系您的组织管理员或 Anthropic 联系人提出建议。

## 故障排除

### 启动 Cowork 时看到“正在设置 Claude 的工作区”是什么意思？

此消息是正常的，表示 Cowork 正在更新到最新版本以应用任何修复和改进。

### Claude 停止处理我的任务

对于本地会话（在专业版、最大版和超级版计划上，**[您在 10 月 6 日之前在计算机上启动的任务](https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile#h_f951c27c48)**），请确保在整个任务期间 Claude 桌面应用保持打开状态。如果应用被关闭或计算机进入睡眠状态，会话可能已结束。云中的会话会在后台继续运行；从任何界面打开会话以检查其进度。

### 我的使用配额消耗得很快

多步骤任务比快速提问消耗更多的使用配额。将相关工作分组到一个任务中，为不相关的工作开始新对话，并在**[设置 > 使用情况](https://claude.ai/settings/usage)**中检查您的使用情况。详细了解**[使用配额最佳实践](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)**。

### 文件未出现在预期位置

检查您是否已授予 Claude 适当的文件访问权限。查看 Claude 完成任务时指定的输出位置。
