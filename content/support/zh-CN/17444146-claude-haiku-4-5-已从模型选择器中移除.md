# Claude Haiku 4.5 已从模型选择器中移除

2026年10月29日，我们从免费、专业和最大计划中的聊天、Claude Cowork 和 Claude Design 的模型选择器中移除了 Claude Haiku 4.5，包括在 Claude Desktop 和 Claude Mobile 中。Claude Haiku 5.5 取代了它。本文解释了发生了什么变化、Haiku 4.5 仍然可用的位置，以及您现有聊天发生了什么。

## 发生了什么变化以及何时发生

我们在2026年10月15日宣布了这一变化。从2026年10月29日起，您无法再在模型选择器中的"更多模型"下选择 Haiku 4.5。如果它是您选定的模型，Claude 会将您切换到 Haiku 5.5。

## Haiku 4.5 仍然可用的位置

此更改不影响以下位置的 Haiku 4.5：

- Claude Code

- 团队和企业计划

- Claude Platform (API)

## 您现有的聊天发生了什么

您的 Haiku 4.5 聊天仍在您的账户中，没有任何内容被删除。当您在10月29日之后继续进行聊天时，Claude 会使用 Haiku 5.5 进行响应。您可以随时切换到其他模型。

要保留聊天副本，您可以随时导出数据。了解更多关于 **[导出您的 Claude 数据](https://support.claude.com/en/articles/9450526)**。

## 在聊天中切换模型

您可以在聊天中的任何时刻更改模型。更改从 Claude 的下一个响应开始生效。

1. 点击发送按钮旁边的模型名称。

2. 选择一个模型，或点击"更多模型"查看其他选项。

了解更多关于 **[更改模型、工作量和思考设置](https://support.claude.com/en/articles/8664678)**。
