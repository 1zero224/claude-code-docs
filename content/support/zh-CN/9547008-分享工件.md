# 分享工件

本文介绍如何分享工件、谁可以打开工件，以及他们打开时会看到什么。涵盖所有计划和创建工件的各个位置：在聊天中、从模板以及在 Claude Code 中。

工件默认仅对您私密。在您分享之前，不会共享任何内容。

| **分享选项**          | **免费版** | **专业版** | **最大版** | **超级版** | **团队版** | **企业版** |
| ----------------- | ------- | ------- | ------- | ------- | ------- | ------- |
| 与拥有链接的任何人分享       |         | ✅       | ✅       | ✅       | ✅       | ✅       |
| 与您组织中的所有人或特定人员分享  |         |         |         |         | ✅       | ✅       |
| 与群组分享             |         |         |         |         |         | ✅       |
| 通过电子邮件邀请特定人员（测试版） |         | ✅       | ✅       | ✅       | ✅       | ✅       |
| 发布旧版工件（在聊天中创建）    | ✅       | ✅       | ✅       | ✅       |         |         |
| 使用"分享并复制链接"分享旧版工件 |         |         |         |         | ✅       | ✅       |

在团队版和企业版计划中，工件默认保留在您的组织内。所有者决定用户是否可以在组织外分享。在**[团队版和企业版计划的工件管理员指南](https://support.claude.com/en/articles/16994751-artifacts-admin-guide-for-team-and-enterprise-plans#h_fd0c095985)**中了解更多信息。

**注意：**实时工件是 2026 年 8 月 19 日之前在 Cowork 中创建的工件，具有自己的分享规则。详细了解**[在 Claude Cowork 中使用实时工件](https://support.claude.com/en/articles/14729249)**。

旧版工件显示"发布"或"分享并复制链接"而不是"分享"。要分享这些工件，请参阅**[发布或分享旧版工件](#h_a5750b9176)**。

## 分享工件

1. 打开工件并点击"分享"。

2. 在团队版和企业版计划中，添加您组织中的人员，并为每个人选择访问级别。企业版计划还可以添加群组。

3. 在**谁有权访问**下，选择谁还可以打开工件。

4. 复制链接并发送。

**注意：**您无法在 Claude for iOS 或 Claude for Android 中更改分享设置。请使用 Claude 网页版或 Claude Desktop。

### 选择谁有权访问

- **专业版、最大版和超级版计划：**"仅限您"或"拥有链接的任何人"。要给予特定人员访问权限，请通过电子邮件邀请他们。

- **团队版和企业版计划：**"仅限受邀人员"、"您组织中的任何人"或"拥有链接的任何人"。当您未添加任何人时，显示"仅限您"。"拥有链接的任何人"仅在所有者启用**外部分享**或单独允许该工件时可用。如果显示为灰色，请咨询所有者或主要所有者。

### 选择访问级别

| **访问权限** | **人员可以执行的操作**                      |
| -------- | ---------------------------------- |
| **可以查看** | 打开工件并阅读其评论。                        |
| **评论者**  | **可以查看**中的所有内容，加上添加评论和下载工件提供的任何文件。 |
| **可以编辑** | **评论者**中的所有内容，加上进行更改。              |

## 通过电子邮件邀请人员

在 Pro、Max、Ultra、Team 和 Enterprise 计划中以测试版形式提供。

您可以通过电子邮件邀请特定人员访问工件。他们使用您提供的电子邮件地址登录 Claude，并使用您给予的访问权限打开工件。与"任何拥有链接的人"不同，邀请仅对您邀请的人有效。

### 邀请前

- **谁可以邀请：**工件的所有者。在 Team 和 Enterprise 计划中，组织中可以编辑工件的任何人也可以邀请人员。当其他人发送邀请时，所有者会收到电子邮件。

- **Team 和 Enterprise 计划：****组织外的电子邮件邀请**需要在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中启用。在 Team 计划中默认启用，在 Enterprise 计划中默认关闭。如果您看不到此选项，请咨询所有者或主要所有者。

- **被邀请者需要具有 Claude 账户**，其电子邮件地址为您邀请的地址。如果他们没有账户，需要使用该地址创建一个才能打开工件。Claude 不会告诉您他们是否拥有账户。

- **某些工件无法以这种方式共享。**"共享"菜单会告诉您何时适用：

  - 连接到其他网站的工件

  - 包含仍在检查或未通过检查的上传文件的工件

### 发送邀请

1. 打开工件并点击"共享"。

2. 在**共享**菜单顶部的字段中（**添加人员**，或在 Pro、Max 和 Ultra 计划中**通过电子邮件邀请人员**），输入该人的电子邮件地址。

3. 选择显示其地址的**邀请**选项。

4. 在**其访问权限**下，选择"可以查看"、"评论者"或"可以编辑"。

5. 点击"邀请"。

在 Team 和 Enterprise 计划中，如果您输入组织中某人的地址，他们会直接添加到工件中，而不是收到邀请。

### 您邀请的人可以做什么

您从组织外邀请的人无法邀请他人或更改共享设置。使用 Claude 或您的连接器的工件部分对他们不起作用。具有"可以编辑"访问权限的人无法删除工件，只能上传图像和视频。

您邀请的具有"评论者"或"可以编辑"访问权限的人可以评论，但他们无法在评论中提及人员或询问 Claude，也不会收到有关评论的电子邮件通知。他们无法对也与"任何拥有链接的人"共享的工件进行评论。

如果工件也与"任何拥有链接的人"共享，您邀请的人将拥有与任何拥有链接的人相同的访问权限，无论您给予他们什么级别。

### 管理您邀请的人员

在工件的**共享**菜单中，您邀请的人会显示在**从组织外邀请**下，待处理邀请会显示其过期时间。从那里，您可以更改某人的访问权限或将其删除。删除某人会立即取消其访问权限。

如果某人因为还没有 Claude 账户而没有收到邀请电子邮件，请要求他们使用该地址创建一个。然后删除邀请并重新邀请他们。

### 访问权限更改时

- **待处理邀请在 30 天后过期。**已接受的邀请不会过期。

- **如果您将谁可以打开工件更改为"仅限您"：**在 Team 和 Enterprise 计划中，您从组织外邀请的所有人都会失去访问权限，其邀请会被删除。在 Pro、Max 和 Ultra 计划中，您邀请的人会保留其访问权限。

- **如果您删除工件：**您邀请的所有人都会失去访问权限。

- **如果发送邀请的人离开您的组织或失去编辑访问权限：**其待处理邀请将停止工作。已接受的人会保留访问权限，直到有人将其删除。

- **如果所有者关闭电子邮件邀请：**您邀请的人无法打开工件，直到该设置重新启用。已接受的邀请不会被删除，待处理的邀请仍会在发送后 30 天过期。

### 限制

- 您可以为每个工件邀请来自组织外的最多 50 人，包括待处理和已接受的邀请。

- 邀请电子邮件为英文。

## 谁可以打开共享工件

- **谁需要 Claude 账户：**要打开与他们或您的组织共享的工件，人员需要登录 Claude。大多数与"任何拥有链接的人"共享的工件无需 Claude 账户或登录即可打开。文档仅对登录到 Claude 的人员打开，他们只能查看。某些其他工件（如仪表板）仅在访问者登录后才显示全部或部分内容。旧版工件有其自己的规则，详见**[发布或共享旧版工件](#h_a5750b9176)**。

- **组织中的所有人：**只有登录到您的组织的人才能打开它。

- **任何拥有链接的人：**任何拥有该链接的人都可以打开它，包括组织外的人员，以及对于大多数以这种方式共享的工件，未登录到 Claude 的人员。在 Team 和 Enterprise 计划中，如果所有者关闭**外部共享**，这些链接将停止工作，直到重新启用，除非所有者已单独允许该工件。

### 无法在组织外共享的工件

- **通过链接：**连接到其他网站的工件，以及包含仍在检查或未通过检查的上传文件的工件，无法使用"任何拥有链接的人"。

- **通过电子邮件邀请：**请参阅**[邀请前](#h_4abce57435)**中的列表。

### 人员打开您的工件时看到的内容

- **查看者使用自己的访问权限。****[从连接的应用程序提取的工件](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them#h_1a161da210)**使用查看者的连接，而不是您的。如果查看者无法访问数据源，工件的该部分会显示错误而不是您的数据。

- **存储的信息可以共享。**某些工件保存打开它们的每个人都可以看到的信息，例如共享跟踪器中的项目。在输入敏感信息之前，请检查**[工件是否使用共享存储](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them#h_135477d2e6)**。

- **仅拥有链接的人看到的内容较少。**从组织外打开"任何拥有链接的人"工件的人，或未登录的人，会看到工件，但使用连接的应用程序或 Claude 的部分对他们不起作用，他们无法看到或添加评论。如果工件保存信息，组织外的人在登录到 Claude 后可以读取它，但无法更改它。未登录的人无法看到该信息，因此将大部分内容保存在那里的工件在他们登录之前向他们显示很少或没有内容。在 Pro、Max 和 Ultra 计划中，"组织外"是指除您以外的任何人。

**重要提示：**仅从您信任的人那里打开共享工件。对待他人的工件就像对待来自未知发件人的文件一样。

## 停止共享工件

要停止共享工件，请打开它，点击"共享"，在**谁有权访问**下，选择"仅限您"（Pro、Max 和 Ultra）或"仅限受邀人员"（Team 和 Enterprise）。要移除您添加的某人，请打开其访问级别并选择"移除"。

在 Team 和 Enterprise 计划中，所有者还可以移除对单个工件的外部访问权限。详见**[Team 和 Enterprise 计划的工件管理员指南](https://support.claude.com/en/articles/16994751-artifacts-admin-guide-for-team-and-enterprise-plans#h_929aa51571)**。

## 打开您被邀请的工件

1. 打开来自 Claude 的电子邮件（<no-reply-claude@mail.anthropic.com>）。它显示邀请您的人的电子邮件地址以及您将拥有的访问权限。

2. 点击"查看邀请"，然后使用邀请发送到的地址在网络浏览器中登录 Claude。

3. 点击"接受并打开"。

要稍后返回工件，请再次打开邀请电子邮件中的链接或为工件添加书签。

### 举报您未预期的邀请

点击电子邮件中的"举报此邀请"，或邀请页面上的"未预期？举报此邀请"。举报会拒绝邀请，发送者不会收到通知。举报邀请后，该人无法再通过电子邮件邀请您。

## 发布或共享旧版工件

旧版工件显示"发布"（Free、Pro、Max 和 Ultra 计划）或"共享并复制链接"（Team 和 Enterprise 计划），而不是"共享"。对这些工件使用本部分中的步骤。

### 在 Free、Pro、Max 和 Ultra 计划上发布旧版工件

1. 打开您要发布的工件。

2. 点击"发布"。

3. 复制公开链接并发送。

发布会将工件添加到侧边栏中的**[工件](https://claude.ai/artifacts)**，以便您可以在原始聊天之外再次找到它。

**谁可以打开已发布的聊天工件：**

- 任何拥有链接的人都可以查看和使用它，无需 Claude 账户。仅在使用 Claude 的功能时才会要求他们注册。

- 登录 Free、Pro、Max 或 Ultra 计划的人也可以复制并保存它。使用 Claude 的功能会计入他们自己的使用限额。

### 嵌入已发布的聊天工件

发布后，点击"获取嵌入代码"以获取可粘贴到另一个网站的代码。在**允许的域**字段中，输入可以嵌入您的工件的网站，用逗号分隔。

### 取消发布聊天工件

点击"取消发布"以撤销对已发布工件的访问权限。

**重要提示：**取消发布工件后，您无法再次发布它。要稍后共享它，您需要创建新工件。取消发布还会永久删除工件使用的任何个人和共享存储数据。

### 在 Team 和 Enterprise 计划上共享聊天工件

1. 打开您要共享的工件。

2. 点击"共享"。

3. 点击"共享并复制链接"。

**谁可以打开它：**

- 您组织中的用户，使用其 Team 或 Enterprise 账户登录。

- 任何拥有链接的人，如果所有者已启用**外部共享**且您选择了"任何拥有链接的人"。他们需要 Claude 账户。

- 如果工件是在项目中创建的，查看者还需要访问该项目。

**重要提示：**当您共享在聊天中创建的工件时，查看者也会获得对该聊天中的附件和文件的访问权限。共享前请检查敏感文档。

**要取消共享聊天工件：**

1. 点击工件右上角的"共享"。

2. 在**工件已共享**模态框中，点击"取消共享"。
