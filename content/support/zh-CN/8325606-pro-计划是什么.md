# Pro 计划是什么？

本文介绍了面向个人消费者的付费 Pro 计划。如果您是想与团队一起使用 Claude 的组织成员，请参阅 **[团队和企业计划](https://support.claude.com/en/collections/9387370-team-and-enterprise-plans)**。

Pro 计划是我们 Claude 聊天体验的付费计划。目前在某些 **[支持的地区](https://support.claude.com/en/articles/8461763-where-can-i-access-claude)** 提供。

## 主要优势

Pro 计划的优势包括：

- 每次会话的使用量比免费计划更多。

- 在高流量期间优先访问 Claude。

- 提前访问新功能，帮助您充分利用 Claude。

- **[Claude Code 访问权限](https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan)**

- **[更长的多步骤任务](https://support.claude.com/en/articles/16761823)**

了解如何 **[注册 Pro 计划](https://support.claude.com/en/articles/8325609-how-do-i-sign-up-for-the-pro-plan)**。

**注意：**  Pro 计划不包括通过 Claude 控制台的 API 使用。如果您对增强的 Claude 功能和 Claude API 都感兴趣，您需要 **[设置控制台访问权限](https://support.claude.com/en/articles/8114521-how-can-i-access-the-claude-api)** 以单独支付 API 使用费用。

## Pro 计划的费用是多少？

Pro 计划的价格为每月 $20（美国），在支持的地区以当地货币计价。月度价格因地区而异，某些地区在显示的价格中包含适用税款，而其他地区在结账时添加税款。

您可以选择年度订阅计划来节省费用。年度订阅按折扣价每年计费一次。

访问 **[claude.ai/upgrade](https://claude.ai/upgrade)** 或查看您的移动应用商店以了解您所在地区的当前价格。

价格和计划可能会根据 Anthropic 的决定而改变。

## 我如何获得免费或折扣的 Pro 计划？

我们不为个人计划（Pro、Max 和 Ultra）提供标准折扣定价，但在支持的地区的任何人都可以通过导航到 **[claude.ai](https://claude.ai/)** 并使用电子邮件地址注册来访问免费版本的 Claude。

我们偶尔会进行限时促销，但没有任何常设折扣可根据要求提供。这些促销优惠通常在可用时通过我们的官方渠道宣布。如果您对未来的潜在促销感兴趣，我们建议您关注我们的官方社交媒体账户或注册我们的新闻通讯，以便在有特别优惠时收到通知。我们的支持团队无法发放一次性折扣或优惠券。

符合条件的非营利组织可以获得团队和企业计划的折扣定价。了解更多关于 **[Claude for Nonprofits](https://claude.com/solutions/nonprofits)** 的信息。

## Pro 计划有使用限制吗？

是的。Pro 计划提供比免费计划更多的每次会话使用量。您可以发送的消息数量将根据消息长度而异，包括您附加的文件长度、当前对话的长度以及您使用的模型或功能。

Pro 计划有五小时限制和适用于所有模型的每周使用限制。每周限制在分配给您账户的固定时间每周重置一次。无论您何时开始使用 Claude 或何时订阅开始，您的重置日期和时间都保持不变，您在每个周期都会获得完整的每周配额。您可以在 **[设置 > 使用情况](https://claude.ai/new#settings/usage)** 中查看您的下次重置时间。

可能会应用其他使用限制来管理容量并确保所有用户的公平访问。例如，我们可能会以其他方式限制您的使用，例如每周和每月上限或模型和功能使用，由我们自行决定。我们不保证不间断的服务。

有关使用和长度限制的更多信息，请参阅 **[了解使用和长度限制](https://support.claude.com/en/articles/11647753-understanding-usage-and-length-limits)**。有关高效使用 Pro 容量的指导，我们还提供 **[使用限制最佳实践](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)**。

**注意：**如果您有限制重置，可以使用它将五小时会话限制或每周使用限制重置为满额。了解更多 **[关于限制重置](https://support.claude.com/en/articles/17007452)** 的信息。

### 我如何增加 Pro 计划的使用限制？

我们的 Max 和 Ultra 计划为个人提供比 Pro 计划更多的使用量。有关更多信息，请参阅 **[什么是 Max 计划？](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)** 和 **[什么是 Ultra 计划？](https://support.claude.com/en/articles/17728952)**

Pro 订阅者还可以启用使用额度，以在计划包含的使用限制之外继续使用 Claude。有关更多信息和启用此功能的说明，请参阅 **[管理付费 Claude 计划的使用额度](https://support.claude.com/en/articles/12429409-)**。
