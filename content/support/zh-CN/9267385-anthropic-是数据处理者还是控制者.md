# Anthropic 是数据处理者还是控制者？

*本文涉及我们的商业产品，如 Claude for Work 和 Anthropic API。关于我们的消费者产品（如 Claude Free、Pro、Max、Ultra）以及这些计划中的账户使用 Claude Code 的情况，请参阅[此处](https://privacy.claude.com/en/collections/10663362-consumers)。*

当商业客户创建 Claude for Work 账户（Team 或 Enterprise 计划）时，根据我们的[商业服务条款](https://www.anthropic.com/legal/commercial-terms)，客户是提交数据的"控制者"。这意味着：

- 客户可以控制谁可以成为其团队成员，并向我们提供有关如何使用提交数据的指示。

- 客户可以访问和导出其用户提交的数据（如对话历史记录）。

- Anthropic 代表客户充当数据的"处理者"。Anthropic 仅按照客户的指示处理数据，以提供 Claude 服务。

- Anthropic 不会使用您在使用我们的商业产品时共享的数据来训练我们的模型，除非您选择参加我们的[开发合作伙伴计划](https://support.claude.com/en/articles/11174108-about-the-development-partner-program)。

总之，对于 Claude for Work，客户组织保持对其用户数据的控制权，Anthropic 仅按照我们的协议代表客户处理该数据以提供服务。您应咨询您所在组织的管理员了解 Claude 使用政策。
