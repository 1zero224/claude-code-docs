# 切换到不同的身份提供商 \(IdP\)

本指南将引导您完成将 Claude 或 Console 组织从一个身份提供商迁移到另一个身份提供商的过程，同时保留用户访问权限并避免中断。

**注意：**此过程适用于已配置 SSO 的组织。如果您是首次设置 SSO，请参阅 **[设置单点登录 (SSO)](https://support.claude.com/en/articles/13132885-setting-up-single-sign-on-sso)**。

## 开始前

- 确认您拥有所需的角色：

  - **对于 Team 或 Enterprise 计划：**您必须是所有者或主要所有者。

  - **对于 Claude Console：**您必须是管理员。

- 提前通知您的用户，他们将在迁移期间暂时退出登录。

- 在中断较少的时间段内安排切换。

- 确保新 IdP 中所有用户的 SSO 和 SCIM 电子邮件属性与之前 IdP 使用的属性完全匹配。如果这些电子邮件地址不完全匹配，用户将被配置为重复账户。

## 切换 IdP 的步骤

1. **禁用来自当前 IdP 的 SCIM 推送**（如适用）：停止当前 IdP 端的创建/更新事件，以防止在迁移期间发送任何同步信号。

  1. 有关 SCIM 的更多信息，请参阅 **[设置 JIT 或 SCIM 配置](https://support.claude.com/en/articles/13133195-setting-up-jit-or-scim-provisioning)**。

2. **将配置模式切换为“仅邀请”**（如适用）：禁用 SCIM 推送约一小时后，导航到所有已连接的 Claude (claude.ai/admin-settings/organization) 或 Console (platform.claude.com/settings/identity) 组织上的“身份和访问”页面。在**全局 SSO 配置**下，将配置模式设置为“仅邀请”。

  1. 这会停止 SCIM 自动管理用户——用户保留在组织中，但不再受 SCIM 事件的影响。

3. **删除 SCIM 目录**（如适用）：点击“管理 SCIM” > “删除目录”。在仅邀请模式下，删除目录不会触发目录同步事件，包括用户取消配置。

4. **删除 SSO 连接**：关闭**要求 Claude 使用 SSO**和**要求 Console 使用 SSO**（如果已启用）。否则，在更改生效前，用户可能会被阻止登录。然后点击“管理 SSO”，在**危险区域**下选择“删除连接”，并输入 DELETE CONNECTION 确认。

  1. **重要：**此操作无法撤销。它将退出所有在您验证域上拥有电子邮件地址的用户。在配置新 IdP 用于 SSO 之前，他们将能够**[通过电子邮件链接登录](https://support.claude.com/en/articles/13189465-logging-in-to-your-claude-account#h_869b162f56)**。

5. **验证删除**：刷新“身份和访问”页面，确认按钮状态已从“管理 SSO”更改为“设置 SSO”。

6. **为新 IdP 设置 SSO 和配置**：按照 **[SSO 设置步骤](https://support.claude.com/en/articles/13132885-setting-up-single-sign-on-sso)**进行操作，并**[配置 JIT 或 SCIM](https://support.claude.com/en/articles/13133195-setting-up-jit-or-scim-provisioning)**，启用组映射（如需要），以确保所有用户在新 IdP 中被分配，并为所有已连接的 Claude 和/或 Console 组织拥有正确的组。如适用，设置后您可以点击“管理 SCIM”验证哪些用户已同步到目录，并确认他们与正确的组相关联。如果您在切换前要求 SSO，请在测试新连接后将其重新启用。在您这样做之前，它保持关闭状态。

7. **重新启用配置**（如适用）：选择“自动批准 (JIT)”或“与 SCIM 同步”以切换配置模式，然后点击“保存更改”以应用。
