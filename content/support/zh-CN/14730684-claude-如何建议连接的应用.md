# Claude 如何建议连接的应用

当你将 Spotify 或 Instacart 等应用连接到 Claude 时，你不需要每次都按名称要求它。Claude 可以在适合你正在做的事情时自动调出连接的应用。本文介绍了这种情况何时发生、Claude 如何在应用之间进行选择，以及你如何保持控制。

连接的应用可在 Claude、Claude Desktop 和 Claude for iOS/Android 上使用。移动设备上的应用安装目前处于测试阶段。

---

## Claude 何时建议应用

Claude 会关注你在对话中提出的问题。当连接的应用与该上下文匹配时，Claude 会在线程中建议它，无需你命名。

例如，如果你连接了 AllTrails 并询问周末远足，Claude 可以找到附近的步道。如果你连接了 Instacart 并寻求帮助准备晚餐，Claude 可以开始构建购物车。

Claude 还会使用你在早期对话中通过记忆功能分享的上下文，使建议更加相关。如果你告诉 Claude 你有一只狗，步道搜索可以默认筛选对狗友好的选项。

### 保持控制

在 Claude 代表你预订、购买或预留任何东西之前，它会先与你确认。对于具有预订或购买流程的连接应用，你需要在完成任何操作之前确认详情。Claude 不会自行进行交易。

连接应用使 Claude 能够代表你进行访问。该应用中的你的数据不会用于训练 Claude 的模型，连接的应用也无法看到你的其他对话。你可以随时断开连接。

### 当多个应用可以帮助时

有时多个连接的应用可以处理你要求的内容。如果你同时连接了 Booking.com 和 TripAdvisor，并寻求帮助规划旅行，Claude 会显示两者并让你选择。Claude 不会默认选择其中一个；你选择使用哪个应用，Claude 从那里继续。

### 无付费推广

Claude 不接受任何付款来推荐连接的应用。没有赞助排名、没有付费推广，也没有广告。当 Claude 调出应用时，是因为该应用与你要求的内容相匹配。

当多个应用可以帮助时，你看到它们的顺序反映的是对你可能有用的内容，而不是合作安排。

## 关闭建议或断开应用连接

你可以控制 Claude 可以将哪些连接的应用引入对话。

**为一次对话禁用应用**：点击聊天左下角的 “+”，悬停在连接器上，然后关闭应用。Claude 不会在该对话中使用它。

**完全断开应用连接**：转到 **[自定义 > 连接器](https://claude.ai/customize/connectors)**，找到应用，然后断开连接。Claude 会立即停止访问它。

有关管理连接应用的更多信息，请参阅 **[使用连接器扩展 Claude 的功能](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)**。
