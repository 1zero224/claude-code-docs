# 添加或更新您的 Claude Console 组织的税务或增值税 ID

## 在注册期间添加您的税务或增值税 ID

创建 Claude Console 组织时，您可能可以选择输入您的税务或增值税 ID，具体取决于您的位置：

1. 在注册过程中，输入您的地址信息。

2. 如果您的地址符合税务条件，将显示一个可选的税务或增值税 ID 字段。

3. 在提供的字段中输入您的税务或增值税 ID。

4. 如果 ID 输入正确，您将能够继续注册。

## 注册后更新您的税务或增值税 ID

如果您需要在已创建 Claude Console 组织后添加或更新您的税务或增值税 ID，请按照以下步骤操作：

1. 登录您的 API Console 账户。

2. 转到**组织**页面 (platform.claude.com/settings/organization)。

3. 根据需要输入或修改您的税务或增值税 ID。

4. 完成后点击
