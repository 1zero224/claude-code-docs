# 使用 Claude 的研究功能

通过研究功能，Claude 会深入调查您的问题。它会进行多次相互关联的搜索，并根据发现的内容决定下一步要探索的方向。它会从不同角度探索您的问题，并系统地解决开放性问题。

研究功能适用于使用付费 Claude 计划（Pro、Max、Ultra、Team 或 Enterprise）的用户，可在 Claude 网页版、Claude Desktop 或 Claude Mobile 上使用。

## 启用或禁用研究功能

**重要提示：**  您必须启用 **[网络搜索](https://support.claude.com/en/articles/10684626)**才能使研究功能正常工作。

点击聊天界面左下角的"+"按钮，然后选择"Research"。聊天窗口底部会出现蓝色指示器。再次点击该指示器可禁用研究功能。

## 使用研究功能

启用研究功能后，您可以向 Claude 提问。Claude 会搜索网络和您连接的工具，包括 **[Google Workspace](https://support.claude.com/en/articles/10166901)**（Gmail、Google Calendar 和 Google Docs）以及您为聊天启用的任何其他连接器。在研究过程中，Claude 可以自动使用连接器中的工具，无需每次都请求批准。详细了解 **[自定义连接器](https://support.claude.com/en/articles/11175166)**。

**重要提示：**在 Claude Mobile 中启动研究时，Claude 仅搜索网络，不使用您的连接器。您不会看到错误或其他表明连接器被跳过的迹象。要包含您的连接器，请在 Claude 网页版或 Claude Desktop 中启动研究。请注意，研究无法使用在 Claude Desktop 中配置的本地 MCP 服务器中的工具。

要查看使用 Claude 研究功能规划团队外出活动的示例，请观看此处的视频：**[使用研究功能](https://claude.com/resources/tutorials/using-research)**。

## 常见问题

### 我启用了研究功能，但 Claude 似乎没有进行研究。我应该怎么办？

在这种情况下，您可以引导并提示 Claude 使用研究工具，例如说"Claude，请使用研究工具来…"

### 研究功能没有从我的连接器中提取内容。我应该怎么办？

如果您在 Claude Mobile 中启动了研究，Claude 仅搜索网络。请改为在 Claude 网页版或 Claude Desktop 中启动研究。否则，引导并提示 Claude

### 研究功能是否会以不同于普通对话的方式计入使用限制？

研究功能受到与标准 Claude 对话相同的限制。但是，由于 Claude 检索多个来源并提供全面的回复，研究会话可能会更快地消耗您的限制。

### 研究功能使用哪个模型？

研究功能在 Claude Opus 5.5 上运行，必要时会回退到 Claude Opus 4.8。无论您为聊天选择了哪个模型，它都会使用这些模型。

在 Team 和 Enterprise 计划中，如果您的管理员已为您的角色关闭了 Claude Opus 5.5 和 Claude Opus 4.8，研究功能将无法工作。请要求您的管理员启用这两个模型中的至少一个。
