# 在 Claude 中使用插件

插件适用于所有付费计划（Pro、Max、Ultra、Team、Enterprise）。

插件可根据您的角色、团队和公司自定义 Claude 的工作方式。每个插件将技能、连接器和子代理打包到一个单一的包中，这样您可以从第一次对话开始就获得现成的设置，而无需自己配置每个部分。

有关插件在聊天、Cowork 和 Claude Code 中各部分功能的完整参考，请参阅 Claude 文档中的**[插件](https://claude.com/docs/plugins/overview)**。

## 您可以在哪里使用插件

您可以在网页版聊天、Claude Desktop 中的"聊天"选项卡以及 Claude Cowork 中添加和使用插件。您添加的插件会保存到您的账户中，因此当您使用同一账户登录时，它们也可在终端中的 Claude Code 中使用。插件中捆绑的技能和命令在所有这些地方都可以使用。Hooks 和子代理仅在 Cowork 和 Claude Code 中运行，不在聊天中运行，因此它们在聊天中显示为灰显。

插件还可以捆绑连接器，这样工作流所需的正确服务就可以设置好，而无需您逐个连接。Claude 可以连接到 Google Drive、Gmail、Slack、DocuSign 等许多服务。

**注意：**在 Cowork 中，连接器通过 Anthropic 的云而不是通过您的本地网络连接到外部服务。自定义连接器必须指向可从 Anthropic 的 IP 范围通过公网访问的服务器。如果您的组织服务器位于防火墙后或专用网络上，请参阅**[自定义连接器的网络要求](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp#h_b66e88c454)**。

### 在 Claude Code 中使用插件

您已安装的插件以及您的组织分发给您的插件会在您使用 Claude 账户登录时同步到 Claude Code。这需要 Claude Code v2.1.273 或更高版本。

- 插件在每次 Claude Code 启动时同步一次。

- 如果您在较旧版本上登录，同步将在几小时内开始，或者如果您再次运行 `/login`，则立即开始。

- 在 Claude Code 中，插件在您的计算机上完整运行，包括其技能、子代理、hooks 和 MCP 服务器。

- 同步是单向的。它从您的 Claude 账户读取数据，永远不会改变其中的任何内容。

- 当 Claude Code 使用 API 密钥登录或在 Amazon Bedrock 等云提供商上运行时，插件不会同步。

要停止插件同步，请在 Claude Code 设置中将 `syncClaudeAiPlugins` 设置为 `false`。在 Claude Code 文档中了解更多关于**[已同步插件](https://code.claude.com/docs/en/plugins-reference#synced-plugins)**的信息。

## 浏览可用插件

Claude 包含一个不断增长的插件库，用于常见的知识工作——包括销售、财务、法律、营销、人力资源、工程、设计、运营、数据分析等。每个插件都预配置了与该功能相关的技能和连接器。某些插件（如 Claude 中的 Salesforce）由合作伙伴构建，并捆绑了合作伙伴自己的连接器和技能。

我们还提供**插件创建**，这是一个帮助您从头开始构建自定义插件的插件。

有关 Anthropic 构建的完整插件集合，请访问**[GitHub](https://github.com/anthropics/knowledge-work-plugins)**。

**注意：**插件可能包含在您的计算机上运行的本地 MCP 服务器，具有与您运行的任何其他程序相同的权限。插件的本地 MCP 服务器在 Cowork 和 Claude Code 中运行，不在聊天中运行。仅从您信任的来源安装插件。如果您的组织使用 Enterprise 计划，您的管理员可能已限制您可以安装的插件，或完全禁用了本地 MCP 服务器。

## 安装插件

1. 在 Claude 中，打开左侧边栏中的**自定义**菜单。自定义将您的插件、技能和连接器汇集在一个地方。

2. 打开**插件**选项卡。

3. 打开**发现**选项卡以查看可用选项。

4. 选择您想要的插件，然后单击"添加"。

在 Cowork 中，先打开"Cowork"选项卡，然后打开**自定义**。

您也可以上传自己构建的自定义插件文件。在 Team 和 Enterprise 计划上，同事可以直接与您共享插件，而不是发送文件。请参阅下面的**[使用与您共享的插件](#h_ef985546b4)**。您在网页版 Claude 或 Claude Desktop 中添加的插件会保存到您的账户而不是您的计算机，因此它们会跟随您到聊天、Cowork 和 Claude Code。

## 自定义插件

在 Cowork 中，您可以调整已安装的插件以更好地适应您的工作流：

1. 查看已安装的插件时，单击右上角的"自定义"。

2. 这会打开一个新的 Cowork 任务，其中包含要求 Claude 自定义您选择的插件的提示。

3. 单击"开始"以开始与 Claude 合作，调整插件的技能和连接器以匹配您的工作方式。

## 共享插件

在所有者或主要所有者启用插件共享后，您可以将在自定义中上传或创建的插件与特定同事（Team 和 Enterprise 计划）或与组（仅 Enterprise 计划）共享。与您共享的人会获得您的当前版本，您可以随时停止共享。从市场添加的插件无法共享。

**注意：**如果您看不到共享选项，请与您的组织所有者联系。

要共享插件：

1. 导航到**[自定义 > 插件](https://claude.ai/new#settings/customize-plugins)**。

2. 找到您创建的插件。

3. 单击其旁边的三点菜单"..."，然后选择"共享"。

4. 选择与谁共享：

  1. **特定人员：**输入名称或电子邮件以直接共享。共享会创建一个链接，为与其共享的任何人打开该项目。该插件会出现在每个收件人的插件选项卡的**与您共享**部分中，在他们启用之前显示为灰显，并显示您的名称作为所有者。

  2. **一个组（仅 Enterprise 计划）：**与您的组织已设置的组共享。该插件会出现在每个组成员的插件选项卡的**与您共享**下，在他们启用之前显示为灰显。需要**与组共享**切换。

5. 单击"共享"。

该插件会出现在每个收件人的**与您共享**部分中，标有您的名称，并保持关闭状态直到他们打开它。共享的插件是只读的。收件人可以启用和使用该插件，但无法编辑其内容。如果您稍后更新插件，收件人会在下次使用时自动获得更新版本。您可以随时移除某人的访问权限，如果他们离开组织，访问权限会自动移除。

要复制共享插件的链接，请在共享对话框中单击"复制链接"。该链接会为您已与其共享的人打开插件；其他任何人都会看到一条消息，表示该插件不可用。

## 停止共享插件

1. 单击插件旁边的"..."按钮，然后选择"共享"。

2. 单击您想要移除的人员或组旁边的"x"。

该插件会立即从他们的列表中移除。删除插件会将其从您与其共享的所有人的列表中移除，当成员离开您的组织时，与成员共享的任何内容都会自动移除。

## 将插件发布到您的组织

在 Team 和 Enterprise 计划上，您可以将在自定义中上传或创建的插件提交到您的组织库，以便您的组织中的任何人都可以安装它。共享会将插件提供给特定人员或组，您保持对其的控制。发布会将其交给您的组织。

要发布插件：

1. 导航到**[自定义 > 插件](https://claude.ai/customize/plugins)**。

2. 打开您想要发布的插件。

3. 单击"发布到组织"。

4. 如果您的组织需要审查，请选择您希望如何提供插件：可安装、默认安装或必需。如果您愿意，请为审查者添加发布说明，然后提交。

如果您的组织需要审查，所有者（或有权审查请求的人）会在发布前检查插件。您选择如何提供插件是一个建议。审查者会看到它被预选，可以更改它，他们也会选择谁获得插件：所有人或特定组。您可以在等待期间继续使用和编辑您的副本，并且可以撤回提交。插件显示其状态：待处理、请求更改（带有审查者的注释）或已发布。当它被批准时，您会收到一封电子邮件。如果您的组织不需要审查，插件会发布到库中，您的组织中的所有人都可以安装。如果您的组织启用了安全扫描，插件在通过扫描之前不会为其他人列出，这通常需要几分钟。

发布后，插件由您的组织管理。要更新它，请再次发布。新版本会经过相同的审查，使用该插件的所有人都会保持在已批准的版本上，直到更新被批准。

**注意：**如果您看不到"发布到组织"，您的组织可能已关闭发布，或该插件可能不是您创建的。您无法发布与您共享的插件或从市场或您的组织库安装的插件。如果这是您自己的插件，请与您的组织所有者联系。

## 使用与您共享的插件

当同事与您共享插件时，它会出现在**自定义**中**插件**选项卡的**与您共享**部分。它处于关闭状态，直到您打开它。打开后，其技能的工作方式与任何其他已安装的插件相同。

您无法编辑与您共享的插件。如果您想改变它的工作方式，请询问构建它的人，或构建您自己的版本。如果他们停止共享插件或删除它，它会自动从您的列表中移除。

**注意：**在打开与您共享的插件之前进行审查，就像您对任何来自 Anthropic 外部的插件所做的那样。了解更多关于**[技能和插件扫描](https://support.claude.com/en/articles/15927065-get-started-with-skill-and-plugin-scanning)**的信息。

## 添加或移除插件市场

Anthropic 提供内置的插件市场，包括默认添加的知识工作市场。您可以添加其他 Anthropic 构建的市场（如金融服务或法律），或从 Git 存储库添加一个。

要添加市场：

1. 打开**自定义**菜单并转到**插件**选项卡。

2. 在**插件**页面上，单击"添加"，然后选择"添加市场"。

3. 选择如何添加它：

  - **浏览 Anthropic 来源：**从 Anthropic 策划的市场中选择，例如知识工作、生命科学、金融服务和法律。单击您想要的旁边的"添加"，然后单击"完成"。

  - **从存储库添加：**输入存储库 URL 或 GitHub 的 owner/repo。github.com 上的存储库可以工作，gitlab.com 和 bitbucket.org 上的公共存储库也可以。

如果您的组织限制可以添加哪些市场，Claude 会拒绝您的组织不允许的存储库。询问所有者允许哪些来源。

要移除市场，包括默认的知识工作市场：

1. 在**插件**部分中找到市场。

2. 单击右角的菜单按钮并选择"移除"。

## 组织管理的插件

如果您使用 Team 或 Enterprise 计划，所有者可以通过插件市场在您的组织中分发插件，或批准用户发布到组织库的插件。这些与同事与您共享的插件不同，后者显示在**与您共享**下。组织管理的插件的工作方式与任何其他插件相同，但有几个区别：

- 您无法编辑组织管理的插件。这可以保持您的团队中的共享工具的一致性。

- 某些插件可能默认安装或对您是必需的。如果您不需要默认安装的插件，可以将其关闭，但必需的插件无法关闭或移除。必需的插件在 Claude Code 中也无法禁用。

- 可用的组织插件显示在**发现**选项卡上，您可以自己添加它们。

在 Enterprise 计划上，您的管理员可能会自定义哪些插件可用于您的组。这意味着您在目录中看到的插件可能与其他组中的同事看到的不同。分配给您的组的插件会出现在使用同一 Claude 账户登录的聊天、Cowork 和 Claude Code 会话中。

有关组织范围内设置和管理插件的指导，请参阅**[为您的组织管理插件](https://support.claude.com/en/articles/13837433-)**。
