# 网络安全验证计划

本文介绍了网络安全验证计划 (CVP) 是什么、谁可以加入、如何申请以及获批后如何启用访问权限。

网络安全验证计划适用于付费 Claude 计划（Pro、Max、Ultra、Team 和 Enterprise）、已设置账单的 Claude 控制台，以及通过关联的云账户和第三方平台。免费计划不支持此功能。

**更新于 2026 年 10 月 6 日。**网络安全验证计划 (CVP) 之前涵盖 Claude Opus 5、4.8 和 4.7，以及 Sonnet 5，仅提供单一访问级别。CVP 现在为 Claude Mythos、Opus 和 Sonnet 模型提供三个访问层级，从 Claude Mythos 5.1、Claude Opus 5.5 和 Claude Sonnet 5.5 开始。

## 计划概览

网络安全验证计划允许经过验证的安全专业人员使用我们最强大的模型进行高级安全工作，同时减少来自我们网络安全防护的干扰。

日常安全开发无需 CVP。您可以使用我们普遍可用的模型来审查代码、修补已知问题和分类安全警报。

如果 Claude 阻止了您的安全工作（例如验证漏洞或运行授权渗透测试），您可能需要 CVP。组织可以申请任何层级。个人（如独立研究人员、开源维护者和漏洞赏金猎人）可以申请防御访问权限。

每个层级都包括 Claude Mythos、Opus 和 Sonnet 模型，从 Claude Mythos 5.2、Claude Mythos 5.1、Claude Opus 5.5 和 Claude Sonnet 5.5 开始。CVP 根据您的层级调整这些模型的防护措施。我们的 **[使用政策](https://www.anthropic.com/legal/aup)** 仍然完全适用。

## 访问层级

以下是网络安全验证计划中三个访问层级的概览：防御访问、红队访问和专业访问。

| ------------ | ------------------------------------------------ | ------------------------------ | ---------------------------------------------- |
| **您可以做什么**   | 安全运营、事件响应、恶意软件分析、检测工程以及漏洞分类和验证                   | 授权渗透测试、红队测试、对手仿真、攻击工具开发和漏洞利用开发 | 对关键基础设施进行授权渗透测试和红队测试，以及对最高严重级别技术的研究            |

我们在每个层级都禁止某些活动，包括：

- 大规模数据或设备破坏

- 拒绝服务攻击

- 物理世界损害

- 勒索

- 选举干扰

- 任何声称具有恶意意图的请求

防御访问权限最适合大多数关键基础设施运营商。运营关键基础设施本身不足以使组织获得专业访问权限的资格。

**注意：**当我们继续完善防护措施并减少跨层级已批准工作的误报时，您可能会遇到一些模型拒绝和分类器阻止。

## 数据保留

数据保留对所有参与该计划的人员都是必需的，以便我们能够帮助监控和缓解网络滥用。如果您的组织对Claude Fable或Claude Mythos模型有数据保留豁免，您可以在该计划中的所有模型上使用CVP，零数据保留(ZDR)用于内部使用。

Enterprise Frontier Safeguards (EFS)正式推出后，符合条件的组织可以在其控制的云基础设施中存储数据。**[注册您对EFS的兴趣](https://claude.com/form/enterprise-frontier-safeguards)**。

## 准备您的申请

默认情况下，CVP仅允许用于内部使用。外部使用需要单独的申请：

- **内部使用：**对您自己组织的代码、产品和基础设施进行安全工作。这也包括您独立进行的漏洞赏金研究和协调披露，而不是为客户进行的工作，需符合该计划的规则。每个批准的层级都涵盖此项。

- **外部使用：**为您的客户或他们使用的产品进行安全工作。这需要在您加入CVP并获得内部使用批准后进行单独的批准。

### 内部使用：准备事项

#### 所有层级

- **正确的账户。**确保您从将使用CVP的组织申请。批准不会转移到您的其他组织。您的Claude和Claude Console账户是独立的组织。

- **您的电子邮件地址。**如果您代表组织申请，请使用具有您组织电子邮件域的账户（如适用）。您之后无法更改账户的电子邮件地址，因此在创建账户时请确保使用正确的电子邮件。

- **一份申请。**每个组织提交一份申请。Claude账户的所有者或主要所有者，或Claude Console账户的管理员必须提交您组织的申请。您组织中的其他用户不应单独申请。

- **验证详情。**准备好有关您的组织和申请人的信息。了解更多关于**[Claude上的身份验证](https://support.claude.com/en/articles/14328960-identity-verification-on-claude)**。

  - 如果您以个人身份进行验证，请准备以下内容：

    - **有效的政府颁发的带照片的身份证件**：护照、驾驶执照、州/省身份证或国家身份证等实体文件（不是复印件）

    - **带摄像头的手机**：您可能被要求用手机拍摄实时自拍照。

  - 如果您代表组织进行验证，您还需要：

    - **关于您的组织的识别信息：**法定名称、地址和营业执照号

- **您的安全工作。**描述您的团队所做的工作以及您将如何使用Claude。

#### 按层级准备的其他项目

**Defense Access**

确保您的组织可以证明已实施以下安全控制：多因素身份验证(MFA)和至少每七天更换一次的API密钥。

**重要提示：**从2026年12月15日起，Defense Access还要求使用抗钓鱼MFA，不再允许静态或长期有效的API密钥。我们建议您立即迁移到**[工作负载身份联合](https://platform.claude.com/docs/en/manage-claude/workload-identity-federation)**。

您需要完成身份验证（组织需进行业务验证）、描述您的安全工作并接受条款。

**红队访问权限**

确保您的组织可以证明已实施以下安全控制措施：抗钓鱼MFA、API密钥至少每七天轮换一次、公司域名账户、组织控制的设备、出站网络控制和背景调查。

然后，找到描述您情况的行，并准备相关信息。匹配某一行不保证获得批准。

**注意：**如果您的组织依赖外部测试人员，测试公司应申请加入该计划。

**专业访问权限**

我们与美国政府合作深入审查每份专业访问权限申请。此级别适用于专门从事系统性重要基础设施红队测试的组织。大多数从事防御工作的关键基础设施组织不需要专业访问权限。要符合条件，您需要证明您有权测试这些类型的系统，并详细说明您在红队访问权限级别无法完成的活动。

如果您申请专业访问权限，请确保您的组织可以证明已实施以下安全控制措施：抗钓鱼MFA、API密钥至少每七天轮换一次、公司域名账户、组织控制的设备、出站网络控制和背景调查，以及单点登录和具有恶意软件保护的托管设备。

#### 加快审查的证据

- 链接到我们可以独立检查的来源，如公开注册表、认证目录或颁发者页面。如果没有公开链接，请上传完整的、带日期的文档。LinkedIn个人资料或屏幕截图通常不够。您自己的网站适用于某些项目，如列出您证书的公开信任中心页面或描述您测试服务的页面。

- 确保您证据上的名称与我们正在验证的组织或个人相匹配。

- 检查每个链接是否有效且公开可见，包括漏洞赏金资料。

## 如何申请

在**[验证门户](https://portal.anthropic.com/programs)**中申请。该门户将指导您完成验证、您的等级、您的等级所需的任何证据以及计划条款。

您将作为企业或个人进行验证。请仔细选择，因为验证类型会影响您的申请：

- **企业**：您代表公司、非营利组织、大学、政府团队或其他组织申请。对于红队或专门访问权限，您必须从团队、企业或 API 计划上的账户申请。

- **个人**：您代表自己申请，例如独立研究人员、开源维护者或漏洞赏金猎人。个人只能申请防御访问权限。您可以使用专业版、最大版、超级版、团队版、企业版或 API 计划申请防御访问权限。

- **红队访问：**红队人员、渗透测试人员和攻击性安全研究人员

## 常见问题

### 我已获得批准。为什么我仍然被阻止？

请您的管理员确认他们已为您分配了访问权限。如果您使用 Claude 控制台，请检查您是否在应用了该程序的工作区中。然后检查该工作是否在您的层级范围内。

### 我有防御访问权限。我可以申请更高的层级吗？

可以，如果您以组织身份申请。在我们审查您的申请期间，您将保留防御访问权限。

### 我公司的不同部门可以有不同的层级吗？

可以。每个 Claude 组织需要自己的申请。在一个组织内，您可以按工作区（控制台）或角色（Enterprise）分配程序。团队计划无法在用户之间分割访问权限。

### 我在安全公司工作。我的层级是否涵盖客户工作？

不仅仅是这样。您需要 CVP 层级和外部使用批准，通常作为托管服务。

### 如果另一个工作区为客户提供服务，我可以在内部使用 CVP 吗？

在 Claude 控制台中，可以。CVP 仅适用于您分配给它的工作区，不能是默认工作区。将其分配给仅用于内部工作的工作区，并将客户流量保留在没有 CVP 的单独工作区中。要将 CVP 用于客户流量，您需要获得外部使用批准。

在团队计划中，访问权限适用于您的整个组织，因此您无法将其限制为仅限内部工作。在我们批准该服务或产品供外部使用之前，不要从具有 CVP 访问权限的组织为客户提供服务。

### 为什么 Amazon Bedrock 上的访问权限受限？

Bedrock 尚不支持对自动安全标志的人工审查，这是 CVP 默认要求的。目前，Bedrock 上的 CVP 仅适用于具有数据保留豁免的组织。一旦企业前沿保障措施 (EFS) 可用，EFS 计划中的 Bedrock 组织可以申请 CVP 访问权限。要注册您对 EFS 的兴趣，请使用此**[企业前沿保障措施表格](https://claude.com/form/enterprise-frontier-safeguards)**。同时，我们正在努力将 CVP 扩展到 Bedrock 客户。请联系您的客户团队以询问豁免。

### Claude Mythos 模型的使用限制如何工作？

Mythos 模型遵循与 Claude Fable 模型相同的使用规则。

- **Pro 计划：**Mythos 模型仅适用于使用额度。

- **Max 和 Ultra 计划：**Mythos 和 Fable 模型共享您每周使用限制的最多 50%。此使用也计入您的常规使用限制。之后，您可以继续使用额度（如果已启用），或切换到另一个模型。

### 我可以下载我的申请副本吗？

可以。您可以从验证门户中的程序页面以 PDF 格式下载您的申请和条款。

### 获得批准后，我可以添加更多人员吗？

可以。您无需重新申请。您的管理员将他们添加到具有该程序的工作区（控制台）或自定义角色（Enterprise），直到达到您的层级限制。对于红队访问和专门访问，您只能添加在您的申请中命名的团队中的人员。您添加的每个人都必须满足您的层级的安全要求。

### 获得批准后，我可以添加另一个云账户吗？

是的。在验证门户中将新账户链接到同一个 Anthropic 组织。您不需要新的应用程序。在 Amazon Bedrock 和 Google Cloud Agent Platform 上，您还需要为新账户启用您的层级。

### CVP 是否会改变网络安全以外的保障措施？

不会。CVP 仅调整我们的网络安全保障。来自研究生物学等其他领域的保障措施在每个层级都适用。我们的**[使用政策](https://www.anthropic.com/legal/aup)**仍然完全适用。

### 提交申请后，我可以更改或取消申请吗？

不可以。您可以在提交前查看和编辑答案，但提交后无法编辑或取消申请。如果您未获批准，可以在七天后重新申请。

### 我在错误的组织中获得了批准。我应该怎么办？

从您将使用 CVP 的组织重新申请，或向您的账户团队寻求帮助。
