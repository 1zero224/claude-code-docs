# 网络安全验证计划

本文介绍了网络安全验证计划 (CVP) 是什么、谁可以加入、如何申请以及获批后如何启用访问权限。

网络安全验证计划可在付费 Claude 计划（Pro、Max、Ultra、Team 和 Enterprise）、已设置账单的 Claude 控制台以及通过关联的云账户和第三方平台上使用。免费计划不支持此功能。

**更新于 2026 年 10 月 6 日。**网络安全验证计划 (CVP) 之前涵盖 Claude Opus 5、4.8 和 4.7，以及 Sonnet 5，仅提供单一访问级别。CVP 现在为 Claude Mythos、Opus 和 Sonnet 模型提供三个访问层级，从 Claude Mythos 5.1、Claude Opus 5.5 和 Claude Sonnet 5.5 开始。

## 计划概览

网络安全验证计划允许经过验证的安全专业人员使用我们最强大的模型进行高级安全工作，同时减少来自我们网络安全防护的干扰。

日常安全开发无需 CVP。您可以使用我们普遍可用的模型来审查代码、修补已知问题和分类安全警报。

如果 Claude 阻止您的安全工作（例如验证漏洞或运行授权渗透测试），您可能需要 CVP。组织可以申请任何层级。个人（如独立研究人员、开源维护者和漏洞赏金猎人）可以申请防御访问权限。

每个层级都包括 Claude Mythos、Opus 和 Sonnet 模型，从 Claude Mythos 5.2、Claude Mythos 5.1、Claude Opus 5.5 和 Claude Sonnet 5.5 开始。CVP 根据您的层级调整这些模型的防护措施。我们的 **[使用政策](https://www.anthropic.com/legal/aup)** 仍然完全适用。

## 访问层级

以下是网络安全验证计划中三个访问层级的概览：防御访问、红队访问和专业访问。

| **CVP 访问层级** | **防御访问**                                         | **红队访问**                       | **专业访问**                                      |
| ------------ | ------------------------------------------------ | ------------------------------ | --------------------------------------------- |
| **您可以做什么**   | 安全运营、事件响应、恶意软件分析、检测工程以及漏洞分类和验证                   | 授权渗透测试、红队活动、对手仿真、攻击工具开发和漏洞利用开发 | 授权渗透测试和关键基础设施红队活动，以及最高严重级别技术的研究               |
| **适用对象**     | 定期从事安全工作的安全团队和其他员工、关键基础设施运营商、开源维护者、漏洞赏金猎人和个人研究人员 | 渗透测试公司和核心工作为攻击性的内部红队           | 工作需要对关键系统（如飞行操作系统、电网和银行间转账基础设施）进行授权高风险攻击测试的团队 |
| **谁可以申请**    | 组织和个人                                            | 仅限组织                           | 仅限组织                                          |
| **计划**       | Pro、Max、Ultra、Team、Enterprise 和 API              | Team、Enterprise 和 API          | Team、Enterprise 和 API                         |
| **已批准用户**    | 无默认限制。个人访问权限仅限于您本人                               | 最多 75 人                        | 最多 25 人                                       |

我们在每个层级都禁止某些活动，包括：

- 大规模数据或设备破坏

- 拒绝服务攻击

- 物理世界损害

- 勒索

- 选举干扰

- 任何声称有恶意意图的请求

防御访问权限最适合大多数关键基础设施运营商。仅运营关键基础设施本身不足以使组织获得专业访问权限的资格。

**注意：**当我们继续完善防护措施并减少跨层级已批准工作的误报时，您可能会遇到一些模型拒绝和分类器阻止。

## 数据保留

所有参与该计划的人员都需要进行数据保留，以便我们能够帮助监控和缓解网络滥用。如果您的组织对 Claude Fable 或 Claude Mythos 模型有数据保留豁免，您可以在该计划中的所有模型上使用零数据保留 (ZDR) 的 CVP 进行内部使用。

企业前沿保障措施 (EFS) 正式推出后，符合条件的组织可以在其控制的云基础设施中存储数据。**[注册您对 EFS 的兴趣](https://claude.com/form/enterprise-frontier-safeguards)**。

## 准备您的申请

默认情况下，CVP 仅允许用于内部使用。外部使用需要单独的申请：

- **内部使用：**对您自己组织的代码、产品和基础设施进行安全工作。这也包括您独立进行的漏洞赏金研究和协调披露，而不是为客户进行的工作，但需遵守该计划的规则。每个批准的等级都涵盖此项。

- **外部使用：**为您的客户或他们使用的产品进行安全工作。这需要在您加入 CVP 并获得内部使用批准后进行单独的批准。

### 内部使用：需要准备的内容

#### 所有等级

- **正确的账户。**确保您从将使用 CVP 的组织申请。批准不会转移到您的其他组织。您的 Claude 和 Claude 控制台账户是独立的组织。

- **您的电子邮件地址。**如果您以组织身份申请，请使用具有您组织电子邮件域的账户（如适用）。您之后无法更改账户的电子邮件地址，因此在创建账户时请确保使用正确的电子邮件。

- **一份申请。**每个组织提交一份申请。Claude 账户的所有者或主要所有者，或 Claude 控制台账户的管理员必须提交您组织的申请。您组织中的其他用户不应单独申请。

- **验证详情。**准备好有关您的组织和申请人的信息。详细了解 **[Claude 上的身份验证](https://support.claude.com/en/articles/14328960-identity-verification-on-claude)**。

  - 如果您以个人身份进行验证，请准备以下内容：

    - **有效的政府颁发的带照片身份证件**：实体文件，如护照、驾驶执照、州/省身份证或国家身份证（不是复印件）

    - **带摄像头的手机**：您可能被要求用手机拍摄实时自拍照。

  - 如果您代表组织进行验证，您还需要：

    - **关于您的组织的识别信息：**法定名称、地址和营业执照号

- **您的安全工作。**描述您的团队所做的工作以及您将如何使用 Claude。

#### 按等级准备的其他项目

**防御访问权限**

确保您的组织可以证明它已实施以下安全控制：多因素身份验证 (MFA) 和至少每七天更换一次的 API 密钥。

**重要提示：**从2026年12月15日起，Defense Access还要求使用抗钓鱼多因素身份验证，不再允许使用静态或长期有效的API密钥。我们建议您现在就迁移到**[工作负载身份联合](https://platform.claude.com/docs/en/manage-claude/workload-identity-federation)**。

您需要完成身份验证（组织需进行业务验证）、描述您的安全工作，并接受条款。

**红队访问权限**

确保您的组织可以证明已实施以下安全控制措施：抗钓鱼多因素身份验证、API密钥至少每七天更换一次、公司域名账户、组织控制的设备、出站网络控制和背景调查。

然后，找到描述您情况的行，并准备相关信息。符合某一行的条件不保证获得批准。

**注意：**如果您的组织依赖外部测试人员，测试公司应申请加入该计划。

| **如果您以以下身份申请** | **需要准备的材料**                                                                                                                                                                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 内部红队           | 以下所有内容：<br>     您组织安全计划的证明，包括：<br><br>最新年度报告的网络安全部分、当前ISO/IEC 27001证书或SOC 2 Type II报告，或已运行至少12个月的付费漏洞赏金计划。关键基础设施运营商也可以使用部门安全义务。<br>您测试团队的名称、负责人及其大致人数

**专项访问权限**

我们与美国政府合作深入审查每份专项访问权限申请。此级别适用于专门从事系统重要基础设施红队测试的组织。大多数从事防御工作的关键基础设施组织不需要专项访问权限。要符合条件，您需要证明您有权测试这些类型的系统，并详细说明在红队访问权限级别无法完成的活动。

如果您申请专项访问权限，请确保您的组织可以证明已实施以下安全控制措施：抗钓鱼多因素身份验证、API密钥至少每七天更换一次、公司域名账户、组织控制的设备、出站网络控制和背景调查，以及单点登录和具有恶意软件保护的托管设备。

#### 加快审查的证据

- 链接到我们可以独立检查的来源，如公开注册表、认证目录或颁发者页面。如果没有公开链接，请上传完整的、带日期的文档。LinkedIn个人资料或屏幕截图通常不够。您自己的网站适用于某些项目，如列出您证书的公开信任中心页面或描述您测试服务的页面。

- 确保您证据上的名称与我们正在验证的组织或个人相匹配。

- 检查每个链接是否有效且公开可见，包括漏洞赏金资料。

### 外部使用：需要准备的内容

您提供的每项服务或产品都需要单独批准。组织获得CVP级别批准后，您可以申请。

| **类型**    | **含义**                                                       | **状态** | **需要准备的内容**                                      |
| --------- | ------------------------------------------------------------ | ------ | ------------------------------------------------ |
| **托管服务**  | 您的员工使用 Claude 为客户进行安全工作。客户仅接收由您的员工审查的最终交付成果，从不向模型提示或查看其原始输出。 | 接受申请   | 服务如何运行、谁操作模型以及客户接收的内容<br>安全联系人，以及签署批准的公司高管的姓名和职位 |
| **受限产品**  | 客户使用您构建的产品，但无法直接指导模型或查看其原始输出。                                | 表示兴趣   | 不适用                                              |
| **不受限产品** | 任何其他面向客户的产品，例如客户可以向模型提示的产品。                                  | 表示兴趣   | 不适用                                              |

**重要提示：**在未获得明确批准的情况下通过服务或产品为客户提供服务违反了 CVP 条款，是被移除该计划的理由。

## 如何申请

在**[验证门户](https://portal.anthropic.com/programs)**中申请。该门户将指导您完成验证、您的等级、您的等级所需的任何证据以及计划条款。

您将作为企业或个人进行验证。请仔细选择，因为验证类型会影响您的申请：

- **企业**：您代表公司、非营利组织、大学、政府团队或其他组织申请。对于红队或专门访问权限，您必须从团队、企业或 API 计划上的账户申请。

- **个人**：您代表自己申请，例如独立研究人员、开源维护者或漏洞赏金猎人。个人只能申请防御访问权限。您可以使用专业版、最大版、超级版、团队版、企业版或 API 计划申请防御访问权限。

### 使用 Anthropic 账户申请

如果您直接通过 Anthropic 使用 Claude、Claude Code 或 Claude API，请按照以下步骤操作：

1. 使用您的 Anthropic 账户登录**[验证门户](https://portal.anthropic.com/programs)**。如果您还没有账户，请创建一个新账户并设置账单。

2. 从程序列表中选择“网络验证计划”。

3. 点击“申请”并完成申请。

4. 接受条款并提交。

### 使用云账户申请

如果您使用 AWS 上的 Claude Platform、Google Cloud 上的 Claude Platform、Google Cloud Agent Platform、Amazon Bedrock（如果符合 EFS 资格）或 Microsoft Foundry，请按照以下步骤操作：

1. 如果您还没有 Anthropic 账户，请创建一个。它是免费的，不需要账单信息，但在您链接云账户或购买 Claude Console 积分之前，您无法申请。

2. 使用您的 Anthropic 账户登录**[AWS 上的 Claude Platform](https://portal.anthropic.com/link?account_source=aws&program=cvp)**、**[Google Cloud 上的 Claude Platform](https://portal.anthropic.com/link?account_source=gcp&program=cvp)**、**[Google Cloud Agent Platform](https://portal.anthropic.com/link?account_source=gcp&program=cvp)**、**[Amazon Bedrock](https://portal.anthropic.com/link?account_source=aws&program=cvp)** 或**[Microsoft Foundry](https://portal.anthropic.com/programs)** 的验证门户，或者如果您没有账户，请注册。

3. 系统将提示您使用 CLI 命令链接您的云服务提供商账户，以验证您是管理员。您最多可以链接 10 个 GCP 项目或 AWS 账户。

4. 打开**程序**并从程序列表中选择“网络验证计划”。

5. 点击“申请”并完成申请。

6. 接受条款并提交。

然后，使用您的云提供商账户按照以下步骤操作：

1. 打开**[关联账户](https://portal.anthropic.com/linked-accounts)**，选择“链接账户”，然后选择您的提供商。

2. 输入您的账户详情并完成您的提供商的设置步骤：

  1. **AWS：**

    1. **输入内容：**12 位账户 ID

    2. **设置步骤：**使用门户的启动链接或命令创建验证角色。在 Bedrock 之前链接 AWS 上的 Claude Platform。

  2. **Google Cloud：**

    1. **输入内容：**项目 ID（不是项目编号）

    2. **设置步骤：**运行显示的 `gcloud` 命令。

  3. **Azure：**

    1. **输入内容：**订阅 ID 和目录（租户）ID

    2. **设置步骤：**首先在 Foundry 中部署 Claude 模型，然后运行显示的命令。

3. 选择“我已授予访问权限”，然后选择“验证”。

4. 选择“网络验证计划”，然后从程序页面点击“申请”。

### 通过第三方平台申请

1. 向您的平台请求 Anthropic 注册链接。

2. 打开该链接，登录验证门户或创建账户，并确认您希望链接您的账户。

3. 选择 “网络安全验证计划”，然后从“计划”页面点击 “申请”。

### 申请外部使用

您必须是 Claude 账户的所有者或主要所有者，或者是已获批 CVP 的 Claude 控制台账户的管理员。然后您可以：

1. 在验证门户中打开 **[网络安全产品化](https://portal.anthropic.com/programs/cyber-productization)**。

2. 选择 “注册产品” 并选择您的类型。

3. 对于托管服务，请完成表单、接受 Anthropic 网络安全防御合作伙伴附录，然后选择 “提交审核”。对于产品，请用一行描述它，添加名称和电子邮件，然后选择 “表示兴趣”。

**注意：**提交后，您无法编辑或撤回此申请。对每个额外的服务或产品重复这些步骤。

## 申请后的预期

### 您何时会收到回复

我们将通过电子邮件向您发送决定或更多信息请求。要检查您的状态，请登录验证门户，打开“计划”，然后选择 “网络安全验证计划”。如果您的审核时间超过目标时间，您无需重新申请或联系支持。

| **申请** | **目标**                                     |
| ------ | ------------------------------------------ |
| 防御访问权限 | 两天                                         |
| 红队访问权限 | 两周。由于需求量大，审核目前耗时更长。                        |
| 专业访问权限 | 无设定目标。这些审核耗时比红队访问权限更长，因为我们与美国政府合作深入审核每个组织。 |
| 托管服务   | 约一周                                        |

如果您申请红队访问权限或专业访问权限并符合较低级别的条件，您将在我们审核您申请的其余部分时获得较低级别的访问权限。

### 如果您未获批准

您可以继续使用我们的通用模型，以及您获批的任何级别。

您也可以在七天后重新申请**。**如果情况有所改变或您可以提供更有力的证据来支持您的申请，这是最佳选择。检查您是否从正确的账户申请，并完成了正确类型的验证（商业或个人）。

如果我们发现违反我们政策的活动，我们可能随时自行决定审核、限制或撤销计划访问权限。

#### Claude 控制台

要在 Claude 控制台中启用 CVP 访问权限：

1. 以组织管理员身份 **[登录控制台](https://platform.claude.com/)**。您将可以选择创建新的 **[工作区](https://platform.claude.com/settings/workspaces)** 或将 CVP 访问权限分配给您已有的工作区。**注意：**您无法将其分配给默认工作区。

2. 仅将应该获得高级网络安全功能访问权限的用户添加到工作区。对于红队访问权限和专业访问权限，控制台显示您正在使用多少个座位。每个组织管理员都占用一个座位。如果您超过您的级别限制，每个工作区都将失去 CVP 访问权限，直到您回到限制范围内。

3. 打开**[Programs page](https://platform.claude.com/settings/programs)**，然后选择您的等级卡片，例如“Defense Access。”

4. 在**Workspaces**表中，为您的工作区打开**Access**开关。

5. 如果工作区行中的单元格显示“Not set，”“Not met，”或“Allowed，”请选择它并按照修复步骤操作。在2026年12月15日之前，Defense Access仅允许在七天内过期的API密钥。在该日期之后，它不允许API密钥。Red Team Access和Specialized Access需要关闭API密钥。

6. 检查页面上活跃工作区的数量，例如“1 of 2 workspaces active。”工作区在满足要求之前保持不活跃状态。

有关详细信息，请参阅**[assign a program to workspaces](https://support.claude.com/en/articles/16764810)**。

#### Claude Enterprise

要在Claude Enterprise中启用CVP访问权限：

1. 以所有者或主要所有者身份登录。

2. 转到**Organization settings > Roles**并添加或编辑自定义角色。

3. 选择**Details**选项卡，然后选择需要访问权限的组。

4. 选择**Models**选项卡，然后在**Grants**下选择授权并保存。

5. 确认您的批准用户具有**Custom**角色类型。内置角色不包括在内。

有关详细信息，请参阅**[assign a program to a custom role](https://support.claude.com/en/articles/17118092)。**

#### Google Cloud Agent Platform

要在Google Cloud Agent Platform中启用CVP访问权限，请为每个项目重复这些步骤：

1. 在**[Verification Portal](https://portal.anthropic.com/programs)**中，转到**[Linked accounts](https://portal.anthropic.com/link?account_source=gcp&program=cvp)**并链接您的项目。

2. 转到**Programs**并启用您的等级。

3. 在**Model Garden**中，打开Claude模型并接受Advanced AI Safety Addendum。

4. 为您使用的每个模型和位置启用数据共享。使用Google的`setPublisherModelConfig` API将`dataSharingEnabledProvider`设置为`ANTHROPIC`。

#### 云提供商上的Claude Mythos

在您获得CVP批准后约五个工作日，Mythos在云合作伙伴上的访问权限开始生效。如果您与Anthropic有承诺合同，您的账户团队将向您发送一份简短表格。完成表格，然后在您的云市场中接受私人报价。两个步骤完成后，我们将配置Mythos。

### 2. 为每个团队分配正确的等级

如果您获得了多个等级的批准，请将每个授权视为任何其他特权访问。将每个授权保持在其自己的工作区、角色或云账户中。

- **Specialized Access：**在Red Team Access中工作仍被阻止的小组

- **Red Team Access：**红队成员、渗透测试人员和攻击性安全研究人员

- **Defense Access：**您的安全团队的其余成员，以及从事安全或安全相关工作的开发人员和其他员工

- **No grant：**其他所有人

## 常见问题

### 我已获得批准。为什么我仍然被阻止？

请您的管理员确认他们已为您分配了访问权限。如果您使用Claude Console，请检查您是否在应用了该程序的工作区中。然后检查该工作是否在您的等级范围内。

### 我有Defense Access。我可以申请更高的等级吗？

可以，如果您以组织身份申请。在我们审查您的申请期间，您将保留Defense Access。

### 我公司的不同部门可以有不同的等级吗？

可以。每个Claude组织需要自己的申请。在一个组织内，您可以按工作区（Console）或角色（Enterprise）分配程序。团队计划无法在用户之间分割访问权限。

### 我在安全公司工作。我的等级是否涵盖客户工作？

仅凭本身不行。您需要CVP等级和外部使用批准，通常作为托管服务。

### 如果另一个工作区为客户服务，我可以在内部使用CVP吗？

在Claude Console中，可以。CVP仅适用于您分配给它的工作区，并且不能是默认工作区。将其分配给仅用于内部工作的工作区，并将客户流量保留在没有CVP的单独工作区中。要将CVP用于客户流量，您需要获得外部使用批准。

在团队计划中，访问权限适用于您的整个组织，因此您无法将其限制为仅限内部工作。在我们批准该服务或产品供外部使用之前，不要从具有CVP访问权限的组织为客户服务。

### 为什么Amazon Bedrock上的访问权限受限？

Bedrock还不支持对自动安全标志的人工审查，这是CVP默认要求的。目前，CVP在Bedrock上仅适用于具有数据保留豁免的组织。一旦Enterprise Frontier Safeguards（EFS）可用，EFS计划中的Bedrock组织可以申请CVP访问权限。要注册您对EFS的兴趣，请使用此**[Enterprise Frontier Safeguards form](https://claude.com/form/enterprise-frontier-safeguards)**。在此期间，我们正在努力将CVP扩展到Bedrock客户。请联系您的账户团队以询问豁免。

### Claude Mythos模型的使用限制如何工作？

Mythos模型遵循与Claude Fable模型相同的使用规则。

- **Pro计划：**Mythos模型仅适用于使用额度。

- **Max和Ultra计划：**Mythos和Fable模型共享您每周使用限制的最多50%。此使用也计入您的常规使用限制。之后，您可以继续使用额度（如果已启用），或切换到另一个模型。

### 我可以下载我的申请副本吗？

可以。您可以从Verification Portal中的程序页面以PDF格式下载您的申请和条款。

### 获得批准后，我可以添加更多人员吗？

可以。您无需重新申请。您的管理员将他们添加到具有该程序的工作区（Console）或自定义角色（Enterprise），直至您的等级限制。对于Red Team Access和Specialized Access，您只能添加在您的申请中命名的团队中的人员。您添加的每个人都必须满足您的等级的安全要求。

### 获得批准后，我可以添加另一个云账户吗？

可以。在验证门户中将新账户链接到同一个 Anthropic 组织。您不需要提交新的申请。在 Amazon Bedrock 和 Google Cloud Agent Platform 上，您还需要为新账户启用您的层级。

### CVP 是否会改变网络安全以外的保障措施？

不会。CVP 仅调整我们的网络安全保障。来自研究生物学等其他领域的保障措施在每个层级都继续适用。我们的 **[使用政策](https://www.anthropic.com/legal/aup)** 仍然完全适用。

### 提交申请后，我可以更改或取消申请吗？

不可以。您可以在提交前查看和编辑您的答案，但提交后无法编辑或取消申请。如果您未被批准，可以在七天后重新申请。

### 我被批准的组织不对。我应该怎么办？

从您将使用 CVP 的组织重新申请，或向您的账户团队寻求帮助。
