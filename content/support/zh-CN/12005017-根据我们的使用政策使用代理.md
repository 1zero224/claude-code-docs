# 根据我们的使用政策使用代理

所有代理和代理功能的使用必须继续遵守Anthropic的使用政策。以下是我们的使用政策如何适用于某些代理使用的非详尽说明。随着代理功能的发展，我们将更新此列表，并提供额外示例，以帮助用户了解我们的使用政策在代理环境中的实际适用范围。

# 不要将代理用于监视或未经授权的数据收集

这包括使用代理来：

- 在未通知或未获得同意的情况下监视或跟踪个人的在线活动、行为或动向

- 收集、汇编或分析个人信息，以根据个人的受保护属性、敏感特征或个人情况创建档案

- 使用面部识别或生物识别软件或网站

- 在多个网站或平台上进行大规模监视，以发送通信或进行任何形式的有针对性的行动

# 不要将代理用于生成或传播有害内容

这包括使用代理来：

- 创建模仿合法网页的网站或域名

- 生成导致网络钓鱼、社会工程或欺诈的内容

- 在未获得同意的情况下冒充个人（私人或公众人物）

# 不要将代理用于大规模滥用

这包括使用代理来：

- 向政府服务、应急系统或危机求助热线发送垃圾邮件

- 用流量淹没服务器以中断服务（例如DDoS攻击）

- 协调跨多个平台或账户的骚扰活动

- 操纵在线投票、投票系统或流量指标

- 创建或管理多个账户以逃避检测或规避平台保护措施

- 在社交媒体上进行点击农场或人工参与（例如通过点赞或评论）

- 自动化影响力操作或协调的非真实行为

- 通过滥用举报系统批量举报人员、用户或内容

# 不要将代理用于未经授权的系统访问或操纵

这包括使用代理来：

- 在未经授权的情况下安装恶意软件、后门或监视软件

- 执行尝试权限提升或系统利用的命令

- 执行可能危害关键基础设施或应急服务的操作

- 进行未经授权、非法或欺诈性的金融交易（如经纪或投资咨询活动）或支付处理

- 在未经授权的情况下使用存储的凭证访问或修改他人的账户
