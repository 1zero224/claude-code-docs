# 设置休息提醒和安静时段

休息提醒和安静时段是可选的控制功能，您可以在 Claude 设置中启用。休息提醒会在您每天与 Claude 互动达到设定时长后给您一个温和的提示。安静时段会在您预留给其他事务的时间窗口内增加轻微的摩擦。两者都不是硬性锁定，所以您可以随时选择继续。

休息提醒和安静时段目前在 Free、Pro、Max 和 Ultra 计划中处于测试阶段。您可以在 Claude 网页版或 Claude Desktop 中设置它们，它们会在网页版、Claude Desktop 和 Claude Mobile 中生效。

## 设置休息提醒

1. 转到**设置 > 健康**（或在较旧的设置布局中转到**设置 > 时间和专注**）。

2. 在**休息提醒**下，使用下拉菜单选择每天与 Claude 互动多长时间后您会收到提示。

当您达到设定的时长时，Claude 会显示一个提醒。您可以停止、延迟或关闭它并继续。

## 设置安静时段

1. 转到**设置 > 健康**（或在较旧的设置布局中转到**设置 > 时间和专注**）。

2. 在**安静时段**下，点击您希望应用安静时段的星期几。

3. 为这些天选择开始和结束时间。

如果您在安静时段期间打开 Claude，您会看到一个提醒，告诉您已将此时间预留。选择"继续"以继续或稍后返回。

## 更改或移除设置

返回**设置 > 健康**（或在较旧的设置布局中返回**设置 > 时间和专注**）以编辑您的休息提醒或安静时段。要移除休息提醒，请清除下拉菜单。要从某一天移除安静时段，请点击该天以取消选择。
