# 查看 Team 和 Enterprise 计划的使用分析

本文介绍如何查看和导出组织的使用分析。

使用分析可供 Team 计划的所有者和主要所有者，以及 Enterprise 计划的所有者、主要所有者和管理员使用。Enterprise 管理员可以查看除支出外的所有分析。

使用分析可帮助您直接从管理员仪表板跟踪团队活动、功能采用情况和支出。您可以监控组织如何使用 Claude，并导出详细报告供自己分析。

主要所有者和所有者可以通过点击左下角的首字母缩写并从菜单中选择 **[Analytics](https://claude.ai/analytics/overview)** 来访问专用分析设置中的分析。此外，Chat、Claude Code、Claude Design 和 Cowork 选项提供特定于产品的分析，Surveys 选项让您可以直接向用户询问他们的体验。

## 导出支出报告

您可以将详细的支出报告导出为 CSV 文件。该报告提供在选定时间段内按用户、按模型的令牌使用情况和估计支出的可见性，每日更新。

要导出支出数据：

1. 导航到 **[设置 > 分析](https://claude.ai/analytics/activity)**。

2. 向下滚动到 **Claude 的成本是多少？** 部分。

3. 点击"导出支出报告"按钮。

4. 选择时间段：MTD、上个月、过去 90 天或自定义。

5. 如果您选择"自定义"，请选择您的开始和结束日期。您最多可以回溯 90 天，最近可用的数据来自昨天。

6. 点击"下载"。

### 报告中包含什么？

CSV 中的每一行代表特定人员对特定模型的使用情况，支出汇总到为导出选择的整个日期范围。报告包括以下字段：

- 用户的电子邮件

- 账户 UUID

- 产品（如 Chat、Claude Code、Cowork 或 Office Agents）

  - Office Agents 汇总来自 Excel、PowerPoint 和 Word 的 Claude 加载项的使用情况。

- 模型和模型系列

- 请求计数 (`total_requests`)

  - 向 Claude 发出的单个 API 调用次数。每当应用或用户发送消息并获得响应时，都会计为一个请求。

- 提示令牌 (`total_prompt_tokens`)

  - 每个请求的输入端消耗的令牌数。这包括系统提示、对话历史、用户消息、工具定义等。

- 完成令牌 (`total_completion_tokens`)

  - Claude 响应时生成的令牌数*，*包括扩展思考令牌。

- 净支出 (`total_net_spend_usd`)

  - 应用任何折扣、额度或协议费率后的成本（以 USD 计）。这是您实际支出的金额。

- 总支出 (`total_gross_spend_usd`)

  - 应用任何折扣或额度前的成本（以 USD 计）。

分析聊天、分析 API 和从分析仪表板导出的支出报告应与您的发票密切匹配。按项目标签分组的支出可能不匹配。分析 API 的成本和使用端点包括折扣价和列表价。

**注意：**之前在 Claude Code 下分组的某些活动（包括代码审查和安全功能）现在显示为单独的行项目。

**重要：**支出数据每天刷新，延迟一天。对于基于使用量的企业计划，导出会捕获您组织的完整使用情况。对于启用了使用额度的基于席位的企业计划，**导出仅反映超过您席位分配的支出。**

## 打开或关闭个人使用分析

**注意：**个人使用分析可供使用量计费的企业组织使用。**成员分析**切换不会出现在团队计划组织或基于座位的企业组织中。

所有者和主要所有者控制成员是否可以看到此视图。该设置适用于整个组织。

1. 导航到**[组织设置 > 使用情况](https://claude.ai/admin-settings/usage)**。

2. 找到**成员分析**切换。

3. 打开或关闭它。

**注意：**自 2026 年 7 月 11 日起，个人使用分析默认打开。如果您想保持成员级别的可见性关闭，请更改设置。

## 以编程方式访问您的分析数据

如果您使用企业计划并想将分析数据拉入您自己的仪表板或报告工具，分析 API 可让您以编程方式访问分析仪表板中提供的相同使用情况和参与指标。要开始使用，请参阅我们的**[分析 API 文档](https://platform.claude.com/docs/en/manage-claude/analytics-api)**。

**重要**：只有您组织的主要所有者才能从**[组织设置 > API](https://claude.ai/admin-settings/api-access)** 启用分析 API 并创建分析 API 密钥：在**API** 下，打开分析 API；在**密钥**下，单击"+ 创建密钥"并选择 `read:analytics` 范围。所有者和管理员根本看不到该页面上的分析 API。这是预期的，不是权限错误——请要求您的主要所有者启用它并创建密钥。如果您的组织链接到父组织，则由父组织的主要所有者执行此操作。
