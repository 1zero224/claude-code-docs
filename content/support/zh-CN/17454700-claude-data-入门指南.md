# Claude Data 入门指南

Claude Data 将关于贵公司数据的问题转化为仪表板、数据故事、叙述性短视频和报告。连接数据仓库或其他应用，用自然语言提问，Claude 会编写查询并生成结果。

本指南涵盖连接数据、创建和优化工作以及共享内容。Claude Data 之前称为 Claude Dashboards，您已创建的仪表板继续正常运行。

Claude Data 可在 Pro、Max、Ultra、Team 和 Enterprise 计划中使用。认证查询和实时共享处于测试阶段。在 Team 计划中，Claude Data 和两项测试功能默认启用。在 Enterprise 计划中，Claude Data 将于 2026 年 11 月 20 日默认启用（除非所有者已保存设置），两项测试功能默认关闭。

## Claude Data 的工作原理

Claude 为每个图表编写 SQL 查询并针对您的数据源运行。每个图表都显示其查询，因此您可以准确看到它在计算什么，以及数据上次刷新的时间。

仪表板是您可以创建的一种格式。您也可以请求：

- **Scrollyteller：**由您的数据构建的滚动故事

- **Visual short：**讲解您数据的短视频

- **Visual analysis：**您数据的书面总结

仪表板用于快速探索性问题，例如本周的注册与上月的比较。当问题需要更深入的分析时，将仪表板发送到另一个工具并在那里继续。

您创建的所有内容都保存在**工件**选项卡中。详细了解**[工件及其使用方法](https://support.claude.com/en/articles/17153992)**。

## 连接您的数据

在创建任何内容之前，连接您想要查询的数据：

- **数据仓库：**连接您公司的数据平台，例如 Amazon Redshift、BigQuery、ClickHouse、Databricks 或 Snowflake。

- **您已连接到 Claude 的其他应用：**例如，请求您的 Salesforce 机会仪表板。

详细了解**[将您的应用连接到 Claude](https://support.claude.com/en/articles/11176164)**。

## 使用 Claude Data 创建

### 从聊天开始

在任何聊天中询问 Claude。例如：

- “构建本季度按地区划分的收入仪表板。”

- “显示过去六个月的每周注册数，按计划分类。”

- “将本季度的收入数据转化为数据故事。”

### 从工件选项卡

1. 转到“工件”选项卡。

2. 选择“数据。”

3. 描述您想要创建的内容。

### 获得更好结果的提示

说出您想了解的内容，而不仅仅是要绘制的内容。“本月按渠道的注册与上月相比如何？”比“注册图表”能让您走得更远。如果数据位于特定表或应用中，请命名它。

### 优化您的工作

- **询问 Claude：**在聊天中请求更改，例如“添加地区筛选器”或“将其更改为每周视图。”

- **直接编辑：**点击标题、标题或图表进行自己的更改，无需询问 Claude。

- **检查查询：**打开图表的查询以查看 Claude 如何获得该数字。如果它没有计算您的意思，告诉 Claude 要更改什么。

### 恢复早期版本

版本历史显示早期版本。您直接进行的编辑也会出现在那里。

1. 打开仪表板并打开其版本历史。

2. 选择一个版本进行预览。预览是只读的，不会更改仪表板。

3. 点击“恢复。”

仪表板对打开它的所有人都恢复到该版本，恢复在版本历史中显示为其自己的条目。具有仅查看访问权限的人员无法编辑仪表板或恢复版本。

### 数据如何刷新

当有人打开仪表板且数据需要刷新时，Claude 会刷新仪表板的数据。它不按计划刷新，但**刷新数据**根据指定的间隔和用户访问模式智能地重新查询数据。

## 使用认证查询（测试阶段）

认证查询是您的数据团队已批准的官方查询。Claude 在构建新仪表板时可以重复使用它们。基于认证查询构建的图表带有徽章。要检查数字，请点击它或打开数据侧边栏。

您的数据团队可以直接在 Claude 中认证查询，或使用它在 dbt、Looker 或 Cube 中已有的定义（通过现有 MCP 连接器）。  任何对数据工件具有写入权限的人都可以认证。

**要认证查询：**

1. 打开图表的查询并编辑它。

2. 启用“认证查询。”

3. 为 Claude 添加任何说明，每行一条。

4. 点击“测试。”

5. 点击“发布。”

检查完成后，查询显示为已认证。

**注意：**编辑认证查询会移除其认证。要自己移除认证，请关闭“认证查询”并点击“发布。”使用该查询的仪表板会失去其认证徽章。

如果您的组织在 Git 支持的插件中存储认证查询，请改为在 GitHub 中通过拉取请求审查来管理它们。

## 共享和发送您的工作

您在 Claude Data 中创建的所有内容最初仅对您私密。要共享它，请打开它并点击“共享。”它们也可以在您的组织外共享。详细了解**[共享工件](https://support.claude.com/en/articles/9547008)**。

## 与您的组织共享实时结果（测试阶段）

没有实时共享，共享仪表板会使用每个人自己的连接加载数据。使用实时共享，您组织中的人员可以看到您的结果，包括保存的结果。它仅限于仪表板需要的确切查询，这些查询在没有编辑者批准的情况下无法更改。

要启用实时共享，请访问工件上的**源**菜单，并在每个 MCP 连接器旁选择“您的访问权限”。

**重要：**实时共享基于您对数据源的访问权限运行。与您共享仪表板的任何人都会看到这些结果，即使他们无权访问该源。在以这种方式共享仪表板之前，请检查它显示的内容。

## 使用情况

Claude Data 计入您计划的使用限制，与您在 Claude 中的其他工作一样。详细了解**[使用和长度限制如何工作](https://support.claude.com/en/articles/11647753)**。

## 为您的组织启用 Claude Data

本部分适用于 Team 和 Enterprise 计划上的所有者和主要所有者。

所有者在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中管理 Claude Data，在**模板**下。认证查询和实时共享在**数据**下有自己的设置。在 Enterprise 计划中，所有者可以使用自定义角色将 Claude Data 限制为特定组。详细了解**[Team 和 Enterprise 计划的工件管理员指南](https://support.claude.com/en/articles/16994751)**。
