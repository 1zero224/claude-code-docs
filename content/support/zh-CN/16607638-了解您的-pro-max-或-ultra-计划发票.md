# 了解您的 Pro、Max 或 Ultra 计划发票

本文介绍了您将收到的 Pro、Max 或 Ultra 计划发票、在哪里找到它们，以及如何阅读其中的费用。

本文涵盖在网络上购买的 Pro、Max 和 Ultra 计划。如果您通过 Claude for iOS 或 Claude for Android 订阅，Anthropic 不会向您发出发票。Apple App Store 或 Google Play 会直接向您收费，您的收据可在您的应用商店账户中获取。

## 您可能收到的发票类型

**订阅发票。**每次您的计划续订时，您都会收到一份发票：按月计划每月一次，或按年计划每年一次。您的订阅会自动续订，直到您取消为止。

**计划变更发票。**如果您在计费周期中途升级计划，您的计费周期将重置，您将立即收到变更发票，而不是等待下次续订。例如，从 Pro 升级到 Max 会向您收取一整月的 Max 费用，减去您当前计费周期中旧计划的未使用价值。

详细了解**[注册 Max 或 Ultra 计划](https://support.claude.com/en/articles/11049752)**。

**使用额度收据。**如果您已启用使用额度，每次购买资金都会与您的订阅分开收费，并有自己的收据。这包括自动重新加载自动进行的购买和您购买的任何使用套餐。

详细了解**[管理付费 Claude 计划的使用额度](https://support.claude.com/en/articles/12429409)**。

## 查找您的发票

每次收费后，我们会自动将发票发送到您的账单邮箱。要在收件箱中查找过去的发票，请搜索主题行"您来自 Anthropic 的收据"。

您也可以从您的账户打开任何发票：

1. 转到**[设置 > 账单](https://claude.ai/settings/billing)**。

2. 找到**发票**部分。

3. 点击您要打开的发票旁边的"查看"。

## 阅读您的发票

**按比例分配的费用。**当您在计费周期中途升级时，您需要支付新计划的一整个计费周期的费用，减去旧计划当前周期中剩余价值的按比例分配金额。您的下次续订发票将收取全价。

**额度。**对于某些中途计划变更，新计划一个周期的成本可能低于旧计划当前周期的剩余价值。在这种情况下，旧计划的任何超额价值将作为额度存储在您的账户中，并将自动用于支付未来的发票。

**税费。**税费根据您的账单地址计算，该地址来自您的付款方式的地址。详细了解**[您的账单地址和税费计算](https://support.claude.com/en/articles/12997130)**。

**已应用余额。**"已应用余额"行表示您账户中已有的额度被用于支付发票的全部或部分费用。这不是新费用，也不是该发票的折扣。

**应付金额。**发票总额减去任何已应用余额。这是您的付款方式被收费的金额。

## 发票上的账单详情

发票上的名称和地址来自发票签发时的付款方式。要显示不同的名称（例如公司名称），请在**[设置 > 账单](https://claude.ai/settings/billing)**中添加或更新付款方式时勾选"在发票上使用不同的名称"。

您也可以添加税号或增值税号。详细了解**[向您的付费 Claude 账户添加税号或增值税号](https://support.claude.com/en/articles/9889408)**。

如需帮助更新您的付款方式或其他账单详情，请参阅**[付费计划账单常见问题](https://support.claude.com/en/articles/8325618)**。

对账单详情的更改仅适用于未来的发票。发票签发后，我们无法编辑或重新签发。

## 常见问题

### 为什么我的发票与我的计划价格不符？

最常见的原因是在计费周期中途进行计划变更（按比例分配收费），或者额度或已应用余额减少了应付金额。两者都在发票上显示为单独的行项目。

### 为什么我在同一个月收到了两份收据？

如果您使用使用额度，这些购买会与您的订阅分开计费。一份收据是您的计划，另一份是您添加的使用额度，无论您是自己添加还是自动重新加载添加的。

### 您能更正我已收到的发票上的详情吗？

不能。已签发的发票无法更改。在**[设置 > 账单](https://claude.ai/settings/billing)**中更新您的账单详情，更改将显示在您的下一份发票上。

### 我可以用不同的货币开具发票吗？

某些订阅者使用与其地区新订阅者将被提供的货币（或货币）不同的货币支付订阅费用。要更改您的订阅货币，您必须首先将您的计划标记为在当前期限结束时取消，并等待期限结束。然后，当您重新购买新的 Pro、Max 或 Ultra 计划时，您将使用与您地区的新订阅者相同的货币（或货币选项）。

### 我在哪里可以看到我的每月 API 额度？

在 Claude 控制台中。所有额度都显示在您链接的控制台组织的**[设置 > 账单](https://platform.claude.com/settings/billing)**下，包括其金额和过期日期。使用费用永远不会计入您的 Claude 计划。详细了解**[Max、Ultra 和 Team 计划的每月 API 额度](https://support.claude.com/en/articles/17154008)**。
