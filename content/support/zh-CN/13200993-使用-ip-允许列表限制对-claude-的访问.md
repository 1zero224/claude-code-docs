# 使用 IP 允许列表限制对 Claude 的访问

IP 允许列表仅适用于企业计划。

IP 允许列表使企业计划管理员能够控制哪些 IP 地址可以通过其组织访问 Claude。此功能确保只能从已批准的网络位置发出请求，提供额外的安全保护层。

启用后，我们会根据您组织配置的允许列表验证每个经过身份验证的请求的源 IP 地址。来自未添加到允许列表的 IP 地址的请求将被阻止。

IP 允许列表支持 CIDR 范围。例如：`10.0.0.0/8, 2001:db8::/32`。

## IP 允许列表涵盖的内容

启用 IP 允许列表后，以下内容仅可从您的允许列表中的 IP 地址访问：

- 聊天和项目

- 工件，包括 Claude Docs 和其他工件类型

- 在您的组织内共享的工件链接

- Claude Docs 中的实时编辑和协作

- 从连接的工具访问 Claude Docs

如果您组织中的某人从不在您的允许列表上的 IP 地址打开工件，他们会看到访问被拒绝的消息，而不是内容。

**重要提示：**在您的组织外共享的工件不受您的允许列表限制。要将工件保留在您的允许列表后面，请在**组织设置 > 工件**中关闭**外部共享**和**组织外的电子邮件邀请**。您已允许外部共享的工件将继续在您的允许列表外可用。了解有关**[管理组织外共享](https://support.claude.com/en/articles/16994751-artifacts-admin-guide-for-team-and-enterprise-plans#h_fd0c095985)**的更多信息。

## 如何配置 IP 允许列表

如果您的企业组织有兴趣启用 IP 允许列表，请编译您的组织所需的所有 CIDR 范围列表，包括办公地点、VPN 出口点和任何其他已批准的访问点。遗漏所需的 CIDR 范围可能导致用户被锁定在 Claude 之外。然后，请联系您的 Anthropic 联系人或我们的**[支持团队](https://support.claude.com/en/articles/9015913)**来共享您的 CIDR 范围列表。他们可以将这些添加到您帐户的允许列表中以启用该功能。

当请求来自不在您的允许列表中的 IP 地址时，访问被拒绝。如果用户认为他们被错误地阻止，应联系其 IT 管理员。
