# 开始使用 Claude Design

**[Claude Design](https://claude.com/product/design)** 让你可以通过与 Claude 聊天来创建设计、交互原型、单页文档和其他视觉作品。它是你可以从中启动工件的模板之一，因此你可以在任何聊天、Claude Code 中以及从 **工件** 标签页中使用它，包括画布上编辑和你的设计系统。本指南将引导你创建第一个设计、对其进行迭代，以及充分利用它。了解更多关于 **[什么是工件以及如何使用它们](https://support.claude.com/en/articles/9487310)**。

Claude Design 在免费、专业版、Max、Ultra、团队和企业计划中可用，默认启用。在企业计划中，它将在 2026 年 10 月 15 日默认启用，所有者可以在此之前在 **[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)** 中启用它。claude.ai/design 上的独立版本将在 2026 年 12 月 14 日关闭。了解更多信息，请参阅 **[从独立 Claude Design 迁移到 Claude](https://support.claude.com/en/articles/17440474)**。

本指南假设你的组织的设计系统已经设置完毕，因此你创建的所有内容都将自动使用你品牌的颜色、排版和组件模式。如果你是需要设置或修改设计系统本身的设计负责人，请参阅 **[在 Claude Design 中设置你的设计系统](https://support.claude.com/en/articles/14604397-set-up-your-design-system-in-claude-design)**。

## 你可以在哪里使用 Claude Design

- **在对话中：**向 Claude 请求设计，例如 “从这个提案中制作一个单页文档” 或 “模拟我们刚才讨论的入职流程。” Claude 会在你的对话旁边构建它，你可以在那里完善它。你也可以在消息框中选择 **输出** > **设计**。

- **在工件标签页中：**转到 **工件** 标签页并选择一个设计模板。

- **在 Claude Code 中：**要求 Claude 将你的想法变成设计，或使用 /design 在桌面或终端中创建、编辑和同步设计。

- **在 iOS 和 Android 的 Claude 应用中：**在任何对话中请求设计，稍后返回查看结果，然后在 **工件** 标签页中全屏查看。你也可以编辑设计。要更改共享设置，请在网页或桌面上使用 Claude。

- **在 claude.ai/design：**独立版本将继续工作，直到 2026 年 12 月 14 日关闭。你的现有项目将保留在那里直到关闭，迁移到 Claude 的功能正在逐步向付费计划推出。在独立版本关闭前将你的设计系统迁移到 Claude。了解更多信息，请参阅 **[从独立 Claude Design 迁移到 Claude](https://support.claude.com/en/articles/17440474)**。

## Claude Design 的工作原理

Claude Design 将对话与画布配对。你描述你想要的内容，Claude 在对话旁边的画布上生成一个可工作的设计。从那里，你进行迭代——通过对话、内联注释和直接在画布上编辑来完善，直到达到你的要求。

典型的流程是：

1. 从对话或 “工件” 标签页启动设计。

2. 附加或导入你希望 Claude 使用的设计系统。

3. 添加任何相关上下文（屏幕截图、代码库）。

4. 描述你想要构建的内容。

5. 查看 Claude 在画布上生成的内容。

6. 通过聊天完善、直接在画布上编辑或留下内联注释。

7. 当你对结果满意时导出或共享。

### 在 Claude Design 和 Claude Code 之间切换

你可以在 Claude Design 和 Claude Code 之间切换工作，同时保持你的工作同步。使用 /design-sync 来引入你的设计系统，这样你在 Claude Design 中构建的所有内容都从你现有的组件开始。当设计准备好成为软件时，你可以将其交接给 Claude Code，它从你现有的工作继续，而不是从屏幕截图重新开始。

从 Claude Code 中，使用 /design 将设计导入到你的代码库中、将你的代码导出为实时原型，或让 Claude 从头到尾构建整个项目。

## 创建新项目

当你创建项目时，它会自动继承你的组织的设计系统。你不需要上传品牌资产或配置任何内容——你的品牌颜色、字体和组件已经就位。

### 附加或导入你的设计系统

使用 Claude Code 中的 /design-sync 命令从 GitHub 仓库、设计文件、原始上传或你的本地代码库中引入一个或多个设计系统。Claude 使用你真实的设计系统组件进行构建，根据你的设计系统检查自己的输出，并在你看到之前进行更正。

在企业计划中，管理员可以为特定用户保留发布、设置默认值和删除设计系统的权限。了解更多信息，请参阅 **[团队和企业计划的工件管理员指南](https://support.claude.com/en/articles/16994751)**。

### 从 claude.ai/design 迁移设计系统

你在 claude.ai/design 独立版本中创建的设计系统可以迁移过来，这样 Claude 可以在任何聊天中使用它们，包括在 Claude Code 中。在独立版本于 2026 年 12 月 14 日关闭前迁移它们。了解更多信息，请参阅 **[从独立 Claude Design 迁移到 Claude](https://support.claude.com/en/articles/17440474)**。

### 为你的项目添加上下文

你提供给 Claude 的上下文越多，你的输出就会越好。你可以在项目的任何阶段附加参考资料。

- **屏幕截图、图像或现有资产：**上传现有设计、竞争对手产品、线框图或视觉灵感的屏幕截图。你也可以附加一个现有的幻灯片或包含你想要复制的设计风格的文档。适用于 “让它看起来像这样” 的请求。

- **代码库和现有设计文件：**链接代码仓库，以便 Claude 了解你现有的组件、架构和样式模式。这使原型从一开始就更接近生产就绪。导入还支持多种方式来上传现有产品设计工作。

### 编写有效的提示

你不需要是设计师就能获得出色的结果。具体说明你正在构建什么、它是为谁构建的，以及什么最重要。

一个好的提示包括 **目标**（你正在构建什么）、**布局**（事物应该如何排列）、**内容**（要显示什么信息）和 **受众**（谁将使用它）。如果需要更多信息，Claude 也会提出澄清问题。

以下是一些效果很好的提示示例：

- “创建一个显示月度收入的仪表板，包含按地区和产品线的筛选器。”

- “设计一个包含 4 个屏幕的移动应用入职流程，引导用户了解我们的核心功能。”

- “为我们的新 API 产品构建一个登陆页面，包含英雄部分、代码示例和定价。”

- “创建一个表单来收集客户反馈，包含基于类别的条件问题。”

- “为我们的运营团队设计一个内部工具，用于审查和批准内容提交。”

## 完善你的设计

第一代是一个起点。真正的价值来自于迭代。

### 使用聊天

聊天最适合影响整体设计的广泛更改：

- “使配色方案更深、更简洁。”

- “重新排列仪表板，使指标在顶行，图表在下方。”

- “在右侧添加设置面板。”

- “为我展示此页面的 2–3 种替代布局。”

您也可以要求 Claude 解释其设计决策、提出改进建议或审查设计的可访问性。

### 使用内联注释

内联注释让您可以直接点击画布上的特定部分并请求有针对性的更改。这比在聊天中描述位置更快。

良好内联注释的示例：

- “增大此按钮的内边距。”

- “将其改为下拉菜单而不是单选按钮。”

- “在此处使用主品牌颜色。”

- “使此部分可折叠。”

**注意：**如果您的注释未被识别，请将反馈直接粘贴到聊天中。这是一个已知的解决方法，用于解决注释在 Claude 读取前可能消失的间歇性问题。

### 直接在画布上编辑

使用丰富的布局控件进行快速的视觉和美学调整，特别是直接拖动、调整大小和对齐元素。

### 何时使用聊天、注释或直接编辑

使用**注释**进行有针对性的组件级更改（“修复此按钮，”“调整此间距”）。使用**聊天**进行结构更改、新增部分或任何需要解释或上下文的内容。**直接编辑**进行快速的视觉和美学更改。

## 使用键盘操作 Claude Design

要进入和退出工件面板，以及从面板标题进行注释，请参阅**[使用键盘或屏幕阅读器操作工件](https://support.claude.com/en/articles/17457950)**。该文章还解释了焦点的含义、在 Mac 笔记本电脑或 Safari 中的操作方法，以及表格如何显示按键。

设计是一个画板的画布。每个画板包含图层，如文本、形状和图像，一个图层可以在其内部包含其他图层。

### 在编辑器的区域之间移动

按 F6 移动到下一个区域，按 Shift+F6 移动到上一个区域。Cmd+F6（Windows 上为 Ctrl+F6）可代替 F6 使用，无论是否带 Shift。这些区域是顶部栏、画布和属性面板。当选中某项且属性面板关闭时，F6 也会停在浮动在选区上方的工具栏。

**注意：**在按 F6 之前完成文本编辑。先按 Escape 或 Tab 结束编辑。F6 会在不结束编辑的情况下将您移出文本编辑。

### 在画板内工作

按 Tab 直到到达画板的标题。其名称包括其位置，例如第 1 个（共 7 个）画板。从标题处，按 Space 选择画板，按 Return 进入其内部的图层。进入后：

- Tab 和 Shift+Tab 在图层之间移动。Home 和 End 移动到第一个和最后一个图层。

- 在包含其他图层的图层上按 Return 会进入其内部。在文本图层上，Return 开始编辑。

- Shift+Return 上升一个级别。

- Escape 离开画板，画板保持选中状态。再按一次 Escape 清除选择。

当您编辑文本图层时，移动时按 Escape 或 Tab 完成。编辑器会告诉屏幕阅读器选中的内容及其位置，例如第 1 个（共 5 个）。

### 移动、复制和删除

要移动画板，请选中它（在其标题上按 Space）并按箭头键。它每次移动一个像素，或按 Shift 时移动 10 个像素。在画板内，箭头键的作用不同：无论是否按 Shift，它们都会将您移动到下一个或上一个图层，永远不会移动图层本身。要移动您所在的图层，请按住 Option（Windows 上为 Alt）并按箭头键。自由放置的图层每次移动一个像素，或按 Shift 时移动 10 个像素。属于行、列或网格的图层会与其邻近图层交换位置：Up 或 Left 将其向前移动，Down 或 Right 将其向后移动。编辑器会向屏幕阅读器发送移动的简短确认。

选中画板或图层后，按 Cmd+D（Windows 上为 Ctrl+D）复制它，按 Delete 或 Backspace 删除它。按 Cmd+Z（Windows 上为 Ctrl+Z）撤销。编辑器会向屏幕阅读器发送每个操作的简短确认。

### 使用选区上方的工具栏

浮动在选区上方的工具栏仅在属性面板关闭时出现，F6 可以到达它。在其中，箭头键在其控件之间移动，Home 和 End 移动到第一个和最后一个，Escape 返回到画布并保持您的选择。您也可以使用 Tab 到达每个控件。

### 使用属性面板和图层列表

按 Cmd+\（Windows 上为 Ctrl+\）打开属性面板并将焦点移入其中。再按一次关闭面板，焦点返回到顶部栏中的“属性”按钮。面板中的颜色、字体和其他弹出窗口在打开时获得焦点，Escape 关闭它们。当您选择文本颜色时，颜色选择器会告诉您其与背景的对比度是好还是差。

在属性面板的图层列表中：Up 和 Down 箭头键在行之间移动，Right 箭头键展开一行然后进入其内部，Left 箭头键折叠它然后移出，Return 或 Space 在画布上选择该图层，在文本图层上再按一次 Return 进行编辑。

**警告：**在图层列表中，Delete、Backspace 和 Cmd+X（Windows 上为 Ctrl+X）作用于画布上选中的任何内容，这可能不是您移动到的行。先在该行上按 Return。

## 使用情况和定价

Claude Design 计入与 Claude 其余部分相同的使用限制。设计活动从与您在 Claude 上的其他工作相同的池中提取，包括 Claude Code，因此没有单独的 Claude Design 额度需要跟踪。具有大型代码库或多次迭代的复杂项目会消耗更多使用量。

如果您达到使用限制，Claude Design 将不可用，直到您的限制重置。如果您启用了使用额度，在达到包含的限制后可以继续工作。详细了解 **[使用情况和长度限制如何工作](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work)**。

**注意：**Claude Design 之前有自己的每周额度，与您的其他使用限制分开。所有 Claude Design 活动现在计入您计划的共享限制。

## 获得最佳效果的提示

- **导入完整的设计系统。**导入包含您的样式、字体和组件的完整设计系统。

- **从简单开始，然后逐层增加复杂性。**从核心布局和内容开始，然后添加交互、边界情况和打磨。Claude 对增量请求反应良好。

- **在反馈中要具体。**“这看起来不对” 很难执行。“将表单字段之间的间距紧缩至 8px” 给 Claude 提供了它需要的确切信息。

- **参考您的设计系统。**如果您知道组件存在于您的品牌系统中，请按名称提及：“使用主按钮组件” 或 “应用卡片布局模式。”

- **尽早考虑响应式设计。**提及您的设计是否需要在移动设备、平板电脑和桌面上工作，或仅在其中一个上工作。

- **要求变体。**如果您不确定某个方向，请要求 Claude 向您展示 2-3 个选项。比较替代方案比猜测快得多。

- **向 Claude 征求反馈。**Claude 可以审查您的设计的可访问性、对比度、信息层次结构和一般可用性。将其视为设计协作者，而不仅仅是生成器。

## 已知限制

需要注意的几点：

- **评论持久性：**内联评论有时不会出现在页面上，但您仍然可以通过打开评论视图来查看它们。

- **大型代码库：**考虑从 Claude Code 链接非常大的存储库以避免延迟或浏览器问题。要同步设计系统，请从 Claude Code 使用 /design-sync。

- **聊天错误：**如果您遇到 “聊天上游错误，” 请尝试在同一项目中启动新的聊天标签页。

- **移动设备：**无法在 iOS 和 Android 的 Claude 应用上更改分享设置，因此您需要使用 Claude 网页版或桌面版。

- **多人编辑：**两个或多个人同时编辑设计项目仍然是基础功能，可能无法可靠地工作。

- **设计系统导入：**设计系统导入的质量取决于其源。混乱的代码库或不完整的文件将显示在输出中。

- **版本历史：**Claude Design 还没有版本历史。

- **从图层列表中删除：**在属性面板的图层列表中，删除、退格和剪切作用于画布上选中的内容，而不是您移动到的行。请先在该行上按 Return。

- **使用键盘添加到设计中：**在画布上放置新的文本图层、画板、形状或注释需要鼠标或触控板。请要求 Claude 添加它。
