# 查看您的每月回顾

您的每月回顾展示了您如何使用 Claude——您花时间的主题、您倾向于何时使用它，以及您可能想尝试的新方向。它旨在客观地反映您的使用模式，让您可以决定是否以及如何改变。

每月回顾目前处于测试阶段，适用于使用 Claude 网页版或 Claude Desktop 的免费版、专业版、最大版和超级版用户。仅当启用记忆功能时才会显示，团队版和企业版计划不可用。它在提供 Claude 的所有地区都可用。

## 打开您的回顾

1. 在网页上打开 Claude 或打开 Claude Desktop。

2. 转到**设置 > 健康**，在**反思**下选择"查看"（或在较旧的设置布局中转到**设置 > 反思**）。

3. 您的回顾将加载过去一个月的数据。点击顶部的"过去一个月"下拉菜单，选择另一个选项以加载不同时间范围的回顾（本月至今、过去 3 个月、过去 6 个月、过去一年）。

4. 您可以点击下拉菜单旁的刷新图标来重新生成当前时间范围的回顾。

**注意：**此功能正在逐步推出。如果您还没有看到它，请稍后再检查。

### 开场摘要

一个简短的标题和段落，描述您与 Claude 的一个月。它列出了您对话中的实际工作和主题，而不是提供笼统的赞美。

您在该时期内向 Claude 提出的主题和话题的比例分解，每个都附有简短描述和百分比。

### 扩展您的技能

从您自己的对话中得出的观察，围绕四项 AI 流畅度技能展开：

## 您的回顾中包含的内容

Claude 从您最近的聊天中构建您的回顾。由于回顾依赖于为记忆功能提供支持的相同聊天历史记录，因此仅当启用记忆时才会显示。如果您关闭记忆，回顾将被隐藏。

您在 Claude Mobile 上的活动包含在您的回顾中，尽管该页面在移动设备上尚不可用。

### 来自连接服务的内容

当 Claude 从连接的服务（如 Gmail 或 Google Drive）提取内容时，您的回顾不会包含原始电子邮件或文件。它可能会包含 Claude 在聊天中关于它的任何内容。例如，如果您要求 Claude 总结您的收件箱，电子邮件本身不会被纳入您的回顾，但 Claude 编写的摘要会被纳入。

### 完全跳过的对话

某些对话完全被排除在您的回顾之外：

- 隐身聊天

- 使用健康集成（如 Apple Health 或 Health Connect）的对话

- Claude Cowork 和 Claude Code 中的活动

了解更多关于**[记忆](https://support.claude.com/en/articles/11817273)**、**[隐身聊天](https://support.claude.com/en/articles/12260368)**以及**[iOS](https://support.claude.com/en/articles/11869619-use-claude-with-ios-apps#h_21f4b10d6d)**和**[Android](https://support.claude.com/en/articles/11869629-use-claude-with-android-apps#h_62b72ef926)**上的健康功能。

## 您的回顾如何处理敏感话题

人们会向 Claude 提出各种各样的问题，有些对话涉及困难或个人话题。这些在您的回顾中得到谨慎处理：

- 敏感或与困扰相关的话题永远不会出现在您的回顾开头。

- 它们永远不会以计数或百分比的形式列出。

- 在适当的情况下，支持资源会与您的回顾一起显示。

## 关闭您的回顾

对于启用了记忆的符合条件的账户，默认情况下您的回顾是可用的。

您可以通过在**设置 > 您的 Claude**中关闭**从聊天历史生成记忆**来禁用它（或在较旧的设置布局中关闭设置 > 记忆）。回顾没有专用切换开关，因此如果启用了记忆设置，回顾也将被启用。即使启用了记忆，您的回顾仅在您打开它时生成（**设置 > 健康**，然后在**反思**下选择"查看"，或在较旧的设置布局中选择**设置 > 反思**页面）；如果您不打开它，Claude 不会为您创建回顾。

关闭回顾不会影响您的聊天历史或您已在**设置 > 健康**中设置的任何休息提醒或安静时段（或在较旧的设置布局中设置 > 时间和焦点）。

## 常见问题

### 查看我的回顾会使用我的计划配额吗？

查看您的回顾不会计入您的使用限制。如果您从页面上的建议开始对话，该对话将像任何其他聊天一样计入您的使用配额。

### 为什么我在设置中看不到反思？

检查记忆是否在**设置 > 您的 Claude**下启用（或在较旧的设置布局中设置 > 记忆），您是否在免费版、专业版、最大版或超级版计划上，以及您是否在网页上或 Claude Desktop 上使用 Claude。回顾在团队版或企业版计划上或在 Claude Mobile 上不可用。
​
在更新的设置布局中，您的回顾位于**设置 > 健康**下。

### 为什么百分比或统计数据看起来不对？

Claude 从您的聊天历史中生成您的回顾摘要和话题分解，因此比例或叙述摘要中可能会出现偶发的不准确。使用页面上的竖起大拇指反馈让我们知道是否有问题。如果您使用多个 Claude 账户，每个账户的回顾仅涵盖该账户。
