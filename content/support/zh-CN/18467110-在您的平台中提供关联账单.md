# 在您的平台中提供关联账单

本文介绍如何提供关联账单，让您的客户将自己的 Claude 控制台组织关联到您的应用。我们直接向他们收费，您无需保存他们的 API 密钥。

关联账单处于测试阶段。

## 关联账单的工作原理

客户使用 OAuth 将其 Claude 控制台组织关联到您的平台，而不是粘贴 API 密钥。您的平台保存连接 ID，而不是密钥。您为客户运行 Claude，我们直接向客户收费。

## 关联账单涵盖的内容

关联账单涵盖 `/v1/messages` 和 `/v1/chat/completions` 端点。您可以选择每个请求由谁付费：客户或您。

消息批处理 API 和 Claude 托管代理暂不支持。

客户付费的请求无法使用可计费的代码执行。API 返回 400 错误，因此请将这些请求作为平台付费发送。

如果仅部分功能向客户收费，请告知客户具体是哪些功能。除非所有 Claude 使用都向其组织收费，否则不要这样说。

关联账单仅适用于 Claude 控制台组织由 Anthropic 直接计费的客户。

以下内容无法关联：

- 通过云提供商（如 Bedrock、Vertex AI 或 Foundry）获取 Claude 的客户无法关联

- Claude 订阅计划（Pro、Max、Ultra、Team 和 Enterprise）无法关联

- 通过 AWS、Google Cloud 或 Azure 市场付款的 Claude 控制台组织无法使用关联账单

请求在您的平台组织中运行，而不是在客户的组织中运行。只有账单转到客户。客户组织中的设置（如 IP 允许列表、加密密钥和数据保留）不适用，内容根据您的组织与 Anthropic 的协议处理。

您的所有关联客户共享您的组织的速率限制、模型访问权限和服务层级。

## 从 API 密钥迁移客户

您可以继续提供客户 API 密钥以及关联账单，并按自己的节奏迁移客户。

要迁移客户：

1. 继续使用客户的 API 密钥，直到您存储了其连接 ID。

2. 将客户的请求标记为客户付费。

3. 删除存储的 API 密钥并告知客户您已删除。

## 设置关联账单

要设置关联账单：

1. 在 Claude 控制台中创建 OAuth 应用。

2. 在**应用可以执行的操作**下，选择“账单和关联到组织。”

3. 在提示时接受关联账单条款。

4. 在应用的**客户端身份验证**选项卡上，设置客户端身份验证、操作员服务账户和默认工作区。

5. 在您的应用中添加一个按钮来启动关联，例如“关联您的 Claude 组织。”使用我们的**[品牌示例](https://platform.claude.com/docs/en/manage-claude/oauth-apps/branding-samples)**。

6. 为每个将付费的客户组织创建一个用户配置文件。每个应用允许每个客户组织一个配置文件，每个配置文件一个客户组织。

7. 在客户应该付费的每个请求上，发送客户的配置文件 ID、账单测试版标头和 `billing_policy`，其中 `bill_to` 设置为 `user_profile`。

8. 准备好接受客户时发布应用。

新应用从测试开始。只有您列出的测试用户（最多 10 个）可以关联它，每个用户的月度限额为 $50 或更少。除非您的组织有发票账单、您验证了应用的域名且 Anthropic 审查了该应用，否则它才会上线。

### 关联规则

- 如果客户的组织已通过另一个配置文件关联到您的应用，则拒绝该链接。

- 已关联到您的应用的配置文件无法关联到第二个组织。

- 要移动链接，请先取消关联，然后重新关联。

- 您无法将应用关联到拥有它的 Claude 控制台组织。要像客户一样测试关联账单，请使用可以关联的第二个 Claude 控制台组织。

- 使用相同的用户配置文件 ID 来启动链接并发出该客户的请求。

- 命名没有链接的配置文件的客户付费请求被拒绝，返回 403 错误，即使客户的控制台将您的平台显示为**已关联**。

- 命名您其他客户配置文件的客户付费请求将向该客户收费。

要为您自己的使用付费，请发送不含 `billing_policy` 的请求。

有关完整步骤和标头值，请参阅**[Claude 平台文档](https://platform.claude.com/docs/en/manage-claude/oauth-apps/organization-billing-connections)**。

## 客户关联时看到的内容

当客户关联其组织时：

1. 他们点击您添加到应用中的按钮，例如“关联您的 Claude 组织。”

2. 他们登录 Claude。如果其电子邮件属于多个组织，他们选择一个。如果他们还没有 Claude 账户或 Claude 控制台组织，他们可以在此创建，添加额度，然后返回完成关联。

3. 他们阅读账单工作原理，然后为您的应用设置月度支出限额或继续不设置限额。如果您的应用仍在测试中，他们必须设置 $50 或更少的限额。

4. 他们看到一个批准页面，显示您的应用名称和您要求的内容。它说使用情况根据组织的现有账单条款计费。

5. 他们批准并返回到您的应用。

只有具有管理员或账单角色的用户才能批准。详细了解**[Claude 控制台角色和权限](https://support.claude.com/en/articles/10186004-claude-console-roles-and-permissions)**。如果其他人尝试批准，我们会将他们返回到您的应用并显示访问被拒绝错误。计划一个交接，例如一种将请求传递给管理员的方式。

一次批准涵盖整个组织。链接属于组织，因此如果批准者离开，它仍然保持活跃。每个组织每个应用可以有一个链接。

批准后，客户的管理员和账单成员通常会收到一封确认链接的电子邮件，以及在他们取消关联时收到另一封。

## 客户如何管理链接

客户在 Claude 控制台的**[关联平台](https://platform.claude.com/linked-platforms)**页面上管理每个链接。他们可以为您的平台设置月度支出限额并随时取消关联。从您的应用链接到此页面。

您也可以取消关联客户。您的组织中的管理员在**[用户配置文件](https://platform.claude.com/user-profiles)**页面上执行此操作。当您在控制台中取消关联他们时，客户不会收到电子邮件，因此请自己告诉他们。您也可以从后端取消关联客户，当您这样做时，Anthropic 通常会向他们发送电子邮件。

您也可以使用**[用户配置文件 API](https://platform.claude.com/docs/en/manage-claude/user-profiles)** 创建、列出和更新客户的配置文件。

## 管理未关联的客户

当客户取消关联时，Anthropic 不会向您的应用发送通知。当该客户的客户付费请求被拒绝并返回 403 错误时，或从控制台中您的**用户配置文件**页面上的**链接状态**，您会发现。403 也可能意味着客户因其他原因无法被计费。

**已关联**状态仅表示链接存在。请求仍然可能被拒绝，例如当客户信用额度不足或达到支出限额时。

取消关联通常在约 10 秒内停止新调用。已在运行的调用完成并向客户收费。向客户显示清晰的消息和重新关联的方式。

## 管理账单错误

如果无法向客户收费，我们拒绝该请求。我们不会为该请求向您收费。

- 如果客户已达到其支出限额或 Anthropic 目前无法向其收费（例如，因为其信用额度不足或已暂停），您会收到 402 错误。

- 如果 Anthropic 因任何其他原因无法向客户收费，您会收到 403 错误。

- 如果 Anthropic 目前无法确认客户是否可以被计费，您可能会收到 503 错误。使用退避重试，不要向客户显示错误。

402 意味着客户必须采取行动。要求他们在 Claude 控制台中检查其限额和账单。

您决定接下来会发生什么。您可以暂停该功能直到客户采取行动，或者您可以通过将请求作为平台付费重新发送来自己承担使用费用。如果您承担，请告知客户承担多长时间。

## 监控使用情况和支出

您可以看到每个客户的使用情况及其成本。您永远看不到客户实际支付的金额。

您可以通过两种方式监控每个客户的使用情况：

- **在 Claude 控制台中：**在**[用户配置文件](https://platform.claude.com/user-profiles)**页面上选择一个客户以查看其使用情况。**您的支出**仅是您代表客户支付的金额。

- **使用 API：**在**[使用情况和成本分析 API](https://platform.claude.com/docs/en/manage-claude/usage-cost-analytics-api)** 中按 `user_profile_id` 分组结果，该 API 处于测试阶段。使用情况端点返回令牌。在成本端点上，`amount` 是您的成本（扣除额度前），对于您的客户付费的请求为 0。`list_amount` 是列表价格的成本，无论谁付费。

两个视图都包括该客户的每个请求，无论谁付费。保留您自己的记录，记录哪些请求是客户付费的。API 数据通常在四小时内刷新，最多可能需要 24 小时。

## 常见问题

### 具有 HIPAA、FERPA 或 CMEK 要求的客户可以关联吗？

在测试期间不能。关联请求在您的组织中运行，因此客户的业务关联协议 (BAA)、加密密钥和保留设置（包括零数据保留）不适用。不要关联需要 HIPAA、FERPA 或 CMEK 覆盖的客户。

### 哪些额度可以支付关联使用？

关联使用向客户的预付余额或发票计费。某些促销额度无法使用。

**可以支付的内容**

- 客户购买的额度（其预付余额）

- 客户的发票（如果按月计费）

- 来自 Anthropic 的账单更正

- 写入客户协议中的额度

**无法支付的内容**

- **[Max、Ultra 和 Team 计划附带的每月 API 额度](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-ultra-and-team-plans)**

- 限制为特定产品的注册额度

- 来自 Anthropic 的合作伙伴、风险投资和初创公司计划的额度（我们仍在推出）

如果客户账户上没有任何内容可以支付，其请求可能被拒绝。客户添加资金后，购买可能需要一些时间才能应用。随着我们的额度计划的变化，我们可能会更新此列表。
