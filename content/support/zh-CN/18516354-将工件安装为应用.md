# 将工件安装为应用

您可以将 Claude 为您创建的工件作为应用安装到 Mac 或 Windows 计算机上。它拥有自己的窗口和图标，像任何其他应用一样打开，甚至可以像其他应用一样与操作系统交互。它使用户能够构建和共享自定义应用。本文介绍如何构建、安装、打开和卸载应用，以及它们的权限如何工作。

将工件安装为应用的功能正在 Free、Pro、Max、Ultra、Team 和 Enterprise 计划中以测试版形式推出。您需要 Claude for Mac 或 Claude for Windows 6.28899.0 版本或更高版本。

在 Team 计划中，此功能默认启用，但最高权限级别（对计算机的完全访问权限）默认关闭，直到管理员启用它。在 Enterprise 计划中，整个功能处于关闭状态，直到所有者在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中将其打开。在**[Team 和 Enterprise 计划的工件管理员指南](https://support.claude.com/en/articles/16994751-artifacts-admin-guide-for-team-and-enterprise-plans)**中了解更多信息。

## 工作原理

已安装的应用在其自己的窗口中显示您的工件。它仍然是同一个工件：当您或其他编辑者更改它时，应用也会随之更改。要打开应用，您需要在线并登录到 Claude Desktop。

应用可以像工件一样使用 Claude 和您的连接器。此外，当您明确允许时，已安装的工件可以与操作系统交互。这使它们能够运行程序、读取文件、发送通知或添加 macOS 菜单栏项目，具体取决于您允许的内容。在**[工件及其使用方法](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them)**中了解更多信息。

**注意：**“添加到 Dock”、“添加浏览器快捷方式”和“添加到主屏幕”在您的浏览器中仅添加快捷方式。它们没有此处描述的桌面功能。

## 构建应用

在聊天中描述您想要的应用。例如：

- “制作一个位于我菜单栏中的番茄工作法计时器。”

- “制作一个小型 Mac 应用，每小时提醒我伸展一下。”

- “制作一个 Windows 应用，按日期重命名文件夹中的照片。”

## 安装应用

要将工件安装为应用：

1. 在主 Claude Desktop 窗口中打开工件。

2. 打开工件的标题菜单，或右键单击工件。

3. 选择“安装为应用。”

4. 选择“安装”以确认。

您也可以在**共享**下找到**安装为应用**。工件也可以构建自己的安装按钮（如果要求的话）。无论您采用哪条路径，Claude 都会要求您确认安装。

如果您看不到“安装为应用，”请更新 Claude Desktop。在 macOS 上，转到**Claude > 检查更新**。在 Windows 上，转到菜单按钮 (☰) 下的**帮助 > 检查更新**。在 Team 和 Enterprise 计划中，询问所有者是否已启用此功能。某些类型的工件无法安装。请参阅下面的**当前限制**。

## 打开应用

要打开已安装的应用：

- **macOS：**从主文件夹中的应用程序文件夹内的**Claude 应用**文件夹中打开它。要在 Dock 中保留一个，右键单击其图标并选择**选项 > 保留在 Dock 中**。您也可以在 macOS Spotlight 和应用启动器中找到您的应用。

- **Windows：**从开始菜单（**Claude 应用**文件夹）或桌面上的快捷方式打开它。

- **在 Claude Desktop 中：**在工件上选择“打开已安装的应用”，或转到**文件 > 应用**，选择应用，然后选择“打开。”在 Windows 上，**文件**位于菜单按钮 (☰) 下。

具有菜单栏项目或系统托盘图标的应用在您关闭其窗口后继续运行。要在 macOS 上停止它，从 Dock 中退出它，或在它是活动应用时按 Cmd+Q。在 Windows 上，在其托盘图标的菜单中选择“退出”。

## 权限

应用必须在使用这些功能中的任何一个之前请求许可。您用“允许”或“不允许”来回答每个请求。

| **权限**                          | **应用可以执行的操作**                                   |
| ------------------------------- | ----------------------------------------------- |
| 通知                              | 在您使用其他应用时显示通知                                   |
| 键盘快捷键                           | 在您使用其他应用时响应按键组合                                 |
| 浮动在其他窗口上方                       | 在其他窗口上方绘制内容，并读取鼠标光标在您屏幕上的位置                     |
| 菜单栏项目 (macOS) 或系统托盘图标 (Windows) | 在应用打开时在那里显示一个项目                                 |
| 对此计算机的完全访问权限                    | 运行程序并读取、更改或删除您的文件，无需每次都询问。也涵盖上述权限，除非您或您的组织将其关闭。 |

“允许”涵盖应用的一个版本。在任何更新后（包括您自己的编辑），Claude 会再次询问。“不允许”会保持到您更改它为止。如果应用从另一个网站加载代码，该代码可以在没有新请求的情况下更改。

如果应用来自您的组织外部，或 Claude 无法确定谁创建了它，请求会显示警告。

### 完全访问权限

**警告：**具有完全访问权限的应用可以运行任何程序并读取、更改或删除您的文件。仅当您信任编写应用的所有人时才允许它。Anthropic 不会在您安装应用之前对其进行审查。

- 如果您的组织外部的人编写了应用的一部分，或 Claude 无法确认谁创建了它，Claude 通常不允许应用请求完全访问权限。

- 在 Free、Pro、Max 和 Ultra 计划中，“您的组织外部”意味着除您以外的任何用户。

### 更改或撤回权限

要更改或撤回权限：

- **macOS：**应用打开时，单击菜单栏中的应用名称并选择“权限。”

- **Windows：**右键单击应用的标题栏（或按 Alt+Space）并选择“权限。”

- **在 Claude Desktop 中：**应用打开时，转到**文件 > 应用**，选择应用，然后选择“权限。”

关闭完全访问权限可能会重新加载或关闭应用，因此请先保存您的工作。它会停止应用启动的程序，除了那些与应用分离的程序。它不会撤销应用已经进行的更改。

如果您失去对应用的访问权限，例如因为其所有者停止与您共享它，它启动的程序也会停止。这可能需要大约 20 分钟。当 Claude 无法检查时（例如当它离线、已登出或使用另一个组织时），可能需要更长时间。

要报告应用，请在与“权限”相同的菜单中选择“报告工件”（如果可用）。

## 卸载应用

要卸载应用：

1. 在 Claude Desktop 中转到**文件 > 应用**。

2. 选择应用。

3. 选择“卸载。”

在 macOS 上，应用移至垃圾箱。在 Windows 上，其快捷方式被删除。如果您将应用保留在 Dock 中或将其固定到任务栏或开始菜单，也请在那里删除它。

卸载会删除您允许的权限，但不会删除工件。如果工件被删除、下架或不再与您共享，当您打开应用时，Claude 通常会提供卸载应用的选项。

## 使用限制

构建应用以及应用向 Claude 发出的任何请求都计入您的计划使用限制。在**[使用和长度限制如何工作](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work)**中了解更多信息。

## 当前限制

将工件安装为应用处于测试阶段。在推出时：

- **平台：**应用在 Linux、Web 或移动设备上不可用。

- **模板：**从模板（如 Docs、Slides 或 Sheets）创建的工件无法安装。旧版工件或来自 Claude Cowork 的实时工件也无法安装。

- **HIPAA：**具有 HIPAA 就绪配置的组织无法使用应用。

- **教育：**在 Claude for Teachers 或 K-12 组织中无法使用完全访问权限。安装应用也可能关闭或不可用。

- **零数据保留 (ZDR)：**在具有 Claude Code 零数据保留的组织中，一旦所有者启用**工件**和**安装为应用**，您就可以安装应用。这些应用不受零数据保留保护。

- **计算机使用：**在 macOS 上，Claude 在使用您的计算机时可以看到已安装的应用，但无法在其中单击或输入。
