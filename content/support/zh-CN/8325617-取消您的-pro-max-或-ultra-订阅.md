# 取消您的 Pro、Max 或 Ultra 订阅

您可以随时通过遵循您注册的平台上的取消说明来取消您的 Pro、Max 或 Ultra 计划订阅。您的取消将在当前计费周期结束时生效，在此之前您可以继续使用您的付费计划。

**注意：**

- 为避免被收取下一个计费周期的费用，请在下一个账单日期前至少 24 小时取消您的订阅。

- Max、Ultra 和 Team 计划附带的每月 API 额度不是购买的，因此无法退款。它们在每个计费周期结束时过期。如果您取消或获得计划退款，新的每月额度将停止，您已有的额度将保持可用直到过期。

## 在 Claude 和 Claude Desktop 上取消您的 Pro、Max 或 Ultra 订阅

如果您在 Claude 网页版（**[claude.ai](https://claude.ai)**）或 Claude Desktop（Mac、Windows 或 Linux）上注册了付费计划，请先在网络浏览器中登录您的账户或打开桌面应用。点击左下角的您的首字母或名字，从菜单中选择

## 在 Claude for iOS 上取消您的 Pro、Max 或 Ultra 订阅

如果您通过 Claude for iOS 订阅了 Pro、Max 或 Ultra 计划，您的订阅和付款将直接在您的 iOS 设备上处理。

要取消您的订阅，请点击 Claude for iOS 右上角的您的首字母，然后从菜单选项中点击"账单"。选择
