# 我如何检查与Claude API的连接？

您可以按照以下步骤以编程方式验证您与 Claude API 的连接：

1. **创建 API 密钥：**您需要有效的 API 密钥才能向 API 发出请求。登录您的 [Claude Console 账户](https://platform.claude.com/)以[创建 API 密钥](https://platform.claude.com/settings/keys)。

2. **发出测试请求：**使用您的 API 密钥向 API 发出测试请求。您可以参考我们的[入门文档](https://platform.claude.com/docs/en/api/overview#examples)获取示例。

3. **验证请求成功：**检查您的测试请求是否成功。这可以包括检查响应状态代码、响应正文和任何错误消息。
