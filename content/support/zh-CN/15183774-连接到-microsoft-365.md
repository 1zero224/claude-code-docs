# 连接到 Microsoft 365

连接 Microsoft 365 让 Claude 可以搜索、分析和处理您的 Outlook 电子邮件、日历和 OneDrive 文件，以及 SharePoint 和 Teams（使用工作或学校账户）。向 Claude 询问您需要的内容，它会提取正确的信息或采取相应的行动。

Microsoft 365 连接器适用于所有 Claude 计划：免费版、专业版、Max、Ultra、Team 和企业版。您可以在免费版、专业版、Max 和 Ultra 计划上连接个人 Microsoft 账户。

您一次只能连接一个 Microsoft 账户。请转到您的账户部分：

- **[工作或学校账户](#h_0fa7577f04)**

- **[个人账户](#h_cffabf2c6c)**

这两个部分之后的部分适用于两种账户类型。

## 工作或学校账户

您的公司或学校为您提供此账户，该账户与 Microsoft Entra 租户相关联。它连接 SharePoint、OneDrive、Outlook 和 Teams。如果您的管理员启用了写入工具，Claude 还可以起草和发送电子邮件、管理日历事件、创建和更新文件以及发送 Teams 消息。如果您不确定您的账户是否符合条件，请咨询您的 IT 管理员。

### 连接前

在您的组织中的任何人连接之前，管理员需要设置 Microsoft 365。在 Team 和企业计划上，您的 Claude 组织所有者或主要所有者为组织启用 Microsoft 365。在每个租户中，Microsoft Entra 全局管理员还需要授予一次性同意。有关管理员方面的详细信息，请参阅**[设置 Microsoft 365 连接器](https://support.claude.com/en/articles/12542951-set-up-the-microsoft-365-connector)**。

### 连接您的账户

管理员完成设置后：

1. 导航到**[自定义 > 连接器](https://claude.ai/customize/connectors)**。

2. 在列表中找到 **Microsoft 365** 并点击 “添加。”

3. 如果系统询问，请选择 “工作或学校账户。”

4. 出现提示时，使用该账户登录。

**注意：**将 Microsoft 365 连接到您的 Claude 账户后，您也可以在 Claude iOS 版和 Claude Android 版上使用它。

### Claude 可以做什么

**SharePoint 和 OneDrive**

- 在 SharePoint 网站和库中搜索文档，以查找项目规范、战略计划和其他业务文档。

- 访问存储在 OneDrive 中的文件，让 Claude 分析内容，无需手动上传。

- 整合来自分散文件位置的信息，并分析多个文档中的趋势。

**Outlook 电子邮件**

- 搜索电子邮件线程和对话，以跟踪项目状态、客户反馈和团队协调。

- 访问消息内容和元数据，按日期、发件人、主题和其他条件进行筛选。

- 从过去的往来信件中查找特定信息。

**Outlook 日历**

- 查看会议摘要、与会者信息和内容，为即将召开的会议做准备或了解您错过的会议。

- 分析日程安排模式并跟踪项目决策。

**Teams**

- 访问您是参与者的 Teams 聊天消息和频道讨论。

- 查看团队协作模式并查找在对话中做出的决策。

**写入工具**

如果您的管理员为您的组织启用了写入工具，Claude 还可以：

- 起草、发送和组织电子邮件，包括管理类别、收件箱规则和自动回复。

- 创建、更新和删除日历事件，并向与会者发送邀请。

- 在 OneDrive 和 SharePoint 中创建和更新文件。

- 发送 Teams 聊天消息、在频道中发布或回复，或开始新的聊天。

当 Claude 发送电子邮件时，它包含一个消息头，标识为代理启动。Teams 消息、文件写入和日历写入目前未标记。写入工具受每用户限制。

**注意：**写入工具目前不支持附件。Claude 无法发送、转发或起草带有附件的电子邮件。

**注意：**在 Team 和企业计划上，您的管理员可以分别设置每个 Teams 写入工具。如果您的组织在 2026 年 9 月 Teams 写入工具推出之前添加了 Microsoft 365 连接器，这些工具可能默认被阻止，直到您的管理员将其打开。

在 Team 和企业计划上，在聊天和 Cowork 中，Claude 在每次发送聊天消息或在频道中发布或回复之前都会要求您确认，除非您的管理员在 2026 年 11 月 9 日或之后将该操作的 Teams 工具设置为**始终允许**，或您的组织在 2026 年 11 月 9 日之后首次添加了 Microsoft 365 连接器。在这些情况下，Claude 默认会询问，如果您的管理员允许，您可以为该工具选择**始终允许**。如果您之前为该工具选择了**始终允许**，该早期选择可以立即生效，因此 Claude 可以停止询问您。

从 2026 年 12 月 9 日起，您可以为管理员设置为**始终允许**的任何这些工具选择**始终允许**。

这些例外不适用于已启用 HIPAA 的组织。在免费版、专业版、Max 和 Ultra 计划上，在“自动批准”模式之外，Claude 默认会询问，您可以为这些工具选择**始终允许**，就像对任何其他工具一样。“自动批准”模式和计划任务不同：如果您的管理员将其中一个工具设置为**始终允许**，Claude 可能会在不先询问任何人的情况下使用它。这适用于“自动批准”模式和某些计划任务，例如设置为“自动批准”的云计划任务或 Claude Code 例程。

Claude 始终可以搜索和分析您的数据。您的管理员决定 Claude 是否也可以采取行动，例如发送电子邮件、更新日历、创建文件或发送 Teams 消息。Claude 无法更改 Teams 设置或权限。

有关集成请求的完整权限列表，请参阅**[设置 Microsoft 365 连接器](https://support.claude.com/en/articles/12542951-set-up-the-microsoft-365-connector)**或[**Microsoft 365 连接器安全指南**](https://support.claude.com/en/articles/12684923-microsoft-365-connector-security-guide)。

### 断开您的账户

断开连接会移除 Claude 对您的 Microsoft 365 数据的访问权限。只要您的管理员的同意仍然有效，稍后重新连接不需要管理员重新批准。

1. 导航到**[自定义 > 连接器](https://claude.ai/customize/connectors)**。

2. 在您的已连接服务中查找 Microsoft 365。

3. 点击“断开连接。”

### 解决身份验证问题

- 确认您选择了“工作或学校账户，”或者如果系统没有询问您要连接哪个账户，请使用工作或学校账户登录。工作或学校账户无法通过“个人账户”登录。

- 确认您的 Microsoft 365 许可证处于活跃状态。

- 如果您不是 Microsoft Entra 全局管理员，请与您的管理员确认已授予 Microsoft 365 的租户范围同意。如果没有此权限，您在身份验证期间会看到错误。

- 您的 IT 团队可能需要批准第三方应用访问权限。如果您的组织限制未批准的应用，请要求管理员检查组织策略。

- 尝试使用其他浏览器，或禁用可能阻止身份验证弹窗的广告拦截器和隐私扩展。

- 清除 Cookie 和缓存，然后重试。

### 常见问题

**Claude 可以修改我的 Microsoft 365 数据吗？**

仅当您的管理员启用了写入工具时才可以。启用后，Claude 可以起草和发送电子邮件、管理日历事件、创建和更新文件以及发送 Teams 消息（聊天消息、频道中的帖子或回复，或新聊天），始终在您现有的 Microsoft 365 权限范围内。未启用时，集成为只读。无论哪种情况，Claude 都无法更改 Teams 设置或权限。写入工具也不支持附件，因此 Claude 无法发送、转发或起草带有附件的电子邮件。

**Claude 会搜索共享驱动器和团队网站吗？**

会。Claude 可以搜索您有权访问的任何 SharePoint 网站和共享驱动器，包括团队网站、通信网站、文档库和共享 OneDrive 文件夹。

**我可以将我的项目指向特定的 SharePoint 网站吗？**

不可以，`Sites.Selected` 不受支持，因此您无法将 Microsoft 365 连接器的范围限制为特定 SharePoint 网站的允许列表。连接器会搜索您已有权访问的所有 SharePoint 内容。

**Claude 可以搜索共享邮箱吗？**

可以。Claude 可以搜索您在 Microsoft 365 中拥有委派访问权限的共享邮箱。这包括完全访问权限的共享邮箱和文件夹级别的委派，例如当您只能看到另一个邮箱的收件箱时。搜索访问权限遵循您现有的 Microsoft 365 权限：如果您可以在 Outlook 中打开共享邮箱，Claude 就可以搜索它。

**为什么我看不到写入工具？**

写入工具需要在管理员端进行额外设置：Microsoft Entra 管理员需要同意更新的权限，您的组织需要为您的账户启用写入工具。如果您在写入工具或 Teams 写入工具推出前连接，请要求您的管理员完成这两个步骤。在 2026 年 12 月 9 日或之后，仍被默认阻止的写入工具将被打开并设置为**需要批准**，除非您的管理员已将其或整个连接器设置为**已阻止**。有关详情，请参阅**[设置 Microsoft 365 连接器](https://support.claude.com/en/articles/12542951-set-up-the-microsoft-365-connector)**。

**为什么 Claude 在发送或更改内容前要求我确认？**

默认情况下，在“自动批准”模式之外，在聊天和 Cowork 中，Claude 会在每次发送或转发电子邮件、发送 Teams 消息、创建、更改、删除或回复日历事件或设置自动回复时要求您确认。在**[“自动批准”模式](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork#h_c274f6c9b5)**中，这些操作可以在不询问您的情况下运行，除非自动检查将其标记为风险或您的组织需要批准。检查可能会遗漏风险操作。要自己批准它们，请使用手动模式或将工具的权限设置为**[“始终询问”](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork#h_c274f6c9b5)**（如果该选项可用）。在免费、专业、最大和超级计划上，您可以为这些工具中的任何一个选择**始终允许**，Claude 将在不每次询问您的情况下使用它。

在团队和企业计划上，Claude 会为这些工具每次询问，除非您的管理员在 2026 年 11 月 9 日或之后为该工具设置了**始终允许**，或您的组织在 2026 年 11 月 9 日之后首次添加了 Microsoft 365 连接器。在这些情况下，如果您的管理员允许，您可以为该工具选择**始终允许**。如果您过去为该工具选择了**始终允许**，该早期选择可以立即生效，因此 Claude 可以停止询问您。这些例外不适用于已启用 HIPAA 的组织。

“自动批准”模式和计划任务是不同的：如果您的管理员将这些工具之一设置为始终允许，Claude 可能会在不先询问任何人的情况下使用它。这适用于“自动批准”模式和某些计划任务，例如设置为“自动批准”的云计划任务或 Claude Code 例程。

**Claude 可以访问私有 Teams 频道吗？**

仅限您是其成员的频道。Claude 镜像您的 Microsoft 365 权限，因此如果您可以看到私有频道，Claude 可以搜索它；如果您不是成员，它就无法搜索。

**为什么 Claude 无法打开我可以打开的文件或电子邮件？**

您的组织可能在 Claude 中阻止了某些 Microsoft Purview 敏感度标签（测试版，企业计划）。连接器随后会拒绝带有被阻止标签的文件或电子邮件，或标签无法确定的文件或电子邮件，即使您可以在 Microsoft 365 中打开它。邮件文件夹列表会排除这些电子邮件。在**[按敏感度标签从 Claude 阻止文件和电子邮件](https://support.claude.com/en/articles/18549037-block-files-and-email-from-claude-by-sensitivity-label)**中了解更多信息。

**如果我在管理员设置之前尝试连接会怎样？**

您会看到一条错误消息，指示管理员必须授予应用权限才能连接。请要求您的组织的 Microsoft Entra 全局管理员完成同意。如果您使用的是团队或企业计划，您的 Claude 组织所有者还需要在组织设置中启用 Microsoft 365。

## 个人账户

在免费、专业、最大和超级计划上，您可以连接个人 Microsoft 账户，例如 Outlook.com、Hotmail、Live 或 MSN 账户。它连接 Outlook 和 OneDrive，Claude 还可以起草和发送电子邮件、管理日历事件以及创建和更新文件。您不需要管理员来设置它。团队和企业计划不会显示此选项。

### 连接您的账户

1. 导航到**[自定义 > 连接器](https://claude.ai/customize/connectors)**。

2. 在列表中找到**Microsoft 365**，然后点击“连接。”

3. 选择“个人账户。”

4. 出现提示时使用该账户登录。

**注意：**在 Claude 网页版中选择个人账户。将 Microsoft 365 连接到您的 Claude 账户后，您也可以在 Claude iOS 版和 Claude Android 版上使用它。

### Claude 可以做什么

**OneDrive**

- 访问存储在您的 OneDrive 中的文件，让 Claude 分析内容，无需手动上传。

- 整合来自分散文件位置的信息，分析多个文档中的趋势。

**Outlook 电子邮件**

- 搜索电子邮件线程和对话，跟踪项目状态、客户反馈和团队协调。

- 访问消息内容和元数据，按日期、发件人、主题和其他条件进行筛选。

- 从过去的往来信件中查找特定信息。

**Outlook 日历**

- 查看与会者信息和内容，为即将召开的会议做准备或了解您错过的会议。

- 分析日程安排模式并跟踪项目决策。

**写入工具**

包含了写入工具。Claude 始终可以搜索和分析您的数据，当您要求时，它还可以：

- 起草、发送和整理电子邮件，包括管理类别和将邮件移动到“已删除项目”。

- 创建、更新和删除日历事件，以及向与会者发送邀请。

- 在 OneDrive 中创建、更新、重命名、移动和删除文件（已删除的文件进入回收站）。

在聊天中，在“自动批准”和“跳过所有批准”模式之外，Claude 在发送、创建、更改、移动或删除任何内容之前会询问您。在**[“自动批准”模式](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork#h_c274f6c9b5)**中，这些操作可以在不询问您的情况下运行，除非自动检查将其标记为有风险或您的组织需要批准。该检查可能会遗漏有风险的操作。要自己批准它们，请使用“手动”或将工具的权限设置为**[“始终询问”](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork#h_c274f6c9b5)**（如果该选项可用）。搜索和阅读无需询问即可运行。您可以在**工具权限**下更改每个工具。

Claude 发送、转发或起草的电子邮件包含一个标头，用于标识这些电子邮件是由代理发起的。Claude 未创建的草稿和日历邀请不会被标记。写入工具受每个用户的限制。

**注意：**写入工具目前不支持附件，因此 Claude 无法发送、转发或起草带有附件的电子邮件。

个人账户不包括 SharePoint、Teams、会议摘要、收件箱规则、自动回复、共享邮箱或日历，或查找其他人何时有空。Claude 搜索您自己的 OneDrive，包括您添加到其中的共享项目。

有关个人账户请求的完整权限列表，请参阅安全指南中的**[个人 Microsoft 账户](https://support.claude.com/en/articles/12684923-microsoft-365-connector-security-guide#h_66d5bff0e6)**。

### 断开账户连接

1. 导航到**[自定义 > 连接器](https://claude.ai/customize/connectors)**。

2. 在您的已连接服务中找到 Microsoft 365。

3. 点击“断开连接。”

断开连接会移除 Claude 的访问权限，Claude 不再读取或更改该 Microsoft 账户中的任何内容。您授予 Claude 的权限在您的 Microsoft 账户中保持活跃，直到您在那里移除它。了解更多关于**[管理对您的 Microsoft 账户具有权限的应用](https://account.microsoft.com/privacy/app-access)**的信息（需要 Microsoft 登录）。

- 确认您选择了“个人账户。”个人账户无法通过“工作或学校账户”登录。如果您没有被询问要连接哪个账户，Microsoft 365 可能已经连接。要切换账户，请断开连接后重新连接。

- 尝试使用不同的浏览器，或禁用可能阻止身份验证弹窗的广告拦截器和隐私扩展。

- 清除 Cookie 和缓存，然后重试。

只能通过写入工具进行修改，这些工具默认启用，除非您在**工具权限**下关闭它们。写入工具不支持附件，因此 Claude 无法发送、转发或起草带有附件的电子邮件。

**Claude 会搜索共享驱动器和团队网站吗？**

不会。Claude 搜索您自己的 OneDrive，包括您添加到其中的共享项目。

检查这些工具是否在**工具权限**下启用。

## 在 Claude 中使用 Microsoft 365

向 Claude 提出一个需要来自您的 Microsoft 365 数据的问题。Claude 会检测它需要哪些工具并检索相关内容。

示例查询：

- “在 SharePoint 中查找第四季度战略规划文档。”

- “总结关于产品发布的电子邮件对话。”

- “Teams 频道中关于营销活动的讨论有哪些？”

- “查看上周领导力同步会议的会议记录。”

- “起草对供应商最新电子邮件的回复，但不要发送。”

- “下周二与设计团队安排一个 30 分钟的同步会议。”

- “在 Teams 的 #project-updates 频道中发布此线程的摘要。”

提及 SharePoint 或 Teams 的示例需要工作或学校账户。

## 支持的文件类型

从 SharePoint 和 OneDrive 读取文件时，Claude 可以打开这些格式：

- **Word、Excel 和 PowerPoint**，包括较旧的 .doc、.xls 和 .ppt 文件

- **PDF**

- **纯文本文件**：.txt、.md、.csv、.tsv、.json、.xml、.html、.htm 和 .log

任何其他格式的文件都无法读取。它们仍会出现在搜索结果中，因为它们是您的库中的普通文件，但当 Claude 尝试打开一个文件时，您会看到“mime 类型 '...' 不被允许”错误。

**注意：**不支持 OneNote。使用工作或学校账户时，笔记本会显示在搜索结果中，但读取尝试会返回“mime 类型 'application/msonenote' 不被允许”错误。要将 OneNote 内容导入 Claude，请将页面或部分导出为 Word 或 PDF 到同一库中。

## 管理您的连接

### 单独打开或关闭工具

您可以选择性地关闭 Microsoft 365 中的特定工具。例如，您可能希望保持文档搜索打开但关闭电子邮件访问。要执行此操作：

1. 导航到**[自定义 > 连接器](https://claude.ai/customize/connectors)**。

2. 点击“Microsoft 365。”

3. 在**工具权限**下切换工具的打开或关闭。

### 按聊天打开或关闭连接器

您也可以在特定对话中启用或禁用 Microsoft 365。

1. 点击聊天窗口左下角的 “+” 按钮。

2. 将鼠标悬停在 “连接器” 上。

3. 在列表中找到 **Microsoft 365** 并切换开启或关闭。

### 切换账户

在免费版、专业版、最大版和超级版计划中，要在工作或学校账户与个人账户之间切换，请断开连接后重新连接。

## Claude 可以访问的内容

连接后，Microsoft 365 始终由您控制。需要注意以下几点：

- **您的权限适用。**Claude 只能访问您已经可以在 Microsoft 365 中看到的数据。如果您无法访问某个 SharePoint 网站或不是私有 Teams 频道的成员，Claude 也无法访问该内容。

- **按您的请求。**当您提出请求或您设置的计划任务需要时，Claude 会访问 Microsoft 365。

- **您可以随时断开连接。**按照您账户的步骤移除 Claude 的访问权限。

## 故障排除

### Claude 说找不到我知道存在的文档

1. 验证您可以直接在 Microsoft 365 中访问该文档。

2. 确保文档在 SharePoint 或 OneDrive 中，而不是存储在您的本地计算机上。

3. 最近上传的文件可能需要时间才能变为可搜索状态。

4. 使用工作或学校账户：

  1. 您的组织可能会阻止文档的敏感度标签（测试版、企业计划），这可能导致其在搜索结果中被排除。请参阅 **[常见问题](#h_7d17060986)** 中的 **为什么 Claude 无法打开我能打开的文件或电子邮件？**

  2. 尝试在提示中指定 SharePoint 网站或库名称。

5. 按确切文件名或文档中的唯一关键词搜索。

6. 如果 SharePoint 自身搜索能找到文件但 Claude 找不到，请要求您的 Microsoft 365 管理员查看 **[Claude 找不到 SharePoint 搜索能找到的文件](https://support.claude.com/en/articles/12542951-set-up-the-microsoft-365-connector#h_cfbc8cb240)**。

### 搜索结果不完整或不相关

- 具体说明您要查找的内容。

- 指定位置，例如网站名称、日期范围或文档类型。

- 使用确切短语以获得更好的匹配结果。

- 将复杂问题分解为更简单、更集中的问题。

- 仔细检查名称、项目或技术术语的拼写。

## 常见问题

### 我如何告诉 Claude 搜索特定位置？

在您的提示中具体说明：

- *“在 SharePoint 中搜索工程团队网站以查找架构文档。”*

- *“查找上周关于第四季度预算的电子邮件。”*

- *“显示与 Sarah 关于产品路线图的 Teams 讨论。”*

- *“在 SharePoint 中查找关于销售策略的 PowerPoint 演示文稿。”*

提及 SharePoint 或 Teams 的提示需要工作或学校账户。

### 为什么 Claude 无法读取 OneNote 笔记本？

OneNote 目前不是受支持的文件类型。使用工作或学校账户时，笔记本会显示在 SharePoint 搜索结果中，因为它们是您库中的普通文件，但 Claude 无法打开它们，因此读取尝试会返回 “mime type 'application/msonenote' is not allowed” 错误。要在 Claude 中处理 OneNote 内容，请将页面或部分导出为 Word 或 PDF。有关 Claude 可以读取的完整格式列表，请参阅上面的 **[支持的文件类型](#h_90f0c97f12)**。

### Claude 可以搜索已存档的电子邮件吗？

可以，但仅限于您的主邮箱中的电子邮件。Claude 可以搜索您主 Outlook 邮箱中的每个文件夹，包括其存档文件夹。Claude 不搜索单独的在线存档邮箱（也称为就地存档），因此保留策略移到那里的邮件不会出现在结果中。要处理其中一条邮件，请将其移回主邮箱中的文件夹，或在 Outlook 中打开它并将内容粘贴到您的聊天中。

### Claude 可以总结长电子邮件线程吗？

可以。尝试使用类似 *“总结关于供应商选择流程的电子邮件线程。”* 的提示。Claude 将读取该线程并提供包含关键要点和决策的摘要。
