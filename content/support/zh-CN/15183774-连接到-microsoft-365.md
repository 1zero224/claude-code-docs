# 连接到 Microsoft 365

连接 Microsoft 365 让 Claude 可以搜索、分析和处理您的 Outlook 电子邮件、日历和 OneDrive 文件，以及 SharePoint 和 Teams（使用工作或学校账户）。向 Claude 提出您的需求，它会提取正确的信息或采取相应的行动。

Microsoft 365 连接器在所有 Claude 计划上都可用：免费版、专业版、Max、Ultra、Team 和 Enterprise。您可以在免费版、专业版、Max 和 Ultra 计划上连接个人 Microsoft 账户。

您一次只能连接一个 Microsoft 账户。请转到您的账户部分：

- **[工作或学校账户](#h_0fa7577f04)**

- **[个人账户](#h_cffabf2c6c)**

这两个部分之后的部分适用于两种账户类型。

## 工作或学校账户

您的公司或学校为您提供此账户，该账户与 Microsoft Entra 租户相关联。它连接 SharePoint、OneDrive、Outlook 和 Teams。如果您的管理员启用了写入工具，Claude 还可以起草和发送电子邮件、管理日历事件、创建和更新文件以及发送 Teams 消息。如果您不确定您的账户是否符合条件，请咨询您的 IT 管理员。

### 连接前

在您的组织中的任何人都可以连接之前，管理员需要设置 Microsoft 365。在 Team 和 Enterprise 计划上，您的 Claude 组织所有者或主要所有者为组织启用 Microsoft 365。在每个租户中，Microsoft Entra 全局管理员还需要授予一次性同意。有关管理员方面的详细信息，请参阅 **[设置 Microsoft 365 连接器](https://support.claude.com/en/articles/12542951-set-up-the-microsoft-365-connector)**。

**注意：**将 Microsoft 365 连接到您的 Claude 账户后，您也可以在 Claude for iOS 和 Claude for Android 上使用它。

### Claude 可以做什么

**SharePoint 和 OneDrive**

- 在 SharePoint 网站和库中搜索文档，以查找项目规范、战略计划和其他业务文档。

- 访问存储在 OneDrive 中的文件，让 Claude 分析内容，无需手动上传。

- 整合来自分布式文件位置的信息，并分析多个文档中的趋势。

**Outlook 电子邮件**

- 搜索电子邮件线程和对话，以跟踪项目状态、客户反馈和团队协调。

- 访问消息内容和元数据，按日期、发件人、主题和其他条件进行筛选。

- 从过去的往来信件中查找特定信息。

**Outlook 日历**

- 查看会议摘要、与会者信息和内容，为即将召开的会议做准备或了解您错过的会议。

- 分析日程安排模式并跟踪项目决策。

**Teams**

- 访问您是参与者的 Teams 聊天消息和频道讨论。

- 查看团队协作模式并查找在对话中做出的决策。

**写入工具**

如果您的管理员为您的组织启用了写入工具，Claude 还可以：

- 起草、发送和组织电子邮件，包括管理类别、收件箱规则和自动回复。

- 创建、更新和删除日历事件，并向与会者发送邀请。

- 在 OneDrive 和 SharePoint 中创建和更新文件。

- 发送 Teams 聊天消息、在频道中发布或回复，或开始新的聊天。

当 Claude 发送电子邮件时，它包含一个消息头，标识为代理启动。Teams 消息、文件写入和日历写入目前未标记。写入工具受每用户限制。

**注意：**写入工具目前不支持附件。Claude 无法发送、转发或起草带有附件的电子邮件。

**注意：**在 Team 和 Enterprise 计划上，您的管理员可以分别设置每个 Teams 写入工具。如果您的组织在 2026 年 9 月 Teams 写入工具推出之前添加了 Microsoft 365 连接器，这些工具可能默认被阻止，直到您的管理员将其打开。

在聊天和 Cowork 中，Claude 会在每次发送聊天消息或在频道中发布或回复之前要求您确认，除非您的管理员在 2026 年 11 月 9 日或之后为该操作的 Teams 工具设置了 **始终允许**，或您的组织在 2026 年 11 月 9 日之后首次添加了 Microsoft 365 连接器。在这些情况下，Claude 默认会询问，如果您的管理员允许，您可以为该工具选择 **始终允许**。如果您之前为该工具选择了 **始终允许**，该早期选择可以立即生效，因此 Claude 可以停止询问您。

从 2026 年 12 月 9 日起，您可以为管理员设置为 **始终允许** 的任何这些工具选择 **始终允许**。

这些例外不适用于已启用 HIPAA 的组织。在免费版、专业版、Max 和 Ultra 计划上，Claude 默认会询问，您可以为这些工具选择 **始终允许**，就像任何其他工具一样。

Claude 始终可以搜索和分析您的数据。您的管理员决定 Claude 是否也可以采取行动，例如发送电子邮件、更新日历、创建文件或发送 Teams 消息。Claude 无法更改 Teams 设置或权限。

有关集成请求的完整权限列表，请参阅 **[设置 Microsoft 365 连接器](https://support.claude.com/en/articles/12542951-set-up-the-microsoft-365-connector)** 或 [**Microsoft 365 连接器安全指南**](https://support.claude.com/en/articles/12684923-microsoft-365-connector-security-guide)。

### 常见问题

**Claude 可以修改我的 Microsoft 365 数据吗？**

仅当您的管理员启用了写入工具时才可以。启用后，Claude 可以起草和发送电子邮件、管理日历事件、创建和更新文件以及发送 Teams 消息（聊天消息、频道中的帖子或回复，或新聊天），始终在您现有的 Microsoft 365 权限范围内。未启用时，集成为只读。无论哪种情况，Claude 都无法更改 Teams 设置或权限。写入工具也不支持附件，因此 Claude 无法发送、转发或起草带有附件的电子邮件。

**Claude 会搜索共享驱动器和团队网站吗？**

是的。Claude 可以搜索您有权访问的任何 SharePoint 网站和共享驱动器，包括团队网站、通信网站、文档库和共享 OneDrive 文件夹。

**我可以将我的项目指向特定的 SharePoint 网站吗？**

不可以，`Sites.Selected` 不受支持，因此您无法将 Microsoft 365 连接器限制在特定 SharePoint 网站的允许列表中。连接器会搜索您已有权访问的所有 SharePoint 内容。

**Claude 可以搜索共享邮箱吗？**

是的。Claude 可以搜索您在 Microsoft 365 中具有委派访问权限的共享邮箱。这包括完全访问共享邮箱和文件夹级别委派，例如当您只能看到另一个邮箱的收件箱时。搜索访问权限遵循您现有的 Microsoft 365 权限：如果您可以在 Outlook 中打开共享邮箱，Claude 就可以搜索它。

**为什么我看不到写入工具？**

写入工具需要在管理员端进行额外设置：Microsoft Entra 管理员需要同意更新的权限，您的组织需要为您的账户启用写入工具。如果您在写入工具或 Teams 写入工具推出前连接，请要求您的管理员完成这两个步骤。在 2026 年 12 月 9 日或之后，仍被默认阻止的写入工具将被打开并设置为**需要批准**，除非您的管理员已将其或整个连接器设置为**已阻止**。有关详情，请参阅**[设置 Microsoft 365 连接器](https://support.claude.com/en/articles/12542951-set-up-the-microsoft-365-connector)**。

**Claude 为什么在发送或更改内容前要求我确认？**

默认情况下，在聊天和 Cowork 中，Claude 会在每次发送或转发电子邮件、发送 Teams 消息、创建、更改、删除或回复日历事件或设置自动回复时要求您确认。在免费、专业版、最大版和超级版计划上，您可以为这些工具中的任何一个选择**始终允许**，Claude 将在不每次询问您的情况下使用它。

在团队和企业计划上，Claude 会为这些工具每次都询问，除非您的管理员在 2026 年 11 月 9 日或之后将该工具设置为**始终允许**，或您的组织在 2026 年 11 月 9 日之后首次添加了 Microsoft 365 连接器。在这些情况下，如果您的管理员允许，您可以为该工具选择**始终允许**。如果您之前为该工具选择了**始终允许**，该早期选择可以立即生效，因此 Claude 可以停止询问您。这些例外不适用于已启用 HIPAA 的组织。

"Automatically approve" mode and scheduled tasks are different: if your admin sets one of these tools to Always allow, Claude may use it without asking anyone first. This applies in "Automatically approve" mode and in some scheduled tasks, such as a cloud scheduled task set to "Automatically approve" or a Claude Code routine.

**Claude 可以访问私有 Teams 频道吗？**

仅限您是其成员的频道。Claude 镜像您的 Microsoft 365 权限，因此如果您可以看到私有频道，Claude 可以搜索它；如果您不是成员，它就无法搜索。

**如果我在管理员设置完成前尝试连接会怎样？**

您会看到一条错误消息，指示管理员必须授予应用权限才能连接。请要求您组织的 Microsoft Entra 全局管理员完成同意。如果您使用的是团队或企业计划，您的 Claude 组织所有者还需要在组织设置中启用 Microsoft 365。

## Claude 可以访问的内容

Microsoft 365 连接后仍在您的控制下。需要记住以下几点：

- **您的权限适用。**Claude 只能访问您已经可以在 Microsoft 365 中看到的数据。如果您无法访问 SharePoint 网站或不是私人 Teams 频道的成员，Claude 也无法访问该内容。

- **按您的请求。**当您提出请求或您设置的计划任务需要时，Claude 会访问 Microsoft 365。

- **您可以随时断开连接。**使用您账户的步骤来移除 Claude 的访问权限。

## 故障排除

### Claude 说找不到我知道存在的文档

1. 验证您可以直接在 Microsoft 365 中访问该文档。

2. 确保文档在 SharePoint 或 OneDrive 中，而不是存储在您计算机的本地。

3. 最近上传的文件可能需要时间才能变为可搜索。

4. 使用工作或学校账户时，请尝试在提示中指定 SharePoint 网站或库名称。

5. 按确切文件名或文档中的唯一关键词搜索。

6. 如果 SharePoint 自身的搜索找到了文件但 Claude 没有找到，请要求您的 Microsoft 365 管理员查看 **[Claude 找不到 SharePoint 搜索能找到的文件](https://support.claude.com/en/articles/12542951-set-up-the-microsoft-365-connector#h_cfbc8cb240)**。

### 搜索结果不完整或不相关

- 明确说明您要查找的内容。

- 指定位置，例如网站名称、日期范围或文档类型。

- 使用确切短语以获得更好的匹配。

- 将复杂问题分解为更简单、更集中的问题。

- 仔细检查名称、项目或技术术语的拼写。
