# 从独立的 Claude Design 迁移到 Claude

Claude Design 现已集成到 Claude 中。独立的 Claude Design 网站 (claude.ai/design) 将于 2026 年 12 月 14 日关闭，在此之前您仍可访问。本文介绍了将发生的变化及时间、如何立即迁移您的设计系统，以及您的项目会发生什么。

Claude Design 在免费版、专业版、Max、Ultra、团队版和企业版计划中可用。

## 将发生什么变化及时间

您可以继续使用独立版本，直到它在 2026 年 12 月 14 日关闭。之后，它将变为只读，您无法在那里启动新项目。

当您在 Claude 中启动新设计、设计系统或幻灯片时，它会被创建为一个工件。

## 您的工作会发生什么

当您迁移设计系统时，原始版本保留在独立版本中。您的聊天和评论无法迁移到 Claude，因此它们将保留在独立版本中，直到其关闭。

**重要提示：**已迁移的设计系统在您的组织可以使用"迁移到 Claude"后，立即对独立版本中的所有人变为只读。如果您继续在那里编辑，这些更改不会迁移，因此请在 Claude 中重新进行。

## 您需要做什么

- 立即迁移您的设计系统。

- 在团队版和企业版计划中，请要求您的组织所有者设置默认设计系统以充分利用工件。

- 将项目迁移到 Claude 正在逐步向付费计划推出。一旦可以，请迁移您想保留的项目。请参阅"您的项目会发生什么"。

- 如果您是团队版或企业版所有者，请检查工件和设计系统是否已启用。在企业版计划中，设计系统默认处于关闭状态。

## 迁移您的设计系统

**注意：**一旦您的组织可以使用**迁移到 Claude**，设计系统将不再有自己的迁移选项。它们的迁移方式与项目相同。每个设计系统的所有者可以迁移它，或您的组织所有者可以一次性迁移所有内容。请参阅**[您的项目会发生什么](#h_1d425b60a1)**。

### 开始前

- 一次迁移会带来您的组织中的每个设计系统，包括其他人的，因此只需启动一次。

- 任何可以使用 Claude Design 的人都可以启动它，不仅仅是您的组织所有者。

- 每个设计系统保留其所有者和与其共享的人员。如果所有者已离开您的组织，主要所有者将成为其所有者。

- 空的设计系统不会被迁移，使用内置启动主题制作的设计系统也不会被迁移，即使您已编辑过它们。

**重要提示：**未设为私密的已发布设计系统将与您的组织中的所有人共享，并出现在他们的设计系统菜单中。在个人计划中，不共享任何内容。

### 启动迁移

1. 在 Claude 中打开**工件**页面。

2. 在"Claude Design 现已在此"横幅中点击"迁移团队设计系统"。如果您已关闭横幅，请从 Claude Design 菜单中选择它。要打开菜单，请点击"新建内容"下的设计磁贴上的"…"按钮。如果没有设计磁贴，请点击页面右上角的"…"按钮。

3. 点击"迁移"以确认。在个人计划中，没有确认步骤，迁移立即开始。

4. 等待迁移完成。如果您关闭窗口，它会继续运行。

5. 检查结果。在"已迁移"下，窗口列出每个设计系统及其所有者的名称和"打开"链接。除非您是组织所有者，否则您只会看到您有权访问的设计系统。

## 迁移后

您迁移的设计系统在您在 Claude 中制作设计和幻灯片时出现在设计系统菜单中。要查看所有内容，请从工件页面上的 Claude Design 菜单中选择"查看设计系统"。该列表在设置中打开。

所有者可以在此处设置您的组织的默认设计系统。打开设计系统的菜单并选择"设置为默认"。点击设计系统的名称以打开它。

迁移的设计系统保留其文件原样，您暂时无法在其页面上自行编辑。其编辑者会在顶部看到一条说明，表示它已被迁移，他们可以要求 Claude 进行更改。

详细了解**[Claude Design 入门](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)**。

### 如果设计系统无法迁移

窗口在**未迁移**下列出它，包括其名称、所有者和简短原因，例如"它太大了"。

要稍后重新打开结果，请点击工件页面上横幅中的计数，例如"您的 11 个设计系统中有 6 个无法迁移"。

任何可以编辑设计系统的人都可以修复其自身文件或大小的问题。如果您无法编辑它，您将无法运行检查，因此请要求其所有者，其名称在该行中。

**要修复设计系统：**

1. 在其行中点击"在 Claude Design 独立版中修复"。

2. 在**检查此设计系统是否可以迁移到 Claude**卡上点击"检查"。

3. 使用下表修复检查列出的文件。

4. 点击"再次检查"，直到显示"未发现任何问题"。

5. 从 Claude 中的**工件**页面再次迁移。

| **检查显示的内容** | **要做什么**  |
| ----------- | --------- |
| 对于工件来说太大    | 缩小或删除它们   |
| 名称工件无法使用    | 重命名它们     |
| 工件无法保存的类型   | 转换或删除它们   |
| 无法进入设计系统工件  | 删除它们      |
| 无法打开        | 重新保存或删除它们 |
| 包含无法读取的字符   | 修复或删除它们   |
| 内容缺失        | 重新上传或删除它们 |

如果整个设计系统过大，卡片会显示"太大了。请缩小。"而不是列出文件。删除不需要的文件，然后重新检查。

**注意：**`uploads` 文件夹通常包含重复文件，是开始精简设计系统的好地方。

某些原因需要您的组织所有者来修复："您的团队已关闭设计系统"、"您的团队无法发布工件"或"其所有者的角色不包括设计系统"。前两个会停止移动，任何尚未开始的设计系统都列在**未开始**下。修复后，重新移动。

有时卡片会显示"无法移动此设计系统"但不说明原因。如果发生这种情况，请点击"下载设计系统"以保留其文件的副本。您可以稍后点击"重新检查"，如果仍然无法移动，请告诉我们。请参阅**[获取帮助](#h_5acf964297)**。

### 重新移动

**注意：**一旦**移动到 Claude** 对您的组织可用，本部分不再适用。后续移动不会更新已移动的设计系统。要用新副本替换它，其所有者在 Claude 中删除它，然后从独立版本再次移动。

要移动新的、已更改或已修复的设计系统，请从工件页面上的 Claude 设计菜单中选择"重新移动"。要重新打开您的最后结果，请选择其下方的"查看最后移动"。

**重新移动时：**

| **如果设计系统是**          | **会发生什么**                                               |
| -------------------- | ------------------------------------------------------- |
| 新的，或自上次移动以来在独立版本中已更改 | 已移动                                                     |
| 在两个位置都未更改            | 保持不变并标记为"已移动"                                           |
| 自移动后在 Claude 中已更改    | 它列在"已在 claude.ai 上更改，保持原样"的"已跳过"下，因此您在 Claude 中的编辑不会被覆盖 |

要用新副本替换已移动的设计系统，请在 Claude 中删除它，然后重新移动。要保留您对其所做的任何更改，请先复制它。

## 您的项目会发生什么

在移动之前，您的项目保留在独立版本中，并在其关闭前继续工作。Claude 中的**工件**页面也列出了其中最多 60 个，它们在独立版本中打开。

将项目移动到 Claude（其中它成为工件）正在逐步推出到付费计划。

- 在团队和企业计划上，工件还需要为您的组织启用。在具有自定义角色的企业计划上，您的角色也需要它们。

- 具有客户管理的加密密钥 (CMEK) 的组织可以一次移动单个项目、项目列表、设计系统或所有内容。独立 Claude 设计不支持 CMEK，因此在您移动之前，其数据不会在您的密钥下加密。项目移动到 Claude 后，它会在您的密钥下加密。

- 具有 HIPAA 就绪配置的组织目前无法移动项目。

- 具有零数据保留 (ZDR) 的组织无法移动项目，因此请在独立版本关闭前下载您的项目。

要移动项目：

1. 在 claude.ai/design 的独立版本中打开项目。只有项目的所有者可以移动它。

2. 从弹出窗口或项目顶部的横幅开始审查。

3. 阅读审查。它列出了移动的内容、任何工作方式不同的内容以及保留的内容。您也可以下载 .zip 文件副本。然后确认移动。

4. 保持标签页打开，直到移动完成。

5. 在 Claude 中打开项目。它现在是工件页面上的工件。

移动后，独立版本中的副本对所有人都是只读的，这无法撤销。您的聊天和评论保留在该副本中，您可以在独立版本关闭前阅读它们。共享在 Claude 支持的地方进行。

您也可以一次移动您自己的所有项目，或仅移动您选择的项目。在团队和企业计划上，您的组织所有者可以使用"全部移动"一次移动所有人的项目。

全部移动"在 Claude 的工件页面上，它也移动模板和设计系统。只有所有者或主要所有者可以启动它，管理员不能。"

大多数项目保留其所有者，私有项目保持私有。如果项目的所有者已离开您的组织，它会转到您的组织的所有者（通常是主要所有者），Claude 会向该人显示一个名为"移动到您的项目"的列表。无法移动的任何内容都保留在独立版本中，结果说明原因。与任何移动一样，已移动项目的独立副本对所有人都变为只读。

**重要：**如果您的组织有涵盖工件的保留期，移动到 Claude 或已移动到 Claude 的项目或设计系统，如果在该期间内没有人打开它，可能会被永久删除。该期间从移动之日开始，当有人打开或编辑工件时重新开始。在**[为企业计划配置自定义数据保留控制](https://support.claude.com/en/articles/10440198)**中了解更多信息。

## 未进行的操作

这些保留在独立版本中，并在其关闭后的某个时间被删除，根据我们的**[数据保留实践](https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data)**：

- 您与 Claude 的聊天

- 对您的项目和设计系统的评论

独立版本中项目的公开链接在其关闭后将不再有效。

**重要：**在独立版本关闭前，保存您需要的聊天和评论中的任何内容。

## 适用于团队和企业所有者

Claude 中的 Claude Design 依赖于工件。如果您的组织关闭了工件，用户将无法在 Claude 中创建设计或移动任何内容，也不会看到"Claude Design 现已推出"横幅。

要检查您的设置，请导航至 **[组织设置](https://claude.ai/admin-settings/artifacts)**[> **工件**](https://claude.ai/admin-settings/artifacts)：

| **设置**                   | **用途**                  | **默认值**       |
| ------------------------ | ----------------------- | ------------- |
| **工件**                   | 以下所有内容都依赖于此             | 开启            |
| **设计系统**，位于**模板**下       | 移动设计系统和创建新的设计系统         | 团队计划开启，企业计划关闭 |
| **设计**和**幻灯片**，位于**模板**下 | 在 Claude 中创建新设计和幻灯片演示文稿 | 开启            |

在具有自定义角色的企业计划中，每个角色还需要这些权限，角色编辑器会在**工件**下列出这些权限。这样您可以仅为使用 Claude Design 的人员启用工件。如果设计系统所有者的角色不包括设计系统，则该设计系统无法移动。

当**设计系统**关闭时，点击"移动团队设计系统"的所有者会看到"您的组织已关闭设计系统"和"打开组织设置"按钮。其他所有人会看到该按钮呈灰显状态，原因是"您的组织的工件设置中已关闭设计系统。"

如果您的组织的默认设计系统移动，它也会成为 Claude 中的默认设计系统，除非您已在那里设置了一个。

零数据保留 (ZDR) 的组织无法启用工件，因此无法移动。如果这是您的组织，请在独立版本关闭前下载您的项目。请参阅 **[我可以下载我的所有项目吗？](#h_a676b76d76)**

## 常见问题

### 独立版本关闭后，我的原始文件会发生什么？

您的原始文件保留在独立版本中，已移动的文件为只读。2026 年 12 月 14 日关闭后，其余文件也将变为只读，但有一个例外。未移动的项目的所有者仍可以更改其文件，以便他们可以修复并将其移动到 Claude。原始文件将根据我们的**[数据保留政策](https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data)**在稍后删除。

### 如果设计系统或项目的所有者已离开我的组织怎么办？

当其移动到 Claude 时，您的组织的主要所有者将成为其所有者。

### 我可以下载我的所有项目吗？

您拥有的所有项目的下载功能与**移动到 Claude**一起推出。获得后，您将在独立版本的主页上找到它。它包括您的文件，不包括您的聊天或评论。它不适用于具有 HIPAA 就绪配置的组织。如果您没有它，可以一次下载一个项目：

1. 在独立版本中打开项目。

2. 点击"共享"，然后选择"项目 HTML"。对于幻灯片演示文稿，它位于"更多格式和应用"下。

3. 保持"项目存档"选中状态并点击"导出"。

您会获得一个 .zip 文件，其中包含项目中的每个文件。这是免费的，不计入您的使用限制。

## 获取帮助

如果某些内容没有正确转移，您的原始文件仍在独立版本中。如果您的设计系统无法移动且您无法修复，请告诉我们。了解更多关于**[如何获取支持](https://support.claude.com/en/articles/9015913-how-to-get-support)**的信息。
