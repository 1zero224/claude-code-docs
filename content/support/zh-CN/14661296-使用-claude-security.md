# 使用 Claude Security

## 概述

**[Claude Security](https://claude.com/product/claude-security)** 是内置于 Claude 中的一项功能，可持续监控您的代码库中的安全漏洞，跟踪每个发现直到修复，并建议针对性的补丁供人工审查。它帮助团队发现和修复传统方法经常遗漏的问题。

Claude Security 目前以测试版形式向企业计划用户提供。

了解如何开始使用以及领先企业如何使用该工具，请访问：**[Claude Security 入门指南](https://academy.claude.com/tutorials/getting-started-with-claude-security)**。

Claude Security 允许您：

1. **全面扫描代码库** — Claude Security 理解代码如何组织在一起，跟踪文件间和项目中存储库间的数据流，并识别传统基于规则的扫描器无法检测的复杂多组件漏洞和缺陷。

2. **深度扫描** — 创建项目并连接来自 GitHub 或其他 Git 提供商的最多八个存储库。Claude 读取代码、编写威胁模型并运行深度基线扫描。

3. **持续扫描** — Claude Security 在新提交到达时运行高效扫描，并快速显示任何新发现以便及时修复。

4. **添加代码无法显示的信息** — 告诉 Claude 您的代码如何部署、谁可以访问它以及您已接受的风险。每个项目在威胁模型中保存这些信息，Claude 使用它来决定标记什么以及如何评级。

5. **验证发现** — 每个发现都经过多阶段验证，Claude 在显示发现前会严格审查自己的发现。结果是：误报更少，噪音更少。

6. **审查和修补** — 无缝从发现进入 Claude Code 会话以生成针对性修复。快速解决漏洞，而不是积累待办事项。

7. **跟踪修复** — Claude 检查开放发现与已更改的代码，并在修复到位时将其标记为已修复。

8. **集成到您的工作流** — 通过 Claude Security API 或 Claude 和 Claude Code 中的 Claude Security 连接器 (MCP) 读取和解决发现，并在添加新发现时获得 webhook。

9. **控制访问** — 与具有完全、分类或查看角色的人员共享每个项目。管理员可以决定谁可以创建项目以及谁可以通过 RBAC 查看、分类或管理所有项目。

## 严重程度

严重程度根据漏洞在您的代码库中的可利用程度分配，而不是类别本身，因此相同的类别在不同的存储库中可能会有不同的严重程度。Claude 使用项目的威胁模型来评估严重程度。

| **严重程度** | **标准**                                               | **典型示例**                  |
| -------- | ---------------------------------------------------- | ------------------------- |
| 严重       | 任何人都可以通过网络利用，无需登录、无需受害者操作且无特殊条件。它允许攻击者读取和更改数据。       | 面向互联网的服务中的未经身份验证的远程代码执行。  |
| 高        | 影响严重，但不属于严重级别：攻击者需要登录或受害者操作，或损害是部分的（例如，数据可以读取但不能更改）。 | 登录后的 SQL 注入，允许攻击者读取和更改数据。 |
| 中        | 影响有限（例如，少量非敏感数据），具有一个现实的前置条件，如登录。                    | 登录后的 SQL 注入，仅暴露少数非敏感字段。   |
| 低        | 影响有限，需要登录或网络邻近性加上攻击者无法控制的特殊条件。                       | 需要网络邻近性和数千个请求的时序侧信道。      |

## 发现结构

每个发现包含以下字段：

- 标题 — 发现的简短描述性名称

- 严重程度 — 严重/高/中/低

- 类别 — 发现类型，及其适用的 CWE ID

- 位置 — 文件路径和行范围，链接到源代码。一个发现可以引用多个文件和存储库。

- 状态 — 开放或已解决，包括发现日期。

- 受理人 — 分配给该发现的人员（如有）

- Claude 发现的内容 — 发现内容及其重要性的描述。可以包括攻击路径图。

- 如何修复 — 关于如何解决它的指导

- 证据 — Claude 引用的文件和行范围，按存储库分组，包括扫描的分支和提交

- 攻击如何工作 — 攻击者如何到达和利用该问题

- Claude 为什么相信它 — Claude 的评估，涵盖利用场景、其前置条件和影响

- 历史 — 对发现的每次更改，最新的在前

- 仅在发现已解决时显示：

  - 解决方案 — 标记为已修复、通过合并的拉取请求修复或作为误报、已接受的风险、重复项或其他原因而驳回

  - 分类说明 — 可选

## 常见问题

### 开始使用

**使用 Claude Security 之前我需要做什么准备？**

需要一个有效的 Claude Enterprise 计划，以及**[为每个 Claude Security 用户配置包含 Claude Code 的席位](https://support.claude.com/en/articles/11845131-use-claude-code-with-your-team-or-enterprise-plan)**。在基于席位的 Enterprise 计划中，还必须启用使用额度。拥有包含 Claude Code 的席位的所有者可在**[组织设置 > Claude Security](https://claude.ai/admin-settings/claude-security)** 中启用 Claude Security。请参阅**[入门指南](https://academy.claude.com/tutorials/getting-started-with-claude-security)**了解设置步骤。

**如何授予 Claude Security 访问我的代码库的权限？**

对于 GitHub.com 和 GitHub Enterprise Server，所有者需要安装 **[Claude GitHub 应用](https://github.com/apps/claude)**并授予其访问您要扫描的代码库的权限。对于其他 Git 提供商（如 GitLab、Azure DevOps 和 Bitbucket），请输入代码库的 https 地址和可读取该代码库的身份验证令牌。地址应使用小写字母，不包含用户名、密码、查询参数或端口，例如：`https://gitlab.com/group/project`。

**我可以扫描不在 GitHub 上的代码库吗？**

可以。项目可以使用托管在 GitHub.com 和 GitHub Enterprise Server 上的代码库，或使用身份验证令牌托管在其他 Git 服务器上的代码库（包括可公开访问的自托管 Git 服务器）。

**我需要允许哪些 IP 地址？**

使用**[出站 IP 地址](https://platform.claude.com/docs/en/api/ip-addresses#outbound-ip-addresses)**列表进行 IP 地址白名单设置。如果您使用 GitHub Enterprise Server 或其他 Git 提供商，您的实例必须允许来自这些 IP 地址的入站流量，以便 Claude Security 可以访问您的代码库。

**Claude Security 是否支持零数据保留 (ZDR)？**

不支持。Anthropic 可能会在法律要求或为了解决使用政策违规时保留数据。

**Claude Security 是否支持客户管理的加密密钥 (CMEK)？**

不支持。启用**[客户管理的加密密钥](https://platform.claude.com/docs/en/manage-claude/cmek-coverage-claude-enterprise)**会为您的组织关闭 Claude Security。

**最新更新后我现有的项目会发生什么？**

我们会自动将现有项目迁移到新体验，早期版本将在 2026 年 11 月 25 日停用。您的发现结果会复制到新项目，原项目会被存档。您将无法在早期版本中启动扫描或添加计划。

当我们迁移没有活跃扫描计划的项目时，它会处于暂停状态。其所有者或具有完全角色的任何人，如果有权访问代码库，可以点击“恢复扫描”。恢复会启用持续监控：Claude 会审查项目中的所有代码并持续审查，按令牌成本计费。具有计划的项目通常在迁移后一两天内会自动启动持续监控，计费方式相同。要停止它，所有者或具有完全角色的任何人可以在项目菜单中点击“暂停扫描”。有些项目会处于暂停状态，例如当另一个项目已覆盖相同代码时，请检查您的项目。

早期版本停用后，您将无法访问它。如果您拥有的项目尚未迁移，请在 Claude Security 主页上点击“迁移您的项目”。如果您看不到该按钮，或项目仍未迁移，请联系您的账户团队或支持部门。

**我可以迁移现有项目吗？**

可以，如果您拥有该项目且您的角色允许您创建项目。在 Claude Security 主页上点击“迁移您的项目”。在早期版本仍然开放时，您也可以打开一个项目并点击“迁移项目”。Claude Security 会创建一个新项目，将发现结果复制到其中，并存档原项目。迁移无法撤销。新项目可能会立即开始扫描，设置和扫描按令牌成本计费。大多数项目已自动迁移。GitHub Enterprise 项目可通过“迁移您的项目”迁移，或由我们为您迁移。

**项目迁移时会带来什么？**

发现结果会保留其状态，已驳回或已修复的发现结果会保留其备注。所有者、成员和共享也会在可能的情况下保留。扫描历史、扫描计划、修复拉取请求的链接、首次发现的日期和驳回者不会被复制。在 API 中，迁移的项目和发现结果有新的 ID，并按迁移时间标记，因此导入发现结果的工具可能会将其视为新发现。暂停的项目状态为 `paused`。

**为什么迁移的项目有我未预期的所有者或共享？**

迁移通常会保留两者。如果所有者已离开您的组织，项目会转移给共享该项目的人，或转移给组织所有者或管理员。要更改它，所有者或具有“管理所有项目”权限的人可以点击“共享”，打开新所有者名称旁的角色菜单，然后点击“转移所有权”。具有“查看所有项目”权限的成员可以看到之前为私密的迁移项目及其发现结果，即使他们无法在 GitHub 上访问这些代码库。

**我的 webhook 会发生什么变化？**

项目的 webhook 会在可能的情况下被复制。Slack webhook 无需更改。其他 webhook 会获得新的签名密钥和标准 Webhook 签名。检查签名的接收器会拒绝消息，直到您更新它，在几次重试后消息会被丢弃。打开 Webhook，点击“轮换签名密钥”，并复制密钥（仅显示一次）。使用标准 Webhook 检查将其添加到您的接收器，并在尚未迁移的项目仍向其发送消息时保留旧检查。如果 webhook 已关闭，请将其打开，然后点击“发送测试事件”。扫描完成事件不再发送，发现结果 ID 现在是字符串。组织范围的 webhook 不会被复制：组织所有者可以在 Webhook 页面上导入它们。

### 持续监控

**首次扫描需要多长时间？**

根据代码库的大小，基线扫描可能需要几分钟或几小时。您可以在扫描运行时离开页面。如果您已为 Claude Security 启用电子邮件通知，当您的项目扫描完成并有新发现结果时，您将收到一封电子邮件。

**首次扫描后 Claude 多久扫描一次？**

Claude 根据新提交的风险和复杂性定期检查并扫描更改。没有固定的计划。

**后续扫描需要多长时间？**

扫描时间根据代码库和代理的操作而异。

**后续扫描会读取什么？**

Claude 检查更改、审查更改，并根据风险、复杂性和您的扫描工作量智能地确定扫描范围。根据您的设置、范围和时间长度，Claude 可能会选择完整扫描或增量扫描。您可以在“活动”选项卡中查看它是否运行了完整或增量扫描以及特定的范围更改。

**为什么同一代码的两次扫描会返回不同的结果？**

扫描在设计上是随机的。与传统的静态分析器不同，Claude Security 使用一个代理，该代理会根据每次运行调整其分析，对代码上下文进行推理，而不是应用固定的模式匹配。这使得能够进行深度分析，以捕获逻辑级别的漏洞。

**如何设置大型代码库或单体仓库？**

在代码库上设置文件夹范围，而不是扫描整个代码库，并排除您不需要覆盖的文件夹。Claude 仍然可以根据需要从代码库的其余部分提取上下文。

**一个项目可以有多少个代码库？**

最多八个。代码库可以在范围内，因此 Claude 会扫描它并报告发现结果，或仅用于上下文，因此 Claude 在扫描期间会读取它但不报告其中的发现结果。两者都计入限制。在项目的“资源”选项卡上管理项目的代码库。

**如何告诉 Claude 我的环境？**

打开项目的“资源”选项卡以编辑威胁模型并添加文档（如架构文档）。Claude 使用它们来决定要标记什么以及如何评级。

**Claude Security 使用哪些模型？**

Claude Security 扫描由 Claude Mythos 模型提供支持。用户接收发现结果，无需直接访问模型。每个项目与 Claude 的聊天使用您的团队从您的组织允许的模型中选择的模型。Claude Security 的某些子组件在不需要 Mythos 级别推理时可能使用其他模型，例如枚举项目目录。

### 发现结果和修复

**严重程度如何分配，我可以更改它吗？**

Claude 根据项目的威胁模型对每个发现结果进行评级，您的团队可以编辑和更正该模型。

**如果发现结果描述的攻击在我的环境中不可能发生怎么办？**

Claude 从您的代码编写威胁模型，因此可能会遗漏部署上下文和您的公司已接受的模式。在项目的聊天中，告诉 Claude 为什么发现结果是错误的，并要求它更新威胁模型。Claude 使用威胁模型来决定要标记什么以及如何评级。

**如何修复发现结果？**

点击发现项上的“修复”以打开 Claude Code 并修复该特定漏洞。如果没有**[云端 Claude Code](https://code.claude.com/docs/en/claude-code-on-the-web)**，您需要将提示复制到您自己的 Claude Code 中。Claude 将在未来的扫描中检测代码修复，并自动解决该发现。此外，您始终可以在 UI 中手动将发现标记为已修复。

**修复跟踪如何工作？**

当代码库中的代码发生变化时，Claude 会重新检查发现。无论发现是手动还是自动标记为已修复，如果 Claude 后来发现问题未解决，它都会自动重新打开该发现。

**当我忽略发现时会发生什么？**

您可以将发现忽略为误报、可接受的风险、重复项或其他原因，并添加分类备注。被忽略的发现将保持关闭状态。当后续扫描报告相同问题时，Claude 会将其与被忽略的发现匹配并保持关闭。您可以随时自行重新打开被忽略的发现。

### 集成和通知

**如何将发现导出到我自己的工具？**

要将发现导出到您自己的跟踪和通知系统，请使用 Claude Security API、Claude Security 连接器或 webhook。

**如何使用 Claude Security API？**

在 Claude Security 设置下创建个人访问令牌。令牌代表您：它只能查看和更改您可以查看和更改的内容。使用 API，您可以列出和读取项目和发现、解决和重新打开发现，以及创建和管理项目及其代码库。

**Claude Security 连接器 (MCP) 可以做什么？**

使用 Claude Security 连接器，Claude 和 Claude Code 可以列出和读取您的项目和发现，并在您要求时解决或重新打开发现。

**当有新发现时，我如何获得通知？**

在 Claude Security 设置下创建 webhook，以将新发现事件推送到您自己的系统，例如 Slack 或 Jira。

### 访问和共享

**管理员如何控制谁可以使用 Claude Security？**

自定义角色上的成员需要同时具有**Claude Security** 和**Claude Code** 功能。在 Claude Security 测试版期间，“所有通常可用”功能设置不包括它。管理员可以通过在**[自定义角色](https://support.claude.com/en/articles/13930452-manage-custom-roles-on-enterprise-plans)**中配置功能来决定哪些 RBAC 角色可以创建项目，以及哪些可以查看、分类或管理所有项目。

**如何共享项目，每个角色可以做什么？**

在项目中，点击“共享”为成员分配角色：完全（管理发现、设置和访问权限）、分类（查看发现、更新其状态和启动修复）或查看。您也可以与整个组织共享项目。

### 定价

**Claude Security 的成本是多少？**

Claude Security 仅按直接令牌成本收费。没有额外的平台费用。使用费涵盖扫描和 Claude Security 在项目中执行的其他工作：编写威胁模型、项目聊天和检查修复。

**如何控制和跟踪 Claude Security 的成本？**

您可以为 Claude Security 设置单独的支出限制。在项目设置中打开“使用情况”以查看其本月至今和每日成本。

**更新的 Claude Security 是否有启动优惠？**

是的，符合条件的 Claude Enterprise 组织每月可获得高达 $25,000 的免费使用额度，为期两个月，至 2026 年 12 月 31 日。对于在 2026 年 10 月 21 日已拥有 Claude Enterprise 的组织，第一个月在 11 月 21 日 00:00 UTC 结束，第二个月在 12 月 21 日 00:00 UTC 结束。这显示为**组织设置 > 使用情况**中的额度。完整**[启动优惠条款](#h_07eed9f41c)**如下。

**启动优惠是否也适用于旧体验？**

否。启动优惠适用于新体验中的使用，包括已迁移到新体验的项目。早期版本中的扫描按常规收费。

### Claude Code 的 Claude Security 插件

**Claude Code 的 Claude Security 插件是什么？**

Claude Code 的 Claude Security 插件是一项独立功能，基于与 Claude Security 相同的技术。它适用于希望直接将扫描器集成到工作流中而不依赖 Anthropic 托管代理基础设施的用户、具有零数据保留 (ZDR) 要求的用户，或需要通过第三方提供商访问模型的用户。了解更多信息：**[扫描代码库以查找漏洞](https://code.claude.com/docs/en/claude-security)**。

**Claude Code 的 Claude Security 插件是否使用相同的模型？**

不一定。该插件使用 Claude Code 账户中可用的任何模型。

**使用范围：**您只能使用 Claude Security 扫描您或您的公司拥有的代码，以及您或您的公司拥有扫描所有必要权利的代码。您不能使用 Claude Security 扫描由第三方拥有或许可的代码，包括但不限于开源项目或您公司代码库之外的代码库。

## Claude Security 启动优惠条款

**谁符合条件：**Claude Enterprise 组织，包括通过 AWS Marketplace 购买的 Claude Enterprise。

**您获得的内容：**在连续两个月中，每个月最多 $25,000 的 Claude Security 使用促销额度。每个月从您组织的开始日期运行到下个月的同一日期。一个月未使用的额度不会结转。

**如何获得：**无需注册。额度自动应用于新 Claude Security 中的使用。早期版本中的项目使用不包括在内，直到它们被迁移。

**何时开始：**已拥有 Claude Enterprise 的组织从 2026 年 10 月 21 日开始。在该日期之后注册 Claude Enterprise 的组织从注册之日开始。无论您的组织是否使用 Claude Security，这两个月都会运行。
