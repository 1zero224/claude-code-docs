# 什么是工件，我如何使用它们？

**[工件](https://claude.com/features/artifacts)**是 Claude 为您创建的任何内容，您会将其展示给他人：设计、演示文稿、文档、仪表板或小型交互式工具。它会在您的对话旁边打开，您可以编辑它、返回查看它，并与他人分享。在与 Claude 的任何对话中（包括在 Claude Code 中）请求一个，或从"工件"标签中的模板开始。

工件在免费、专业版、最大版、超级版、团队和企业计划中可用，在包含 Claude Code 的每个计划的 Claude Code 中也可用。文档、幻灯片和设计模板在所有计划中可用，默认启用。在企业计划中，它们将在 2026 年 10 月 15 日默认启用，所有者可以在此之前启用。

仪表板模板在专业版、最大版、超级版、团队和企业计划中处于测试阶段。在企业计划中，默认关闭，直到所有者启用。Motion 模板在团队和企业计划中处于测试阶段。在团队计划中默认启用，在企业计划中默认关闭，直到所有者启用。

## 什么是工件？

**注意：**旧版工件是在 2026 年 9 月 16 日之前在聊天中创建的工件。它们继续工作，您仍然可以发布和分享它们，但您无法创建新的。

当 Claude 分享的内容符合以下条件时，它会创建一个工件：

- 这是一个重要的、独立的内容，通常超过15行。

- 这是你可能想要编辑、迭代或在对话外重复使用的内容。

- 它可以独立存在，无需对话中的额外背景信息。

- 这是你可能稍后会参考或使用的内容。

Claude 几乎可以将任何内容制作成工件，包括文档、代码片段、单页网站、图像、图表和流程图、仪表板以及小型交互式工具。

## 在哪里可以使用工件

- **Claude 网页版和 Claude Desktop：**创建、编辑和共享工件，以及从模板开始。

- **Claude Code：**将会话输出发布为工件，或制作设计和文档。请参阅下面的**[Claude Code 中的工件](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them#h_dca5623bec)**。

- **Claude for iOS 和 Claude for Android：**在任何聊天中请求设计、演示文稿或文档，在**工件**标签中查看结果，并编辑工件。要更改共享设置，请使用 Claude 网页版或 Claude Desktop。

## 从模板开始

模板是你将与他人共享的工作的起点。在任何聊天中请求一个，在消息框中选择"输出"并选择一个模板，或在**工件**标签中选择一个。

- **文档：**你与 Claude 和你的团队实时编写的活文档。在**[Claude 文档入门](https://support.claude.com/en/articles/16923645)**中了解更多信息。

- **幻灯片：**从你的笔记、报告或聊天中已有的工作构建的演示文稿。直接编辑任何幻灯片，在不离开 Claude 的情况下演示，并导出到 PowerPoint 或 PDF。要使用键盘或屏幕阅读器编辑和演示，请参阅下面的**[使用 Claude 幻灯片和键盘](#h_11975db891)**。

- **设计：**使用你的设计系统构建的视觉效果、模型、原型、单页纸和登陆页面。在**[Claude 设计入门](https://support.claude.com/en/articles/14604416)**中了解更多信息。

- **仪表板（测试版）：**从你的数据平台或连接的应用程序（如 Salesforce）构建的仪表板。Claude 编写查询，每个图表显示其查询和上次刷新的时间。在**Claude 仪表板入门**中了解更多信息。

- **Motion（测试版）：**从你的内容构建的动画解释器、图表和演练。要求 Claude 更改任何细节，如单词、数字或时间，其余部分保持不变。将结果导出为 MP4 视频。在 Team 和 Enterprise 计划中可用。在**Claude Motion 入门**中了解更多信息。

无论你从哪个模板开始，工件的工作方式都是相同的：通过与 Claude 交谈或直接在工件中编辑它，当你工作时它会实时更新。准备好后，共享或导出它。

设计和演示文稿可以使用设计系统，因此新工作会采用你的颜色、字体和组件。在**[设置你的设计系统](https://support.claude.com/en/articles/14604397)**中了解更多信息。

## 查找你的工件

你创建的所有内容都保存到 Claude 侧边栏中的**[工件](https://claude.ai/artifacts)**标签，因此你可以从任何对话中再次找到它。从那里你可以在一个地方查看所有工件，从模板开始新的工件，并组织你创建的内容。

## 使用工件

工件在你对话旁边的自己的窗口中打开。从模板创建的工件在你可以直接工作的画布或页面上打开。

## 编辑和迭代

- 要求 Claude 更改工件。

- 在从模板创建的工件中，直接编辑：在文档中输入、编辑幻灯片或在设计画布上移动元素。

- 在文档或 Markdown 文档中，突出显示要更改的文本，单击"使用 Claude 编辑"，然后输入你的请求。Claude 在你标记的位置进行编辑，因此你不必描述你指的是哪个部分。

- 编辑之前的消息以创建聊天的不同版本，具有自己的工件，因此你可以探索另一个方向而不会丢失以前的工作。

**注意：**当 Claude 在多个 Markdown 文件中起草内容（如技能或插件）时，你可以在提交之前在多个文件中留下编辑请求。每个请求都会添加到你的下一条消息中，文件列表显示每个文件中有多少个待处理。发送消息，Claude 在一次通过中应用整个批次。

## 查看和导出

- **从模板创建的工件：**单击"导出"。文档导出到 Word、PDF、Markdown 和 Google Docs。演示文稿导出到 PowerPoint 和 PDF，或直接转到 Google Slides 作为可编辑文件。设计导出为 .zip、PDF、PowerPoint 或独立 HTML，或直接转到另一个工具。动画导出为 MP4 视频。

- **旧版工件：**使用工件面板顶部的控件查看代码、复制内容或下载它。

## 基于已发布的工件进行构建

在 Free、Pro、Max 和 Ultra 计划中可用，适用于从聊天中发布的旧版工件。

如果有人发布了你喜欢的工件，你可以将其用作你自己版本的起点。你的版本是独立的，因此你所做的任何事情都不会影响原始版本。

**重要：**仅对来自你信任的人的工件执行此操作。你正在将他人的代码和内容引入你自己的聊天中，因此请像对待来自未知发件人的文件一样对待它。

1. 打开已发布的工件并单击"复制"以复制其代码。

2. 开始新聊天，粘贴代码，并描述你想要的更改。例如："这是一个测验游戏的代码。将问题改为关于电影的问题并添加计时器。"

3. 以与你自己创建的任何工件相同的方式完善新工件。

## 修复错误

如果工件生成错误，请在错误消息附近查找"尝试使用 Claude 修复"按钮。单击它以将错误详情复制到新消息中，然后将其发送给 Claude 以诊断问题并建议修复。Claude 将尝试修复错误，但不保证成功。某些错误需要更多故障排除。

## 使用 Claude 幻灯片和键盘

要进入和退出工件面板，以及从面板的标题进行评论，请参阅**[使用工件和键盘或屏幕阅读器](https://support.claude.com/en/articles/17457950)**。该文章还解释了焦点的含义、在 Mac 笔记本电脑或 Safari 中的操作方式，以及表格如何显示键。

编辑器分为几个区域：顶部的工具栏、你正在编辑的幻灯片、浮动在所选内容上的格式工具栏、幻灯片缩略图列表和属性面板。

### 在编辑器的区域之间移动

按 F6 移动到下一个区域，按 Shift+F6 移动到上一个区域。Cmd+F6（Windows 上的 Ctrl+F6）可以代替 F6 使用，无论是否带有 Shift。每个区域都会记住你上次在其中的位置。当菜单、弹出窗口或对话框打开时，以及当你演示时，F6 会暂停。

### 编辑幻灯片

当你按 Tab 时，幻灯片是一个单一的停止点。它上面的对象在幻灯片内部：你进入幻灯片以到达它们，组也以相同的方式在其内部有自己的对象。

1. 按 Tab 直到你到达幻灯片。

2. 按 Return 进入幻灯片。

3. 按 Tab 或 Shift+Tab 在幻灯片上的对象之间移动。Tab 不会离开幻灯片。

4. 在文本框上按 Return 开始编辑。光标从文本末尾开始。在组上，Return 会进入组内。

5. 输入您的更改。

6. 按 Escape 或 Tab 完成编辑。您的更改会被保留。

7. 再次按 Escape 返回幻灯片。从组内，Shift+Return 会上升一个级别。

在表格中，Tab 和 Return 在单元格之间移动。按 Escape 或 Cmd+Return（Windows 上为 Ctrl+Enter）完成。

选中独立对象后，箭头键可移动它（作为幻灯片布局一部分的对象会保持在布局指定的位置），F6 可打开其格式工具栏。使用屏幕阅读器时，幻灯片和每个对象会告诉您哪个键进入，哪个键返回。

### 在幻灯片之间移动

在幻灯片上未选中任何内容时，按左箭头或右箭头键，或 Page Up 或 Page Down，以更改幻灯片。使用屏幕阅读器时，您会听到新幻灯片的编号和标题。如果选中了对象，箭头键会移动该对象，因此请先按 Escape。

您也可以按 F6 直到到达缩略图列表。在那里，左箭头和右箭头键在幻灯片之间移动，在您移动时在编辑器中显示每一个，Return 会将您移到该幻灯片。

**重要：**在缩略图上按 Delete 或 Backspace 会立即删除该幻灯片。Cmd+Z（Windows 上为 Ctrl+Z）可恢复。

### 演示幻灯片

1. 按 Tab 直到到达工具栏中的"演示"。

2. 按 Return 打开其菜单。

3. 按 Return 在"演示"上开始。

演示时，按右箭头键或空格键查看下一张幻灯片，按左箭头键查看上一张，按 Escape 结束。使用屏幕阅读器时，当每张幻灯片出现时，您会听到其编号和标题。结束演示后，焦点返回到"演示"。

### 对幻灯片进行评论

要对幻灯片或其上的内容进行评论，请参阅**[使用键盘或屏幕阅读器处理工件](https://support.claude.com/en/articles/17457950)**中的"对幻灯片或设计进行评论"。

画布"视图一次显示所有幻灯片，屏幕阅读器无法读取任何内容。请改用缩略图列表。"

## 在工件中存储数据

在 Pro、Max、Ultra、Team 和 Enterprise 计划中可用，在 Claude 网页版和 Claude Desktop 上可用。

工件可以在会话之间存储数据，因此您可以构建日记、跟踪器和协作工具等内容。存储可以是个人的或共享的：

- **个人存储：**每个人都保留自己的私人数据。在日记工件中，您的条目仅对您可见。

- **共享存储：**每个人都看到并处理相同的数据。在游戏排行榜中，每个人都看到相同的分数。

第一次使用具有共享存储的工件时，Claude 会显示一个确认，说明您的数据将对使用它的其他人可见。

**注意：**在旧版工件中，存储仅在发布后才有效。在构建和测试时，存储操作在发布之前不会成功。新工件无需发布即可存储数据。

存储的限制为每个工件 20 MB，仅接受文本，不接受图像、文件或二进制数据。个人和共享存储是分开保存的，取消发布旧版工件会永久删除其所有存储的数据。

**警告：**构建工件的人决定哪些数据使用个人存储，哪些使用共享存储。在输入任何敏感信息之前，请检查工件是否使用共享存储。

## Claude Code 中的工件

工件在包含 Claude Code 的每个计划中的 Claude Code 中可用。

Claude Code 可以将其会话输出发布为工件，即私有 URL 处的实时交互页面。该页面在您的会话继续时就地更新，您可以分享它。工件可能是带有注释差异的拉取请求演练、从会话数据构建的仪表板，或随着 Claude 工作而填充的调查时间线。

您还可以从 Claude Code 制作设计和文档。使用 /design 进行 Claude Design，或要求提供文档。在桌面上，文档在侧面板中打开。在终端中，Claude 为您提供在网络上打开它的链接。

要了解如何在 Claude Code 中创建、更新和共享工件，请参阅**[Claude Code Docs 上的工件文档](https://code.claude.com/docs/en/artifacts)**。

## 来自 Claude Cowork 的实时工件

2026 年 8 月 19 日之前在 Claude Cowork 中制作的工件是实时工件。它们继续工作，但您无法就地编辑它们。在**[在 Claude Cowork 中使用实时工件](https://support.claude.com/en/articles/14729249)**中了解更多信息。

## 分享工件

工件默认仅对您私有。了解更多关于**[分享工件](https://support.claude.com/en/articles/9547008)**的信息，包括谁可以打开它们以及他们看到的内容。
