# 我如何为企业计划付费？

企业计划的计费分为两部分：固定的席位费和单独的使用费。席位费涵盖平台访问权限。使用费在此基础上单独计费，根据您的团队实际消耗的内容计算。

计费方式取决于您的组织是采用自助式还是销售协助式企业计划，以及您使用的是当前的单一企业席位还是旧版席位类型。下面的部分按计划类型组织——请确保您阅读的部分与您的设置相匹配。如果您不确定自己使用的是哪种计划类型，请咨询设置您企业账户的人员或联系您的 Anthropic 账户经理。价格和计划可能会根据 Anthropic 的决定而改变。

**重要提示：**本文的主要部分介绍当前企业席位计费模式，适用于所有新的企业计划。

- 如果您的组织在过渡到单一企业席位之前已配置，并且您在**[组织设置 > 组织](https://claude.ai/admin-settings/organization)**中看到**Chat**和**Chat + Claude Code**席位类型，请跳转到**[Chat 和 Chat + Claude Code 席位部分](#h_f6aa4f4dd2)**。

- 如果您的组织使用的是具有**标准**和**高级**席位的基于席位的计划，请跳转到**[基于席位的计划部分](#h_3b87de90bd)**。

- 仅限 Chat 的席位和标准/高级席位不再适用于新合同——两种旧版计划类型都将在下次续订时过渡到单一企业席位。

## 席位费

所有基于使用量的企业计划（自助式和销售协助式）使用相同的席位定价：**按用户按月定价，按年计费**。

席位费为每个人提供在网络、桌面和移动设备上访问 Claude 的权限，以及 Claude Code 和 Cowork，但不包括任何使用量。您的团队消耗的每个令牌都按标准 API 费率单独计费。

您需要为计划中的席位数量在年度计费周期开始时付费。如果您在期限内添加席位，您将立即被收取剩余年份的按比例分配金额。

**示例：**您的年度计划从 1 月 1 日开始，有 50 个席位。您需要提前为这些席位付费。4 月 1 日，您添加了 10 个席位。您将立即被收取剩余月份的费用。

**注意：**在自助式企业计划中，席位不能在期限中途移除。有关购买、添加和管理席位的分步说明，请参阅**[在企业计划上购买和管理席位](https://support.claude.com/en/articles/13393991-purchasing-and-managing-seats-on-enterprise-plans)**。

## 使用费计费和付款方式

在基于使用量的企业计划中，使用费与您的席位费分开计费，并基于标准 API 费率下的实际令牌消耗。有关当前的按模型定价，请参阅我们的**[API 定价页面](https://www.anthropic.com/pricing#api)**。

**重要提示：**如果您的组织启用了仅限美国的推理设置，Claude Opus 4.6、Claude Sonnet 4.6 和更新版本的使用费将按标准 API 费率的 1.1 倍计费。这适用于自助式和销售协助式计划。详细了解**[为您的组织启用仅限美国的推理](https://support.claude.com/en/articles/15422948)**。

### 销售协助式企业

**使用费计费**

使用费**按月后付**，基于您的组织在每个计费周期内的实际消耗。您将收到反映该期间使用情况的月度发票。如有关于您的使用发票的问题，请与您的账户经理联系。

**付款方式**

在销售协助式企业计划中，发票不会自动从保存的卡中扣费。每张发票，包括您的席位发票和每月使用发票，都会通过安全付款链接发送到您的组织的计费联系人。付款条款显示在发票上。

您可以通过银行转账（ACH 或电汇）或信用卡付款。50,000 美元或以上的发票只能通过银行转账付款。对于达到或超过此金额的发票，付款页面上不会显示信用卡选项。

要让未来的发票自动从卡中扣费，请联系您的 Anthropic 账户经理，他将与我们的计费团队安排。使用自动付款，您的卡将在发票日期而不是付款期限结束时被扣费。您无法在**[组织设置 > 计费](https://claude.ai/admin-settings/billing)**中设置此功能，因为这些付款方式设置仅适用于自助式企业计划。

## 使用如何在您的团队中工作

企业席位不附带个人令牌额度。您的组织中的所有使用都按 API 费率一起计费，无论谁消耗了它。

这在实践中的样子取决于您的计划类型：

### 自助式企业

每个人的使用都从同一个积分余额中提取。一个人的大量使用会更快地为每个人消耗积分，因此监控和支出限制在这里很重要。当余额达到零时，使用将停止，直到所有者购买更多积分。

### 销售协助式企业

没有要消耗的余额。每个人的使用都被计量并添加到同一张月度发票中。一个人的大量使用不会阻止其他人——它只是增加了账单上显示的内容。如果您想要一个上限，请设置支出限制。

## 支出限制

具有**计费**权限设置为"可管理"的所有者、主要所有者和自定义角色可以设置支出限制来管理您的组织消耗。这适用于自助式和销售协助式计划。

要配置支出限制，请导航到**[组织](https://claude.ai/admin-settings/organization)[设置 > 使用](https://claude.ai/admin-settings/usage)**。

您可以在两个级别设置限制：

- **组织级别：**您的组织中所有使用的最大支出。

- **个人级别：**特定用户的最大支出。

这些限制按层级工作，因此用户不能超过其个人限制或组织限制，以较低者为准。

在**自助式计划**中，支出限制与您的积分余额一起工作。如果用户达到其个人限制或组织限制，即使还有积分，其使用也会停止。所有者可以随时调整限制。

在**销售协助式计划**中，支出限制可防止使用超过限制阈值。如果达到限制，使用将停止，直到下一个计费周期开始或所有者提高限制。

**所有者可以将限制设置为"无限制"，**但消耗仍将被计费。您无法禁用使用费计费——基于使用量的定价是企业计划的核心部分。

## 监控使用和支出

您可以在几个地方跟踪您的组织的使用和支出：

### 组织设置 > 使用

查看每个成员的本月至今支出、当前支出限制状态和积分余额（自助式计划）。

在此页面的顶部是一个名为**被支出限制阻止**的部分，显示成员达到其支出限制的频率。**被支出限制阻止**是为基于使用量的企业计划构建的。没有基于使用量的席位的组织只会看到有多少成员现在被阻止或接近其限制。

您将在顶部看到三个指标：

- **现在被阻止：**当前因达到支出限制而被锁定的用户数。单击此项可查看他们是谁。

- **接近其限制：**接近其支出限制的用户数。

- **本月成员天数损失：**本月您的组织中被阻止使用的总天数，与上月同一天相比。

下方是一个图表，显示本月每个活跃席位的限制时间，适用于所有成员和您的高级用户（按支出排名前 10%），与之前的月份进行对比，并预测本月的走向。它还指出哪个组或限制类型占用了最多的限制时间，因此您可以快速看到限制按预期工作的地方，以及您最活跃的用户可能需要更多空间的地方。

您可以从同一页面调整限制，包括提高席位类型的默认值或增加达到该限制的成员的限制。

**注意：**如果用户的额外使用支出限制设置为 $0，则完全为他们关闭额外使用。他们可能会出现在"现在被阻止"计数中，但他们的时间不会被计为因支出限制而损失的时间。成员天数数字和图表仅包括限制高于 $0 且达到其限制的成员。

### 月度发票

查看计费周期内每个用户的详细使用情况（销售协助式计划）。

### 支出限制通知

当用户或您的组织接近配置的支出阈值时获取警报。

## 使用停止时会发生什么

如果您的企业计划上的使用停止，具有**计费**权限设置为"可管理"的所有者、主要所有者和自定义角色可以按以下方式恢复：

- **自助式计划：**如果积分用完或达到支出限制，请从**[组织](https://claude.ai/admin-settings/organization)[设置 > 使用](https://claude.ai/admin-settings/usage)**购买额外积分或提高支出限制。

- **销售协助式计划：**如果达到支出限制，您可以提高限制，或使用将在下一个计费周期开始时恢复。如有问题，请联系您的账户经理。

## Chat 和 Chat + Claude Code 席位

**重要提示：**Chat 和 Chat + Claude Code 是不再适用于新企业合同的旧版席位类型。本部分仅适用于在过渡到单一企业席位之前使用这些席位类型配置的组织。如果您最近签署了新的企业合同，本文的主要部分适用于您——您的计划使用单一企业席位。

一些现有的基于使用量的企业组织目前有两种定价不同的席位类型。如果您在**[组织设置 > 组织](https://claude.ai/admin-settings/organization)**中看到**Chat**和**Chat + Claude Code**席位，本部分适用于您。

席位费按年计费。使用费计费的工作方式与上面**[使用费计费部分](#h_540cbc3861)**中描述的相同：与席位费分开、按 API 费率、在销售协助式计划中按月后付。

### 过渡到单一企业席位

在您的下一次合同续订时，您的计划将自动过渡到单一企业席位模式。当这种情况发生时，所有用户——无论其当前席位类型如何——都将移至**企业席位**。此席位包括 Claude Code、Cowork、Chat 等。

如果您对即将进行的续订有任何疑问，请联系您的 Anthropic 联系人或**[我们的销售团队](https://claude.com/contact-sales)**。

## 基于席位的计划

**重要提示：**标准和高级是不再适用于新企业合同的旧版席位类型。本部分仅适用于在过渡到基于使用量的计费之前使用这些席位类型配置的组织。如果您最近签署了新的企业合同，本文的主要部分适用于您。

一些企业组织使用的是具有**标准**和**高级**席位的较旧的基于席位的计划。这些计划按席位收取固定的月费，包括使用额度，这是一种与上述基于使用量的计费不同的模式。

如果您在**[组织设置 > 组织](https://claude.ai/admin-settings/organization)**中看到"标准"和"高级"席位，本部分适用于您。

在基于席位的计划中，使用积分可用于允许团队成员在达到其席位的包含限制后继续工作。有关使用积分如何工作以及如何在您的计划中计费的详细信息，请参阅**[管理团队和基于席位的企业计划的使用积分](https://support.claude.com/en/articles/12005970-)**。

### 过渡到基于使用量的企业

在您的下一次合同续订时，您的计划将过渡到本文中描述的基于使用量的单一企业席位模式。如果您想在续订前迁移，请联系您的 Anthropic 联系人或**[我们的销售团队](https://claude.com/contact-sales)**。
