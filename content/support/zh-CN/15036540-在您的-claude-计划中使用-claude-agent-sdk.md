# 在您的 Claude 计划中使用 Claude Agent SDK

**2026 年 10 月 7 日更新：**Claude Max、Ultra 和 Team 计划现已包含**[每月 API 额度](https://support.claude.com/en/articles/17154008)**。这些额度涵盖 Claude API、Claude Managed Agents 以及当您使用来自关联 Claude Console 组织的 API 密钥运行 Claude Agent SDK 和 `claude -p` 时的使用。您的计划不会改变：当您使用 Claude 计划登录时，Claude Agent SDK 和 `claude -p` 仍然从您的订阅限额中扣除。

**2026 年 6 月 15 日更新：**我们已暂停之前宣布的 Claude Agent SDK 使用方式变更。目前，一切保持不变：Claude Agent SDK、`claude -p` 和第三方应用使用仍然从您的订阅限额中扣除。
