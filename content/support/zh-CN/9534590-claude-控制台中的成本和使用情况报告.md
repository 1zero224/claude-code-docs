# Claude 控制台中的成本和使用情况报告

Claude 控制台提供详细的成本和使用情况报告，帮助您有效管理 API 使用情况和相关成本。本指南将引导您了解这些功能及其使用方法。

使用情况和成本报告对以下用户角色可见：**开发者、账单和管理员**。有关更多信息，请参阅 **[Claude 控制台角色和权限](https://support.claude.com/en/articles/10186004-claude-console-roles-and-permissions)**。

## 访问成本和使用情况报告

有权限的用户可以在以下地址打开这些报告。

## 使用情况报告

**使用情况**页面 (platform.claude.com/usage) 提供了您跨不同模型和 API 密钥的 API 使用情况的详细分解。

### 主要功能

- **详细分解**：按模型、日期/时间和 API 密钥查看使用情况数据。点击柱状图上的柱子可获得小时和分钟级别的粒度。

- **灵活筛选**：使用选择器选择特定的模型、月份或 API 密钥

- **可视化表示**：显示输入和输出令牌计数的图表。

- **使用情况统计**：查看所选筛选条件的总输入和输出令牌。

- **速率限制请求：**查看因达到速率限制而被阻止的请求。

- **速率限制使用：**显示每分钟输入和输出令牌与整体 ITPM 或 OTPM 速率限制的对比可视化。

- **CSV 导出**：下载您的使用情况数据以进行进一步分析或报告。

### 如何使用

1. 选择您要查看的工作区（或选择"所有工作区"）。

2. 选择您要查看的模型（或选择"所有模型"）。

3. 选择您感兴趣的月份（或缩小到特定的月份/日期）。

4. 选择 API 密钥（或查看所有密钥的数据）。

5. 图表和统计数据将根据您的选择进行更新。

6. 使用导出按钮下载显示数据的 CSV 文件。

### 速率限制使用

使用情况页面还包括一个单独的部分，显示每个模型的输入和输出令牌的速率限制使用情况。您可以点击此部分左上角的下拉菜单来更改模型并查看相关的速率限制指标。这些可视化可用于确定您的组织何时达到峰值使用，哪些特定的速率限制需要增加，以及如何增加您的缓存速率。

**速率限制使用 + 缓存 - 输入令牌：**此图表显示每小时最大未缓存输入令牌数/分钟 (ITPM) 以及您的缓存速率（即从缓存读取的输入令牌百分比）和您当前的 ITPM 速率限制。

**速率限制使用 - 输出令牌：**此图表显示每小时最大输出令牌数/分钟 (OTPM) 以及您当前的 OTPM 速率限制。

## 成本报告

**成本**页面 (platform.claude.com/cost) 帮助您了解跨不同模型的支出。

### 主要功能

- **特定于模型的数据**：查看单个模型或所有模型的成本。

- **月度分解**：查看特定月份的成本。

- **每日成本图表**：可视化您随时间的支出。

- **总成本统计**：获得所选期间的总支出概览，包括网络搜索和代码执行成本。

- **CSV 导出**：下载成本数据以供您记录和进一步分析。

### 如何使用

1. 选择您要查看成本的工作区（或选择"所有工作区"）。

2. 选择您要查看成本的模型（或选择"所有模型"）。

3. 选择您感兴趣的月份。

4. 您可以看到图表、令牌成本和工具使用成本，这些将根据您的选择进行更新。

5. 使用导出按钮下载成本数据的 CSV 文件。

**注意**：目前无法按单个用户分解使用情况或成本。
