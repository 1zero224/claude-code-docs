# 受限模型和访问程序的规划

您的组织可以通过验证程序获得某些访问权限，然后在您使用的每个平台上启用。如果您的组织目前依赖某个程序或受限模型，请将其作为单独的步骤进行规划，并预留充足的准备时间。

本指南适用于 Claude Enterprise 计划的组织管理员。

本文是 **[从 Claude Enterprise 迁移到云提供商上的 Claude Desktop](https://support.claude.com/en/articles/18426225)** 的一部分，该指南定义了波次、重叠期和截止日期等术语。

自定义角色和模型访问设置在您的 Claude Enterprise 组织中进行配置。在第三方云提供商的 Claude Desktop 上，**[您自己的配置决定了选择器提供哪些模型](https://claude.com/docs/third-party/claude-desktop/models)**，因此请计划重新设置这些内容。

## 网络安全验证计划 (CVP)

有关资格、访问层级、数据保留和申请方式，请参阅 **[网络安全验证计划](https://support.claude.com/en/articles/14604842-cyber-verification-program)**。对于迁移，请规划以下几点：

- **关联每个云账户：**在验证门户中，关联您的 AWS 账户、Google Cloud 项目或 Azure 订阅。该文章提供了每个平台的步骤。即使您仅使用云提供商，也需要 Anthropic 账户才能使用该门户。

- **检查可用性：**在 Amazon Bedrock 上，可用性受限。检查程序文章以了解谁符合资格。在 Google Cloud 的 Agent Platform 上，接受《高级 AI 安全附录》，然后为您使用的每个模型和位置启用高级 AI 功能和数据共享。请参阅 **[Google 的注册步骤](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/partner-models/claude/cyber-verification-program)**。

- **预留准备时间：**在云提供商上，对程序受限模型的访问权限在获得批准后约需五个工作日。承诺合同会在云市场中添加表单和私人报价。

- **凭证：****[安全要求](https://support.claude.com/en/articles/17202708-cyber-verification-program-security-requirements)**不允许长期有效的云凭证（对于防御访问，请参阅文章了解何时适用），每个获批用户必须以自己的身份登录。在决定用户如何向您的提供商进行身份验证之前，请检查这些要求。

- **如果您已获得批准：**每个 Claude 组织需要自己的应用程序。要添加云账户，请在验证门户中将其关联到同一 Anthropic 组织。您不需要新的应用程序。同时为新账户启用您的层级。

## 其他程序

每个程序都列出了它支持的平台。例如，**[生命科学验证计划](https://www.anthropic.com/news/life-sciences-verification-program)**处于测试阶段，尚未在第三方平台上提供。其下的访问权限保留在 Enterprise 计划、Team 计划和 API 上。

## 受限模型

某些模型仅通过类似这样的有限访问程序提供。**[受限模型](https://support.claude.com/en/articles/15425695-covered-models)**列出了这些模型，**[每个模型的页面列出了它可用的平台](https://platform.claude.com/docs/en/models/overview)**。
