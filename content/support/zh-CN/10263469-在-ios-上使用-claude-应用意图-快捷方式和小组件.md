# 在 iOS 上使用 Claude 应用意图、快捷方式和小组件

本指南中描述的功能在 iOS 18 及更高版本上可用。

Claude for iOS 支持多项强大功能：Claude 小组件、"使用 Claude 分析照片"控制、"询问 Claude"应用意图，以及在 iOS 快捷方式中使用此意图的功能。本指南将解释这些功能并向您展示如何充分利用它们。

## 询问 Claude 意图

询问 Claude"意图是一项独立功能，让您可以直接从以下位置与 Claude 交互："

- Spotlight 搜索

- Siri

- 分享菜单

- 任何支持 iOS 意图的应用

您可以单独使用此意图快速向 Claude 提问或分配任务，而无需打开 Claude 应用。例如，您可以：

- 选择文本并使用分享菜单将其直接发送给 Claude

- 要求 Siri"询问 Claude"，它会提示您输入消息

- 在 Spotlight 搜索中输入"询问 Claude"以快速发送查询

## 将询问 Claude 与快捷方式一起使用

虽然"询问 Claude"意图本身功能强大，但您也可以将其用作快捷方式应用中的构建块来创建更复杂的工作流。快捷方式允许您：

- 将多个"询问 Claude"操作链接在一起

- 将 Claude 的功能与其他应用和操作相结合

- 创建自动化工作流

- 以各种方式处理 Claude 的响应

## 创建您的第一个 Claude 快捷方式

您可以在快捷方式应用中设置许多可自定义的工作流。让我们看一个简短但有用的快捷方式示例，它可以帮助您总结文本：

1. 在您的 iOS 设备上打开快捷方式应用

2. 点击"+"按钮创建新快捷方式

3. 添加"分享"操作并选择您首选的输入类型

4. 添加"询问 Claude"操作

5. 在"询问 Claude"操作中，创建如下提示：

6. 为您的快捷方式命名（例如，"使用 Claude 总结"）

7. 可选：将快捷方式添加到您的分享表以便轻松访问

现在您可以在 iOS 中的任何位置选择文本，点击分享按钮，然后选择您的"使用 Claude 总结"快捷方式以获得即时摘要。

使用"询问 Claude"意图和快捷方式时，将使用打开 Claude 应用时看到的默认模型。

有关在您的 iOS 设备上设置快捷方式的更多信息，请参阅[此处](https://support.apple.com/guide/shortcuts/welcome/ios)。

**注意：**使用"询问 Claude"意图时，发送给 Claude 的消息将计入您的总体使用限制。

## 添加 Claude 小组件

Claude 小组件提供从您的主屏幕或今日视图直接访问聊天和语音功能的快速方式。小组件包括以下按钮：

- 开始新聊天

- 立即以听写模式打开应用

- 拍照与 Claude 分享

### 将 Claude 小组件添加到您的主屏幕

1. 从主屏幕，触摸并按住小组件或空白区域，直到应用抖动

2. 点击左上角的编辑

3. 点击添加小组件

4. 搜索并选择 Claude

5. 点击添加小组件

6. 点击完成

### 将 Claude 小组件添加到您的今日视图

从主屏幕或锁定屏幕向右滑动，然后按照与添加到主屏幕相同的步骤操作。

### 使用小组件

- 点击聊天按钮与 Claude 开始新对话。

- 点击麦克风按钮立即以听写模式打开应用，允许您立即开始与 Claude 交谈。

- 点击相机按钮拍照并与 Claude 分享以进行分析。

**注意：**与"询问 Claude"意图一样，通过小组件启动的交互将计入您的使用限制。

## 使用 Claude 分析照片"控制"

使用 Claude 分析照片"控制让您可以直接从控制中心或锁定屏幕快速将图像发送给 Claude 进行分析。"

### 添加到控制中心

1. 打开控制中心（在配备 Face ID 的 iPhone 上从右上角向下滑动，或在配备主屏幕按钮的 iPhone 上从底部向上滑动）

2. 点击控制中心左上角的添加按钮（加号）开始编辑

3. 点击屏幕底部的"添加控制"以打开控制库

4. 找到并点击"使用 Claude 分析照片"将其添加到控制中心

5. 您可以通过将其拖动到您首选的位置来重新排列其位置

6. 完成后，通过从屏幕底部中心向上滑动来关闭控制中心

添加后，您可以通过从屏幕右上角向下滑动来从控制中心快速访问它。

有关使用和设置控制中心控制的更多信息，请参阅[此处](https://support.apple.com/guide/iphone/use-and-customize-control-center-iph59095ec58/ios)。

### 添加到您的锁定屏幕

1. 在您的锁定屏幕上，触摸并按住直到自定义屏幕出现

2. 点击"自定义"

3. 选择您要修改的锁定屏幕

4. 使用删除按钮（减号）删除屏幕底部的其中一个控制，然后点击添加按钮（加号）打开控制库

5. 从可用控制菜单中，滚动或搜索"使用 Claude 分析照片"

6. 点击选择它

7. 点击"完成"保存您的更改

现在您可以快速访问"使用 Claude 分析照片"控制，而无需解锁设备或首先打开 Claude 应用。
