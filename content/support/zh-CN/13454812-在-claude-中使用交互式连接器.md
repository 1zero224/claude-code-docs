# 在 Claude 中使用交互式连接器

所有 Claude、Cowork、Claude Desktop 和 Claude for iOS/Android 用户都可以使用交互式连接器。

## 什么是交互式连接器？

某些连接器现在可以直接在 Claude 对话中显示实时交互式应用。这些连接器不再只返回纯文本响应，而是呈现界面（如分析仪表板、任务板或设计工具），您可以在不离开聊天的情况下与之交互。

例如，您可以询问 Claude 您的项目状态，Claude 不仅会描述它，还会在对话中打开您的 Asana 看板。您可以勾选任务、更新状态，并继续与 Claude 聊天——一切都在一个地方完成。

Claude 还可以生成自己的自定义视觉效果——为您的问题从头开始构建的图表、图形和简单交互式元素。当连接的服务提供可处理您的请求的交互式界面（如 MCP 应用）时，Claude 会使用它。当没有连接器界面适合您的需求时，自定义视觉效果可以填补空白。

有关 Claude 生成的视觉效果的更多信息，请参阅 **[聊天中的自定义视觉效果](https://support.claude.com/en/articles/13979539-custom-visuals-in-chat)**。

---

## 交互式连接器的显示方式

交互式连接器以两种方式显示：

**内联卡片**是直接嵌入对话中的紧凑组件。它们非常适合快速摘要、确认和单个操作——如状态更新或准备发送的消息草稿。

**全屏视图**为复杂交互（如数据可视化、文档编辑或详细项目视图）提供沉浸式界面。对话输入框保持可用，因此您可以在与连接器交互的同时继续与 Claude 聊天。

## 与连接器交互

您可以直接与连接器内的元素交互：

- 筛选、排序或深入数据

- 切换设置、勾选复选框或进行选择

- 确认并执行操作（标记完成、发送、保存）

- 展开和折叠内容部分

如果您需要要求 Claude 修改某些内容、优化结果或导航到不同的上下文，请在对话输入框中输入——Claude 可以解释您的请求并相应地更新界面。

## 哪些连接器是交互式的？

在 **[连接器目录](https://claude.ai/directory)**中，具有此功能的连接器会标有"交互式"徽章。当前的交互式连接器包括：

- **Amplitude** — 查看和交互分析仪表板

- **Asana** — 管理任务和项目看板

- **Box** — 处理文档和文件

- **Canva** — 创建和编辑设计

- **Clay** — 管理联系人和外展

- **Figma** — 审查和注释设计

- **Hex** — 探索数据和笔记本

- **Slack** — 起草和发送消息

我们将随着时间的推移为更多交互式连接器添加支持。

## 开始使用交互式连接器

1. 导航到 **[连接器目录](https://claude.ai/directory)**。

2. 查找标有"交互式"徽章的连接器。

3. 连接并使用连接器进行身份验证。

4. 与 Claude 开始对话，并询问连接器处理的相关内容——当相关时，交互式元素将自动出现。

**注意：**启用相关连接器后，交互式连接器默认处于打开状态。无需额外设置。

## 团队和企业计划的注意事项

### 团队和企业所有者能否单独控制交互式连接器与标准连接器？

可以。团队和企业所有者可以在 **[组织设置 > 连接器](https://claude.ai/admin-settings/connectors)**中禁用呈现交互式连接器的特定工具调用。这不会禁用连接器本身——基于文本的工具功能继续正常工作。

## 权限和安全

### 交互式连接器如何保护？

交互式连接器在具有严格内容安全策略的沙箱 iframe 中运行。界面和 Claude 之间的所有通信都使用可审计的 JSON-RPC 消息传递。服务器必须预先声明它们需要的外部域，主机可以在呈现前审查 HTML 内容。

### 交互式连接器是否需要超出连接器本身的额外权限？

否。交互式连接器使用您在连接工具时授予的相同权限。它们不会请求对您数据的额外访问权限。

### 交互式连接器能否进行购买或财务交易？

否。不支持通过第三方交互式连接器进行购买。

## 故障排除

### 界面未出现

- 检查连接器是否已连接并为您当前的对话启用。

- 尝试开始新对话，并询问 Claude 连接器处理的问题。

### 连接器未响应交互

- 检查您的互联网连接。

- 尝试刷新页面或重启 Claude Desktop。

- 如果问题仍然存在，请在 **自定义 > 连接器**中断开连接并重新连接连接器。

### 我想禁用交互式连接器

- **团队和企业用户：**请要求您的组织所有者在 **[组织设置 > 连接器](https://claude.ai/admin-settings/connectors)**中禁用相关工具调用。

- **个人用户：**您可以通过对话中的"搜索和工具"菜单禁用特定连接器工具。

## 我是开发者。我在哪里可以了解构建 MCP 应用？

MCP Apps 是为交互式应用提供支持的模型上下文协议的开源扩展。如果您正在构建自己的交互式连接器，请注意它必须满足额外的设计、安全和测试要求。有关详细信息，请参阅 Claude Docs 上的 **[提交到连接器目录](https://claude.com/docs/connectors/building/submission)**。
