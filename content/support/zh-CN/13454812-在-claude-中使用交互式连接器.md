# 在 Claude 中使用交互式连接器

交互式连接器适用于 Claude、Cowork、Claude Desktop 和 Claude for iOS/Android 上的所有用户。侧面板、全站点视图以及从 Claude 导航中打开或固定交互式连接器的功能正在向具有新 Claude 体验的账户在网页和 Claude Desktop 上推出。这些功能在 Claude Mobile 上暂不可用。

## 什么是交互式连接器？

某些连接器现在可以在 Claude 对话中直接显示实时交互式应用。这些连接器不再只返回纯文本响应，而是呈现界面（如分析仪表板、任务板或设计工具），您可以在不离开聊天的情况下与之交互。

例如，您可以询问 Claude 您的项目状态，Claude 不仅会描述它，还会在对话中打开您的 Asana 看板。您可以勾选任务、更新状态，并继续与 Claude 聊天——所有操作都在一个地方完成。

某些交互式连接器还可以在 Claude 中打开工具的网站。您可以自己进行更改，也可以要求 Claude 进行更改。每个连接器的开发者选择支持哪些视图和操作，因此您看到的内容因连接器而异。

Claude 还可以生成自己的自定义视觉效果——为您的问题从头开始构建的图表、图形和简单交互元素。当连接的服务提供可处理您请求的交互式界面（如 MCP 应用）时，Claude 会使用它。当没有连接器界面适合您的需求时，自定义视觉效果可以填补空白。

有关 Claude 生成的视觉效果的更多信息，请参阅 **[聊天中的自定义视觉效果](https://support.claude.com/en/articles/13979539-custom-visuals-in-chat)**。

## 交互式连接器的显示方式

交互式连接器以三种方式显示：

**内联卡片**是直接嵌入对话中的紧凑组件。它们非常适合快速摘要、确认和单个操作——如状态更新或准备发送的消息草稿。

**侧面板**将交互式连接器保持在聊天旁边打开，因此您可以继续聊天并观看其更新。从面板的标题栏将其展开为全屏。

**全屏视图**为复杂交互（如数据可视化、文档编辑或详细项目视图）提供沉浸式界面。对话输入保持可用，因此您可以在与连接器交互时继续与 Claude 交谈。

如果您需要要求 Claude 修改某些内容、优化结果或导航到不同的上下文，请在对话输入中输入——Claude 可以解释您的请求并相应地更新界面。Claude 只能执行连接器开发者提供的操作。您以与批准任何连接器操作相同的方式批准这些操作。

## 与连接器交互

您可以直接与连接器内的元素交互：

- 筛选、排序或深入数据

- 切换设置、勾选复选框或进行选择

- 确认并执行操作（标记完成、发送、保存）

- 展开和折叠内容部分

- 要求 Claude 在您打开的交互式连接器中进行更改

如果您需要要求 Claude 修改某些内容、优化结果或导航到不同的上下文，请在对话输入中输入——Claude 可以解释您的请求并相应地更新界面。

## 打开并固定交互式连接器

您可以从 Claude 导航中打开受支持的交互式连接器而无需先询问 Claude，并将其固定到您的侧边栏。当交互式连接器以全页方式打开时，在底部的框中询问 Claude 相关问题，或自己在其中工作。

**注意：**固定是按浏览器保存的，因此您在网页上添加的固定不会出现在 Claude Desktop 中。

## 哪些连接器是交互式的？

在 **[连接器目录](https://claude.ai/directory)**中，具有此功能的连接器标有 “交互式”徽章。当前交互式连接器包括：

- **Amplitude** — 查看和交互分析仪表板

- **Asana** — 管理任务和项目看板

- **Box** — 处理文档和文件

- **Canva** — 创建和编辑设计

- **Clay** — 管理联系人和外展

- **Figma** — 审查和注释设计

- **Hex** — 探索数据和笔记本

- **Slack** — 起草和发送消息

我们正在随着时间的推移添加对更多交互式连接器的支持。

## 开始使用交互式连接器

1. 导航到 **[连接器目录](https://claude.ai/directory)**。

2. 查找标有 “交互式”徽章的连接器。

3. 连接并使用连接器进行身份验证。

4. 与 Claude 开始对话，并询问连接器处理的相关内容——当相关时，交互式元素将自动出现。

**注意：**启用相关连接器时，交互式连接器默认处于打开状态。无需额外设置。

## Team 和 Enterprise 计划的注意事项

### Team 和 Enterprise 所有者能否单独控制交互式连接器与标准连接器？

可以。Team 和 Enterprise 所有者可以在 **[组织设置 > 连接器](https://claude.ai/admin-settings/connectors)**中禁用呈现交互式连接器的特定工具调用。这不会禁用连接器本身——基于文本的工具功能继续正常工作。

## 权限和安全

### 交互式连接器如何保护？

聊天内视图在具有严格内容安全策略的沙箱 iframe 中运行。界面和 Claude 之间的所有通信都使用可审计的 JSON-RPC 消息传递。服务器必须预先声明它们需要的外部域，主机可以在呈现前审查 HTML 内容。

### 交互式连接器是否需要超出连接器本身的额外权限？

交互式连接器使用您在连接工具时授予的相同权限。

### 谁提供交互式连接器？

第三方交互式连接器由连接器的开发者提供，开发者对显示的内容负责。

### 交互式连接器能否进行购买或财务交易？

不能。不支持通过连接器的聊天内视图进行购买。

## 故障排除

### 界面未显示

- 检查连接器是否已连接并为您当前的对话启用。

- 尝试开始新对话并询问 Claude 连接器处理的问题。

### 连接器未响应交互

- 检查您的互联网连接。

- 尝试刷新页面或重启 Claude Desktop。

- 如果问题仍然存在，请在 **自定义 > 连接器**中断开连接并重新连接连接器。

### 我想禁用交互式连接器

- **Team 和 Enterprise 用户：**要求您的组织所有者在 **[组织设置 > 连接器](https://claude.ai/admin-settings/connectors)**中禁用相关工具调用。

- **个人用户：**您可以通过对话中的 “搜索和工具”菜单禁用特定连接器工具。

## 我是开发者。我在哪里可以了解构建 MCP 应用？

MCP Apps 是为交互式应用提供支持的模型上下文协议的开源扩展。如果您正在构建自己的交互式连接器，请注意它必须满足额外的设计、安全和测试要求。有关详细信息，请参阅 Claude Docs 上的 **[提交到连接器目录](https://claude.com/docs/connectors/building/submission)**。
