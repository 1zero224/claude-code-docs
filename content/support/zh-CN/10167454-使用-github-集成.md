# 使用 GitHub 集成

将您的 GitHub 存储库直接连接到 Claude，为您的软件开发任务提供全面的上下文。您可以通过从列表中选择存储库来轻松添加存储库，帮助 Claude 更好地理解和协助您的代码库。

有关在您的账户中启用 GitHub 的更多信息，请参阅 **[使用连接器扩展 Claude 的功能](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)**。

## 如何添加 GitHub 存储库

**注意：**  如果您当前未通过 GitHub 身份验证，您将被重定向到 GitHub 进行身份验证，然后才能使用此集成。

### 聊天

1. 点击聊天界面左下角的 "+" 按钮。

2. 从下拉菜单中选择 "从 GitHub 添加"。

3. 使用文件浏览器选择特定的文件和文件夹。

4. 当您发送消息时，Claude 将访问并处理内容以告知其响应。

### 项目

1. 点击项目知识部分右上角的 "+" 按钮。

2. 从下拉菜单中选择 "GitHub"。

3. 搜索您可访问的存储库，或粘贴存储库 URL。

4. 使用文件浏览器选择特定的文件和文件夹。

5. 您选择的内容将被添加到项目知识中，供 Claude 访问和处理。

6. 您可以使用 "同步" 图标确保您使用的是代码库的最新版本。

7. 您可以使用 "配置文件" 图标来修改 Claude 分析的文件和文件夹。

## 连接到私有存储库

- **如果 Claude 在您输入有效 URL 后无法访问存储库，这很可能意味着您正在尝试将 Claude 连接到私有存储库**：请访问我们的 GitHub App 链接，如果您是 GitHub 管理员，可以授予对存储库的访问权限，或向您的 GitHub 组织管理员发送请求。

- **如果可以，请自行授予访问权限**：您可以选择让 Claude 访问所有存储库或特定存储库。

- **如果您没有必要的权限，请请求访问权限**：您的 GitHub 组织管理员将收到有关您的请求的电子邮件通知。一旦他们批准请求，您将能够在 Claude 中同步和访问存储库。

## 最佳实践

1. **从小处开始**：首先选择代码库的一个小子集进行分析。这将帮助您熟悉 Claude 如何解释和讨论您的代码。

2. **迭代和改进**：如果 Claude 的初始响应没有完全解决您的问题，请不要犹豫，提出后续问题或请求澄清。

3. **结合人类专业知识**：使用 Claude 的见解作为进一步调查和与您的团队讨论的起点。请审查 Claude 的工作。

4. **深思熟虑的文件选择**：使用 "配置文件" 时，要对您的选择进行战略性考虑。包括对您当前任务或项目至关重要的关键文件和目录，但避免选择不必要的文件以保持在令牌限制内并保持专注。

5. **定期更新**：记住定期刷新您项目的 GitHub 同步，以确保 Claude 使用的是代码库的最新版本，特别是在开始新分析之前或当您知道存储库有重大更改时。

## 故障排除

### 连接后组织中的存储库未出现

如果您的 GitHub 连接显示为已连接，但来自特定组织的私有存储库未出现，该组织可能需要单点登录 (SSO)。需要 SSO 时，每个用户必须分别为该组织授权 Claude 应用。在您这样做之前，GitHub 会从您的视图中过滤该组织的私有存储库，即使您的连接在其他方面正常工作。

当 Claude 检测到此状态时，存储库选择器会显示一个横幅，提示您授权 SSO。要为您的组织授权 Claude 应用：

1. 转到 **[github.com/settings/applications](https://github.com/settings/applications)** 并打开 **Claude** 条目。

2. 在 **组织访问** 下，点击相关 GitHub 组织旁边的 "授予"。

3. 如果按钮显示 "请求" 而不是 "授予"，则您没有权限自行授权该应用。GitHub 组织管理员必须从组织的 OAuth 应用策略设置中批准您的请求。

**重要：**在您的 Claude 设置中断开连接并重新连接 GitHub 不会解决此问题。新连接不会自动授权需要 SSO 的组织，因此您需要完成上述授权步骤。

如果您的组织使用带有企业托管用户 (EMU) 的 GitHub Enterprise Cloud，请在使用您的托管账户登录并有活跃 SSO 会话时连接 GitHub。组织所有者可以在您的 GitHub 组织中的"设置">"第三方访问">"GitHub 应用"下检查 Claude 应用，并确认它有权访问您需要的存储库且没有待处理的权限请求。

### 无法将 GitHub 链接到零数据保留的组织

如果您的组织为 Claude Code 启用了零数据保留 (ZDR)，您无法将 Claude GitHub 应用链接到您的 Claude 组织。这是 ZDR 的限制，而不是 GitHub 权限问题：链接需要 Anthropic 存储您的组织的 GitHub 连接，而 ZDR 不允许这样做。

当您尝试在 **[组织设置 > Git 提供商](https://claude.ai/admin-settings/source-control)** 中链接 GitHub 时，您可能会看到一条错误消息，说您需要是 GitHub 组织的所有者，即使您已经是所有者。

**重要：**更改 GitHub 上的角色或应用权限，或断开连接并重新连接 GitHub，都不会解决此问题。由于同样的原因，Claude Code 分析中的贡献指标对 ZDR 组织不可用。

如果您的组织需要 GitHub 链接，请联系您的 Anthropic 账户团队讨论您的 ZDR 配置。了解更多关于 **[Claude Code 的零数据保留](https://code.claude.com/docs/en/zero-data-retention#zero-data-retention)**。

## 常见问题

### 从 GitHub 检索了哪些信息？

仅同步存储库中特定分支上的文件（名称和内容）。我们不检索提交历史、PR 或其他元数据。

### 如果我的存储库在添加到项目后被更新会发生什么？

您可以点击 "立即同步" 从您的存储库获取最新更改。这将更新所有先前选择的文件和文件夹。

### 我可以将多个存储库添加到单个项目或聊天吗？

是的，您可以添加多个存储库为 Claude 提供开发任务的全面上下文。存储库必须适应 Claude 的上下文窗口。

### 如果我失去对存储库的访问权限会发生什么？

如果您失去对存储库的访问权限，您将无法在之前添加它的项目中查看其内容。存储库预览将被删除，但对话历史将被保留。

在 **[连接器目录](https://claude.ai/directory)** 中浏览所有可用的连接器。
