# 按成本代码跟踪支出（使用项目标签）

本文介绍如何使用贵组织已在使用的代码（如工作分解结构 (WBS) 代码、费用代码或客户事项编号）为项目添加标签。之后，您可以在组织设置中或通过 API 查看这些项目中的大部分支出（按标签分类）。

项目标签在 Claude Enterprise 计划中以测试版形式提供。不适用于具有 HIPAA 配置、客户管理的加密密钥 (CMEK)、零数据保留 (ZDR)（包括 Claude Code 的 ZDR）、最小数据保留或数据存储在美国以外的组织。也不适用于通过自己的模型提供商路由 Claude Desktop 的组织。

**重要提示：**项目标签仅在项目内有效。项目外的工作不会获得标签。

## 项目标签的工作原理

项目标签使用两个部分：

- **标签：**您报告的类别，如 `cost_code` 或 `client_matter`。

- **值：**代码本身，如 `CC-1042`。

所有者创建标签及其值，任何可以编辑项目的人都可以为该项目设置值。每个标签每个项目只保存一个值，一个项目最多可以有 16 个标签。

## 开始前

- **创建标签和管理其值所需的角色：**主所有者、所有者或具有所有者访问权限的自定义角色

- **设置项目标签所需的角色：**对项目具有"可编辑"访问权限

- **按标签查看支出所需的角色：**主所有者、所有者或具有分析视图和计费视图访问权限的自定义角色

- **创建 API 密钥所需的角色：**主所有者

## 设置项目标签

项目标签对符合条件的组织自动启用，没有打开的设置。要开始，请创建一个标签。

## 创建标签并添加其值

所有者可以按照以下步骤创建标签：

1. 导航到**[组织设置 > 组织 > 项目标签](https://claude.ai/admin-settings/tags)**。

2. 点击"创建标签"。

3. 输入名称，如 `cost_code`。名称为小写且不含空格，之后无法更改名称。

4. 在**允许的值**下，选择"仅预定义值"让用户从您的列表中选择，或选择"任何值"让他们输入自己的值。

5. 如果您选择了"仅预定义值"，请在**值**下添加您的列表。每行输入一个值，或添加一个 CSV 文件，其中包含以 `value` 为标题的单列。

6. （可选）打开"必需"切换开关，使用户必须在新项目上设置值。

7. 点击"继续"。

要稍后添加值，请在**项目标签**页面上打开标签，然后点击"添加值"或"导入 CSV"。

**注意：**标签名称和值对组织中的所有用户可见，因此请勿在其中包含敏感信息。

## 将标签添加到项目

任何具有"可编辑"访问权限的人都可以将标签添加到项目：

1. 打开项目。

2. 在**标签**下，点击"添加标签"。

3. 选择标签，然后选择或输入值。

**注意：**标签名称和值对组织中的所有用户可见，因此请勿在其中包含敏感信息。

## 为 Claude Code 设置项目

Claude Code 没有项目选择器，因此用户在设置文件中设置项目。如果未设置项目，Claude Code 使用情况不会被标记，也不会有警告，因此请告知您的用户。

1. 在 Claude 中打开项目并复制其 ID，即 URL 的最后一部分：claude.ai/project/**this-part**。

2. 打开存储库中的 `.claude/settings.json`，或打开 `~/.claude/settings.json` 以在存储库间应用。

3. 添加下面的行，使用您的项目 ID。

4. 如果您使用了存储库的设置文件，当 Claude Code 询问时信任该文件夹。设置在之后生效。

```
{ "attributionProject": "PROJECT_ID" }
```

**警告：**确保文件保持有效的 JSON。一个多余的逗号可能会破坏该计算机上的 Claude Code。

## 按标签查看支出

主所有者、所有者和具有分析视图和计费视图访问权限的自定义角色可以按标签查看支出：

1. 导航到**组织设置 > 使用情况 > 按项目支出**。

2. 使用"分组依据"菜单选择您的标签。

3. 使用"时间段"和"产品"菜单缩小结果范围。

数据运行到昨天结束 (UTC)。要下载结果，请点击"导出 CSV"。

**注意：**私有项目的名称在此页面和 CSV 中显示为"私有项目"。分析仪表板、分析 API 和合规性 API 仍显示其真实名称。

阅读数字时请记住以下几点：

- **在工作开始前添加标签。**支出仅在标签生效后才计入标签，这大约需要两小时。该项目中的早期支出不计入其中。

- **没有使用情况的项目不会出现。**项目在您选择的日期范围内被使用后才会显示。

- **报告从项目标签对您的组织可用时开始。**不要将早期日期视为完整历史记录。

- **新标签大约需要两小时才能显示。**该时间窗口内的使用情况可能保持在之前的标签下或无标签。

- **更改标签不会更改过去的支出。**使用情况保持在项目当时拥有的任何标签下。

- **项目外的支出显示为"不在项目中"。**这包括未设置项目的 Claude Code 会话。项目中没有标签值的支出显示为"无标签值"。

- **金额可能与您的发票不符。**金额在您的折扣后和信用额前显示，最近的数字可能会在月末后约一周内变化。

- **座位覆盖的使用情况不计入。**主要在座位上使用的项目可能显示很少或没有支出。

## 使用 API 管理标签和提取支出

您可以从自己的系统中设置标签和提取支出。两个 API 都处于测试版，因此路径和名称可能会更改。您的主所有者在**[组织设置 > 组织 > API](https://claude.ai/admin-settings/api-access)** 中创建 API 密钥。

### 使用 Admin API 设置标签

创建具有 read:project_tags 和 write:project_tags 范围的密钥。Admin API 可以列出您的标签、向标签的列表添加值以及设置项目的标签。它无法创建标签、存档值或创建项目。

```
POST /v1/organizations/apps/projects/claude_proj_.../tags

Header: anthropic-beta: ce-project-tags-2026-10-09

Body: {"tags": {"cost_code": "CC-1042"}}
```

Admin API 使用 `claude_proj_` ID，而不是项目 URL 中的 ID。要列出 ID，请使用至少一天前的日期调用 `GET /v1/organizations/analytics/apps/chat/projects?date=YYYY-MM-DD`。它仅返回在该日期有聊天活动的项目。此调用需要 `read:analytics` 范围，因此请打开分析 API 并将该范围添加到您的密钥。

### 使用使用情况和成本报告提取支出

打开分析 API 并创建具有 `read:analytics` 范围的密钥。每次调用的日期桶最多可覆盖 31 天，因此使用它们来提取整个月份。

```
GET /v1/organizations/analytics/cost?starting_at=...&ending_at=...&time_bucket_width=1d&group_by[]=tags.claude_project[cost_code]&limit=1000

Header: anthropic-beta: analytics-usage-cost-2026-08-24
```

- 金额以美分为单位，可能包含美分的小数部分，已包含您的折扣，但可能与您的发票不符。

- 每次调用最多返回 1000 行。如果 `has_more` 为真，请继续分页，否则您的总计会不足。

- 标签过滤器文本在 URL 中传输，因此可能会出现在请求日志中。

## 当前限制

- **共享：**标签名称和值对组织中的所有用户可见，因此请勿在其中包含敏感信息。

- **编辑：**任何可以编辑项目的人都可以更改其标签，并且可以清除一个（除非它是必需的）。您无法锁定标签。

- **必需标签：**这些仅适用于在网络上创建的新项目，因此现有项目不受影响。在网络上，必需标签的值可以更改但不能删除。Admin API 仍然可以删除它。

- **字符：**值最多可以是 256 个字符，可以包含空格和逗号。依赖于不可见字符的值（如组合表情符号或某些波斯语或僧伽罗语单词）会被拒绝。

- **本测试版中不包括：**单个聊天或会话上的标签、跨标签分割支出、重命名标签或值以及按标签的支出限制。

## 常见问题

### 一个项目可以有多个标签吗？

可以，使用单独的标签，如 `cost_center` 和 `client_matter`，每个项目最多 16 个。每个标签保存一个值，因此项目的支出无法跨同一标签的两个值分割。

### Claude 会检查我们的标签值吗？

不会。列表限制用户可以选择的内容，但值不会针对您的财务系统进行检查。

### 我如何关闭项目标签？

项目标签在所有者创建标签之前不会改变任何内容。要关闭它们，请联系您的客户团队。
