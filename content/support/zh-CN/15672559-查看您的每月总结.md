# 查看您的每月总结

您的每月总结展示了您如何使用 Claude——您花时间的主题、您倾向于何时使用它，以及您可能想尝试的新方向。它旨在客观地反映您的使用模式，让您可以决定是否以及如何改变。

每月总结适用于网页版、Claude Desktop 以及 iOS 和 Android 版 Claude 上的免费版、专业版、最大版和超级版用户。仅当启用记忆功能时，总结才会显示，团队版和企业版计划不可用。它在提供 Claude 的所有地区都可用。

## 打开您的总结

1. 在网页版或 Claude Desktop 上打开 Claude。

2. 转到 **设置 > 健康**，在 **反思** 下，选择 “查看”（或在旧版设置布局中转到 **设置 > 反思**）。

3. 您的总结会加载过去一个月的数据。点击顶部的 “过去一个月” 下拉菜单，选择其他选项以加载不同时间范围的总结（过去 3 个月、过去 6 个月、过去一年）。每个时间范围以最后一个完整月份结束。如果您上个月没有活动，“过去一个月” 会显示本月至今的数据。

4. 您可以点击下拉菜单旁的刷新图标来重新生成当前时间范围的总结。您的总结已保存，因此通常在所有设备上看到同一时期的相同总结。

在 iOS 或 Android 上：点击左上角的菜单按钮，点击菜单底部的您的头像或首字母打开设置，然后点击 “反思”。

**注意：**此功能正在逐步推出。如果您还没有看到它，请稍后再检查。

## 您的总结显示什么

### 开场总结

一个简短的标题和段落，描述您在 Claude 上的一个月。它列出了您对话中的实际工作和主题，而不是提供笼统的赞美。

### 您与 Claude 的时间

三个主要统计数据：您的 **最活跃日期**、您的 **高峰时段** 和您的 **总对话数**。下方是一个每日活动图表，显示您的对话在该时期内的分布情况。

要设置安静时段和休息时间，请转到 **设置 > 健康**（在旧版设置布局中，点击图表下方的 “设置安静时段和休息时间”）。有关详细信息，请参阅 **[设置休息提醒和安静时段](https://support.claude.com/en/articles/15672868)**。

### 您使用 Claude 的用途

您在该时期内向 Claude 提出的主题和话题的比例分解，每个都附有简短描述和百分比。

### 扩展您的技能

在 “您与 Claude 配合良好的地方” 下，您会看到对您有效的习惯的简短说明，每个都带有复选标记。在 “2 个要尝试的事项”（或 “1 个要尝试的事项”）下，您会看到一或两张卡片，每张都根据您的活动提供建议和一个操作按钮，例如 “复制提示” 或 “连接此工具”。任一列表都可能不存在。选择 “了解更多” 以阅读有关 AI 流畅性的信息。

在旧版布局中保存的总结会在 AI 流畅性技能下显示卡片（网页和 Claude Desktop 上最多四张，iOS 和 Android 上最多三张），直到您重新生成它。

从您自己的对话中得出的观察，围绕四项 AI 流畅性技能展开：

- **委派**：什么应该交给 Claude，什么应该保留

- **描述**：您提供给 Claude 的背景信息

- **辨别**：评估 Claude 返回的内容

- **勤奋**：您如何在工作中表示 AI 的使用

每张卡片都将一个观察与您可以采取的具体下一步配对，例如创建技能或项目。点击 “了解更多” 以阅读有关该框架的更多信息。

### 反思时刻

iOS 和 Android 上的三个问题。选择其中一个会打开一个包含该问题的新对话。

### 目标

在专业版、最大版和超级版计划上，输入一个目标，Claude 会为您设置关于它的定期检查。

### 决定何时关闭 Claude

在 iOS 和 Android 上，以及网页版的旧版设置布局中：您的安静时段和休息提醒的快捷方式。

### 页面底部

两个拇指用于评分总结、关于记忆的句子和 “删除存储的反思”。

## 您的总结中包含的内容

Claude 从您最近的对话、Claude Code 会话和云中的 Cowork 任务构建您的总结。页面上的一行说明您的总结使用了其中哪些。例如，“基于您的 Claude 对话、云 Claude Code 会话和云 Cowork 任务，不包括仅在您的计算机上运行的会话或任务。”

您的总结仅在启用记忆时显示。如果您关闭记忆，总结将被隐藏。关闭记忆会隐藏您存储的总结，但不会删除它们。要删除它们，请在反思页面上使用 “删除存储的反思”，无论记忆是打开还是关闭。

您在所有设备上的对话都包括在内。

### 来自连接服务的内容

当 Claude 从连接的服务（如 Gmail 或 Google Drive）将内容拉入对话时，您的总结不会包含原始电子邮件或文件。它可能会包含 Claude 在对话中关于它的任何内容。例如，如果您在对话中要求 Claude 总结您的收件箱，电子邮件本身不会被拉入您的总结，但 Claude 编写的摘要会被拉入。

### 被排除的对话和会话

您的总结旨在排除某些对话和会话，包括：

- 隐身对话

- 使用健康集成（如 Apple Health 或 Health Connect）的对话

- 使用您在个人财务中的关联账户的对话，包括它们的标题

- 仅在您的计算机上运行的 Claude Code 会话和 Cowork 任务

- 云会话，其中我们可以判断 Claude 在您的计算机、手机或浏览器上使用了工具

- 使用健康集成或您在个人财务中的关联账户的会话。

- 我们仍然记录您在这些会话期间打开 Claude 的时间。

了解更多关于 **[记忆](https://support.claude.com/en/articles/11817273)**、**[隐身对话](https://support.claude.com/en/articles/12260368)** 以及 **[iOS](https://support.claude.com/en/articles/11869619-use-claude-with-ios-apps#h_21f4b10d6d)** 和 **[Android](https://support.claude.com/en/articles/11869629-use-claude-with-android-apps#h_62b72ef926)** 上的健康功能。

## 您的总结如何处理敏感话题

人们向 Claude 提出各种问题，有些对话涉及困难或个人话题。这些在您的总结中得到谨慎处理：

- 总结旨在不突出敏感或与困扰相关的话题，也不用计数或百分比列出它们。

- 在适当的情况下，支持资源会与您的总结一起显示。

## 删除您存储的总结

您的总结会一直存储，直到您删除它们、删除它们使用的对话或会话，或删除您的账户。新总结也可以替换或删除同一月份的总结。在某些情况下，总结可能会存储更长时间。较早月份的总结可以在您的数据导出中找到。要删除它们，请选择 “删除存储的反思”，或删除基础对话或会话，或删除您的账户。

要删除它们，请打开您的总结，选择 “删除存储的反思”（页面上的最后一项），然后选择 “删除”。这会删除您正在使用的账户的所有时期的存储总结，在所有设备上，且无法撤销。在某些情况下，总结可能会存储更长时间。了解更多关于 **[我们的数据保留实践](https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data)**。

您的对话不会被删除。您作为反馈发送的评分和笔记，以及您打开 Claude 的时间记录会保留。您的目标也会保留。启用记忆后，下次打开页面时可能会生成新的总结。

## 关闭您的总结

对于启用了记忆的符合条件的账户，默认情况下可以使用总结。

您可以通过在 **设置 > 您的 Claude** 中关闭 **从对话生成记忆** 来禁用它（或在旧版设置布局中关闭设置 > 记忆）。总结没有专用切换开关，因此如果启用了记忆设置，总结也将被启用。即使启用了记忆，您的总结也仅在您打开它时生成（**设置 > 健康**，然后在 **反思** 下选择 “查看”，或旧版设置布局中的 **设置 > 反思** 页面）；如果您不打开它，Claude 不会为您创建总结。

关闭记忆会隐藏您存储的总结，但不会删除它们。要删除它们，请在反思页面上使用 “删除存储的反思”，无论记忆是打开还是关闭。

关闭总结不会影响您的对话历史或您已在 **设置 > 健康** 中设置的任何休息提醒或安静时段（或旧版设置布局中的 **设置 > 时间和专注**）。我们仍然记录您打开 Claude 的时间。

## 常见问题

### 查看我的总结会使用我的计划配额吗？

查看您的总结不会计入您的使用限制。如果您从页面上的建议开始对话，该对话会像任何其他对话一样计入您的使用配额。

### 为什么我在设置中看不到反思？

检查您是否在免费版、专业版、最大版或超级版计划上。团队版和企业版计划不提供总结。
​
在 iOS 和 Android 上，将应用更新到最新版本。在 iPhone 和 iPad 上，目前需要 iOS 26 或更高版本。每月总结还不在所有账户上，因此同一计划上的账户可能不会都看到它。在网页版和 Claude Desktop 上，在更新的设置布局中，您的总结位于 **设置 > 健康** 下。

### 为什么百分比或统计数据看起来不对？

Claude 从您的对话以及云中的会话和任务生成您的总结摘要和话题分解，因此比例或叙述摘要中可能会出现偶发的不准确。使用页面上的拇指反馈让我们知道是否有问题。如果您使用多个 Claude 账户，每个账户的总结仅涵盖该账户。

### 为什么我的某些 Claude Code 或 Cowork 工作丢失了？

您的总结读取在云中运行的会话和任务。如果您运行了很多，只会读取最新的，因此较旧的可能会丢失。对于长会话，只读取开始部分，在少数情况下长会话会被排除。如果在创建总结时无法读取会话，它也可能丢失。在 2024 年 11 月 24 日之前保存的总结在您重新生成它之前不包括会话。仅在您的计算机上运行的工作不包括在内，云会话中我们可以判断 Claude 在您的计算机、手机或浏览器上使用了工具的也不包括。

### 我的总结在我的数据导出中吗？

您保存的总结包括在内，即使是反思页面不显示的总结，例如记忆关闭时的总结或较早月份的总结。您删除的总结不包括。应用隐藏的任何其他总结也不包括，例如因为它使用的对话、会话或任务被删除，或同一月份的较新总结替换了它。在某些情况下，已删除的对话、会话或任务的总结可能会存储更长时间，并可能在您的数据导出中显示，直到被删除。

数据导出不包括您打开 Claude 的时间记录、总结使用的对话列表或您的休息提醒和安静时段设置。您可以在网页版或 Claude Desktop 上导出您的数据。
