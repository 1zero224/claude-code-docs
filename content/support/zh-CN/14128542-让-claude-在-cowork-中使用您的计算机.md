# 让 Claude 在 Cowork 中使用您的计算机

Claude 现在可以使用您的计算机在 Claude Cowork 和 Claude Code 中完成任务（有关此功能的更多信息，请参阅我们的 **[Claude Code 文档](https://code.claude.com/docs/en/desktop#let-claude-use-your-computer)**）。启用计算机使用后，当 Claude 没有连接器或工具来满足您的需求时，它可能会直接导航到您的屏幕——点击、输入和打开应用程序，就像您操作一样。它可以在浏览器中工作、打开文件并自动使用您的应用程序，除了启用外无需其他设置。

## 可用性

计算机使用功能适用于 Claude Desktop 应用程序中 Cowork 和 Claude Code 的 Pro、Max 和 Ultra 计划。在 Team 和 Enterprise 计划上，计算机使用处于测试阶段，仅在新 Claude 体验中工作，需要组织所有者为您的组织启用它。此功能正在逐步向各个组织推出。请参阅下面的 **Team 和 Enterprise 计划上的计算机使用**。

在某些 Pro、Max 和 Ultra 账户上，**启用计算机使用**切换已打开。Claude 首次请求使用应用程序时，您仍需要确认。您可以在 **设置** 中将其关闭。请参阅下面的 **计算机使用入门**。

此功能存在风险——使用前请查看 **[安全使用 Claude Cowork](https://support.claude.com/en/articles/13364135-use-cowork-safely)**。

新 Claude 体验结合了聊天和 Cowork，正在向 Pro、Max 和 Ultra 计划推出。在 Team 计划（测试版）和 Enterprise 计划上，它在启用 **聊天和 Cowork 统一** 的地方可用。如果您的消息框不再显示 “聊天” 和 “Cowork” 选项，说明您已拥有新体验，本文中的某些步骤可能看起来不同。在 **[Claude Cowork 和聊天是一个 Claude](https://support.claude.com/en/articles/16761823)** 中了解更多信息。

## 计算机使用如何与 Cowork 配合工作

在 Cowork 中，Claude 首先使用最精确的工具。分配任务时，Claude 遵循以下顺序：

1. **连接器。**如果有可用的连接器（如 Gmail、Google Drive、Microsoft 365 或 Slack），Claude 会使用它。这是最快和最可靠的方式。

2. **浏览器。**当您需要的工具没有连接器时，Claude 可能会在 Claude Desktop 应用程序中内置的浏览器中处理您的任务，或者如果这是您首选的浏览器，可以通过 Claude in Chrome 在您自己的 Chrome 浏览器中处理。在 **[在 Claude Cowork 中使用内置浏览器](https://support.claude.com/en/articles/16607400)** 中了解更多信息。

3. **屏幕交互。**Claude 使用计算机使用功能直接与您的屏幕交互：点击、输入和导航您的桌面应用程序。

Claude 通常优先选择最快的方法。例如，通过 Slack 连接拉取消息需要几秒钟，但通过屏幕导航 Slack 需要更长时间且更容易出错。

## 您可以做什么

计算机使用让 Claude 可以使用您机器上的应用程序和文件。例如：

- 使用本地文件和连接的工具汇总竞争分析，然后将其编译成格式化报告。

- 打开您的手机模拟器，与您开发的应用程序交互，并找到用户体验问题。

- 导航没有连接器的应用程序——如内部仪表板或您的团队使用的专用工具。

如果您的工作涉及物理机器，Claude 在您离开时继续工作。您的计算机只需要保持开启状态。

在 macOS（15 版本或更高版本）上，Claude 在后台窗口中工作，因此您可以在它运行时继续使用您的计算机。Claude 不会接管您的指针或键盘，通常在您正在输入时会等待。在每个会话中，Claude 首次需要全屏时会在接管前请求您的许可。

**注意：**在 macOS 15 或更高版本上，后台工作是默认设置。如果您希望 Claude 在工作时接管屏幕，请转到 **设置 > 功能** 中的 **计算机使用** 部分（或者如果不存在，请转到 **设置 > 系统**，在 **此计算机** 下），并将 **Claude 如何使用您允许的应用程序** 设置为 “完全控制。”

## 权限和访问

Claude 在访问每个应用程序之前会请求您的许可。您会看到一个提示，必须批准后 Claude 才能与该应用程序交互。之后，Claude 可以在该会话中继续使用该应用程序而无需再次询问，您可以随时停止 Claude。某些应用程序默认被禁用。

如果启用了 **启用计算机使用** 切换，Claude 可以列出和搜索您计算机上安装的应用程序，有时可以看到哪些应用程序已打开，以便它可以向您询问正确的应用程序。在某些 Pro、Max 和 Ultra 账户上，该切换默认打开。在这些账户上，Claude 可以执行此操作，直到您关闭该切换，即使您从未自己打开过它。

查看您拥有的应用程序不会让 Claude 看到您的屏幕或使用这些应用程序。在 Claude 首次使用计算机使用之前，您会被要求确认您想要启用它。您还需要在 Claude 使用每个应用程序之前批准它。

要停止计算机使用显示 Claude 安装或打开的应用程序，请在 **设置** 中关闭 **启用计算机使用** 切换（请参阅下面的 **计算机使用入门**），然后退出并重新打开 Claude Desktop。

计算机使用不限于您已连接的文件夹。通过您批准的应用程序，Claude 可以打开、更改或删除这些文件夹外的文件。**[Cowork 的删除保护](https://support.claude.com/en/articles/13364135)**不涵盖计算机使用。

Claude 通过您批准的应用程序中的计算机使用可以做什么取决于应用程序的类型：

- **浏览器以及许多投资、交易和加密应用程序：**Claude 可以看到它们，但无法点击或在其中输入。

- **终端和代码编辑器：**Claude 可以点击和滚动，但无法输入。点击仍然可以在这些应用程序中运行代码。

- **大多数其他应用程序：**Claude 拥有完全访问权限。

某些应用程序（如音乐、视频流和电子书应用程序）被禁止使用。您也可以自己阻止应用程序。

Claude 经过训练和指示以避免高风险操作，如交易股票或加密货币，或输入密码和卡号。它还经过训练和指示以检查您的请求未明确涵盖的操作，如发送消息或提交表单。它经过训练和指示以将屏幕上看到的内容视为信息而非指令，并在内容试图引导它时告诉您。

仅在 “自动批准” 模式下，自动检查也会在 Claude 的操作运行前审查它们。

这些保护措施并不完美，Claude 可能偶尔会超出这些界限。

## 保护个人数据

当 Claude 使用计算机使用时，Claude 会对您的计算机进行屏幕截图以了解如何导航屏幕和您已授予权限的应用程序。这意味着 Claude 可以看到屏幕或这些应用程序上可见的任何信息，包括个人数据、敏感文档或属于您或他人的私人信息。审查 Claude 操作的自动检查也可以看到最新的屏幕截图，Anthropic 可以在其检查记录中保留一份副本。

使用 Claude 时要注意屏幕上显示的内容，特别是在包含机密信息的应用程序上。在使用计算机使用之前关闭包含敏感信息的文件或应用程序。

### Claude 经过训练以避免

- 交易股票、加密货币或其他投资

- 输入敏感数据

这些护栏是 Claude 训练和指示方式的一部分，但它们并非绝对的。不要依赖它们作为阻止访问敏感应用程序的替代品。

### 建议

- 不要向敏感应用程序（如银行、医疗保健、政府）授予计算机使用权限访问权限。

- 从简单任务（如研究或组织）开始，而不是复杂的多步工作流程。

- 确保您的提示具体且精心定制，以避免 Claude 执行您未打算的操作。

### 要避免的事项

我们强烈建议不要使用计算机使用来管理或对敏感信息采取行动，包括但不限于：

- 管理财务账户或投资

- 处理法律文件或合同

- 处理医疗或健康信息

- 与包含他人个人信息的应用程序交互

### 记忆

云中的 Cowork 与您在聊天中使用的记忆共享，因此 Claude 可以从它已经了解的关于您工作方式的内容开始。默认情况下，Claude 不会保存某些人认为敏感的主题（如健康信息），除非您在 **设置 > 您的 Claude**（或旧设置布局中的 **设置 > 记忆**）中打开 **在记忆中包含敏感主题**。某些信息永远不会被保存，包括政府身份证号码、犯罪历史、财务账户号码和移民身份。您可以随时查看、编辑和删除 Claude 记住的内容。在 **[Claude 的记忆](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context#h_82126ebcc9)** 中了解更多信息。

## 安全

计算机使用在 Claude 和您的应用程序之间没有沙箱。Claude 直接与您的桌面和应用程序交互——点击、输入和导航您的屏幕。我们为此构建了保护措施：

- **按应用程序权限。**Claude 在访问每个应用程序之前会请求许可，许多投资、交易和加密应用程序 Claude 可以查看，但无法点击或在其中输入。

- **应用程序黑名单。**通过将应用程序添加到黑名单来防止 Claude 访问某些应用程序。来自 Claude 使用被阻止应用程序的任何请求都将被自动拒绝。

- **操作审查。**我们的系统在 Claude 使用您的计算机时扫描提示注入的迹象，Claude 在访问新应用程序之前会请求许可。您可以随时停止 Claude。但此功能仍处于早期阶段，攻击不断演变——保持谨慎。

也就是说，计算机使用是一项新功能，它防御的威胁不断演变。Claude 会犯错误，没有保护措施是完美的。从您信任的应用程序开始并监控 Claude 的工作——特别是在早期。请注意，在一个应用程序中采取的操作可能会影响其他应用程序。例如，点击您的电子邮件应用程序中的链接可能会在 Chrome 中打开它，即使您未明确授予 Claude 使用 Chrome 的权限（我们可以防止 Claude 看到 Chrome 窗口，但无法阻止链接打开）。我们不建议在包含与您的医疗保健、财务或其他个人记录相关的敏感数据的应用程序上使用。

有关详细的安全指导，请参阅 **[安全使用 Cowork](https://support.claude.com/en/articles/13364135-use-cowork-safely)**。

## 当前限制

请记住以下几点：

- 您的桌面必须处于活动状态。您的计算机需要处于唤醒状态，Claude Desktop 应用程序需要打开才能使计算机使用工作。

- 复杂任务有时需要第二次尝试。计算机使用适用于许多任务，但可能在复杂的多步工作流程中遇到困难。

- 屏幕交互比连接器慢。当 Claude 通过您的屏幕而不是直接集成工作时，任务需要更长时间。尽可能连接您最常使用的工具。

- 适用于 Pro、Max 和 Ultra 计划。在 Team 和 Enterprise 计划上，仅在新 Claude 体验中可用，需要所有者启用它。

## Team 和 Enterprise 计划上的计算机使用

在 Team 和 Enterprise 计划上，计算机使用处于测试阶段，默认关闭，直到您的组织所有者启用它。此功能正在逐步向各个组织推出。

计算机使用仅在 Claude Desktop、Claude 网页版和 Claude Mobile 中的新 Claude 体验中工作，其中没有单独的 “Cowork” 选项。它在使用 “Cowork” 选项启动的任务或 Claude Code 中不工作。所有者可以在 **[为 Team 和 Enterprise 计划设置计算机使用](https://support.claude.com/en/articles/18483812-set-up-computer-use-for-team-and-enterprise-plans)** 中了解更多信息。

您需要在 Claude 将使用的计算机上打开最新版本的 Claude Desktop。如果尚未打开，请打开 **启用计算机使用**。

从 Claude 网页版或 Claude Mobile 使用它还需要您的组织的 **计算机访问** 设置打开，并且聊天必须连接到您希望 Claude 使用的计算机。如果您被要求选择要使用的计算机，请选择该计算机。在 Claude 网页版中，您也可以在 “+” > “设备” 下选择它。

如果您无法打开计算机使用，请将鼠标悬停在灰显的切换上以查看原因：

- **“您的组织无法使用计算机使用。”**它还未到达您的组织，或您的组织无法使用它。如果所有者已启用它，请在大约一小时后再次检查。

- **“您的组织已关闭计算机使用。”**请要求所有者启用它。如果他们刚刚启用，请稍后再检查。

- **“您的组织已关闭计算机使用。您可以在组织设置 → 功能中启用它。”**您可以自己启用它。

- **“计算机使用对您的角色已关闭。请要求您的管理员获得访问权限。”**您的任何自定义角色都不包括它。请要求管理您的组织中角色的人员为您提供访问权限。

- **“计算机使用需要新 Claude 体验，但您的账户未启用它。”**请要求所有者或管理您的组织中角色的人员为您提供访问权限。

- **“您的组织已启用计算机使用，但此应用程序还无法使用它。请稍后再检查，并确保 Claude 是最新的。”**从 **[Claude 下载页面](https://claude.com/download)** 更新 Claude Desktop。

- **“计算机使用被您的组织的政策禁用。”**您的组织的合规设置不允许它，没有设置可以启用它。

- **“您的组织已在此计算机上关闭计算机使用。请要求您的 IT 管理员获得访问权限。”**您的组织的 IT 团队控制此功能。按照消息操作。

- **“无法检查此计算机上是否允许计算机使用。退出并重新打开 Claude 以重试。如果仍然关闭，请要求您的 IT 管理员。”**您的组织的 IT 团队控制此功能。按照消息操作。

- **“计算机使用需要 macOS 14 或更高版本。”**更新 macOS。

如果 Claude 说您的组织阻止了应用程序，或该应用程序不在您的组织列表中，所有者很可能限制了 Claude 可以使用的应用程序。请要求所有者。

## 计算机使用入门

要开始使用计算机使用：

1. 确保您拥有最新版本的 Claude Desktop。在 claude.com/download 下载或更新。

2. 打开桌面应用程序并转到 **设置 > 功能**。如果那里没有 **计算机使用** 部分，请转到 **设置 > 系统**，在 **此计算机** 下。

3. 找到 **启用计算机使用** 切换并将其打开（如果尚未打开）。要关闭计算机使用，请关闭此切换。

4. 在桌面应用程序中打开聊天、Cowork 或 Claude Code 并启动会话。在 Team 和 Enterprise 计划上，改为在新 Claude 体验中启动聊天。

5. 要求 Claude 执行涉及您计算机上的应用程序的操作。Claude 会在继续之前请求访问该应用程序的权限。

如果某些内容未按预期工作，请使用应用内反馈按钮。
