# 访问审计日志

审计日志仅适用于企业组织。

组织所有者和主要所有者可以在**[组织设置 > 数据和隐私](https://claude.ai/admin-settings/data-privacy-controls)**中导出数据，并点击“导出日志”按钮。触发此导出后，将汇总过去180天内组织的所有审计日志。请求导出的所有者将收到一封包含下载链接的电子邮件，该链接有效期为24小时。请注意，触发导出和收到电子邮件之间可能存在延迟，因为日志正在汇总中。

请注意，聊天和项目的标题和内容无法在审计日志中导出（仅导出其唯一标识符）。但是，主要所有者可以通过**[数据导出](https://support.claude.com/en/articles/9450526-how-can-i-export-my-claude-data)**导出聊天输入/输出。

**注意：**如果您的组织在企业计划中使用客户管理的加密密钥，则无法使用“导出日志”按钮导出数据。审计日志事件可在合规性API中获得。有关更多信息，请参阅**[访问合规性API](https://support.claude.com/en/articles/13015708-access-the-compliance-api)**。

## 日志结构

审计日志包含以下列：

| **列名**           | **类型**             | **描述**                                  |
| ---------------- | ------------------ | --------------------------------------- |
| created\_at      | datetime           | 日志写入的时间                                 |
| actor\_info      | dict[str, Any]     | 执行者的信息（如果可用）                            |
| event            | AuditEventType     | 事件类型。                                   |
| event\_info<br>  | dict[str, Any]<br> | 给定事件类型的其他相关信息。                          |
| entity\_info     | dict[str, Any]     | 受操作影响的实体（如果相关）。通常，实体表示受事件影响的内容。         |
| ip\_address      | str \| None        | 与事件对应的IP地址（如果可用）。                       |
| device\_id       | str \| None        | 与事件对应的设备ID（如果可用）。                       |
| user\_agent      | str \| None        | 与事件对应的用户代理标头（如果可用）。包含有关用于执行事件的程序的信息。    |
| client\_platform | str \| None        | 与事件对应的客户端平台（如果可用）。对应于移动平台，为iOS或Android。 |

## 实体

可能受事件影响的实体。实体信息遵循以下结构：

| **字段名** | **字段类型**               | **备注**          |
| ------- | ---------------------- | --------------- |
| type    | AuditEntityType        | 实体的类型。          |
| uuid    | str                    | 实体的UUID。        |
| name    | str \| None            | 实体的名称（如果可用）     |
| 元数据     | dict[str, Any] \| None | 与实体相关的元数据（如果可用） |

| **审计实体类型**              | **元数据**                                                          | **描述**                    |
| ----------------------- | ---------------------------------------------------------------- | ------------------------- |
| account                 | email\_address: 账户上的电子邮件地址                                       | 用户账户。                     |
| invite                  | role: 邀请所针对的角色                                                   | 邀请加入团队/组织                 |
| chat\_project           | is\_private: 项目的可见性                                              | 由聊天组成的项目                  |
| chat\_project\_document | project\_uuid: 此文档相关的项目的UUID                                     | 聊天项目知识库中的文档               |
| chat\_conversation      | project\_uuid: 此对话所属项目的UUID（如相关）                                 | 与Claude的聊天对话。可以在项目中或独立存在。 |
| file                    | n/a                                                              | 上传到Claude的文件              |
| sso\_connection         | connection\_type: SSO连接的类型<br>state: 连接状态<br>domains: 与SSO连接相关的域 | SSO连接                     |
