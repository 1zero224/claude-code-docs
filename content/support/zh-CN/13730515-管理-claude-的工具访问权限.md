# 管理 Claude 的工具访问权限

当您将许多服务连接到Claude时，您可以控制这些连接器如何加载到您的对话中。这有助于Claude更准确、更高效地工作，特别是当您添加了10个或更多连接器时。

工具访问模式适用于Claude、Claude Desktop和Claude Mobile（iOS和Android）上的所有用户。

# 为什么工具访问很重要

每个连接器都会占用对话中的空间。对于少量连接的服务，这通常不会引起注意。但随着您的连接器库增长，累积的开销可能会限制您实际工作的空间：文档、代码和对话历史。

为了解决这个问题，Claude支持三种工具访问模式，可以控制何时以及如何加载您的连接器。

---

# 工具访问模式

您可以使用聊天中的**工具访问**设置来管理Claude对每个对话中连接器的访问。

从三个选项中选择：

- **自动***（默认）*：Claude根据您正在处理的内容动态决定加载哪些连接器。这是大多数用户的最佳起点。

- **始终可用**：所有连接器在每个对话开始时都会被加载。Claude可以立即使用其中任何一个，无需额外步骤。

- 最适合：少于10个您经常使用的连接器。

- 权衡：预先使用更多对话空间。

- **按需：**连接器在Claude根据您的请求搜索正确的连接器之前不会被加载。Claude查找最相关的连接器，仅加载这些连接器。

- 最适合：大型连接器库（10个或更多），或当您遇到对话长度问题时。

- 权衡：Claude可能需要额外的步骤来找到正确的连接器后再使用它。

---

# 我应该使用哪种模式？

| **您的情况**<br>         | **推荐模式**<br> |
| -------------------- | ------------ |
| 少于10个连接器，全部频繁使用<br>  | 始终可用<br>     |
| 10–30个工具，使用情况混合<br>  | 自动<br>       |
| 30个以上工具或多个连接器已连接<br> | 按需或自动<br>    |
| 特定连接器需要每次都无故障工作<br>  | 始终可用<br>     |
| 对话达到长度限制<br>         | 按需<br>       |

# 如何更改您的工具访问设置

您可以按照以下步骤为每个对话设置工具访问模式：

1. 打开与Claude的聊天。

2. 点击聊天左下角的"+"  按钮，或使用斜杠(/)命令打开菜单。

3. 将鼠标悬停在"连接器"上，然后悬停在"工具访问"上。

4. 从三个选项中选择您首选的模式：

# 常见问题

## "按需"模式会错过我需要的连接器吗？

Claude根据您的请求搜索最相关的连接器，因此它适用于大多数任务。对于需要每次都可用的连接器，请使用"始终可用"或单独设置该连接器的访问权限。

## 为什么Claude有时会添加额外的消息来使用连接器？

在"按需"模式下，Claude在使用工具之前会搜索正确的工具。这个搜索步骤会增加一次交互，但可以防止您在连接许多工具时对话达到长度限制。
