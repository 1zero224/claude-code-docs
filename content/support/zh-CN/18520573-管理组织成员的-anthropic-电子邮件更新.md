# 管理组织成员的 Anthropic 电子邮件更新

本文介绍企业计划的所有者和主要所有者如何为组织成员打开或关闭 Anthropic 电子邮件更新。

## 此设置的作用

启用“来自 Anthropic 的电子邮件更新”设置后，Anthropic 将向组织成员发送电子邮件，帮助他们更好地使用 Claude，包括新功能、提示和偶尔的优惠。成员仍将收到账户、安全和账单电子邮件，并可随时管理其偏好设置或取消订阅。

此设置不影响发送给所有者和主要所有者的更新。具有自定义角色的成员会受到影响，即使该角色包含所有者访问权限。默认情况下，“来自 Anthropic 的电子邮件更新”设置处于启用状态。

- 此设置仅适用于电子邮件，且仅适用于一个组织。如果贵公司有多个组织，请在每个组织中更改此设置。

- 成员可随时使用任何营销电子邮件中的链接取消订阅。关闭此设置后，成员无法自行重新启动这些电子邮件。

- 更改此设置时，不会通知成员。

## 关闭此设置时成员收到的内容

| **停止发送**                                       | **继续发送**                                      |
| ---------------------------------------------- | --------------------------------------------- |
| 帮助成员更好地使用 Claude 的电子邮件，包括新功能、提示和偶尔的优惠          | 交易通知，如账户、安全、账单和法律电子邮件以及登录链接                   |
| 管理员从 Claude 发送的邀请，用于试用产品或使用额度，如 Claude Code 邀请 | 产品通知，如加入组织的邀请、同事分享项目、对工件的评论、席位更新以及对成员提出的请求的回复 |
|                                                | 成员请求或选择接收的电子邮件，如数据导出                          |
|                                                | 网络研讨会和活动邀请                                    |

**注意：**此设置不影响发送给所有者、主要所有者和管理员的关于组织运营的电子邮件。

## 谁可以更改此设置

企业计划的所有者和主要所有者可以更改此设置。具有包含所有者访问权限的自定义角色的成员也可以更改它。

并非每个企业组织都可使用此设置。如果您是所有者但看不到此设置，请联系支持。

**[详细了解角色和权限](https://support.claude.com/en/articles/9267276-roles-and-permissions)**

## 关闭或打开电子邮件更新

要关闭或打开电子邮件更新，请执行以下操作：

1. 导航至**[组织设置 > 组织和访问权限](https://claude.ai/admin-settings/organization)**。

2. 转到**Anthropic 支持和更新**。在某些组织中，此部分称为**Anthropic 更新**。

3. 找到**来自 Anthropic 的电子邮件更新**。

**要关闭电子邮件更新：**关闭开关，然后在对话框中选择“关闭”。

**要重新打开电子邮件更新：**打开开关。无需确认任何内容。开关会立即显示为打开状态，但实际更改可能需要更长时间，如下面的注意所述。

- 设置会自动保存。没有“保存”按钮或确认消息，因此开关位置显示当前设置。

- 如果更改未保存，您会看到“来自 Anthropic 的电子邮件更新无法保存。您可以重试。”

- 每项更改都会记录在组织的审计日志和合规性 API 中。

**注意：**此设置的更改可能需要一些时间才能生效。关闭后，成员在此期间可能仍会收到电子邮件。

## 常见问题

### 为什么此设置已关闭？

如果贵组织在此设置存在之前要求 Anthropic 停止向其成员发送电子邮件，则该设置可能已关闭。您可以打开或保持关闭状态。

### 我可以仅为某些成员关闭此设置吗？

不可以。此设置适用于整个组织。个别成员可以使用任何营销电子邮件中的取消订阅链接。

### 如果某人属于多个组织怎么办？

如果他们作为成员所属的任何组织都关闭了此设置，他们将停止接收这些电子邮件。

### 我也可以停止产品通知吗？

此设置无法停止产品通知。产品通知与 Anthropic 电子邮件更新是分开的。如需了解如何关闭某些产品通知，请联系**[我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)**。
