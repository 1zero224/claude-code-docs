# 在 Claude Design 中设置您的设计系统

设计系统可以捕捉您的颜色、排版、组件和布局模式，使 Claude 能够将它们应用到每个新设计和演示文稿中。Claude 会从您提供的资源（如代码库、幻灯片或其他设计参考）中提取这些元素。

设计系统在 Pro、Max、Ultra、Team 和 Enterprise 计划中以测试版形式提供。在 Pro、Max、Ultra 和 Team 计划中，它们默认启用。在 Enterprise 计划中，它们处于关闭状态，直到所有者在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中启用**设计系统**。独立的 Claude Design（claude.ai/design）有其自己的单独设置。

本指南适用于将设置设计系统的设计师或品牌所有者。在 Team 和 Enterprise 计划中，您只需执行一次，之后所有人的工作都会自动应用该系统。

## 开始前

- 在 Team 和 Enterprise 计划中，需要为您的组织启用**设计系统**，所有者可能会限制谁可以发布或设置默认值。

- 您至少需要以下其中一项作为源材料：

  - 包含您的设计系统或组件库的代码库

  - 反映您视觉识别的幻灯片或文档

  - 品牌指南资源（徽标、调色板、排版规范）

## 创建设计系统

### 从聊天

要求 Claude 从您连接的应用、上传的文件、Figma 文件、演示文稿、徽标和字体中构建设计系统。这最适合具有字体、颜色和指南的品牌设计系统。

### 从 Claude Code

如果您的设计系统已作为 React 组件存在，请在 Claude Code 中运行 /design-sync。它直接读取您的令牌和组件，最适合代码中的产品设计系统。

### 从 claude.ai/design 导入设计系统

1. 打开侧边栏底部的"设计"选项卡。

2. 点击横幅中的"移动团队设计系统"。

每个设计系统都成为 Claude 可以在任何聊天中使用的工件，包括在 Claude Code 中。移动后，设计系统可能需要进行一些清理，因此每个系统都会显示一个横幅，您可以点击"让 Claude 清理它"，Claude 会整理其指南、令牌和组件。如果您的组织有涵盖工件的保留期，移动的设计系统在该期间内没有人打开它时可能会被永久删除。打开使用该设计系统的设计或演示文稿不算作打开它。

## 使用键盘操作设计系统

要进入和退出工件面板，请参阅**[使用键盘或屏幕阅读器操作工件](https://support.claude.com/en/articles/17457950)**。该文章还说明了焦点的含义、在 Mac 笔记本电脑或 Safari 中的操作方法，以及快捷键的写法。

设计系统以您正在阅读的部分旁边的部分列表形式打开。在列表中的某个部分上按 Return 可进入该部分，Cmd+F6（Windows 上为 Ctrl+F6）可在列表和部分之间切换，Cmd+Z（Windows 上为 Ctrl+Z）可在不在文本框中时撤销更改。

**注意：**设计系统中的实时组件预览无法通过 Tab 键访问，因此无法从键盘操作。可以读取每个组件的名称和注释。

## 在 claude.ai/design 中设置设计系统

这些步骤使用独立的 Claude Design。

### 创建或切换到您的组织

1. 打开**[Claude Design](https://claude.ai/design)**。

2. 在项目选择器的左下角，点击当前组织名称。

3. 选择您的组织，或创建一个新组织。

4. 完成您被重定向到的入职流程。

### 上传您的品牌和产品资源

在入职期间或之后从您的组织设置中，上传定义您的品牌和产品的资源。Claude 会分析它们并提取可重用的设计系统。

- **代码库：**如果您的设计系统存在于代码中，如 React 组件库，请链接或上传存储库。Claude 会读取组件和样式。

- **原型：**屏幕截图、网页流程和现有设计文件。

- **幻灯片或文档：**即使是反映您品牌的精心设计的 PowerPoint 或 PDF 也可以使用。Claude 会提取颜色、布局模式和排版选择。

- **单个资源：**徽标、调色板文件、排版样本。

您只需要一个源就可以开始，但更多源可以为 Claude 提供更多信息。

### 查看生成的设计系统

上传后，Claude 会为您的组织生成一个设计系统。这通常包括：

- **调色板：**从您的资源中提取的主要、次要和强调色。

- **排版：**字体系列、大小和粗细。

- **组件：**按钮、卡片、导航元素和其他可重用的 UI 模式。

- **布局模式：**间距、网格系统和页面结构。

要验证它，请创建一个测试项目并检查输出是否与您的品牌相符。尝试以下提示：

- 为 [您的产品] 创建登陆页面。

- 设计一个显示 [相关指标] 的仪表板。

- 制作一份关于 [您的团队经常展示的主题] 的单页文档。

### 向您的团队提供

当您对设计系统满意时，打开"已发布"切换开关。发布后，从您组织中的 Claude Design 主屏幕创建的项目将使用您的设计系统而不是默认系统。

## 更新您的设计系统

当您的设计系统发生变化时，您可以在 Claude Design 中更新它。从您的 Claude Design 组织设置中，点击您要编辑的设计系统旁边的"打开"按钮。点击窗口右上角的"混音"按钮以打开窗口左侧的聊天界面。从这里，您可以与 Claude 合作更改您的设计系统。

## 获得最佳效果的提示

- **包含真实示例，而不仅仅是规范。**完成的登陆页面或营销网站比单独的调色板更能向 Claude 传达您品牌的感觉。

- **迭代。**如果第一次提取没有很好地捕捉您的品牌，请尝试上传其他或不同的资源。
