# 使用链接打开 Claude 移动应用

iOS 和 Android 上的 Claude 移动应用支持 `claude://` URL 协议。第三方应用、快捷方式和网页可以使用这些链接打开代码选项卡、跳转到现有会话或预填充新会话编辑器。所有参数值必须进行 URL 编码。

这些链接需要您的账户具有 Claude Code 访问权限。如果您没有 Claude Code 访问权限，这些链接将无法使用。

## 打开代码选项卡

`claude://code`

在会话列表中打开代码选项卡。

## 打开现有代码会话

`claude://code/{session-id}`

按 ID 打开现有 Claude Code 会话。如果 ID 未知，您将进入会话列表。

## 打开新代码会话

`claude://code/new`

带有可选参数：`claude://code/new?q=Fix%20the%20failing%20test&repo=anthropics%2Fclaude-code&branch=main`

打开新会话编辑器，可选择预填充。所有参数都是可选的。

| **参数**   | **必需** | **描述**                                                            |
| -------- | ------ | ----------------------------------------------------------------- |
| `q`      | 否      | 在编辑器中预填充的文本。`prompt` 可作为别名使用。                                     |
| `mode`   | 否      | 预选会话模式。接受 `plan` 或 `code`。如果您的计划中不提供该模式，则忽略。                      |
| `repo`   | 否      | 预选 `owner/name` 格式的 GitHub 仓库（不区分大小写）。如果该仓库不在您连接的 GitHub 账户中，则忽略。 |
| `branch` | 否      | 预选分支。需要 `repo`。                                                   |

**[仅限桌面版的文件夹和文件参数](https://support.claude.com/en/articles/14729294-open-claude-desktop-with-a-link)**在移动设备上被忽略。

## 通用链接

相同的代码路由也可通过 **<https://claude.ai/code/>...** 通用链接访问。如果已安装应用，操作系统将打开它；否则链接将在浏览器中打开。

| **URL**                                                                                                 | **打开**                             |
| ------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| **<https://claude.ai/code>**                                                                            | 新会话编辑器                             |
| **[https://claude.ai/code/{session-id}](https://claude.ai/code/%7Bsession-id%7D)**                      | 现有会话                               |
| **<https://claude.ai/code/new?q=Fix%20the%20failing%20test&repo=anthropics%2Fclaude-code&branch=main>** | 新会话编辑器，预填充 GitHub 仓库、分支和"修复失败的测试"。 |
