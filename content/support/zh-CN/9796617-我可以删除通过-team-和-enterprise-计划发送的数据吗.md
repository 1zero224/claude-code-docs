# 我可以删除通过 Team 和 Enterprise 计划发送的数据吗？

*本文介绍我们的商业产品，如 Claude for Work 和 Anthropic API。关于我们的消费者产品（如 Claude Free、Pro、Max、Ultra）以及这些计划中的账户使用 Claude Code 的情况，请参阅[此处](https://privacy.claude.com/en/collections/10663362-consumers)。*

使用 Team 和 Enterprise 计划时，产品中的提示和对话会被保留，以便您可以在产品中查看对话历史记录。您可以[删除聊天](https://privacy.claude.com/en/articles/11117329-how-can-i-delete-or-rename-a-conversation)以将其从可见历史记录中移除。

我们还在后端系统中保留数据，详情请参阅[此处](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data)。

阅读[此处](https://privacy.claude.com/en/articles/7996875-can-you-delete-data-that-i-sent-via-api)了解有关删除通过 API 发送的数据的更多信息。

Enterprise 计划客户还可以为其组织的数据设置[自定义保留时间表](https://support.claude.com/en/articles/10440198-custom-data-retention-controls-for-claude-enterprise)。
