# 使用键盘或屏幕阅读器操作工件

本文介绍如何使用键盘或屏幕阅读器进出工件、对工件进行评论，以及使用 Claude Docs、Claude Slides 和 Claude Design 共享的快捷键。每个模板的专属文章涵盖其编辑器的快捷键。

Claude Docs、Claude Slides 和 Claude Design 可在免费版、专业版、Max、Ultra、Team 和企业版计划中使用。在企业版计划中，它们将在 2026 年 10 月 15 日默认启用，所有者可以在此之前在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中启用。设计系统在专业版、Max、Ultra、Team 和企业版计划中以测试版形式提供。要编辑工件，请在网络上使用 Claude 或使用 Claude Desktop。

常用快捷键：

- Tab 键将您移入工件，Escape 键将您移回工件面板。

- 在幻灯片或设计中，Return 键进入幻灯片、画板、组或文本框，Escape 键退出。

- F6 或 Cmd+F6（Windows 上为 Ctrl+F6）在 Slides 和 Design 编辑器的各个区域之间移动。在文档中，它从选定的文本移动到格式工具栏。

## 本文如何显示快捷键

快捷键首先为 Mac 编写，Windows 快捷键在括号中，如下所示：Cmd+Option+M（Windows 上为 Ctrl+Alt+M）。如果只显示一个快捷键，则在两者上相同。Return 是 Windows 键盘上标记为 Enter 的键。

焦点是您下一次按键的去向。大多数浏览器在具有焦点的按钮、字段或对象周围绘制轮廓。

多个快捷键使用 F6 键。某些浏览器为其自己的工具栏保留 F6，因此 Claude Docs、Claude Slides 和 Claude Design 也接受 Cmd+F6（Windows 上为 Ctrl+F6）。如果单独按 F6 没有任何作用，请使用该快捷键。

在 Mac 笔记本电脑上，按住 Fn 键以获取键盘没有的键。Fn+左箭头是 Home，Fn+右箭头是 End，Fn+上箭头是 Page Up，Fn+下箭头是 Page Down。如果顶行键设置为亮度和音量，也按住 Fn 以获取功能键：Fn+F6 或 Fn+Shift+F10。

在 Safari 中，Tab 键可能会跳过按钮和链接。如果是这样，请改为按 Option+Tab。

Plus 是具有 = 和 + 的键。在表格单元格中，"或"分隔执行相同操作的键，逗号分隔行命名的两个操作的键。

## 进出工件面板

工件在您的对话旁边的面板中打开。该面板有一个带按钮的标题，工件位于其下方。本部分介绍您从对话中打开的工件。无论是否从模板创建，它对每个新工件的工作方式都相同。

### 打开工件并进入其中

1. 按 Tab 键直到到达对话中的工件。

2. 按 Return 键。工件打开，焦点移动到工件面板。

3. 按 Tab 键在面板标题中的按钮之间移动。

4. 继续按 Tab 键进入工件本身。

按 Shift+Tab 从工件返回到标题。

### 离开工件

Escape 键一次一步地将您向外移动。

1. 按 Escape 键关闭任何打开的菜单、弹出窗口或对话框。

2. 再次按 Escape 键以退出您正在处理的内容，例如幻灯片上的文本框或评论框。

3. 继续按 Escape 键直到焦点到达工件面板。使用屏幕阅读器，您会听到"工件面板"和工件的标题。面板保持打开。

4. 再按一次 Escape 键关闭面板。焦点返回到您打开工件的位置或消息框。

当焦点在面板本身上时，最后一步有效。在标题的按钮之一上，Escape 键作用于该按钮。

**注意：**旧版工件（在面板顶部有用于查看代码、复制内容或下载内容的控件的工件）没有从工件内容中逃出的 Escape 路由。从"工件"选项卡在其自己的页面上打开的工件没有要关闭的面板。

## 编辑器共享的快捷键

在 Claude Slides 和 Claude Design 中，编辑器分为多个区域，例如工具栏、幻灯片或画布以及属性面板。按 F6 移动到下一个区域，按 Shift+F6 移动到上一个区域。Cmd+F6（Windows 上为 Ctrl+F6）可代替 F6 使用，无论是否带 Shift。在 Claude Docs 中，当选择文本时，F6 或 Cmd+F6（Windows 上为 Ctrl+F6）从文本移动到格式工具栏，或移动到光标所在的表格或代码块的"更多操作"按钮，Escape 或 Tab 返回到文本。在文档中，F6 不与 Shift 一起使用。

在编辑器内，F6 在编辑器的各个区域之间移动。Tab 和 Escape 在对话和工件面板之间移动您，如上所述。

在幻灯片或设计中，事物位于其他事物内部：幻灯片上的对象位于幻灯片内，图层位于画板内，组内有其自己的对象。相同的几个键将您移入和移出：

- Tab 键作为单个停止点到达幻灯片或画板的标题。

- Return 键进入：进入幻灯片、画板或组，或进入文本框进行编辑。

- Tab 和 Shift+Tab 在同一级别的事物之间移动。在幻灯片上，Tab 不会离开幻灯片。

- Escape 键完成文本编辑，然后将您带回幻灯片或画板外。

- Shift+Return 一次上升一个级别。

使用屏幕阅读器，按 Return 键进入幻灯片或画板，并选择要评论的内容。Return 或 Space 按下按钮。

## 对幻灯片或设计进行评论

文档有自己的评论快捷键。请参阅**[Claude Docs 入门](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs#h_3762015b90)**。

1. 移动到面板标题中的"评论"。如果您在工件内，按 Escape 键直到焦点到达工件面板，然后按 Tab 键直到到达它。该按钮是一个图标。当工件有打开的评论时，其标签包括有多少个，例如"3 条打开的评论"。

2. 按 Return 键。这将打开评论模式，您选择的下一个内容将获得评论。焦点移动到工件中，按钮的名称更改为"完成评论"。

3. 按 Tab 键移动到您想要评论的内容。在幻灯片中，那是幻灯片，然后是其上的每个对象。在设计中，它是每个画板。

4. 按 Return 键。"添加评论"框打开，焦点在其中。

5. 输入您的评论。

6. 按 Return 键发布。Cmd+Return（Windows 上为 Ctrl+Enter）也会发布。发布的评论打开，焦点在其回复字段中。

7. 按 Escape 键关闭该框。

8. 再次按 Escape 键离开评论模式。焦点返回到"评论"。要从那里关闭面板，请按 Tab 键直到到达"关闭"。

发送按钮前的"发送给Claude"复选框用于设置评论是否也作为请求发送给Claude。使用仅查看权限时，您无法添加评论。

**注意：**要保存已发布评论的编辑，请按Cmd+Return（Windows上为Ctrl+Enter）。单独按Return不会保存编辑。

### 阅读并回复幻灯片或设计上的评论

每条评论在工件上都有一个标记，标记名称为评论作者的名字。这些标记仅在评论模式打开时显示，因此请先打开它。按Tab键直到到达标记，然后按Return或Space打开评论。焦点落在其回复字段中。按Return发送回复，按Escape关闭评论并将焦点返回到标记。再按一次Escape退出评论模式。

要在一个列表中查看所有评论，请打开"更多评论选项"（标题中"评论"按钮旁边的按钮），然后选择"显示所有评论"。在一行上按Return可移至该评论。

## 工件面板快捷键

这些快捷键适用于在当前工件面板中打开的每个工件，位于您的对话旁边。旧版工件（面板顶部有控件用于查看代码、复制内容或下载）没有Escape退出其内容的路由。评论模式行适用于幻灯片和设计。在文档中，标题的评论按钮显示或隐藏所有评论的列表，您可以使用**[Claude文档入门](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs#h_3762015b90)**中的快捷键进行评论。

| **操作**                   | **Mac**           | **Windows**      |
| ------------------------ | ----------------- | ---------------- |
| 从对话中打开工件                 | Return            | Enter            |
| 在标题的按钮之间移动并进入工件          | Tab               | Tab              |
| 从工件返回到标题                 | Shift+Tab         | Shift+Tab        |
| 关闭打开的菜单或弹出窗口，然后向外步进到工件面板 | Escape            | Escape           |
| 关闭面板（焦点在面板本身上）           | Escape            | Escape           |
| 在幻灯片或设计中：打开评论模式，焦点在"评论"上 | Return或Space      | Enter或Space      |
| 在评论模式中：移至下一个可以评论的内容      | Tab               | Tab              |
| 在评论模式中：对其进行评论            | Return            | Enter            |
| 发布评论或回复                  | Return或Cmd+Return | Enter或Ctrl+Enter |
| 保存已发布评论的编辑               | Cmd+Return        | Ctrl+Enter       |
| 关闭评论框，然后退出评论模式           | Escape            | Escape           |
| 从其标记打开评论                 | Return或Space      | Enter或Space      |

## 已知限制

在任何工件中需要注意的一点：

- **网页工件：**如果 Claude 编写的网页工件没有链接或按钮，Tab 会跳过它，箭头键无法滚动它。

如果您的键盘或屏幕阅读器出现问题，我们很乐意听取您的反馈。了解更多关于 **[如何获得支持](https://support.claude.com/en/articles/9015913)** 的信息。
