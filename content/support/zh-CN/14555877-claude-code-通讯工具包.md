# Claude Code 通讯工具包

此工具包涵盖发布通讯、一个包含二十条消息的“提示和技巧”滴灌活动，以及常见问题的快速参考指南。每条消息都链接到开发人员可以深入了解的文档页面。

## 如何使用此工具包

三个部分，按照您需要的顺序。**第 1 部分**是您的发布公告——电子邮件和 Slack 格式的一条主要消息，包含可替换的变体，用于高管赞助发送和试点组。**第 2 部分**提供二十条滴灌活动消息，打包为即用型 Slack/Teams 帖子。**第 3 部分**是快速参考常见问题和链接目录。

**将此工具包中的所有内容视为草稿副本，而非最终副本。**用您组织的语气重写每条消息，将示例任务替换为您自己代码库中的真实错误和模块，并在发送前替换[括号占位符]。真正推动采用的公告是那些看起来像您公司某人写的。

直接从下面的每个表格中将消息正文复制到 Slack 或 Teams。发送前替换 [括号占位符]。

### 2.3 控制和安全

**消息 6 — 权限模式**

| 🛡️ **提示：一个按键在 “只看不动” 和 “直接做” 之间切换**<br>有时你希望 Claude 在每次编辑前询问。有时你只想让它直接发布。你不应该永远只能选择其中一个。<br>**Shift+Tab** 循环切换 Claude 的权限级别 — **default**（在风险操作前询问）、**acceptEdits**（文件编辑和常见文件系统命令如 mkdir/mv/cp 直接执行；仍在其他 shell 命令前检查）、**plan**（提议，你在任何更改前批准）。计划模式是信任构建者 — 对于涉及多个文件的任何操作，从这里开始。<br>**现在就试试：**在你的下一次重构中，按 Shift+Tab 直到看到 “plan”，然后描述更改。你会在单个文件移动前获得完整的提议。<br>📖 **[权限模式](https://code.claude.com/docs/en/permissions)**<br> |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

*快速参考（你最常用的三个 — 完整列表见 **[文档](https://code.claude.com/docs/en/permissions)**）：*

| **plan**            | **default**        | **acceptEdits**                               |

| 🧩 **提示：给 Claude 权限来真正思考困难的问题**<br>有一个困扰你两次的 bug？不要要求快速答案 — 要求仔细的答案。<br>`/effort max` 将推理深度推到最高。Claude 花费更长时间、探索更多分支，答案更可能经得起推敲。将其保留用于错误代价高昂的问题。<br>**现在就试试：**在描述你最难的未解决 bug 之前输入 `/effort max `。然后去重新装满你的水杯，让它工作。<br>📖 **[努力等级](https://code.claude.com/docs/en/model-config#adjust-effort-level)**<br> |

**消息 14 — 截图和图像**

**消息 15 — Git 工作流**

### 2.8 安全和管理

**消息 19 — 安全架构**

| 🔐 **提示：“这安全吗？”的答案——下次被问到时可以用**<br>你的团队中有人会问 “等等，我的代码去哪了？” 这是你可以粘贴的简短版本。<br>权限优先的设计。每个文件编辑、shell 命令和外部调用都需要你的批准。Claude Code 在你的机器上运行，直接与 Anthropic 的 API 通信——没有第三方服务器——shell 命令可选操作系统级沙箱。在我们的企业计划下，Anthropic 不会使用你的代码或提示来训练模型。<br>**现在就试试：**保存这两个链接，下次有人提出这个问题时可以用——它们能回答大多数安全审查问题。<br>📖 **[安全和权限](https://code.claude.com/docs/en/security)** · **[数据使用](https://code.claude.com/docs/en/data-usage)**<br> |

### 3.1 常见问题解答

你会被问到最多的问题的一行 Slack 回复。

| **问题**              | **回复**                                                                                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| “它在 VS Code 中工作吗？”  | 可以——VS Code 扩展和 JetBrains 插件。功能相同，嵌入在你的编辑器中。**[文档 →](https://code.claude.com/docs/en/vs-code)**                                                 |
| “我必须先配置什么吗？”        | 不需要——登录 Claude Desktop 并打开代码选项卡，或安装 CLI 并在任何仓库中运行 `claude`。运行一次 `/init` 就可以了。**[快速开始 →](https://code.claude.com/docs/en/quickstart)**           |
| “我的代码去哪了？”          | Claude Code 在你的机器上运行，将上下文发送到 Anthropic 的 API 进行推理——没有第三方服务器。在我们的企业计划下，你的代码和提示不会被用来训练模型。**[数据使用 →](https://code.claude.com/docs/en/data-usage)** |
| “它能看到我的整个仓库吗？”      | 它读取你给它访问权限的内容。在你的工作目录内的文件读取不会提示；权限提示会限制编辑、shell 命令和该目录外的任何操作。**[权限 →](https://code.claude.com/docs/en/permissions)**                            |
| “这与 Copilot 有什么不同？” | Copilot 自动完成行。Claude Code 是一个代理——读取文件、运行命令、进行多文件编辑。**[概述 →](https://code.claude.com/docs/en/overview)**                                         |
| “我应该先尝试什么？”         | 一个你一直想修复但因为太繁琐而搁置的 bug。*“[文件] 中的测试不稳定——找出原因。”* **[快速开始 →](https://code.claude.com/docs/en/quickstart)**                                         |
