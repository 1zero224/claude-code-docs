# 为什么Claude API使用费用与我的付费Claude计划分开计费？

Claude付费计划和Claude控制台是为不同目的设计的独立产品：

- Claude付费计划为订阅者提供在网页、桌面和移动设备上使用Claude的权限，并提供更多使用量和高流量期间优先访问等增强功能。

- Claude控制台是我们的开发者平台，提供API密钥和Claude模型访问权限，用于构建应用程序和集成。

付费Claude订阅可增强您的聊天体验，Claude API单独计费。Claude Max、Ultra和Team计划包括Claude API的月度额度。了解更多关于**[Max、Ultra和Team计划的月度API额度](https://support.claude.com/en/articles/17154008)**。

如果您对增强的聊天功能和API访问都感兴趣，您需要注册付费Claude计划，并单独**[设置控制台访问权限](https://support.claude.com/en/articles/8114521-how-can-i-access-the-anthropic-api)**以使用API。这样您可以根据具体需求从两种服务中受益。

请参考本文章了解更多关于Claude控制台计费的信息：**[我如何为API使用付费？](https://support.claude.com/en/articles/8977456-how-do-i-pay-for-my-api-usage)**
