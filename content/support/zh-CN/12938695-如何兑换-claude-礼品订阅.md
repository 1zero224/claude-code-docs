# 如何兑换 Claude 礼品订阅

有人向您发送了 Claude 礼品订阅——以下是兑换方式和开始使用 Claude 的方法。

## 如何兑换您的礼品

1. 打开您收到的礼品电子邮件或链接。

2. 点击

3. 登录您的 Claude 账户，或者如果您没有账户，请创建一个新账户。

4. 确认兑换。

5. 您也可以直接在 [claude.ai/gift/redeem](https://claude.ai/gift/redeem) 兑换并输入您的礼品代码。

**重要提示：**您的礼品将在购买日期后 365 天过期。无法同时兑换多个礼品或堆叠兑换。

## 兑换时会发生什么

您的体验取决于您当前的订阅状态：

**如果您是新用户或免费用户：**您的账户将立即升级到礼品计划。在礼品有效期内，您将拥有完全访问权限。

**如果您是 Pro 订阅者（网页版）并收到 Pro 礼品：**您的 Pro 订阅将延长礼品时长。

**如果您是 Pro 订阅者（网页版）并收到 Max 或 Ultra 礼品：**您将在礼品期间升级到 Max 或 Ultra 计划。礼品结束后，您的 Pro 订阅将恢复。Pro 计费周期中的任何未使用时间将作为账户余额添加。

**如果您是 Max 或 Ultra 订阅者（网页版）并收到较低级别的礼品：**礼品价值将转换为账户余额，自动应用于您的未来发票。

**如果您是 Max 订阅者（网页版）并收到 Max 或 Ultra 礼品：**您的 Max 订阅将相应延长或升级到 Ultra。

## 移动订阅者

如果您通过 iOS App Store 或 Google Play Store 有有效订阅，您需要等到该订阅结束后才能兑换礼品订阅。礼品订阅只能在网页上兑换。

您的礼品在等待期间不会过期——您可以在移动订阅结束后兑换。

## 故障排除

### 我没有看到兑换电子邮件

检查您的垃圾邮件或垃圾箱文件夹。如果仍然找不到，请要求发送礼品的人确认您的电子邮件地址或重新发送礼品链接。

### 我在尝试兑换时收到错误

确保您已登录网页版 Claude（而不是移动应用）。

### 我可以在不同的电子邮件地址上使用礼品吗？

任何 Claude 账户都可以兑换礼品，无论哪个电子邮件收到了礼品。
