# 谁拥有和管理我的团队数据？

本文提供了关于您与组织的 Claude for Work 计划（团队或企业计划）相关联的 Claude for Work 账户的重要信息。其中包含了在设置 Claude for Work 计划账户时与您共享的数据访问和控制的详细信息。

*本文涉及我们的商业产品，如 Claude for Work 和 Anthropic API。关于我们的消费者产品（如 Claude Free、Pro、Max、Ultra）以及这些计划中的账户使用 Claude Code 的信息，请参阅[此处](https://privacy.claude.com/en/collections/10663362-consumers)。*

## 账户管理

您组织指定的主要所有者管理您的 Work 账户和所有相关数据。这包括通过数据导出请求访问您的用户数据的能力，导出的数据可能包含您与 Claude 的对话、上传的文件和使用模式。主要所有者也可以在必要时移除您对 Claude for Work 计划账户的访问权限。

您的组织决定您在 Claude for Work 计划账户中可以访问哪些 Claude 服务和功能，他们可能会选择限制某些功能。

## 管理协议

您的 Claude for Work 计划账户的使用受 Anthropic 与您的组织之间的协议管理。请联系您的主要所有者了解该协议的详细信息。

虽然 Anthropic 的[隐私政策](https://www.anthropic.com/legal/privacy)描述了我们在作为数据控制者向您的组织提供 Claude 服务时如何收集、使用和共享个人信息，但请注意，Anthropic [消费者服务条款](https://www.anthropic.com/legal/consumer-terms)和[隐私政策](https://www.anthropic.com/legal/privacy)不适用于 Anthropic 作为数据处理者的 Claude for Work 计划的使用。

## 组织政策

您的组织可能对 Claude for Work 计划的使用有自己的内部政策。请咨询您的主要所有者以获取指导。

## 关于隐私的问题

如果您对 Claude for Work 计划账户中的数据隐私有任何疑问，我们建议您联系您组织的账户所有者。
