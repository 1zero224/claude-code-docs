# 我如何访问 Claude API?

有意使用 Claude API 进行开发的组织可以创建 [Claude Console 账户](https://platform.claude.com)。Claude Console 是您可以创建 API 密钥、将用户添加到您的团队、设置账单以及在 Workbench 上体验 Claude 的地方。请注意，API 访问权限受我们的 [商业服务条款](https://www.anthropic.com/legal/commercial-terms)约束。

了解更多关于 [使用 Claude API 进行开发的信息](https://claude.com/platform/api)。

如果您是对齐研究员，并且有意为了 AI 对齐研究目的访问 API，请了解更多关于访问 Claude API 的信息：[什么是外部研究员访问计划？](https://support.claude.com/en/articles/9125743-what-is-the-external-researcher-access-program)
