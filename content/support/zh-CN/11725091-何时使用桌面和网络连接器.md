# 何时使用桌面和网络连接器

Claude 可以通过两种方式连接到您的工具：通过网络（远程连接器）或通过 Claude 桌面应用（桌面扩展）。大多数连接器是远程的——它们是默认选择，可在您使用 Claude 的任何地方工作。

## 在以下情况下使用远程连接器

- 该工具是您登录的云服务（Slack、Notion、Linear、GitHub、您公司的 SaaS）

- 您希望连接器在任何地方都可用——网络、移动设备、Cowork、桌面和 Claude Code

- 您正在连接来自 **[连接器目录](https://claude.ai/directory)** 的内容

远程连接器可在所有 Claude 界面上工作。连接后，无需额外设置即可在任何地方使用。

## 在以下情况下使用桌面扩展

- 该工具在您的计算机上运行——本地文件、localhost 上的数据库、桌面应用程序

- 该工具需要操作系统级别的访问权限（文件系统、剪贴板、本地进程）

- 没有云版本可连接

桌面扩展在本地运行，仅在 Claude 桌面和 Claude Code 中可用——不在网络或移动设备上。

## 插件适用于两者

插件可以捆绑远程或本地 MCP 服务器（或两者）。添加引用远程 MCP 的插件会使其在任何地方都可用。引用本地 MCP 的插件在 Cowork 和 Claude Code 中工作，不在聊天中。

## 快速指南

| **您的工具是…**      | **使用**        | **可用于**        |
| --------------- | ------------- | -------------- |
| 云/SaaS 产品       | 远程连接器         | 所有界面           |
| 在连接器目录中         | 远程连接器         | 所有界面           |
| 在您的计算机上运行       | 桌面扩展          | 桌面、Claude Code |
| 本地文件或文件夹        | 桌面扩展          | 桌面、Claude Code |
| 您使用公共 URL 构建的内容 | 远程连接器（添加为自定义） | 所有界面           |
| 您构建的在本地运行的内容    | 桌面扩展          | 桌面、Claude Code |

## 开始使用

- 浏览并添加远程连接器：**自定义 → 连接器** 或 **连接器目录**

- 安装桌面扩展：打开 Claude 桌面 → 设置 → 桌面应用 → 扩展旁的"管理"（或在较旧的设置布局中选择设置 → 扩展）

- 构建自己的？请参阅 **[连接器构建文档](https://claude.com/docs/connectors/building)** 了解远程连接器，或参阅 **[MCPB 指南](https://claude.com/docs/connectors/building/mcpb)** 了解本地连接器。
