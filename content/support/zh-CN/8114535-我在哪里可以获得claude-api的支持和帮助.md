# 我在哪里可以获得Claude API的支持和帮助?

对于我们的API用户，我们目前维护三个主要资源：

- 我们的[客户端软件开发工具包（SDK）](https://docs.claude.com/en/api/client-sdks)；

- 我们的[Claude文档](https://docs.claude.com/en/home)；以及

- 我们的社区[Discord](https://anthropic.com/discord)，开发者可以在此分享想法和交换技巧。

如果您需要[联系我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)，您可以点击帮助中心右下角的消息图标，或点击您的Claude控制台账户左下角的首字母缩写，然后选择"获取帮助"。
