# 我如何删除我的 Claude Console 账户？

本文介绍了 Claude Console 管理员如何通过 Console 设置删除其组织。请注意，删除会影响 Console 组织的所有成员。

只有 Console 管理员可以请求删除。如需了解您的角色功能的完整概览，请参阅 **[Claude Console 角色和权限](https://support.claude.com/en/articles/10186004-claude-console-roles-and-permissions)**。

## 删除前

- 确认需要删除的具体 Console 组织。

- 删除会影响组织内的所有用户，因此请确保在删除前通知他们。

- 备份任何必要的数据，因为此操作在七天后无法撤销。

## 如何删除您的 Console 组织

1. 登录您的 Console 管理员账户。

2. 转到 **Organization** 页面 (platform.claude.com/settings/organization)。

3. 点击红色的"删除组织"按钮。

4. 将出现 **Delete [your org name]** 模态框；点击"确认并继续"以继续。

5. 要确认删除，请按照模态框中的指示输入

6. 您将在屏幕右上角看到"组织已删除"的确认消息。

## 常见问题

### 我不小心删除了我的 Console 组织 – 我应该怎么办？

如果您按照上述步骤删除了 Console 组织，但想撤销此操作，我们的支持团队可以在删除后的七天内恢复您的账户数据。请 **[联系支持](https://support.claude.com/en/articles/9015913-how-to-get-support)** 以获得进一步帮助。

### 我有未结余额；我如何删除我的 Console 组织？

如果您有未结余额，在删除流程中您将看到一条消息，提示您先支付余额，系统会将您路由到 **Billing** 页面 (platform.claude.com/settings/billing)。

您必须支付此未结余额，才能继续进行删除流程。
