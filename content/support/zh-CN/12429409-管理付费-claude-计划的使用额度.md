# 管理付费 Claude 计划的使用额度

本文介绍了使用额度在付费 Claude 计划（Pro、Max 或 Ultra）上的工作原理，允许您在达到计划的使用限制后，通过切换到按使用量付费的定价方式继续使用 Claude。

## 什么是使用额度？

使用额度允许订阅付费 Claude 计划（Pro、Max 和 Ultra）的用户在达到包含的使用限制后继续使用 Claude。大多数付费计划都有每五小时重置一次的会话限制和每周限制。Ultra 计划有每周限制，已验证的 Ultra 账户没有五小时限制（**[了解更多](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan#h_ff4fcea367)**）。Max 和 Ultra 计划还对 Fable 有单独的每周限制。当您达到计划的某个限制时，您可以切换到按标准 API 费率的消费定价，而不是被阻止，并继续工作而不中断。

使用额度与 Max 和 Ultra 计划附带的每月 API 额度分开。每月 API 额度不适用于 Claude、Claude Code 或 Claude Cowork 中的使用额度。了解更多关于 **[Max、Ultra 和 Team 计划的每月 API 额度](https://support.claude.com/en/articles/17154008)**。

**注意：**您可以在提供应用内购买的 Claude 移动应用中购买使用额度并设置支出限制。自动充值仅在网络上可用。

---

## 使用额度如何工作

当您完全使用计划的包含使用限制（任何五小时会话限制、您的每周限制或 Max 和 Ultra 计划上的 Fable 每周限制）且启用了使用额度时：

- 您的请求切换到使用额度上的按使用量付费定价并继续工作。

- 您可能仍会短暂看到您即将达到使用限制的通知。一旦您的下一个请求通过使用额度进行，它会更改为“现在使用额度。”您没有被切断；您的工作继续。

- 您的后续使用将按标准 API 定价费率计费。

- 您的使用将继续，直到您达到每月支出限制或关闭自动充值时余额用尽。

- 任何会话限制每五小时重置一次，您的每周限制每周重置一次，如常。

**注意：**使用额度与您的付费 Claude 订阅分开计费，并在您的账单上显示为额外费用。

---

## 启用使用额度

要在您的付费 Claude 计划上启用使用额度：

1. 在您的 Claude 账户中导航到[**设置 > 使用**](https://claude.ai/settings/usage)。

2. 找到**使用额度**部分并点击切换以启用它们。

3. 如果尚未配置，请设置您的付款方式。

4. 配置您的支出偏好。

5. 点击“调整限制”以通过每月支出限制控制成本。您也可以选择“设置为无限制”，如果您更喜欢没有支出限制。

6. 然后您需要购买额度以覆盖超出计划限制的使用。点击“购买使用额度，”选择您想购买的金额，然后点击“继续。”您的购买过期日期在您确认前显示。

7. 您也可以启用自动充值，以在您的余额低于您设置的阈值时自动进行购买。

## 设置支出限制

使用以下方式控制您的使用额度支出：

- **每月支出上限：**设置您每月愿意在使用额度上花费的最大金额。

- **自动充值设置：**当您的余额低于阈值时自动购买额外额度。

- **使用警报：**在接近使用额度限制时接收通知。

## 使用额度定价

使用额度按标准 API 费率计费；有关详细信息，请参阅我们的**[定价页面](https://claude.com/pricing#api)**。

价格和计划可能会根据 Anthropic 的判断而改变。

## 过期和退款

**过期。**通常，2026 年 12 月 7 日或之后购买的使用额度在购买日期后 12 个月过期。这适用于一次性购买、使用包和自动充值购买。任何未使用的额度在过期时从您的余额中移除。2026 年 12 月 7 日之前购买的额度不过期。

过期日期在某些国家/地区可能有所不同。有关更多信息，请参阅**[消费者额度条款](https://www.anthropic.com/legal/consumer-credit-terms)**。

您的过期日期显示在设置中的**使用**页面上，我们会在您购买的额度过期前向您发送电子邮件。

**退款。**使用额度购买不可退款，包括如果您取消订阅或删除您的账户。您直接从我们购买的额度在您升级到 Team 就地、将您的个人账户移动到组织、使用**重新开始**选项关闭它或在域名声明截止日期关闭时退款。您已经使用的额度永远不会退款。在当地法律要求的情况下或欺诈情况下适用例外。了解更多关于**[请求退款付费 Claude 计划](https://support.claude.com/en/articles/12386328)**。

## 管理您的使用额度

### 监控使用和成本

通过以下方式跟踪您的使用额度：

- **使用仪表板：**在**[设置 > 使用](https://claude.ai/settings/usage)**中查看实时消费。

- **当前支出：**监控您的本月迄今使用额度成本。

- **使用历史：**查看过去的消费模式以优化未来的使用。

## 成本效益使用的提示

要在保持生产力的同时管理使用额度成本：

- **选择高效模型：**使用我们最高效的 Haiku 模型，或最新的 Sonnet 模型用于大多数任务。这些提供了比 Opus 模型更低的令牌成本的出色性能。

- **首先使用您计划的包含使用：**如果您的计划有会话限制，请围绕您的五小时使用窗口计划密集工作会话。

- **开始新对话：**为新主题开始新聊天以最小化您的上下文窗口大小。

- **有效使用项目：**在项目知识中存储经常引用的文档，而不是重新上传。

- **设置适当的限制：**从保守的支出上限开始，并根据您的需求进行调整。

## 使用额度如何与其他功能配合工作

### Claude Code

使用额度适用于 Claude 对话和 Claude Code 终端使用。您在两个界面上的组合使用计入您的限制。

### 研究模式

使用研究模式时，一旦您超过计划的包含限制，使用额度就适用。由于多次搜索和全面分析，研究会话可能会更快地消耗令牌。

### 项目和文件

存储在项目文件中的文档在对话中使用时计入您的上下文。使用额度适用于所有处理的令牌，包括项目内容。

## 常见问题

### 启用使用额度后，我可以禁用它们吗？

是的，您可以随时通过**[设置 > 使用](https://claude.ai/settings/usage)**禁用使用额度。禁用后，您将只能访问您计划的包含使用。

### 我的常规使用限制重置有多快？

大多数付费计划包括两个使用限制：每五小时重置一次的会话限制和每周重置一次的每周限制。已验证的 Ultra 账户没有五小时限制（**[了解更多](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan#h_ff4fcea367)**）。Max 和 Ultra 计划还对 Fable 有单独的每周限制，每周重置一次。使用额度不影响这些限制中任何一个的重置时间。

### 达到每周限制后，我可以继续使用 Claude 吗？

是的。启用使用额度后，一旦您的包含限制之一完全用尽（任何五小时会话限制或您的每周限制之一），您的请求切换到使用额度上的按使用量付费定价并继续工作。您的使用将继续，直到您达到每月支出限制或关闭自动充值时使用额度余额用尽。

### 我在应用商店或 Play 商店订阅了付费 Claude 计划；我如何访问使用额度？

如果您通过 Claude 移动应用之一购买了付费计划，您可以在提供应用内购买的应用中购买使用额度并设置支出限制。自动充值仅在网络上可用。

### 我可以将使用额度与包含的使用分开跟踪吗？

是的，使用仪表板清楚地区分了您的包含计划使用限制和任何使用额度消费。

### 在切换到使用额度前我会收到警告吗？

是的。当您接近会话限制或您的每周限制之一时，您会看到通知。该通知在您的使用切换到使用额度的时刻可能仍在显示，因此看起来您已被切断。如果启用了使用额度且您有可用资金，您的下一个请求通过使用额度进行，通知更改为“现在使用额度。”

### 使用额度会过期吗？

是的。通常，2026 年 12 月 7 日或之后购买的使用额度在购买后 12 个月过期。在该日期之前购买的额度不过期。**[过期日期在](https://www.anthropic.com/legal/consumer-credit-terms)**某些司法管辖区有所不同。您可以在设置中的使用页面上查看过期日期，我们会在您购买的额度过期前向您发送电子邮件。了解更多信息，请参阅上面的**[过期和退款](#h_3499c80e6a)**。

### 如果我取消订阅，我的使用额度会发生什么？

取消时您的额度不会退款。您的余额保留在您的账户中，但使用额度只能与活跃的付费计划一起使用。

### 如果我删除我的账户，我的使用额度会发生什么？

删除您的账户时，任何剩余的使用额度都会被没收，并且不会退款。您直接从我们购买的额度在您升级到 Team 就地、将您的个人账户移动到组织、使用**重新开始**选项关闭它或在域名声明截止日期关闭时退款。在删除您的账户前使用您的余额。

### 我可以获得使用额度的退款吗？

使用额度购买不可退款，除非当地法律要求或欺诈情况。有关详细信息，请参阅上面的**[过期和退款](#h_3499c80e6a)**。
