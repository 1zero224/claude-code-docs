# 报告、屏蔽和删除 Claude 中的内容

Anthropic 支持多种方式让人们控制其内容和个人信息。作为网站所有者，您可以控制在使用网络搜索的 Claude 输出中显示的内容。作为用户或公众成员，您可以报告其他用户公开分享或您在 Claude 输出中收到的有问题的内容。对于每种类型的问题，请按照下面的报告说明进行操作。

请注意，我们保留暂停经常提供明显非法内容的用户以及暂停处理经常提交明显无根据的通知的用户的权利。我们将在暂停前提供警告。

## 如何报告安全问题

我们欢迎有关安全问题的报告，以便我们能够增强模型的安全性和无害性。如果您发现我们的安全机制导致任何用户体验问题，我们也很乐意听取您的意见。请将此类问题报告至 <usersafety@anthropic.com>，并提供足够的详细信息以便我们复现该问题。

## 如何屏蔽或删除内容

### 从 Claude 网络搜索中屏蔽或删除网站

| 从您的网站删除内容                  | 适用于：所有内容类型<br>从您的网站删除内容是确保其不会在 Claude 搜索网络时出现在 Claude 输出中的最佳方式。                                                                                                                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 密码保护您的文件                   | 适用于：所有内容类型<br>如果您的网站上有机密或私密内容，您需要对其进行密码保护，以确保只有授权用户才能访问。这也将防止该内容出现在依赖网络搜索的 Claude 输出中，或者如果已经出现，它最终会从我们的搜索结果中删除该内容。                                                                                                                          |
| `noindex` 标签               | 适用于：所有内容类型<br>`noindex` robots 元标签是一条规则，它告诉我们的合作伙伴不要索引您的内容，以便他们不会根据您的网络搜索查询将其发送给我们。您的内容仍然可以通过其他网页链接到和访问，或者用户可以通过链接直接访问，但该内容不会出现在使用网络搜索的 Claude 输出中。                                                                                         |
| 使用 robots.txt 禁止爬取         | 适用于：图像和视频<br>我们的搜索合作伙伴仅索引其机器人被允许爬取的图像和视频。要防止它们访问您的媒体文件，请使用 robots.txt 规则来阻止这些文件。                                                                                                                                                            |
| 禁止 Anthropic 的机器人          | 适用于：所有内容类型<br>按照[此处](https://privacy.anthropic.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler)的说明进行操作。                                                                            |
| 屏蔽已出现在 Claude 输出中的 URL<br> | 适用于：所有内容类型<br>向 <webresultsoptout@anthropic.com> 提交请求，包括证明您拥有该 URL 所需的信息，可以是：[ICANN 注册](https://www.icann.org/resources/pages/register-domain-name-2017-06-20-en)、[WHOIS 查询结果](https://whois.domaintools.com/)、域名注册收据、SSL 证书或使用特定于域的电子邮件地址。 |

### 从共享的 Claude 内容中屏蔽或删除内容

| 在产品中报告内容<br>    | 适用于：共享 Claude 对话中的所有内容<br>使用共享内容上的"报告"按钮。                                                  |
| --------------- | ------------------------------------------------------------------------------------------ |
| 通过我们的独立报告表单报告内容 | 适用于：共享 Claude 对话中的所有内容<br>请通过[此表单](https://claude.com/form/anthropic-content-reporting)报告。 |
