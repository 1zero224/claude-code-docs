# Claude 教师版：您的数据和我们的条款

## 概述

**[Claude 教师版](https://claude.com/solutions/teachers)**对经过验证的美国 K-12 教育工作者免费提供，有效期至 2028 年 7 月 30 日。无论您以个人教师身份注册，还是由您的学校或地区为所有人建立组织，都包括在内。此服务包括免费访问 Claude Pro 功能、为课程规划和差异化教学而设计的教学技能、与所有 50 个州学术标准相对应的课程连接，以及为 K-12 编写的条款。

本页面说明了**[美国 K-12 服务条款](https://www.anthropic.com/legal/k12-terms)**、**[美国 K-12 公共部门附录](https://anthropic.com/legal/k12-addendum)**和**[美国 K-12 数据处理协议](https://www.anthropic.com/legal/k12-dpa)**。

## 这是为谁准备的？

Claude 教师版适用于在美国 K-12 学校和地区工作的教育工作者：课堂教师、教学指导员、专家、干预专家、图书馆员、辅导员和其他持证工作人员。

提供两种方式：

- **个人教育工作者**使用学校电子邮件进行验证以获得免费访问权限，并自行接受 K-12 条款。

- **学校和地区**由授权管理员建立免费的 Claude Enterprise 组织。教师通过地区单点登录加入，学校或地区为所有人一次性接受 K-12 条款，包括数据处理协议，以及公立学校和地区的公共部门附录。

## 您将获得什么

Claude 教师版包括专业级功能，包括 Claude Code 和 Claude Cowork。它还包括：

- **学习共享连接器**，为 Claude 提供所有 50 个州的学术标准、其下的先决条件技能和课程背景

- **教学技能**用于课程规划和差异化教学，以学习科学为基础

- **来自 MagicSchool、TeachFX 和 Canva for Education 等合作伙伴的教育连接器**

- **符合 FERPA 的保护措施**

**重要提示：**Claude 教师版不适用于学生。这是仅限教育工作者的服务。如果您是 18 岁以上的学生或在教育工作之外使用 Claude，Claude 将受我们的消费者服务条款管制。

如果您的地区已建立 Claude 教师版组织，您的地区接受的 K-12 条款将管制您在该组织内对 Claude 的使用。

## K-12 隐私和条款

### 我们不使用您的对话进行训练

Anthropic 不会使用您的输入或输出来训练我们的模型。您保留对您的输入的所有权利。您拥有您的输出。

### 保护您的数据

当您创建 Claude 教师版账户时，您是提交数据的“控制者”。您控制数据的使用方式，可以随时访问或删除该数据。Anthropic 代表您充当数据“处理者”。我们仅按照您的指示处理数据以提供 Claude 服务。这意味着：

- 学生数据保持在您（或您的地区）的控制下，Anthropic 仅使用它来提供服务。

- Anthropic 不出售或共享学生数据，也不将其用于广告、营销或建立学生档案。

- Anthropic 不直接从学生那里收集学生数据。学生账户不是 Claude 教师版的一部分。

- 来自学生或家长关于其信息的请求将转发给您或您的地区处理，Anthropic 帮助您回应。

**注意：**Claude 教师版提供符合 FERPA 的设置来处理学生数据。Claude 教师版中是否以及如何使用可识别的学生信息由您的学校或地区的政策决定，而不是由 Anthropic 决定。如果您使用个人教师账户且未获得学校或地区授权做出该决定，请勿在 Claude 教师版中包含可识别的学生信息。

### 安全性

静态数据采用 AES-256 加密。传输中采用 TLS 1.2 或更高版本。保存您数据的每个系统都采用多因素身份验证，访问权限仅限于需要的工作人员。每年进行第三方审计和渗透测试。包括 SOC 2 在内的认证可在我们的**[信任中心](https://trust.anthropic.com/)**查看。Anthropic 在添加新的子处理者之前提前通知，您有 15 天的反对期，地区可以每年审计一次 Anthropic 的控制措施。

### 删除您的数据

您可以控制您的对话，并可以随时从仪表板删除您的聊天。有关数据删除的更多信息可以在此处找到：**[我可以删除通过团队和企业计划发送的数据吗？](https://support.claude.com/en/articles/9796617-can-you-delete-data-that-i-sent-via-team-and-enterprise-plans)**

您地区的管理员也可以在地区政策要求时通过合规 API 删除任何成员的数据。如果您的地区离开 Claude，Anthropic 将根据请求返回您地区的数据，并在 30 天内删除其副本，除非法律要求保留。

## 关于您的 Claude 教师版账户

### 个人教师账户

验证后，您的账户将转移到 Claude 教师版计划——为经过验证的教育工作者提供的免费 Claude Teams 计划。它附带特定于教育工作者的条款和数据处理协议，您的聊天和文件不用于训练我们的模型，并内置了学生数据保护。您的使用限制高于标准免费账户——足以满足日常课堂工作，如课程规划、测验和家长沟通。

某些 Team 计划功能对 Claude 教师版已关闭。您将看不到计费和座位购买、**[成员邀请和管理](https://support.claude.com/en/articles/13133750-manage-members-on-team-and-enterprise-plans)**、角色和权限、SSO 和域捕获或高级座位。如有疑问，请**[联系我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)**。

### 学校和地区组织

当您的学校或地区建立 Claude 教师版时，教师是地区拥有和管理的**[Claude Enterprise 组织](https://support.claude.com/en/articles/16559896)**的成员。

与个人 Claude K-12 教师版账户的区别：

- **一套条款。**您的地区为所有人一次性接受 K-12 条款和数据处理协议。

- **地区登录。**您使用地区登录（单点登录）而不是创建自己的账户进行登录。一旦您的地区验证了其电子邮件域，就无法使用地区电子邮件地址创建新的个人 Claude 账户。

- **管理员控制。**您地区的管理员决定您可以使用哪些功能、模型和连接器，并可以管理成员和角色。

- **管理员访问内容。**您地区的主要所有者可以启用合规 API 并使用它读取或删除任何成员的聊天、文件和项目。

- **相同的使用额度。**您获得与个人 Claude 教师版账户相同的滚动五小时和每周限制。

**注意：**公立学校、地区和特许学校也接受**[美国 K-12 公共部门附录](https://anthropic.com/legal/k12-addendum)**，该附录为公共实体调整条款——例如，您所在州的法律适用，当州法律禁止时，仲裁和赔偿不适用。它不改变学生数据的处理方式，也不适用于个人教师账户。
