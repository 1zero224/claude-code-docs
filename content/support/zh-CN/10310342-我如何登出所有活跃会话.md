# 我如何登出所有活跃会话？

如果您需要在所有设备上登出 Claude 账户，可以通过网页版 Claude 的 **[设置 > 账户](https://claude.ai/settings/account)** 进行操作。如果您忘记在共享设备上登出，或怀疑账户遭到未授权访问，这个选项特别有用。

**注意：**此选项目前在 iOS 或 Android 的 Claude 移动应用中不可用。

## Claude 网页应用的会话持续多长时间？

当您通过 **[claude.ai](https://claude.ai)** 登录时，会创建一个持续 28 天的会话。这决定了在网页应用上不活跃时，您保持登录状态的时长。如果您在 **[claude.ai](https://claude.ai)** 上执行任何操作（例如重新加载页面），您的会话将自动刷新，从该时间点起重新计算 28 天。

## 如何登出所有活跃会话

1. 在网络浏览器中访问 **[claude.ai](https://claude.ai/)**。

2. 登录您的账户。

3. 点击左下角的您的首字母缩写。

4. 从菜单中选择 “设置”。

5. 导航到 “账户” 部分。

6. 点击 “登出” 按钮。

7. 在提示时确认您的选择。

此操作将立即在您之前登录过的所有设备上登出您的账户，包括：

- 网络浏览器

- 移动设备

- 桌面应用程序

- Claude Code，包括使用 `setup-token` 为持续集成 (CI) 创建的令牌

- 您的工具中的 Claude，例如 Chrome 中的 Claude 和 Slack 中的 Claude

要在任何设备上重新获得账户访问权限，您需要使用 Google 登录或发送到您电子邮件地址的登录链接重新进行身份验证。

**注意：**登出所有活跃会话不会影响您的 API 密钥。

## 如何仅从 Claude Code 登出

登出所有活跃会话也会将您从 Claude Code 登出。要仅从 Claude Code 登出并在其他地方保持登录状态，请改为移除其授权令牌。

如果您使用 Claude 账户进行 Claude Code 身份验证，可以在 **设置 > 账户** 中查看并登出这些登录，它们与您的其他会话一起列出。如果它们未在那里列出，请在 **设置 > Claude Code** 中管理您的授权令牌。要移除令牌并登出 Claude Code，请点击垃圾桶图标。

## 无法访问您的账户？

如果您无法登录账户以登出所有会话，请通过点击任何帮助中心页面右下角的消息图标与我们的支持团队联系。如需更多信息，请参阅 **[如何获得支持](https://support.claude.com/en/articles/9015913)**。
