# 我如何才能获得 Claude API 的更高速率限制？

使用层级会自动分配。没有存款或购买可以提升您的层级，您也无需采取任何行动。

与团队计划关联的 Claude 控制台组织可获得每月 API 额度，至少会升至 Build 层级，因此完整的 $500 月度额度将在组织的支出限制范围内。领取月度 API 额度不会改变您的使用层级。详细了解 **[Max、Ultra 和 Team 计划的月度 API 额度](https://support.claude.com/en/articles/17154008)**。

如果您需要更高的限制，一旦您使用了当前限制的至少 50%，就可以在 Claude 控制台中请求提高限制。您可以在 **[Claude 控制台](https://platform.claude.com/settings/limits)** 中查看您的层级和当前限制。

如需自定义限制或承诺容量，请 **[联系我们的销售团队](https://claude.com/contact-sales)**。

请参阅 **[我们的 Claude 平台文档](https://docs.claude.com/en/api/rate-limits)** 以了解有关速率限制和使用层级的更多信息。
