# 在 Mac 上通过 Claude Desktop 使用快速输入

快速输入是 Claude Desktop 在 Mac 上的重新设计体验，让您可以从计算机上的任何位置即时访问 Claude。通过快速输入，您可以启动聊天、捕获屏幕截图、共享应用程序窗口，以及使用语音听写与 Claude 交互，而无需离开当前任务。

快速输入适用于所有使用 Claude Desktop on macOS 的 Claude 用户（免费版、专业版、Max、Ultra、Team 和企业版计划）。

## 主要功能

快速输入包括三项主要功能：

- **即时访问**：双击 Option 键从任何应用打开 Claude。

- **视觉上下文**：捕获屏幕截图或点击应用程序窗口以共享您正在处理的内容。

- **语音输入**：按 Caps Lock 键向 Claude 听写您的消息，实时转录。

## 系统要求

要使用快速输入，您需要：

- macOS 12 或更高版本以使用快速输入功能

- macOS 14 或更高版本以使用语音听写

- 已安装并运行 Claude Desktop（可在后台运行）

## 设置快速输入

首次打开更新版本的 Claude Desktop 时，您会看到启用快速输入快捷键的提示。

### 启用聊天快捷键

1. 在快速输入提示中勾选**打开快捷键**。

2. 点击"继续"。

3. 双击 Option 键以测试快捷键。

4. 今后，在**设置 > 桌面应用**（或**设置 > 系统**中的**此计算机**，在较旧的设置布局中）中管理此项。

启用后，双击 Option 将打开一个文本框，您可以在其中输入消息并启动新聊天。您也可以点击"新聊天"查看您最近的五个对话。

### 启用语音快捷键（可选）

语音听写快捷键默认禁用，因为它会接管您的 Caps Lock 键。

要启用语音听写：

1. 在语音听写提示中勾选**打开快捷键**。

2. 点击"继续"。

3. 按一次 Caps Lock 开始听写。

4. 说完后再按一次 Caps Lock。

5. 点击箭头将转录的消息发送给 Claude。

6. 今后，在设置 > 桌面应用（或设置 > 系统中的此计算机，在较旧的设置布局中）中管理此项。

## 使用快速输入

### 启动快速对话

1. 从任何应用程序双击 Option 键。

2. 在出现的文本框中输入您的消息。

3. 点击箭头图标或按 Enter 键将消息发送给 Claude。

### 捕获屏幕截图

1. 通过双击 Option 键打开快速输入。

2. 光标旁会出现"拖动以截图"提示。

3. 点击并拖动以选择要截图的屏幕区域。

4. 屏幕截图将附加到您发送给 Claude 的消息中。

### 共享应用程序窗口

1. 通过双击 Option 键打开快速输入。

2. 点击应用程序窗口以将其内容附加到您的消息中。

3. 添加任何其他上下文或问题。

4. 将消息发送给 Claude。

### 使用语音听写

1. 按 Caps Lock 开始听写（如果已启用）。

2. 说出您的消息——您会看到您的话语实时转录。

3. 再次按 Caps Lock 停止听写。

4. 查看转录的消息。

5. 点击箭头将其发送给 Claude。

## 自定义快捷键

您可以在 Claude Desktop 设置中自定义快速输入快捷键。

1. 打开 Claude Desktop。

2. 转到**设置 > 桌面应用**（或**设置 > 系统**中的**此计算机**，在较旧的设置布局中）。

3. 在**快速访问快捷键**旁选择以下选项：

  - 双击 Option（默认）

  - Option + Space

  - 自定义键盘快捷键

4. 点击**语音快捷键**旁的下拉菜单以：

  - 启用 Caps Lock 进行语音输入

  - 设置自定义键盘快捷键

  - 完全禁用快捷键

## 权限

快速输入需要某些 macOS 权限才能正常运行：

- **屏幕录制**：捕获屏幕截图和共享应用程序窗口所需。

- **辅助功能**：快速输入功能所需。

- **语音识别**：语音听写所需（仅限 macOS 14+）。

您可以在系统设置 > 隐私和安全中查看或更改这些权限。

## 常见用例

快速输入专为您需要 Claude 帮助而不中断工作流的时刻而设计：

- **代码审查**：直接与 Claude 共享错误消息或应用程序窗口以获得调试协助。

- **快速答案**：从 Claude 获得即时协助，无需切换离开当前任务。

- **研究和写作**：浏览时捕获屏幕截图并提出上下文相关的问题。

- **头脑风暴**：使用语音听写进行免提构思，同时思考或走动。

## 常见问题

### 我需要保持 Claude Desktop 打开才能使用快速输入吗？

是的。Claude Desktop 需要在您的 Mac 上运行，但可以在后台运行。您不需要让 Claude 窗口可见。

### 我可以在 Windows 上使用快速输入吗？

不可以。快速输入目前仅适用于 macOS 用户。Windows 用户仍然可以访问 Claude Desktop，但没有快速输入功能。

### 使用听写时我的语音会被录制吗？

语音听写将您的语音实时转录为文本。转录的文本作为您的消息的一部分发送给 Claude，就像任何其他文本输入一样。

### 启用快速输入后我可以禁用它吗？

可以。您可以随时在**设置 > 桌面应用**（或**设置 > 系统**中的**此计算机**，在较旧的设置布局中）中禁用快速输入快捷键。您可以关闭快速访问快捷键、语音快捷键或两者。

### 如果快捷键与其他应用冲突怎么办？

您可以自定义快速访问快捷键以使用 Option + Space 或创建不与其他应用冲突的自定义键盘快捷键。语音快捷键可以使用 Caps Lock 或自定义键盘快捷键，或被禁用。
