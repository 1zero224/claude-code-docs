# 如何获取支持

本指南说明如何获取 Claude 或 Console 账户的支持。根据您的计划，可获得不同的支持选项。支持通过支持信使和电子邮件以书面形式提供。我们不提供电话支持。

## Pro、Max 和 Ultra 计划、Team 和 Enterprise 计划所有者以及 Console 管理员

您可以完全访问：

- 所有帮助文档

- Fin，我们的 AI 支持机器人

- 来自我们产品支持团队的进一步协助

虽然我们不提供电话或实时聊天支持，但我们的产品支持团队很乐意通过我们的支持信使为您提供帮助。

**Enterprise 管理员注意：**主要所有者和所有者可以通过指定支持联系人来配置其组织的哪些成员可以获得人工支持。默认情况下，管理员和所有者保持人工支持访问权限。有关配置详情，请参阅 **[为人工支持指定支持联系人](https://support.claude.com/en/articles/15263885)**。

### 寻求 Claude 支持

1. 登录您的 Claude 账户。

2. 点击左下角的您的首字母或名字，然后从菜单中选择"获取帮助"。

3. 在支持信使中：

  - 搜索帮助资源

  - 与 Fin（我们的 AI 支持机器人）聊天

4. 点击"发送消息"开始与 Fin 聊天。

5. 点击"接受"，然后从可用选项中选择您的问题。

6. 根据选定的问题，在出现提示时提供其他详情。

7. 如果您的问题需要我们产品支持团队进行额外调查或输入，Fin 将转发您的询问。团队的回复会在同一对话中显示。您将在信使中看到它，并在您 Claude 账户上的电子邮件地址收到副本，因此您无需保持此窗口打开。

### 寻求 Claude API 或 Console 支持

1. 登录您的 **[Console 账户](https://platform.claude.com)**。

2. 点击 Console 左下角的您的首字母或名字，然后从菜单中选择"获取帮助"。

3. 这将在 Console 的右下角打开一个支持信使。

4. 在支持信使中：

  - 搜索帮助资源

  - 与 Fin（我们的 AI 支持机器人）聊天

5. 点击"发送消息"开始与 Fin 聊天。

6. 点击"接受"，然后从可用选项中选择您的问题。

7. 根据选定的问题，在出现提示时提供其他详情。

8. 如果您的问题需要我们产品支持团队进行额外调查或输入，Fin 将转发您的询问。团队的回复会在同一对话中显示。您将在信使中看到它，并在您 Claude 账户上的电子邮件地址收到副本，因此您无需保持此窗口打开。

### 从帮助中心寻求任何账户类型的支持

登录到其 Claude 或 Console 账户的用户将能够点击任何帮助中心页面右下角的图标来打开支持信使并开始与 Fin 聊天。

## 您给我们发送消息后会发生什么

支持是异步的。您的请求到达我们的团队后，专家会进行调查并在同一对话中回复。响应时间因计划和问题的严重程度而异。

### 聊天和电子邮件是同一对话

- 我们发送的每条回复都会显示在支持信使中，并通过电子邮件发送到您 Claude 账户上的地址（您启动对话时登录的账户）。

- 回复该电子邮件会继续同一对话。您无需返回聊天，可以随时关闭聊天窗口而不会错过我们的回复。

- 每个问题保持一个对话。为同一问题打开第二个请求会创建一个必须重新分类的重复项，这通常会减慢答案速度。如果您还没有收到回复，请在现有对话中回复。

### 让同事了解情况

- 在信使中启动的对话仅包括您。要引入同事（如受影响的用户或您的 IT 管理员），请从电子邮件线程回复对话并抄送他们。他们的回复会加入同一对话。

- 如果您代表他人报告问题，请在第一条消息中包含其工作电子邮件地址、任何错误消息或屏幕截图以及问题开始的时间。这样可以避免额外的问题轮次。

- Enterprise 组织也可以 **[指定支持联系人](https://support.claude.com/en/articles/15263885)**。

## Team 和 Enterprise 计划非所有者以及 Console 非管理员

您将与 Fin（一个 AI 支持代理）聊天，以帮助回答您的问题。

### Team 计划和 Console 组织

人工专家支持不直接适用于您的账户座位类型。如果 Fin 找不到解决方案，您需要升级到我们的人工专家团队，您账户的主要所有者、所有者或 Console 管理员可以代表您联系。

### Enterprise 计划

主要所有者和所有者可以指定支持联系人：可以获得人工支持而无需持有所有者角色的成员。如果您是指定的支持联系人，在与 Fin 聊天时您将有选项等待人工。否则，Fin 将处理您的对话，如果需要升级，您账户的主要所有者、所有者或指定的支持联系人可以代表您联系。

有关配置详情，请参阅 **[为人工支持指定支持联系人](https://support.claude.com/en/articles/15263885)**。

免费 Claude 用户可以访问：

3. 选择"获取帮助"。

4. 使用支持信使来：

  - 搜索帮助资源。

## 无法登录？

如果您无法访问您的账户，我们仍然可以帮助：

1. 账户删除

2. 数据导出

3. 订阅支持

请求协助：

1. 点击帮助中心右下角的消息图标。

2. 开始对话。

3. 选择"我无法登录"。

## 关于订阅支持

如果您是付费订阅者且在访问账户时遇到问题，我们的团队可以：

- 帮助查找登录信息

- 处理订阅取消

- 检查退款资格

**注意：**为了协助完成这些任务，我们需要验证有关您的账户和所使用的付款方式的详情。

## 常见问题

### 您提供电话或视频支持吗？

不提供。支持通过信使和电子邮件以书面形式提供。需要实时工作会话的 Enterprise 客户可以通过其 Anthropic 账户团队安排。

### 我在等待时可以关闭聊天窗口吗？

可以。回复会发送到信使和您的账户电子邮件，因此您不会错过任何回复。

### 您将使用哪个电子邮件地址回复？

您启动对话时登录的 Claude 账户上的电子邮件地址。
​

### 我还没有收到回复。我应该打开另一个请求吗？

不应该。在您现有的对话中回复（在信使或电子邮件中），它会以其历史记录完整地重新进入队列。
​

### 我有一个业务关键的中断。有更快的路径吗？

符合条件的 Enterprise 计划上的组织所有者和管理员在信使中有优先选项。平台状态始终可在 **[我们的状态页面](https://status.claude.com)**上获得。

## 与 Fin 聊天会影响 Claude 使用情况或支出限制吗？

不会。与 Fin 聊天不会影响 Claude 使用情况或支出限制。
