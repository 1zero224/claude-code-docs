# 在一个目录中浏览技能、连接器和插件

我们的统一目录将技能、连接器和插件汇集在一个地方，让您可以找到并安装所有自定义 Claude 的内容，无需在不同菜单之间切换。在 Team 和 Enterprise 计划中，该目录也是您组织发布的技能和插件出现的地方。

---

## 访问目录

1. 打开 Claude 或 Claude Desktop

2. 点击左侧边栏中的 “自定义”。

3. 点击您想查看的标签页：技能、连接器或插件。

4. 打开 **发现** 标签页。

### 技能

要打开技能目录，请转到 **[自定义 > 技能](https://claude.ai/customize/skills)**，点击 “+” 按钮，然后点击 “浏览技能。” 点击任何技能上的 “添加” 按钮将其添加到您的技能列表。安装后，该技能会出现在 **[自定义 > 技能](https://claude.ai/customize/skills)** 中并默认启用，因此 Claude 可以在相关时自动使用它。您可以随时将其关闭，但该技能会保留在目录中，以便您稍后重新启用它。

您从目录安装的技能是只读的。您可以使用它们，但无法编辑其内容。如果您想改变技能的工作方式，请下载副本、修改它，然后将其作为您自己的技能上传。

在 Team 和 Enterprise 计划中，“您的组织” 标签页列出了您整个组织可用的技能。这包括所有者集中配置的技能和同事发布到组织的技能。您无法从列表中完全删除这些技能。只有组织所有者可以将其从目录中删除。

**注意：** 同事直接与您共享的技能和插件不会出现在目录中，它们直接进入您的技能列表。有关共享技能和插件如何工作的详细信息，请参阅 **[在 Claude 中使用技能](https://support.claude.com/en/articles/12512180-use-skills-in-claude)** 和 **[在 Claude 中使用插件](https://support.claude.com/en/articles/13837440-use-plugins-in-claude)**。

### 连接器

连接器标签页显示您可以连接 Claude 的相同服务目录，现在采用统一视图。点击任何服务上的 “连接” 以开始身份验证流程。有关连接和管理服务的更多信息，请参阅 **[使用连接器扩展 Claude 的功能](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)**。

### 插件

**自定义 > 插件** 中的 **发现** 标签页显示可用的插件，包括您的组织通过市场分发的任何插件。同事直接与您共享的插件列在 **自定义 > 插件** 中的 **与您共享** 下。

选择一个插件，然后点击 “添加。” 该插件会保存到您的账户。其技能和命令在聊天（网页和 Claude Desktop 中的聊天标签页）、Cowork 和使用同一 Claude 账户登录的 Claude Code 会话中可用。要稍后从您的账户中删除插件，请打开它并选择 “删除。”

## 对于组织所有者

人们是否可以发布到目录取决于您的发布设置。要让您组织中的人员发布技能到目录，请在 “策略” 标签页中的 **[组织设置 > 插件和技能](https://claude.ai/admin-settings/skills)** 中将 **发布** 设置为 **开放** 或 **需要审核**。单独的 **技能共享** 允许人员与特定同事共享技能和插件，而无需发布到目录。

有关配置共享和集中配置技能的完整详细信息，请参阅 **[为您的组织配置和管理技能](https://support.claude.com/en/articles/13119606-provision-and-manage-skills-for-your-organization)**。
