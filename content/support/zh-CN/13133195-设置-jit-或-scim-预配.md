# 设置 JIT 或 SCIM 预配

本指南介绍如何为您的 Claude 或 Claude Console 组织配置用户预配和角色分配。

JIT 预配适用于团队计划、企业计划和 Console 组织。SCIM 预配仅适用于企业和 Console 组织。

**开始前：**本指南假设您已完成**[设置单点登录 (SSO)](https://support.claude.com/en/articles/13132885-setting-up-single-sign-on-sso)** 中的步骤，包括域验证和与身份提供商 (IdP) 的 SSO 配置，且您拥有管理员 (Console) 或所有者 (Claude) 角色。

---

## 步骤 1：选择您的预配模式

配置 SSO 后，您需要决定如何将用户预配到您的组织。这通过**[组织设置 > 组织和访问](https://claude.ai/admin-settings/organization)**中的**用户预配**部分进行控制。

### 预配选项

**仅邀请**是默认选项。用户直接在 Claude 或 Console 设置中添加和删除。

**即时 (JIT)：**分配给您的 Anthropic IdP 应用的用户在首次登录时自动预配。此选项适用于所有计划。

**SCIM 目录同步：**用户根据 IdP 中的分配自动预配和取消预配，无需他们先登录。SCIM 适用于企业计划和拥有自己的父组织或加入企业父组织的 Console 组织。SCIM 不适用于团队计划或加入团队计划父组织的 Console 组织。

启用 SCIM 目录同步后，Claude 会向每个新预配的成员发送欢迎电子邮件。要关闭此功能，所有者和主要所有者可以导航到**组织设置 > 组织和访问 > 用户预配**，找到**SCIM 目录同步**，然后关闭“向新成员发送欢迎电子邮件。”

**注意：**Claude 不会向具有额外数据处理或合规要求（如客户管理的加密密钥 (CMEK)、HIPAA 或 FERPA）的组织发送此欢迎电子邮件，因此这些组织不会显示该设置。更改适用于您保存后预配的成员，已发送的电子邮件保持已送达状态。

### 预配行为概览

使用此表格帮助决定哪种预配模式适合您的组织：

| **模式**     | **预配**                                     | **角色和座位类型更改**                        | **删除**                                                                                         |
| ---------- | ------------------------------------------ | ------------------------------------ | ---------------------------------------------------------------------------------------------- |
| 仅邀请        | 用户手动添加                                     | 角色和座位类型手动更改                          | 用户手动删除                                                                                         |
| 即时 (JIT)   | 分配给您的 IdP 应用的用户在登录时以用户角色预配                 | 角色和座位类型手动更改                          | 需要手动删除。JIT 永远不会自动删除成员。如果您从 IdP 应用中取消分配某人，他们将无法再登录，但他们会保留在您的成员列表中并保持其座位，直到管理员将其删除。              |
| JIT + 组映射  | 至少在一个映射组中的用户在登录时以其组成员身份中权限最高的角色预配          | 角色和座位类型在下次登录时根据组成员身份更新。主要所有者的角色不会更改。 | 大多数手动。从所有映射组中删除但仍分配给应用的用户在下次登录时从组织中删除。这不适用于主要所有者。您完全取消分配的用户无法再登录，但会保留在您的成员列表中并保持其座位，直到管理员将其删除。 |
| SCIM 目录同步  | 分配给您的 IdP 应用的用户自动预配到加入您的父组织的所有组织。          | 角色和座位类型手动更改                          | 从您的 IdP 应用中删除的用户自动删除                                                                           |
| SCIM + 组映射 | 至少在一个映射组中的用户自动预配（具有适当的角色）到仅加入父组织且添加了该组的组织。 | 角色和座位类型更改根据组成员身份自动传播                 | 撤销组访问权限时自动删除                                                                                   |

**注意：**要永久删除 JIT 用户，请在 Claude 中删除他们并在您的 IdP 中取消分配他们。仅在 Claude 中删除的用户将在下次使用 SSO 登录时重新添加。

JIT 和 SCIM 都可以与**启用组映射**结合使用，以根据 IdP 组成员身份控制角色或座位层级分配。如果您为预配模式选择这两个选项之一，**启用组映射**将出现在**用户预配**部分内：

**重要：**组映射仅设置用户的角色类型和座位层级。具有自定义角色的用户从 Claude 中的组获取其权限，这些组仅在您的预配模式为 SCIM 目录同步时从您的 IdP 同步。使用 JIT 时，您需要在**[组织设置 > 组](https://claude.ai/admin-settings/groups)**中手动创建组并将用户添加到其中。如果您在不执行此操作的情况下将 IdP 组映射到 JIT 下的自定义角色，这些用户在登录时将没有权限。了解有关**[在企业计划上管理组](https://support.claude.com/en/articles/13799932)**的更多信息。

## 步骤 2：设置 SCIM 目录同步（如果使用 SCIM）

**注意：**如果您使用的是仅邀请或 JIT 配置，请跳过此步骤。

如果您选择 SCIM 作为配置模式，需要在启用前建立身份提供商与 Anthropic 之间的连接。

1. 在 Claude 中导航到**组织和访问**设置（**[claude.ai/admin-settings/organization](https://claude.ai/admin-settings/organization)**）或在控制台中导航到**身份和访问**设置（**[platform.claude.com/settings/identity](https://platform.claude.com/settings/identity)**）

2. 在**用户配置**部分，点击**SCIM 目录同步**旁边的“设置 SCIM”（或“管理 SCIM”）。

3. 按照 WorkOS 设置指南在您的身份提供商中配置 SCIM。您需要将 WorkOS 中的值复制到您的 IdP 的 Anthropic 应用程序中。

**‼️ 当您到达 IdP 组步骤时，暂停以查看本指南的步骤 3 和 4，以及其他指南。**

有关 IdP 特定的 JIT / SCIM 设置说明，请参阅：

- **[Okta SAML](https://workos.com/docs/integrations/okta-saml)** / **[OKTA SCIM](https://workos.com/docs/integrations/okta-scim)**

- **[Entra ID SAML](https://workos.com/docs/integrations/entra-id-saml)** / **[Entra ID SCIM](https://workos.com/docs/integrations/entra-id-scim)**

- **[Google SAML](https://workos.com/docs/integrations/google-saml)** / **[目录同步](https://workos.com/docs/integrations/google-directory-sync)**

- **[OneLogin SAML](https://workos.com/docs/integrations/onelogin-saml)** / **[OneLogin SCIM](https://workos.com/docs/integrations/onelogin-scim)**

- **[JumpCloud SAML](https://workos.com/docs/integrations/jumpcloud-saml)** / **[JumpCloud SCIM](https://workos.com/docs/integrations/jumpcloud-scim)**

- 查看其他 IdP **[此处](https://workos.com/docs/integrations)**

IdP 连接后，继续执行步骤 3。

## 步骤 3：配置配置模式并启用组映射

1. 找到您设置中的**用户配置**部分。

2. 选择您的选项：

  1. **仅邀请**：新成员只能通过现有成员的手动邀请加入。仅 SSO 访问不会将他们添加到您的组织。

  2. **即时配置 (JIT)**：允许具有 SSO 访问权限的人员在首次登录时加入。每个新成员使用您可用座位中的一个。

  3. **SCIM 目录同步**：当您的目录更改时自动添加或删除成员。您的组织始终保持最新。

3. 如果您选择了“即时配置 (JIT)”或“SCIM 目录同步”，请不要点击“保存更改”。首先，确保所有用户都已分配到您的 IdP 中的 Anthropic 应用程序。保存时未分配的任何用户将从组织中取消配置。

4. 确认所有用户都已在您的 IdP 中分配后，选择一个：

  1. 点击“保存更改”完成设置并触发初始配置。在可用的地方，管理控制台会显示同步将更改的内容的预览，包括将删除多少用户。在确认前查看它，如果删除数量高于您的预期，请取消。了解更多关于**[SCIM 同步如何工作](https://support.claude.com/en/articles/14499648-how-scim-sync-works-for-enterprise-organizations)**的信息。

  2. 打开**启用组映射**并移至步骤 4。如果您使用的是企业计划并计划使用 SCIM 将任何 IdP 组映射到“自定义”角色，请先按照下一部分中的步骤操作。

### 将自定义角色与 SCIM 组映射结合使用（企业计划）

您的 IdP 组仅在第一次 SCIM 同步运行后才会出现在 Claude 中，因此您无法提前将它们分配给自定义角色。在将同步的组分配给自定义角色之前，映射到“自定义”的组中的用户没有权限：需要权限的功能会变灰或隐藏，Claude Code 登录失败。为避免这种情况，请分两次设置 SCIM：

1. 在**启用组映射**关闭的情况下点击“保存更改”，让初始同步完成。

2. 转到**[组织设置 > 角色](https://claude.ai/admin-settings/roles)**并将同步的组分配给您的自定义角色。如果组尚未列出，请在**[组织设置 > 组](https://claude.ai/admin-settings/groups)**中点击“检查更新”并仅同步组。

3. 返回**用户配置**，打开**启用组映射**，并移至步骤 4。

了解更多关于**[在企业计划上设置基于角色的权限](https://support.claude.com/en/articles/13930458-set-up-role-based-permissions-on-enterprise-plans)**的信息。

## 步骤 4：在您的身份提供商中配置组并将组映射到角色和座位类型

1. 在您的 IdP 中为您想要分配的每个角色创建组。除非您使用的是单座位企业计划，否则也为每个座位类型创建组。

  1. 虽然这些组不再有命名要求，但我们建议在组名中包含一些内容（例如 `anthropic-claude-` 或 `anthropic-console-`）以便更容易识别。

2. 将用户添加到您创建的组中，确保至少一个用户（包括您自己）在将映射到管理员 (Console) 或所有者 (Claude) 角色的组中。

3. 返回到 Claude 或控制台中的**组织和访问**或**身份和访问**设置，并找到**用户配置**。

4. 打开**启用组映射**（如果尚未打开）：

  ![](https://downloads.intercomcdn.com/i/o/lupk8zyo/2312714635/b57870b51e6511c8293637bceee2/da1ceabc-b6bc-451b-9cda-24ff6aa90d02?expires=1795451400&amp;signature=920e144849adbb7abee0aca267d25a710824076a1c21f4506eb345046c2400c5&amp;req=diMmFM5%2FmYdcXPMW1HO4zeBEb8DckvtMyb72rapuHpP%2BzWLRD9PhQ9ns9OXn%0AlfhG%0A)

5. 在**启用组映射**部分，点击每个角色旁边的“添加”并从下拉菜单中选择您的 IdP 中的相应组。

  1. 使用组映射时，您*必须*将所有用户分配给基于角色的组以确保为他们配置帐户。将用户分配给基于座位层级的组是可选的。

  2. 您可以将 IdP 组映射到“自定义”角色。分配此角色的用户没有默认权限；他们的访问权限完全由分配给 Claude 中其组的自定义角色决定。如果您使用 JIT，请在他们登录前在**[组织设置 > 组](https://claude.ai/admin-settings/groups)**中手动将这些用户添加到组，因为 JIT 不会从您的 IdP 同步组成员身份。

6. **对于除单座企业版外的所有计划：**在**将座位等级分配给 IdP 组**部分（可选），点击每个座位类型旁的“添加”，然后从您的 IdP 中选择相应的组。不在任何座位等级组中的用户不会被移除。现有用户保留其当前座位类型。新用户获得仍有未分配购买座位的最高座位类型（例如，在有未分配的高级座位时为高级，然后为标准），如果没有可用座位则不分配座位。

  1. **对于单座企业版：**座位类型映射不适用。所有预配用户都会自动分配企业座位（如果您的组织中有可用座位）。

7. 验证所有必要的组都映射到相应的角色和座位类型。

8. 点击“保存更改。”

  1. **注意：**Microsoft Entra 每 40 分钟才推送一次 SCIM 更改，因此更改可能需要一段时间才能显示。您可以通过点击“管理 SCIM”并查看目录来检查从 IdP 同步的用户。目录中的这些用户将被预配到 Claude / Console。

**重要提示：**所有需要访问权限的用户必须在您保存组映射配置前分配到相应的组。这些用户应该已经在您启用 SSO 时分配给 IdP 中的 Anthropic 应用程序。

### 主所有者角色如何与 JIT 和 SCIM 配合使用

- 您组织的主所有者不受 SCIM 协调的影响。如果主所有者账户不在 IdP 目录中，或不是映射到角色的任何组的成员，SCIM 同步时将跳过它。使用 JIT 和组映射时，主所有者的角色在他们登录时不会更改，如果他们不在任何映射的组中也不会被移除。主所有者的成员身份和角色会被保留。

- 此豁免仅适用于单个主所有者角色。所有者和管理员角色**不**豁免，**必须**在映射到角色的组中，否则启用 SCIM 组映射时将被移除。使用 JIT 和组映射时，他们在下次登录时会被移除。

- 主所有者角色无法通过组映射分配。它只能从**[组织设置 > 成员](https://claude.ai/admin-settings/members)**手动转移。在启用 SCIM 或组映射前设置您的预期主所有者。

- 主所有者不豁免 SSO 登录强制执行。SSO 强制执行按电子邮件域应用；如果主所有者的电子邮件在强制执行的域上，他们必须通过 SSO 进行身份验证。

## 故障排除

### 用户分配正确并显示在目录中，但未被添加到 Claude 作为成员？

验证您有足够的购买座位和可用座位来将成员添加到您的组织。

1. 检查**[组织设置 > 组织和访问](https://claude.ai/admin-settings/organization)**中显示的可用座位数，如需要请购买额外座位（请参阅我们的**[团队计划](https://support.claude.com/en/articles/12004354-purchasing-and-managing-seats)**和**[企业计划](https://support.claude.com/en/articles/13393991-purchasing-and-managing-seats-on-enterprise-plans)**指南）。

2. 获得可用座位后，返回“组织和访问”页面，点击**目录同步 (SCIM)** 旁的“立即同步，”。这将触发同步以为尚未添加为成员的用户预配账户。

### 用户未使用正确的角色进行预配

1. 验证用户在您的 IdP 中分配到正确的组。

2. 验证该组在您的**组织和访问**设置中映射到正确的角色。

3. **对于 JIT：**用户需要登出并重新登录以使角色更改生效。

4. **对于 SCIM：**点击“同步”以提示立即同步，或等待自动同步周期：

  ![](https://downloads.intercomcdn.com/i/o/lupk8zyo/2312717421/c97fce49ad17d4660880a05fbaaf/59fbfa2a-1072-4662-8ca5-102970d5a795?expires=1795451400&amp;signature=9d2c1149b95c54298c97eb930c830d8205d85334524a53c72c859d872b497ffe&amp;req=diMmFM5%2FmoVdWPMW1HO4zZ9LalipHMvG5hujYvMis4dtpM9R6NhYvwSZDct2%0ABby7%0A)

### 映射到自定义角色的用户登录后无法访问任何内容

当您的预配模式是 JIT 且 IdP 组映射到自定义角色时会发生这种情况。JIT 分配角色类型但不从您的 IdP 同步组成员身份，因此这些用户不在任何具有附加自定义角色的组中，没有权限。

要解决此问题，请执行以下操作之一：

1. 在**[组织设置 > 组](https://claude.ai/admin-settings/groups)**中手动将受影响的用户添加到相应的组。详细了解**[在企业计划上管理组](https://support.claude.com/en/articles/13799932)**。

2. 将您的预配模式切换到 SCIM 目录同步，它从您的 IdP 同步组及其成员身份。详细了解**[SCIM 同步如何工作](https://support.claude.com/en/articles/14499648)**。

### 启用组映射后我失去了管理员/所有者访问权限

当配置组映射的人员未分配到映射到管理员或所有者角色的组时会发生这种情况，导致其权限被降级为用户。不在任何映射组中的人员会被从组织中移除（使用 JIT 时在下次登录时；使用 SCIM 时在下次同步时），需要重新添加。这不影响主所有者。

要解决此问题，请执行以下操作之一：

**选项 1：让另一个管理员/所有者恢复您的角色**

1. 联系您组织的另一个管理员或所有者。

2. 要求他们导航到**[组织设置 > 组织](https://claude.ai/admin-settings/organization)**（对于 Claude）或**[设置 > 成员](https://platform.claude.com/settings/members)**（对于 Console）。

3. 让他们将您的角色改回管理员或所有者。

**选项 2：通过您的身份提供商修复**

1. 在您的 IdP 中，将自己分配到具有正确前缀的组，该组映射到管理员或所有者角色。

2. **对于 JIT：**登出并重新登录以恢复访问权限。

3. **对于 SCIM：**要求另一个管理员或所有者在**组织和访问**设置中点击“同步”，或等待自动同步周期。
