# 我需要添加或更新我的 Claude Team 计划的税务或增值税 ID

# 在注册期间添加您的税号或增值税ID

当您注册Claude Team计划时，根据您的位置，您可能可以选择输入您的税号或增值税ID：

1. 在注册过程中，输入您的地址信息。

2. 如果您的地址符合税务资格，将出现一个可选的税号或增值税ID字段。

3. 在提供的字段中输入您的税号或增值税ID。

4. 如果ID输入正确，您将能够继续完成注册。

**重要提示**：如果您以企业身份注册，并希望在发票上使用与您的付款方式关联的名称不同的名称，组织所有者应在**[组织设置 > 账单](https://claude.ai/admin-settings/billing)**中添加或更新付款方式时勾选"在发票上使用不同的名称"复选框。然后，在"账单收款人"字段中输入您的公司名称，以确保它在发票上正确显示。

# 注册后更新您的税号或增值税ID

**注意**：对账单详情的更新仅适用于未来的账单周期。已完成的发票无法进行追溯更新。

如果您需要在已注册后添加或更新您的税号或增值税ID，请按照以下步骤操作：

1. 导航到您的**[账单设置](https://claude.ai/settings/billing)**。

2. 点击您的付款方式旁边的"更新"按钮。

3. 在付款更新表单中，您应该会看到一个输入或更新您的税号或增值税ID的字段。

4. 根据需要输入或修改您的税号或增值税ID。

5. 保存您的更改。

**注意：**您的账单地址决定了您的税务管辖权。有关如何查看或更新账单地址的详情，请参阅**[了解您的账单地址和税费计算](https://support.claude.com/en/articles/12997130-understanding-your-billing-address-and-tax-calculation)**。
