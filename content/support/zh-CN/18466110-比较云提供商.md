# 比较云提供商

Claude Desktop on 3P 可与 Amazon Bedrock、Google Cloud 和 Microsoft Foundry 配合使用。最大的区别在于谁处理对话数据。AWS 和 Google Cloud 在各自的平台上处理此数据。在 Microsoft Foundry 上，Anthropic 处理此数据。

本指南适用于 Claude Enterprise 计划的组织管理员。

本文是 **[从 Claude Enterprise 迁移到云提供商上的 Claude Desktop](https://support.claude.com/en/articles/18426225)** 的一部分，该文定义了波次、重叠期和截止日期等术语。

有关设置步骤和提供商特定的限制，请使用表格第一行中的设置指南。Claude Desktop on 3P 还支持 **[LLM 网关](https://claude.com/docs/third-party/claude-desktop/gateway)**、**[Amazon Bedrock Mantle](https://claude.com/docs/third-party/claude-desktop/mantle)** 和 **[Claude API](https://claude.com/docs/third-party/claude-desktop/claude-api)**。大多数组织在进行此迁移时不需要它们。
