# 启用和使用桌面扩展允许列表

桌面扩展允许列表适用于 Team 和 Enterprise 计划的所有者和主要所有者。

本文介绍了一个桌面扩展允许列表，Team 和 Enterprise 计划的所有者可以使用它来管理其组织对扩展的访问权限。

# 如何启用允许列表

**重要提示：**如果您之前在用户-机器级别配置了 Enterprise 策略控制，这些将覆盖应用内允许列表。确保 `isDesktopExtensionDirectoryEnabled` 和 `isDesktopExtensionEnabled` 都未设置为"false"，以便允许列表可以填充可用的注册表。有关更多信息，请参阅我们的 **[桌面企业配置文档](https://support.claude.com/en/articles/12622667-enterprise-configuration)**。

桌面扩展允许列表默认处于禁用状态，因此组织所有者需要手动将其打开。请注意，**在您启用允许列表之前，用户将能够访问注册表中的所有桌面扩展。**为了防止这种情况，请确保激活允许列表以默认阻止所有桌面扩展，然后仅添加您的团队需要访问的扩展。

**要打开允许列表：**

1. 打开 Claude Desktop

2. 点击左下角的您的首字母或名字

3. 导航到"组织设置">"连接器"

# 启用允许列表后会发生什么？

启用允许列表后：

- 任何现有的桌面扩展安装将从 Claude Desktop 客户端中被强制删除。

- 用户将无法再安装不在允许列表中的新桌面扩展。

- 用户只能从受认可的应用内注册表下载扩展；他们不再能够通过拖动或点击来安装 MCPB。

请注意，允许列表不能防止个人在安装后篡改本地 MCP 文件内容。

考虑在非工作时间完成允许列表设置，以最大程度地减少对现有用户的干扰。如果用户的已安装扩展在配置允许列表时被删除，他们将需要手动重新安装该扩展。

**重要提示：**允许列表需要 Claude Desktop 版本 0.13.91 或更高版本，因此用户应通过点击"Claude"，然后选择"检查更新"或"重启以更新到 Claude 0.13.91"来更新桌面应用：

# 管理允许的扩展

启用允许列表后，您可以选择允许哪些扩展：

1. 导航到"组织设置">"连接器"并选择"桌面"选项卡。

2. 点击"浏览扩展"以查看可用扩展列表。

3. 选择您要添加的扩展。

4. 点击"添加到您的团队"按钮。

5. 该扩展将出现在您的允许列表中。

如果您想从允许列表中删除扩展，请点击"..."按钮，然后选择"从允许列表中删除"。

# 上传自定义扩展

您还可以通过"组织设置">"连接器">"桌面"上传自定义扩展以在整个组织中部署。

**注意：**确保 manifest.json 中的名称字段不与任何现有 MCPB 重叠。所有唯一 MCPB/桌面扩展的名称必须是唯一的。

1. 点击"添加自定义扩展"

2. 这将打开一个文件选择器；选择 .mcpb 文件。

3. 该扩展将出现在**自定义团队扩展**下。

4. 点击"..."，然后点击"添加到团队"以将其添加到您的允许列表并为您的团队启用它。

当您将自定义扩展加入允许列表时，它的范围限定于您的特定组织，无法在其他组织中使用。有关使用 MCP Bundles (.mcpb) 创建自定义扩展的更深入信息，请参阅我们的 **[桌面扩展开发者文档](https://github.com/anthropics/mcpb)**。

# 更新自定义扩展

我们还引入了更新先前安装的自定义扩展到新版本的功能，而无需删除和重新安装它们。

您可以通过对 manifest.json 进行更改来更新新的 MCPB 版本，确保更新候选版本的版本字段从当前上传的版本递增，并且保持名称值不变。更改名称将创建新的自定义桌面扩展，而不是上传新版本。然后导航到自定义上传窗格，通过菜单选择"上传新版本"，并上传新文件。
