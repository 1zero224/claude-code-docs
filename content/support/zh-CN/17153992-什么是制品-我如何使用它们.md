# 什么是制品，我如何使用它们？

一个**[制品](https://claude.com/features/artifacts)**是Claude为你创建的任何东西，你会把它展示给别人：一个设计、一个演示文稿、一份文档、一个仪表板或一个小型交互工具。它在你的对话旁边打开，你可以编辑它、返回查看它，并与他人分享。在与Claude的任何对话中（包括在Claude Code中）请求一个，或从“制品”标签中的模板开始。

制品在Free、Pro、Max、Ultra、Team和Enterprise计划中可用，以及在包含Claude Code的每个计划中的Claude Code中可用。Docs、Slides和Design模板在所有计划中可用，默认启用。在Enterprise计划中，它们将在2026年10月15日默认启用，所有者可以在此之前启用。

Data模板在Pro、Max、Ultra、Team和Enterprise计划中可用。在Enterprise计划中，它将在2026年11月20日默认启用，除非所有者已保存设置。

Sheets和Whiteboards模板在Pro、Max、Ultra、Team和Enterprise计划中处于测试阶段。它们在Team计划中默认启用，在Enterprise计划中默认关闭，直到所有者启用。Motion模板在Team和Enterprise计划中处于测试阶段。它在Team计划中默认启用，在Enterprise计划中默认关闭，直到所有者启用。

## 什么是工件？

**注意：**旧版工件是指2026年9月16日之前在聊天中创建的工件。它们仍然可以使用，您仍然可以发布和共享它们，但无法创建新的工件。

当Claude分享的内容符合以下条件时，它会创建一个工件：

- 内容重要且独立，通常超过15行。

- 这是您可能想要编辑、迭代或在对话外重复使用的内容。

- 它可以独立存在，无需对话中的额外上下文。

- 这是您可能想要返回查看或稍后使用的内容。

Claude几乎可以从任何内容创建工件，包括文档、代码片段、单页网站、图像、图表和流程图、仪表板以及小型交互式工具。

## 您可以在哪里使用工件

- **网页版Claude和Claude桌面版：**创建、编辑和共享工件，以及从模板开始。

- **Claude Code：**将会话输出发布为工件，或创建设计和文档。请参阅下面的**[Claude Code中的工件](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them#h_dca5623bec)**。

- **Claude iOS版和Claude Android版：**在任何聊天中请求设计、演示文稿或文档，在**工件**标签中查看结果，并编辑工件。要更改共享设置，请使用网页版Claude或Claude桌面版。

## 从模板开始

模板是您将与他人共享的工作的起点。在任何聊天中请求一个，在消息框中选择“输出”并选择一个模板，或在**工件**标签中选择一个。

- **文档：**您与Claude和您的团队实时编写的活动文档。在**[Claude文档入门](https://support.claude.com/en/articles/16923645)**中了解更多信息。

- **幻灯片：**从您的笔记、报告或聊天中已有的工作构建的演示文稿。直接编辑任何幻灯片，在不离开Claude的情况下演示，并导出为PowerPoint或PDF。要使用键盘或屏幕阅读器编辑和演示，请参阅下面的**[使用Claude幻灯片和键盘](#h_11975db891)**。

- **设计：**使用您的设计系统构建的视觉效果、模型、原型、单页文档和登陆页面。在**[Claude设计入门](https://support.claude.com/en/articles/14604416)**中了解更多信息。

- **数据：**从您的数据平台或连接的应用程序（如Salesforce）构建的仪表板、数据故事、旁白短视频和信件。Claude编写查询，每个图表都显示其查询和上次刷新的时间。在**[Claude数据入门](https://support.claude.com/en/articles/17454700)**中了解更多信息。

- **表格（测试版）：**Claude与您一起构建的电子表格，具有跨标签的公式，您和Claude可以在同一单元格中编辑。在**[Claude表格入门](https://support.claude.com/en/articles/18324300)**中了解更多信息。

- **白板（测试版）：**与Claude和您的团队一起思考想法的共享板。在**[Claude白板入门](https://support.claude.com/en/articles/18324319)**中了解更多信息。

- **动画（测试版）：**从您的内容构建的动画解释器、图表和演练。要求Claude更改任何细节，如单词、数字或时间，其余部分保持不变。将结果导出为MP4视频。适用于团队和企业计划。在**Claude动画入门**中了解更多信息。

无论您从哪个模板开始，工件的工作方式都是相同的：通过与Claude交谈或直接在工件中编辑它，当您工作时它会实时更新。准备好后，共享或导出它。

设计和演示文稿可以使用设计系统，因此新工作会采用您的颜色、字体和组件。在**[设置您的设计系统](https://support.claude.com/en/articles/14604397)**中了解更多信息。

## 查找您的工件

您创建的所有内容都保存到Claude侧边栏中的**[工件](https://claude.ai/artifacts)**标签，因此您可以从任何对话中再次找到它。从那里，您可以在一个地方查看所有工件，从模板开始新工件，并组织您创建的内容。

## 使用工件

工件在您对话旁边的自己的窗口中打开。从模板创建的工件在您可以直接工作的画布或页面上打开。

## 编辑和迭代

- 要求Claude更改工件。

- 在从模板创建的工件中，直接编辑：在文档中输入、编辑幻灯片或在设计画布上移动元素。

- 在文档或Markdown文档中，突出显示要更改的文本，单击“使用Claude编辑，”然后输入您的请求。Claude在您标记的位置进行编辑，因此您不必描述您指的是哪个部分。

- 编辑之前的消息以创建聊天的不同版本，具有自己的工件，因此您可以探索另一个方向而不会丢失以前的工作。

**注意：**当Claude在多个Markdown文件中起草内容（如技能或插件）时，您可以在提交之前在多个文件中留下编辑请求。每个请求都会添加到您的下一条消息中，文件列表显示每个文件中有多少个待处理。发送消息，Claude会在一次通过中应用整个批次。

## 查看和导出

- **从模板创建的工件：**单击“导出。”文档导出为Word、PDF、Markdown和Google文档。演示文稿导出为PowerPoint和PDF，或直接转到Google幻灯片作为可编辑文件。设计导出为.zip、PDF、PowerPoint或独立HTML，或直接转到另一个工具。动画导出为MP4视频。

- **旧版工件：**使用工件面板顶部的控件查看代码、复制内容或下载它。

## 基于已发布的工件进行构建

适用于免费、专业、最大和超级计划，用于从聊天发布的旧版工件。

如果有人发布了您喜欢的工件，您可以将其用作自己版本的起点。您的版本是独立的，因此您所做的任何事情都不会影响原始版本。

**重要提示：**仅对来自您信任的人的工件执行此操作。您正在将他人的代码和内容引入您自己的聊天中，因此请像对待来自未知发件人的文件一样对待它。

1. 打开已发布的工件，然后点击“复制”来复制其代码。

2. 开始新的聊天，粘贴代码，并描述你想要的更改。例如：“这是一个测验游戏的代码。将问题改为关于电影的内容，并添加计时器。”

3. 以与你自己制作的任何工件相同的方式完善新工件。

## 修复错误

如果工件生成错误，请查找错误消息附近的“尝试使用 Claude 修复”按钮。点击它将错误详情复制到新消息中，然后发送给 Claude 以诊断问题并建议修复方案。Claude 将尝试修复错误，但不保证成功。某些错误需要更多故障排除。

## 使用键盘操作 Claude Slides

要进入和退出工件面板，以及从面板标题进行评论，请参阅**[使用键盘或屏幕阅读器操作工件](https://support.claude.com/en/articles/17457950)**。该文章还说明了焦点的含义、在 Mac 笔记本电脑或 Safari 中的操作方法，以及表格如何显示按键。

编辑器分为几个区域：顶部的工具栏、你正在编辑的幻灯片、浮动在所选内容上的格式工具栏、幻灯片缩略图列表和属性面板。

### 在编辑器的区域之间移动

按 F6 移动到下一个区域，按 Shift+F6 移动到上一个区域。Cmd+F6（Windows 上为 Ctrl+F6）可代替 F6 使用，无论是否带 Shift。每个区域都会记住你上次所在的位置。当菜单、弹出窗口或对话框打开时，以及你正在演示时，F6 会暂停。

### 编辑幻灯片

按 Tab 时，幻灯片是单个停止点。其上的对象在幻灯片内部：你进入幻灯片以到达它们，组内的对象以相同的方式在其内部。

1. 按 Tab 直到到达幻灯片。

2. 按 Return 进入幻灯片。

3. 按 Tab 或 Shift+Tab 在幻灯片上的对象之间移动。Tab 不会离开幻灯片。

4. 在文本框上按 Return 开始编辑。光标从文本末尾开始。在组上，Return 会进入组内。

5. 输入你的更改。

6. 按 Escape 或 Tab 完成编辑。你的更改会被保留。

7. 再次按 Escape 返回到幻灯片。从组内，Shift+Return 会向上移动一个级别。

在表格中，Tab 和 Return 在单元格之间移动。按 Escape 或 Cmd+Return（Windows 上为 Ctrl+Enter）完成。

选中独立对象后，箭头键可移动它（作为幻灯片布局一部分的对象会保持在布局放置的位置），F6 会将你带到其格式工具栏。使用屏幕阅读器时，幻灯片和每个对象会告诉你哪个键进入，哪个键返回。

### 在幻灯片之间移动

当幻灯片上没有选中任何内容时，按左箭头或右箭头键，或 Page Up 或 Page Down，以更改幻灯片。使用屏幕阅读器时，你会听到新幻灯片的编号和标题。如果选中了对象，箭头键会移动对象，因此请先按 Escape。

你也可以按 F6 直到到达缩略图列表。在那里，左箭头和右箭头键在幻灯片之间移动，在你移动时在编辑器中显示每一个，Return 会将你移动到该幻灯片。

**重要：**在缩略图上按 Delete 或 Backspace 会立即删除该幻灯片。Cmd+Z（Windows 上为 Ctrl+Z）会将其恢复。

### 演示幻灯片组

1. 按 Tab 直到在工具栏中到达“演示”。

2. 按 Return 打开其菜单。

3. 在“演示”上按 Return 开始。

演示时，按右箭头键或空格键进入下一张幻灯片，按左箭头键进入上一张，按 Escape 结束。使用屏幕阅读器时，你会听到每张幻灯片的编号和标题。结束演示后，焦点返回到“演示”。

### 对幻灯片进行评论

要对幻灯片或其上的内容进行评论，请参阅**[使用键盘或屏幕阅读器操作工件](https://support.claude.com/en/articles/17457950)**中的“对幻灯片组或设计进行评论”。

### 获取幻灯片组概览

“画布”视图显示所有幻灯片，但不会为屏幕阅读器提供任何可读内容。请改用缩略图列表。

## 在工件中存储数据

在 Pro、Max、Ultra、Team 和 Enterprise 计划中可用，支持 Claude 网页版和 Claude Desktop。

Artifacts 可以在会话之间存储数据，因此您可以构建日志、追踪器和协作工具等应用。存储方式分为个人存储和共享存储两种：

- **个人存储：**每个人都保留自己的私密数据。在日志 artifact 中，您的条目仅对您可见。

- **共享存储：**所有人都可以看到并处理相同的数据。在游戏排行榜中，所有人都看到相同的分数。

首次使用具有共享存储的 artifact 时，Claude 会显示一条确认信息，说明您的数据将对使用它的其他人可见。

**注意：**在旧版 artifacts 中，存储仅在发布后才能工作。在构建和测试期间，存储操作在发布前不会成功。新 artifacts 无需发布即可存储数据。

**存储限制：**默认情况下，artifact 最多可存储 100 MB 的数据和 25,000 个文档（保存的记录），以先达到的为准。

**上传的文件：**Artifact 可以包含用于上传文件的控件，例如图像、PDF 或保存为 CSV 的电子表格。Artifact 的所有者和您组织中可以编辑它的人员可以上传。每个文件最大 20 MB（SVG 图像为 2 MB），artifact 最多可容纳 5000 个文件和总共 1 GB。

**旧版 artifacts：**存储限制为每个 artifact 20 MB，仅接受文本，不支持图像、文件或二进制数据。取消发布旧版 artifact 会永久删除其所有存储的数据。

**警告：**构建 artifact 的人决定哪些数据使用个人存储，哪些使用共享存储。在输入任何敏感信息之前，请检查 artifact 是否使用共享存储。

## Claude Code 中的 Artifacts

Artifacts 在包含 Claude Code 的每个计划中都可用。

Claude Code 可以将其会话输出发布为 artifact，即私密 URL 上的实时交互页面。该页面会随着会话继续而实时更新，您可以共享它。Artifact 可能是带有注释差异的拉取请求演练、从会话数据构建的仪表板，或随着 Claude 工作而填充的调查时间线。

您也可以从 Claude Code 创建设计和文档。使用 /design 调用 Claude Design，或请求文档。在桌面上，文档在侧面板中打开。在终端中，Claude 会给您一个链接以在网络上打开它。

要了解如何在 Claude Code 中创建、更新和共享 artifacts，请参阅 **[Claude Code 文档中的 artifacts 文档](https://code.claude.com/docs/en/artifacts)**。
