# 取消您组织的 Team 计划订阅

所有者或主要所有者可以通过导航到 **[组织设置 > 账单](https://claude.ai/admin-settings/billing)** 来取消 Team 计划访问权限。取消 Team 计划订阅意味着您的组织在下一个计费周期内不会被收费。您的团队将继续能够访问 Claude，直到当前计费周期结束。

取消后，在 **[组织设置 > 成员](https://claude.ai/admin-settings/members)** 中移除成员的选项将不再可用。如果您需要在订阅被取消期间从您的组织中移除成员（例如，在以较低座位数重新订阅之前），请 **[联系我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)**。

如果您的团队已领取每月 API 额度，取消时新的每月额度将停止，您已有的额度将保持可用，直到每个计费周期结束时过期。Max、Ultra 和 Team 计划附带的每月 API 额度不是购买的，因此无法退款。
