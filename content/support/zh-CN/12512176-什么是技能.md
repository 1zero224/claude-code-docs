# 什么是技能？

技能是指令、脚本和资源的文件夹，Claude 可以动态加载这些文件夹以改进专业任务的性能。技能教会 Claude 如何以可重复的方式完成特定任务，无论是使用您公司的品牌指南创建文档、使用您组织的特定工作流程分析数据，还是自动化个人任务。

技能适用于免费版、专业版、最大版、超级版、团队版和企业版计划的用户。此功能需要**[启用代码执行](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude#h_1c99382190)**。技能也可在 Claude Code 中使用，并对所有使用代码执行工具的 API 用户进行测试版提供。

---

## 技能如何工作？

技能提高了 Claude 在许多任务上的一致性、速度和性能。技能通过渐进式披露工作——Claude 确定哪些技能相关并加载完成该任务所需的信息，有助于防止上下文窗口过载。

当您要求 Claude 完成任务时，它会查看可用的技能，加载相关的技能，并应用其说明。

---

## 技能类型

### Anthropic 技能

这些是由 Anthropic 创建和维护的技能，例如针对 Excel、Word、PowerPoint 和 PDF 文件的增强文档创建功能。Anthropic 技能可供所有用户使用，Claude 在相关时会自动调用它们。

### 自定义技能

这些是您或您的组织为专业工作流程和特定领域任务创建的技能。以下是您可以使用自定义技能启用的一些潜在工作流程：

- 将品牌风格指南应用于文档和演示文稿。

- 生成遵循公司电子邮件模板的通信。

- 使用公司特定格式组织会议记录。

- 在公司工具（JIRA、Asana、Linear）中创建任务，遵循团队约定。

- 执行公司特定的数据分析工作流程。

- 自动化个人工作流程并自定义 Claude 以匹配您的工作风格。

### 组织配置的技能

对于团队版和企业版计划，组织所有者可以为所有用户配置技能。以这种方式配置的技能会自动出现在每个团队成员的技能列表中，可以设置为默认启用或禁用。这允许组织：

- 在所有员工中一致地分发已批准的工作流程

- 确保团队使用标准化的程序和最佳实践

- 部署新功能，无需要求个人上传

了解有关在**[为您的组织配置和管理技能](https://support.claude.com/en/articles/13119606-managing-skills-as-an-admin)**中配置技能的更多信息。

### 合作伙伴技能

技能目录提供来自 Notion、Figma、Atlassian 等合作伙伴的专业构建的技能。这些技能旨在与各自的 MCP 连接器无缝协作，实现强大的集成工作流程。

---

## 主要优势

**改进 Claude 在特定任务上的性能**：技能为文档创建、数据分析和需要补充 Claude 通用知识的特定领域工作等任务提供专业功能。

**组织知识捕获**：打包您公司的工作流程、最佳实践和机构知识，供 Claude 在您的团队中一致使用。

**轻松自定义**：任何人都可以通过用 Markdown 编写说明来创建技能——简单技能不需要编码，但您可以将可执行脚本附加到自定义技能以获得更高级的功能。

**组织的集中管理：**团队版和企业版计划所有者可以在整个组织范围内配置技能，确保团队之间的工作流程一致，无需每个用户进行单独设置。

---

## Agent Skills 开放标准

Agent Skills 规范作为开放标准发布在**[agentskills.io](https://agentskills.io)**。这意味着您创建的技能不会被锁定到 Claude——相同的技能格式可在采用该标准的 AI 平台和工具中使用。开发人员在其自己的平台中实现技能支持时也可以使用参考 Python SDK。

## 技能与其他 Claude 功能的比较

### 技能与项目

**[项目](https://support.claude.com/en/articles/9517075-what-are-projects)**提供在您在其中启动聊天时始终加载的静态背景知识。技能提供在需要时动态激活的专业程序，并在整个 Claude 中工作。

### 技能与 MCP（模型上下文协议）

MCP 将 Claude 连接到外部服务和数据源。技能提供程序知识——关于如何完成特定任务或工作流程的说明。您可以同时使用两者：MCP 连接为 Claude 提供工具访问权限，而技能教会 Claude 如何有效地使用这些工具。

### 技能与自定义说明

**[自定义说明](https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features)**广泛应用于您的所有对话。技能是特定于任务的，仅在相关时加载，使其更适合专业工作流程。
