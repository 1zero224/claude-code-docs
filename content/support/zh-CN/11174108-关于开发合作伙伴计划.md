# 关于开发合作伙伴计划

开发合作伙伴计划是一种可选的、透明的方式，让组织能够帮助塑造 Claude 的未来，同时保持对其数据的控制。

默认情况下，Anthropic 不会在您使用我们的商业产品（例如 Claude Enterprise、Claude API 等）时对您生成的数据进行模型训练。请在我们的 **[隐私中心](https://privacy.claude.com/en/collections/10663361-commercial-customers)**了解更多关于我们的隐私承诺以及我们如何处理您的数据。

我们认识到许多组织希望为人工智能技术的进步做出贡献。开发合作伙伴计划允许您自愿选择是否允许我们使用您的 Claude Code 会话来改进我们的服务，包括模型训练。这种自愿共享帮助我们增强 Claude 在所有用户中的编码能力、根据实际开发者工作流改进我们的模型，并推进人工智能辅助编码领域的发展。

## 什么是开发合作伙伴计划？

通过开发合作伙伴计划，符合条件的组织可以通过自愿与我们共享其 Claude Code 会话来帮助改进 Claude。

### 关键信息

- 在开发合作伙伴计划下，只有您来自第一方 Claude API 的 Claude Code 输入和输出令牌会提供给我们。数据共享不适用于 Claude 应用或与 Claude Code 无关的 API 调用，使用我们的商业产品时亦是如此。

- 您的数据将被安全存储长达两年，用于模型训练的数据不会与其他客户信息相关联。

- 此设置适用于您组织中的所有成员。

- 您组织中的所有成员都将被告知您已加入该计划。

- 您可以随时离开该计划，但之前提供的数据将被存储长达两年。

拥有我们 **[零数据保留协议](https://privacy.claude.com/en/articles/8956058-i-have-a-zero-data-retention-agreement-with-anthropic-what-products-does-it-apply-to)**的账户不符合该计划的资格。

## 加入/退出开发合作伙伴计划

### 对于预付费账户

如果您是管理员且获得了您的组织的授权来签订协议，请按照以下说明操作。

加入开发合作伙伴计划：

1. 从您的 Claude Console 账户，转到**数据保留**页面 (platform.claude.com/settings/privacy)，找到**使用数据和反馈**。

2. 找到**加入我们的开发合作伙伴计划以帮助改进 Claude**。

3. 点击“加入”。

点击加入后，系统会要求您同意我们的开发合作伙伴计划服务特定条款。您可以随时禁用参与，但之前共享的数据将被保留长达两年。

退出开发合作伙伴计划：

1. 从您的 Claude Console 账户，转到**数据保留**页面 (platform.claude.com/settings/privacy)，找到**使用数据和反馈**。

2. 找到**加入我们的开发合作伙伴计划以帮助改进 Claude**。

3. 点击“离开”。

**注意**：拥有我们 **[零数据保留协议](https://privacy.claude.com/en/articles/8956058-i-have-a-zero-data-retention-agreement-with-anthropic-what-products-does-it-apply-to)**的账户不符合该计划的资格，在其设置中将看不到加入开发合作伙伴计划的选项。

### 对于采用发票计费的组织

请联系您的 Anthropic 客户经理，了解您是否符合开发合作伙伴计划的资格。这些组织在其设置中将看不到加入开发合作伙伴计划的选项。
