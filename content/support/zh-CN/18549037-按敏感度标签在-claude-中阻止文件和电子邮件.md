# 按敏感度标签在 Claude 中阻止文件和电子邮件

所有者和主要所有者可以选择 Microsoft Purview 敏感度标签以在 Claude 中阻止。Claude 随后不会处理在 Microsoft 365 连接器以及 Claude for Excel、PowerPoint、Word 和 Outlook 中具有这些标签的内容。

您将 Microsoft Entra 租户连接到 Claude，然后从列表中选择标签。您可以将一个租户连接到每个 Claude 组织。

敏感度标签阻止功能在企业计划中处于测试阶段。标签阻止不适用于已启用 HIPAA 的组织、混合部署或政府和国家云。它也不适用于具有 FERPA 或零数据保留条款的组织。

**重要提示：**启用后，Claude 将被限制访问具有特定 Purview 标签的文件，即使用户通常有权访问这些文件。并非所有文件或表面都被覆盖，因此此设置不应替代您组织自己的访问控制。请参阅 **[标签阻止不覆盖的内容](#h_5d523d6ae7)**。

## 标签阻止的工作原理

标签阻止使用 Microsoft 365 内容上的敏感度标签。它限制 Claude 可以处理的内容，不会改变人们在 Microsoft 365 中拥有的权限。它在每个产品中的应用方式不同：

- **Microsoft 365 连接器：**对于使用来自您租户的工作或学校帐户通过 Anthropic 的 Microsoft 365 连接器的所有人（包括您 Claude 组织外的人员），标签被阻止。

  - 如果另一个 Claude 组织连接到同一租户，连接器将阻止任一组织选择的标签。

- **Claude for Excel、PowerPoint、Word 和 Outlook：**对于使用您 Claude 组织中的帐户登录加载项的成员，标签被阻止。使用第三方平台（如 Amazon Bedrock 或网关）的加载项有自己的设置。请参阅 “本地连接器和第三方平台。”

### 在 Microsoft 365 连接器中

| **当 Claude 尝试**                                 | **发生的情况**                                              |
| ----------------------------------------------- | ------------------------------------------------------ |
| 打开或下载具有阻止标签的文件，或标签无法确定的文件（如受密码保护的文件）            | Claude 收到通知而不是内容。                                      |
| 重命名、移动、复制或删除具有阻止标签的文件，或标签无法确定的文件                | 被拒绝。                                                   |
| 替换标记文件的内容                                       | 当 Microsoft 报告文件上有任何标签时被拒绝，因为替换内容可能会删除标签。              |
| 搜索 SharePoint 和 OneDrive，或整个邮箱                  | 当 Microsoft 的搜索索引包含标签时，具有阻止标签的文件和电子邮件被排除。              |
| 列出 SharePoint 或 OneDrive 文件夹                    | 具有阻止标签的文件按名称列出。Claude 无法打开它们。                          |
| 打开具有阻止标签的电子邮件或其附件之一                             | Claude 收到通知而不是内容。                                      |
| 列出或搜索邮件文件夹，或搜索共享邮箱                              | 具有阻止标签的电子邮件和标签无法确定的电子邮件被排除。                            |
| 回复、转发、移动、更改、发送或删除具有阻止标签的电子邮件或草稿，或标签无法确定的电子邮件或草稿 | 被拒绝。如果操作涉及一个线程或多封电子邮件，一封被阻止的电子邮件会拒绝整个操作。               |
| 打开具有阻止标签的 Word、Excel、PowerPoint 或 PDF 附件        | 被拒绝，即使电子邮件本身未被阻止。受密码保护的 PDF 和加密的 Office 附件无论其标签如何都被拒绝。 |

连接器检查 Word、Excel 和 PowerPoint 文件、PDF 和 MP4 视频。当您的列表至少有一个标签时，它也会拒绝 OneNote、Loop 和 Whiteboard 项目，无论其标签如何。

### 在 Claude for Excel、PowerPoint、Word 和 Outlook 中

Claude 不会处理具有阻止标签的打开文档、电子邮件或草稿，或其标签无法检查的文档、电子邮件或草稿。窗格显示消息。如果加载项无法加载您组织的列表，Claude 可能会读取和处理具有阻止标签的内容，直到列表加载。

有关每条消息的含义、如何检查其工作方式以及加载项中未覆盖的内容，请参阅 **[按敏感度标签阻止文档和电子邮件](https://claude.com/docs/office-agents/sensitivity-labels)**。

## 开始前

### 在 Claude 中

您需要是企业计划上的所有者或主要所有者。具有所有者访问权限的自定义角色也可以。管理员角色和仅具有隐私权限的自定义角色无法管理标签。

### 在 Microsoft Entra 中

您登录的 Microsoft 帐户需要以下角色之一：

- 全局管理员

- 特权角色管理员

- 合规性管理员

- 合规性数据管理员

- 安全管理员

- Azure 信息保护管理员

第一次时，Microsoft 可能还会要求管理员批准。全局管理员或特权角色管理员可以在连接时批准。否则，请要求其中一个批准，然后重新连接。如果您的组织使用特权身份管理，请在登录前激活您的角色。

### 在 SharePoint 和 Purview 中

连接器只能阻止 Microsoft 报告的标签。请要求您的 Microsoft 365 管理员检查这些设置：

- **文件：**启用 **[具有敏感度标签的文件的共同创作](https://learn.microsoft.com/en-us/purview/sensitivity-labels-coauthoring)**和 **[PDF 支持](https://learn.microsoft.com/en-us/purview/sensitivity-labels-sharepoint-onedrive-files#adding-support-for-pdf)**，以及 **[视频支持](https://learn.microsoft.com/en-us/purview/sensitivity-labels-sharepoint-onedrive-files#video-support-mp4-files)**（如果您标记视频）。否则 SharePoint 可能不会报告文件的标签，Claude 可以读取它。

- **电子邮件：**在 Purview 中，将电子邮件包含在要在电子邮件上阻止的每个标签的范围内。

- **多地理位置租户：**在每个地理位置运行 `Set-SPOTenant -EnableAIPIntegration $true`。

## 连接您的租户

1. 在网络浏览器中导航到 **[组织设置 > 数据和隐私](https://claude.ai/admin-settings/data-privacy-controls)**。

2. 打开 “已阻止的敏感度标签。”

3. 单击 “连接租户。”

4. 使用具有 “开始前” 中所述 Microsoft Entra 角色之一的 Microsoft 帐户登录。如果 Microsoft 要求，全局管理员或特权角色管理员可以选择 “代表您的组织同意。”

5. 检查名称和租户 ID，然后单击 “连接租户” 以确认。请尽快执行此操作，因为您的 Microsoft 登录在短时间后会过期。

Claude 使用此登录来检查角色并读取您的标签列表。它不会用它来读取文件或电子邮件。

## 选择要阻止的标签

要选择要阻止的标签：

1. 导航到 **[组织设置 > 数据和隐私](https://claude.ai/admin-settings/data-privacy-controls)**。

2. 打开 “已阻止的敏感度标签。”

3. 单击 “添加标签。”

4. 搜索并选择要阻止的每个标签，然后单击添加它们的按钮。

选择标签时，请记住以下规则：

- **子标签是独立的。**阻止父标签不会阻止其子标签，因此也要选择它们。稍后添加的子标签不会自动被阻止。

- **新标签可能需要时间才能显示。**如果标签缺失，请再次登录 Microsoft 以刷新列表。

- **仅您自己的租户的标签有效。**由另一个 Microsoft Entra 租户标记的内容具有该租户的标签，因此您的列表与其不匹配。

- **您可以在每个租户中阻止最多 48 个标签，**计数跨越连接到该租户的每个 Claude 组织。

对标签阻止列表的更改通常在 30 分钟内到达 Microsoft 365 连接器。用户可能需要重新加载或重新打开加载项。请参阅 **[设置标签阻止](https://claude.com/docs/office-agents/sensitivity-labels#set-up-label-blocking)**。

更改生效后，Claude 无法打开新阻止的内容。Claude 已读取的内容保留在现有聊天中。

## 检查阻止是否有效

使用带有不应用加密的已阻止标签的 OneDrive 或 SharePoint 文件，以及从另一个帐户发送的带有已阻止标签的电子邮件。在标记它们后等待几分钟，在更改列表后等待 30 分钟。

要求 Claude 使用连接器打开文件和电子邮件。Claude 应该用解释其无法显示其内容的消息进行响应，或说它找不到它们。

要检查加载项，请参阅 **[检查阻止是否有效](https://claude.com/docs/office-agents/sensitivity-labels#check-that-blocking-works)**。

## 删除标签或断开连接

要停止阻止标签，请打开 “已阻止的敏感度标签，” 然后将其删除。

要停止阻止您组织的所有标签，请断开租户连接。如果另一个 Claude 组织连接到您的租户，它阻止的标签在 Microsoft 365 连接器中保持被阻止。您在 Microsoft Entra 中授予 Claude 的批准将保留，直到您在 Microsoft Entra 中将其删除。

如果您的组织迁出企业计划或启用 HIPAA，标签阻止将不再可用。您无法添加标签，列表上的标签可能不会被阻止。您仍然可以从列表中删除标签。

## 标签阻止不涵盖的内容

Claude 将您的列表与 Microsoft 报告的标签或存储在文档或电子邮件附件中的标签进行比较。未标记或标记错误的内容，或 Microsoft 尚未记录其标签的内容，可能不会被阻止。

**名称和详细信息仍可能出现。**Claude 仍然可以看到有关已阻止内容的一些信息：

- SharePoint 和 OneDrive 文件夹列表显示已阻止文件的名称、大小、修改时间和链接。

- 在 Microsoft 的搜索索引包含该标签之前，搜索可能会返回已阻止文件的名称或已阻止电子邮件的主题、发件人、收件人和日期。已标记的“已发送邮件”和“草稿”中的电子邮件可能仍会出现在整个邮箱的搜索中。

- 未被阻止的电子邮件按名称、类型和大小列出其附件，包括已阻止的附件。

**某些内容未被检查：**

- **其他文件类型：**例如文本文件、图像、存档和另存为文件的电子邮件消息。

- **文件夹内的文件：**当 Claude 移动、复制或删除文件夹时，不会检查其中的文件。

- **其他附件：**图像、文本文件、附加的电子邮件和云链接仅由电子邮件自己的标签覆盖。

- **其他 Microsoft 365 内容：**日历事件、Teams 消息、会议记录以及 SharePoint 页面和列表。已阻止的会议邀请仍可作为日历事件读取。

- **直接提供给 Claude 的文件，在连接器之外：**在聊天、项目或 Cowork 中附加的文件，以及 Cowork 中的本地文件。

- **租户外的人员：**对于使用另一个租户帐户或个人 Microsoft 帐户连接的人员，标签不会被阻止，即使是您与他们共享的文件。

- **粘贴、键入或引用的文本：**例如，从已阻止文档复制的文本，或引用已阻止电子邮件的未标记回复、转发或草稿。

- **文档中的链接或嵌入内容：**仅检查文档自己的标签。

- **Claude 创建的内容：**新文件和电子邮件。

- **加载项：**请参阅 **[不涵盖的内容](https://claude.com/docs/office-agents/sensitivity-labels#what-is-not-covered)**。

**加密内容的标签：**将要阻止的每个标签添加到列表中。不要仅依赖加密来防止 Claude 访问内容。

**新应用的标签** **可能需要时间才能注册。**Microsoft 按照自己的计划记录标签，包括来自自动标记策略和库默认值的标签。在此之前，Claude 可以读取内容。

## 本地连接器和第三方平台

组织设置中的列表不适用于这些设置，它们有自己的设置：

- **Claude Desktop 中的本地 Microsoft 365 连接器：**请参阅 **[按敏感度标签阻止内容](https://claude.com/docs/third-party/claude-desktop/connectors-m365#block-content-by-sensitivity-label)**。

- **使用第三方平台的加载项，**例如通过 Amazon Bedrock、Google Cloud Vertex AI、Azure AI Foundry、API 密钥或网关：请参阅 **[通过第三方平台使用 Claude for M365](https://claude.com/docs/office-agents/third-party-platforms#admin-feature-controls)**。

## 故障排除

### 没有被阻止标签的文件或电子邮件被拒绝

当 Claude 无法确定标签时，它会阻止内容。对于文件，请检查该文件是否已加密、受密码保护或已损坏，以及 “开始前” 下的设置是否已启用。当您的列表中有标签时，OneNote、Loop 和 Whiteboard 项目始终被拒绝。当 Microsoft 报告文件上有任何标签时，Claude 也无法替换文件的内容。

### 标记的文件或电子邮件未被阻止

- 检查确切的标签或子标签是否在您的列表中。

- 如果您刚刚应用了标签，请等待几分钟后重试。如果您刚刚更改了列表，请等待 30 分钟。

- 检查 “开始前” 下的设置。如果 Microsoft 未报告标签，连接器将无法阻止它。

## 常见问题

### 标签阻止是否适用于 Microsoft Purview 数据丢失防护？

标签阻止不会评估您的数据丢失防护策略或为 Microsoft Copilot 设置的策略。它仅将标签与您的列表进行比较。

### 我能看到哪些文件或电子邮件被阻止了吗？

Claude 的审计日志不包括每个被阻止项目的事件。连接或断开租户以及添加或删除标签会记录在您组织的 **[审计日志](https://support.claude.com/en/articles/9970975-access-audit-logs)** 中。

### 标签阻止是否会改变人们在 Microsoft 365 中的访问权限？

不会。人们仍然可以在 Microsoft 365 中打开内容。
