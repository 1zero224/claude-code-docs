# Claude Design 管理员指南（适用于团队和企业计划）

Claude Design 让您的团队通过与 Claude 对话来创建品牌一致的设计、原型和交互式微网站。演示文稿现在有了自己的工具 Claude Slides。

Claude Design 可在免费版、专业版、Max、Ultra、团队和企业计划中使用。在团队计划中默认启用。在企业计划中，将于 2026 年 10 月 15 日默认启用，所有者可以提前启用。

**注意：**工件、模板（包括**设计**）、设计系统和共享的设置现在集中在一个地方。详见**[工件管理员指南（适用于团队和企业计划）](https://support.claude.com/en/articles/16994751)**。本指南介绍如何在设计系统就位的情况下推出 Claude Design，以及在独立 Claude Design **claude.ai/design** 关闭前需要做什么。

Claude Design 在为您的组织首先设置**设计系统**时效果最佳。这确保您的团队创建的每个项目都符合您的品牌、排版、调色板和组件模式。本指南将引导您启用 Claude Design、建立正确的基础并将其推出给您的团队。

**[使用 Claude 创建工件](https://claude.ai/artifacts)**

## 为您的组织启用 Claude Design

您的团队可以在两个地方使用 Claude Design，每个地方都有自己的设置。启用其中一个不会启用另一个。

### 对话和工件选项卡中的 Claude Design

要启用**设计**模板，请参阅**[工件管理员指南（适用于团队和企业计划）](https://support.claude.com/en/articles/16994751)**中的说明。

### claude.ai/design 上的独立 Claude Design

1. 转到**[组织设置 > Claude Design](https://claude.ai/admin-settings/claude-design)**。

2. 在**Claude Design [独立]**下找到**为您的组织启用**切换开关并将其打开。

在企业计划中，您可以使用**[自定义角色](https://support.claude.com/en/articles/13930452)**控制对独立 Claude Design 的访问。

**重要提示：**独立 Claude Design 将于 2026 年 12 月 14 日关闭。在此之前，请检查**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中是否启用了**工件**和**设计系统**，以便用户可以移动他们的项目和设计系统。在企业计划中，**设计系统**默认关闭。如果您的组织有涵盖工件的保留期，移动到 Claude 或已移动到 Claude 的项目或设计系统，如果在该期间内没有人打开它，可能会被永久删除。详见[**从独立 Claude Design 迁移到 Claude**](https://support.claude.com/en/articles/17440474)和**[为企业计划配置自定义数据保留控制](https://support.claude.com/en/articles/10440198)**。

在启用广泛访问之前，请阅读下面的推出方法。在没有设计系统的情况下启用 Claude Design 意味着您的团队会获得功能性但通用的输出。

## 设计系统：为什么它首先出现

在推出 Claude Design 之前，您可以做的最重要的事情是让经验丰富的设计师为您的组织设置设计系统。一旦建立，您的团队创建的每个项目都会自动反映您的品牌。

这意味着您的推出有一个自然的顺序：首先设置设计系统，然后扩大访问范围。

### 谁应该设置设计系统

为了获得最佳效果，我们建议从品牌和产品设计中吸取设计师。他们可以共同确保设计系统涵盖品牌标识和产品 UI 模式。

### 他们将做什么

1. 在 Claude Design 中创建您的组织（请参阅**[在 Claude Design 中设置您的设计系统](https://support.claude.com/en/articles/14604397-set-up-your-design-system-in-claude-design)**）。

2. 完成入职流程。

3. 上传品牌资产（代码库、幻灯片或其他设计参考）。

4. 验证 Claude 生成的设计与您的品牌一致。

任何有 Claude Design 访问权限的成员都可以创建和编辑设计系统。在企业计划中，您可以限制谁可以发布设计系统、设置组织默认值和删除设计系统。

## 推荐的推出阶段

在企业计划中，您可以使用**[自定义角色](https://support.claude.com/en/articles/13930452-manage-custom-roles-on-enterprise-plans)**分阶段访问独立 Claude Design，使用设计功能（在**工件**下）。

### 第 1 阶段：设计系统设置

- **人员：**2–4 名来自品牌和产品设计的受信任设计师和设计主管。

- **目标：**创建和验证您的组织的设计系统，包括每个人都可以用作起点的产品模板。

- **检查点：**在继续之前检查生成的输出是否符合品牌一致性。

### 第 2 阶段：设计团队入职

- **人员：**完整的设计团队。

- **目标：**熟悉 Claude Design；在实际项目中对设计系统进行压力测试。

- **检查点：**收集有关设计质量的反馈，并在需要时改进设计系统。

### 第 3 阶段：产品和 UX 入职

- **人员：**产品经理、UX 研究人员和相关职能部门。

- **目标：**在设计团队之外实现更快的原型设计和设计协作。

- **检查点：**观察整个组织的使用情况并收集有关可用性的反馈。

### 第 4 阶段：更广泛的组织

- **人员：**整个组织或特定部门。

- **目标：**在保持品牌一致性的同时广泛提供设计创建。

- **检查点：**观察整个组织的使用情况并收集有关可用性的反馈。

### 推出提示

- 清楚地宣布每个阶段，以便人们知道何时轮到他们。

- 考虑在早期阶段进行简短的培训课程或办公时间。

- 为设计系统改进建立反馈渠道。

- 在内部分享 Claude Design 的创意使用示例，以帮助培养创意。

## 您的团队可以使用 Claude Design 做什么

设置完成后，您的团队可以使用 Claude Design 来：

- **创建原型和模型：**描述 UI 并获得可工作的交互式原型。

- **使用 Claude Slides 构建演示文稿：**从笔记、报告或现有对话创建品牌一致的演示文稿，并将其导出为 PowerPoint 或 PDF。Claude Slides 在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中有自己的设置。

- **设计微网站和登陆页面：**创建精美的单页网站。

- **使用内联注释进行迭代：**直接在画布上注释设计，并要求 Claude 实施更改。

- **移交给工程部门：**导出设计意图以与 Claude Code 或现有开发工作流一起使用。

## 预览沙箱隔离

Claude Design 项目预览在 Anthropic 运营的单独内容域上的沙箱 iframe 内运行。这些沙箱 iframe 帮助每个项目预览保持在自己的空间中，与其他项目分开。预览中的代码无法访问您的 Claude 账户、您的登录或编辑器。
​
对预览的访问由签名令牌控制——短期通行证，证明某人被允许进入。Claude 每次有人打开预览时都会根据您的共享权限重新检查这些令牌，因此当您移除某人的访问权限时，他们会立即被锁定。

## 常见问题

### 所有团队成员都需要上传品牌资产吗？

不需要。一旦设计师设置了您的组织的设计系统，在该组织内创建的所有项目都会自动使用它。团队成员只需开始创建。

### 我们可以为不同的品牌或子团队拥有多个设计系统吗？

可以。组织可以拥有多个设计系统。

### 如果有人在设置设计系统之前开始使用 Claude Design 会怎样？

他们会获得功能性设计，但这些设计不会反映您的品牌。我们强烈建议首先完成设计系统设置以获得最佳的团队体验。

### 我们一次可以入职多少用户？

没有严格的限制，但我们建议采用上述分阶段方法，以确保质量和在整个组织中成功采用。

### 我们可以导出或存档生成的设计吗？

Claude Design 支持导出为 HTML 包、PPTX、PDF 和 Google Slides，移交给 Claude Code，以及将设计发送到**[Claude Design 入门](https://support.claude.com/en/articles/14604416)**中列出的合作伙伴工具。
