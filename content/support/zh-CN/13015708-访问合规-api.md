# 访问合规 API

合规 API 让您的组织能够以编程方式从所有 Claude 部署中提取活动源事件、聊天数据和文件内容。使用它来监控、审计并通过您自己的工具满足合规要求。

合规 API 可供企业计划组织和 Claude 平台客户在 Claude 聊天中使用。在 Anthropic 专用政府部署（如 Claude for Government）上的组织使用**[单独的合规 API](https://claude.com/docs/government/org-admin/compliance-api)**。

**重要提示：**对于 Claude 企业组织，只有您组织的主所有者可以从**[组织设置 > API](https://claude.ai/admin-settings/api-access)** 启用合规 API。您可以通过点击**密钥**下的 “+创建密钥”在同一页面上创建密钥：主所有者可以创建涵盖每个关联组织的密钥，所有者可以创建仅限于其自己组织的密钥。所有者可以看到此页面，但看不到**合规 API** 切换开关——只有主所有者可以打开或关闭 API。管理员根本看不到此页面。如果您的组织关联到父组织，则由父组织的主所有者启用它，该设置适用于每个关联的组织。

## 合规 API 技术文档

有关设置说明、端点和参考资料，包括如何启用 API 和创建访问密钥以开始提取数据，请参阅 Claude 平台文档上的**[合规 API 文档](https://platform.claude.com/docs/en/manage-claude/compliance-api)**。

## 合规 API 安全集成

安全和合规平台已在 Claude 合规 API 之上构建集成，因此您的团队可以在您已使用的工具中监控 Claude 活动。详细了解**[合规 API 集成](https://support.claude.com/en/articles/15167101-get-started-with-claude-compliance-api-integrations)**。

## 合规 API 中的审计日志事件

合规 API 现在包括审计日志事件，让您全面了解所有 Claude 部署。要查看通过审计日志记录的事件，请参阅**[如何访问审计日志](https://support.claude.com/en/articles/9970975-how-to-access-audit-logs#h_41cdad187a)**。
