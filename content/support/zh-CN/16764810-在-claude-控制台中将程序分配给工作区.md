# 在 Claude 控制台中将程序分配给工作区

本文介绍如何为 Anthropic 控制台和 API 应用授权并启用程序。

Anthropic 提供多个验证程序，例如网络验证程序 (CVP) 或访问可能不公开提供的模型。要获得这些程序的访问权限，请访问我们的 **[验证门户](https://portal.anthropic.com/)**，查看您可以使用的程序，然后申请。

申请并获得程序批准后，Anthropic 会向您的组织颁发"程序"或"授权"。要使用该程序或授权，您必须将其分配给组织内的一组人员。在 Claude 控制台中，程序仅适用于您分配给它的工作区。本文介绍如何分配程序。

## 开始前

- 您的组织必须已拥有授权。授权仅在 Anthropic 向您的组织颁发后才会显示。要申请特定程序，您的组织管理员或所有者应访问我们的 **[验证门户](https://portal.anthropic.com/)**，查看可用的程序。

- 在控制台中，您需要是组织管理员或所有者。其他角色无法查看或管理授权。

## 为控制台工作区授予访问权限

在控制台中，程序被颁发给您的组织并适用于工作区。您需要将每个程序分配给应该使用它的工作区。程序仅适用于来自满足其要求的工作区的 API 流量。

按照以下步骤操作：

1. 以组织管理员身份**[登录控制台](https://platform.claude.com/)**。

2. 转到**[组织设置 > 程序](https://platform.claude.com/settings/programs)**。

3. 选择程序以打开其页面。**工作区**表显示每个工作区的状态。标记有问题的工作区尚未满足要求。

4. 将鼠标悬停在问题上，查看未满足的要求。

5. 在程序页面上，单击**工作区**表中工作区的名称，然后检查**资格**面板。

未满足的要求会标记有补救步骤。

## 将程序分配给工作区

程序仅适用于您分配给它的工作区。

### 1. 创建新工作区并添加用户

某些程序无法分配给默认工作区。如果您的程序是其中之一，请先创建专用工作区。

1. 以组织管理员身份**[登录控制台](https://platform.claude.com/)**。

2. 转到**工作区**页面 (platform.claude.com/settings/workspaces)。

3. 单击"创建工作区"（您无法使用默认工作区来访问该模型）。**创建工作区**页面打开。

4. 为新工作区输入名称并选择颜色。颜色可帮助您在 Claude 控制台中识别您的工作区。

5. 单击"创建工作区"。

6. 将获批准的用户添加到新工作区。

**重要提示：**某些程序有座位限制。如果您的组织超过限制，分配的工作区将失去访问权限，直到恢复到限制以下。

详细了解**[在 Claude 控制台中创建和管理工作区](https://support.claude.com/en/articles/9796807-creating-and-managing-workspaces-in-the-claude-console)**。

**注意：**如果支持要求您提供工作区 ID，请转到**工作区**页面 (platform.claude.com/settings/workspaces) 并选择您的工作区。工作区 ID 以 `wrkspc_` 开头。您的组织 ID 在**组织**页面 (platform.claude.com/settings/organization) 上。

### 2. 在您的组织中启用访问权限

您将授权添加到现有 Anthropic 组织中的工作区。对于 API 组织，访问权限在现有 Anthropic 组织内的工作区中启用。您不需要新组织或单独的组织。

1. 以组织管理员身份**[登录控制台](https://platform.claude.com/)**。

2. 转到**程序**页面 (platform.claude.com/settings/programs)，您将看到您的组织可用的已批准访问授权和模型的代号。

3. 在程序页面上，单击**工作区**表中您在第 1 步中设置的工作区的名称。

4. 单击"添加授权"。

5. 选择程序或授权以将其附加到工作区。

6. 确保授权设置为**活跃**。

授权激活后，您可以通过 API 使用该程序与该工作区。如果 Anthropic 为您的程序发送了设置说明，请接下来按照这些说明操作。

## 故障排除

- **授权页面缺失。**您的组织还没有授权，或者您不是组织管理员。请联系您的 Anthropic 账户团队或您的管理员。

- **您看不到您的程序、其他授权部分为空，或程序选项卡缺失。**您的组织可能还没有程序，或者您可能不是组织管理员。请联系您的 Anthropic 账户团队或您的组织管理员。

- **工作区显示为不活跃。**在程序页面上，单击**工作区**表中工作区的名称，然后检查**资格**面板中是否有未满足的要求。

- **授权超过其座位限制。**某些程序有座位限制。分配的工作区将失去访问权限，直到您的组织恢复到限制以下。减少计入授权的成员数量，然后重新检查。

- **您正在尝试使用默认控制台工作区。**某些程序不允许将程序分配给默认工作区。如果默认工作区不起作用，请分配不同的工作区或创建新工作区。

- **您无法将程序分配给工作区。**确认您是组织管理员，并且您没有选择默认工作区。某些程序无法分配给默认工作区，因此如果需要，请创建专用工作区。

- **API 返回 401 错误。**确认您的 SSO 会话处于活跃状态（交互式）或您的联合令牌未过期（工作负载），并且您的凭证的范围限定为工作区。

- **API 为模型返回 404 错误。**仔细检查模型字符串，并确认您的请求的范围限定为工作区，而不是默认工作区。
