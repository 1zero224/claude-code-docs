# Claude Docs 键盘快捷键

本文列出了 Claude Docs 中的所有键盘快捷键，以及在表格、图像、链接和文档标签列表中有效的按键。有关分步说明，请参阅 **[Claude Docs 入门](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs#h_3762015b90)**中的

Claude Docs 可在免费版、专业版、Max、Ultra、团队版和企业版计划中使用。除企业版计划外，所有计划都默认启用。在企业版计划中，它将在 2026 年 10 月 15 日默认启用，所有者可以在 **[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中提前启用。

本文将文档的标签称为文档标签，以区别于 Tab 键。快捷键首先为 Mac 编写，Windows 按键在括号中。Return 是 Windows 键盘上标记为 Enter 的按键。

## 文档中任何位置的快捷键

这些表格取自 Claude Docs 本身的快捷键列表。要打开该列表，请在文档内任何位置按 Cmd+/（Windows 上为 Ctrl+/）。

| **操作**            | **Mac**                | **Windows**           |
| ----------------- | ---------------------- | --------------------- |
| 打开键盘快捷键列表         | Cmd+/ 或 ?              | Ctrl+/ 或 ?            |
| 离开文本              | Escape                 | Escape                |
| 撤销                | Cmd+Z                  | Ctrl+Z                |
| 重做                | Cmd+Shift+Z 或 Cmd+Y    | Ctrl+Shift+Z 或 Ctrl+Y |
| 全选                | Cmd+A                  | Ctrl+A                |
| 在标题和正文之间移动        | Tab 或 Shift+Tab        | Tab 或 Shift+Tab       |
| 移动到格式工具栏或光标所在块的操作 | F6、Cmd+F6 或 Option+F10 | F6、Ctrl+F6 或 Alt+F10  |

## 文档标签页列表

要打开文档标签页列表，请按 Escape 离开文本，然后在文档标签页按钮上按 Return。如果焦点尚未在文档标签页上，请按 Tab 直到到达列表。如果文档标签页列表显示在文本旁边，文档标签页按钮不会打开它；请参阅此表后的段落。

| **操作**                                 | **按键**         |
| -------------------------------------- | -------------- |
| 下一个或上一个文档标签页或标题                        | 向下箭头或向上箭头      |
| 列表中的第一项或最后一项                           | Home 或 End     |
| 显示或隐藏文档标签页下的行：其子标签页以及在您所在文档标签页下列出的任何标题 | 向右箭头或向左箭头      |
| 打开文档标签页并进入其中，或移动到文本中的标题                | Return 或 Space |
| 关闭列表                                   | Escape         |

如果文档标签页列表显示在文本旁边，文档标签页按钮不会打开它。从文档的工具栏按 Tab 可到达它。在您只能查看或评论的文档中，从文本按 Escape 直接进入列表，如果工具栏对您没有按钮，从面板的标题按 Tab 也可到达它。使用屏幕阅读器时，它是"标签页"地标。在其中，向下箭头和向上箭头键在行之间移动，Home 和 End 转到第一个和最后一个。Return 或 Space 打开文档标签页，焦点保留在列表中。向右箭头键显示行下的内容（其子标签页，以及在您所在的文档标签页上，其标题，如果有两个或更多），向左箭头键再次隐藏它。在标题上按 Return 或 Space 会将您移动到文本中的该标题。在您可以编辑的文档中，F2 重命名文档标签页。Shift+F10（Mac 笔记本电脑上为 Fn+Shift+F10）打开文档标签页的菜单。

## 工具栏和菜单内的按键

在格式工具栏中（选择文本后使用 Cmd+F6（Windows 上为 Ctrl+F6）到达）：向左箭头和向右箭头键在按钮之间移动，Home 和 End 移动到第一个和最后一个，Return 或 Space 使用按钮，向下箭头键打开按钮的下拉菜单，Escape 或 Tab 返回到文本。

在文本上方的文档工具栏中（Escape 从文本通常到达的位置（在文档标签页按钮上，工具栏的开始处））：向左箭头和向右箭头键在按钮之间移动，Home 和 End 移动到第一个和最后一个，Return 使用按钮。

在插入菜单 (/)、提及列表 (@) 和表情符号列表 (:) 中：继续输入以筛选，按向下箭头和向上箭头键移动，按 Return 或 Tab 选择，按 Escape 关闭。

## 表格、图像、视频和链接

在表格中，在最后一个单元格中按 Tab 会添加一行，Cmd+Z（Windows 上为 Ctrl+Z）会再次删除它。未选择任何内容时，从单元格按 Cmd+F6（Windows 上为 Ctrl+F6）移动到表格的"更多操作"按钮，其中 Return 打开一个菜单用于对表格进行评论、反应或删除。

要添加或删除行或列，在表格单元格中按 Shift+F10（Mac 笔记本电脑上为 Fn+Shift+F10）。在具有菜单键的 Windows 键盘上，该键执行相同操作。菜单打开，焦点在其第一项上。使用屏幕阅读器时，您会听到"单元格操作"。

按向下箭头和向上箭头键移动，按 Return 或 Space 选择，按 Escape 或 Tab 返回到单元格。从此菜单插入行或列后，Cmd+Y（Windows 上为 Ctrl+Y）插入另一个。

选择多个单元格时，菜单还具有"合并单元格"。当表格在其标题行下至少有两行且没有跨行合并的单元格时，菜单还具有"按升序排序列"和"按降序排序列"。它们按光标所在的列排序。

使用箭头键将光标移动到图像、视频或图表上以将其选择为一个对象。然后 Cmd+F6（Windows 上为 Ctrl+F6）移动到其按钮，Escape 返回到文本。

在图像上，其中一个按钮是"更多操作"。使用向左箭头或向右箭头键移动到它，然后按 Return。菜单打开，焦点在其第一项上。使用向下箭头或向上箭头键移动到"编辑替代文本"，然后按 Return。为看不到图像的人输入图像的描述，然后按 Return 保存或按 Escape 取消。

**重要提示：**在选择对象时输入会替换它。按 Cmd+Z（Windows 上为 Ctrl+Z）将其恢复。

光标在链接内时，Cmd+K（Windows 上为 Ctrl+K）打开链接的操作：打开、复制、编辑和删除。

要打开文档标签页或另一个文档的提及，使用箭头键将光标移动到提及上以选择它，然后按 Option+Return（Windows 上为 Alt+Enter）。单独按 Return 不会打开它。

要从文本打开评论，将光标移动到已评论的文本中，并在未选择任何内容的情况下按 Cmd+Option+M（Windows 上为 Ctrl+Alt+M）。焦点移动到评论，Escape 将光标放回原来的位置。如果相同的单词有多个评论，从文本再次按快捷键打开下一个。

在某些 Windows 键盘布局上，例如德语、俄语和希腊语，Ctrl+Alt+M 仍会向选定的文本添加评论，但不会打开光标处的评论。从文本旁边的评论中到达评论。

在您只能查看的文档中，Tab 在文本中的链接、文档标签页或另一个文档的提及、任何宽表格（以便您可以使用箭头键滚动它）、视频播放按钮以及标题旁边的按钮之间移动，这些按钮可以折叠或展开部分（如果文档有的话）（每个按钮在焦点到达时出现）。在提及上按 Return 打开它，在标题的按钮上按 Return 或 Space 折叠或展开其部分。在网站链接上按 Return 显示其地址，并带有打开或复制它的按钮。按"打开链接"上的 Return 在新标签页中打开网站。如果焦点改为在"完整 URL"上，请按向右箭头键一次以到达"打开链接"。
