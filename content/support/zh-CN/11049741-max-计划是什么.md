# Max 计划是什么？

本文介绍了面向个人消费者的付费 Max 计划。如果您是组织的一部分，想要与团队一起使用 Claude，请参阅 **[团队和企业计划](https://support.claude.com/en/collections/9387370-team-and-enterprise-plans)**。

Max 计划专为经常与 Claude 协作且需要更多使用量来处理各种任务的用户设计。除了提供比 Pro 计划更高的使用限制外，Max 计划订阅者还将获得对我们最新功能和模型的优先访问权。

## 主要优势

- **更多使用容量**：每五小时和每周获得 Pro 计划使用量的五倍。

- **中断更少**：通过更高的使用限制保持工作流畅，允许与 Claude 进行更深入、更广泛的工作。

- **优先访问**：率先体验新模型、功能和产品。

- **访问 Claude Code：[使用 Claude Code](https://support.claude.com/en/articles/11145838)** 进行终端编码工作流，使用一个统一的订阅。

- **更长的多步骤任务：**将报告、电子表格和演示文稿等工作交给 Claude，它会在后台继续运行。在 **[Claude Cowork 和聊天是一个 Claude](https://support.claude.com/en/articles/16761823)** 中了解更多信息。

- **每月 API 额度：**Claude Max、Ultra 和 Team 计划包括 Claude API 的每月额度。了解更多关于 **[Max、Ultra 和 Team 计划的每月 API 额度](https://support.claude.com/en/articles/17154008)**。

**需要更多使用量？**了解更多关于 **[Ultra 计划](https://support.claude.com/en/articles/17728952)**。

## Max 计划的费用是多少？

### 定价

Max 计划的价格为每月 $100。

**注意：**此价格仅适用于网络订阅。移动应用定价可能因您的应用平台而异。

价格和计划可能会根据 Anthropic 的决定而改变。

### 账单信息

- Max 计划目前仅作为月度订阅提供。

- 从 Max 升级到 Ultra 时，您的账户将按比例收费，以支付您计费周期的剩余部分。如果您已领取每月 API 额度，您会立即收到按比例分配的额度，然后在之后的每个计费周期获得更高的金额。

- 从年度 Pro 计划转换到 Max 计划时，如果您年度 Pro 计划的剩余余额大于 Max 计划价格，您的账户将获得剩余余额的信用额。此信用额将应用于未来的订阅费用。

  - 要获得您的信用额，用于购买 Max 计划的账单地址必须与您之前订阅的账单地址相同。

  - 如果您的账单地址已更改，您需要取消 Pro 订阅，并等待订阅结束日期后再使用新的账单地址注册新的 Max 订阅。

  - 如果您通过 Google Play 订阅，升级时将按新计划的全价收费。您之前计划的未使用价值将转换为新计划上的额外天数，因此您的续订日期将比整月晚几天。

### 我如何获得免费或折扣的 Max 计划？

我们不为个人计划（Pro、Max 和 Ultra）提供标准折扣定价，但在支持的地区的任何人都可以通过导航到 [**claude.ai**](https://claude.ai/) 并使用电子邮件地址注册来访问 Claude 的免费版本。

我们偶尔会进行限时促销，但我们没有任何可应要求的常设折扣。这些促销优惠通常在可用时通过我们的官方渠道宣布。如果您对潜在的未来促销感兴趣，我们建议您关注我们的官方社交媒体账户或注册我们的新闻通讯，以便在有特别优惠时获得通知。我们的支持团队无法发放一次性折扣或优惠券。

符合条件的非营利组织可以获得 Team 和 Enterprise 计划的折扣定价。了解更多关于 **[Claude for Nonprofits](https://claude.com/solutions/nonprofits)**。

**注意：**符合条件的非营利组织可以获得 Team 和 Enterprise 计划的折扣定价。了解更多关于 [**Claude for Nonprofits**](https://claude.com/solutions/nonprofits)。

## Max 计划有任何使用限制吗？

有。Max 计划每五小时和每周包括 Pro 计划使用量的五倍。如果您需要更多使用量，了解更多关于 **[Ultra 计划](https://support.claude.com/en/articles/17728952)**。

Max 计划有五小时限制、适用于所有模型的每周使用限制，以及 Fable 的单独每周限制。每周限制在分配给您账户的固定时间每周重置。无论您何时开始使用 Claude 或何时订阅开始，您的重置日期和时间都保持不变，您在每个周期都会获得完整的每周额度。您可以在 **[设置 > 使用情况](https://claude.ai/new#settings/usage)** 中查看您的下次重置时间。

可能会应用额外的使用限制来管理容量并确保所有用户的公平访问。例如，我们可能会以其他方式限制您的使用，例如每周和每月上限或模型和功能使用，由我们自行决定。我们不保证不间断的服务。

有关使用和长度限制的更多信息，请参阅 **[了解使用和长度限制](https://support.claude.com/en/articles/11647753-understanding-usage-and-length-limits)**。有关有效使用 Max 或 Ultra 容量的指导，我们还提供 **[使用限制最佳实践](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)**。

**注意：**如果您有限制重置，可以使用它将您的五小时会话限制或每周使用限制重置为满额。了解更多关于 **[限制重置](https://support.claude.com/en/articles/17007452)**。
