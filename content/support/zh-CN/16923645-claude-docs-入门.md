# Claude Docs 入门

Claude Docs 让你能够与 Claude 和你的团队成员一起编写活文档。在任何对话中请求一份文档，Claude 会在你面前起草它，提前提出澄清问题，并留下注释解释它的选择。你可以自己编辑文档，请求 Claude 进行下一步修改，并通过链接分享，无需将工作转移到其他工具。

本指南涵盖创建你的第一份文档、与 Claude 和你的团队一起编辑它，以及在准备好时分享或导出它。

**[使用 Claude 创建工件](https://claude.ai/artifacts)**

Claude Docs 在免费版、专业版、Max、Ultra、团队版和企业版计划中可用，默认启用。在企业版计划中，它将在 2026 年 10 月 15 日默认启用，所有者可以在 **[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)** 中提前启用。

## Claude Docs 的工作原理

文档是保存到你的 Claude 账户的富文本文档。它可以包含标题、表格和其他格式，可以有多个标签页，就像笔记本的各个部分。你创建的每份文档都保存在 **工件** 标签页中，所以你可以从任何对话中再次找到它。

Claude 从它已有的上下文开始。当你请求一份文档时，Claude 可以利用你的文件、记忆、项目、技能和你连接的应用，所以你不会从空白页开始。

创建文档的人是其所有者。所有者与之分享的任何人都可以查看或编辑它。Claude 仅在有登录的人要求时才对文档进行操作，它不能做该人没有权限做的任何事情。每项更改都归属于做出更改的人，无论是人还是 Claude。

## 创建文档

### 从对话中

在任何对话中请求 Claude 提供文档。例如：

- “将我们刚刚完成的计划转变为我可以与团队分享的产品规格说明。”

- “根据我的笔记和上周的数据起草本周的状态报告。”

- “根据我 Google Drive 中的福利资料为新员工编写入职指南。”

- “将我关于此账户的笔记整理成明天电话会议的一页简报。”

Claude 在开始前会提出几个问题，然后在屏幕上起草文档。你也可以用 /docs 开始你的请求，或从消息框中选择 “输出” 然后 “文档”。

### 从工件标签页

1. 转到 **[工件](https://claude.ai/artifacts)** 标签页。

2. 从库中选择一个文档模板。

3. 描述你想要的文档。

### 你可以在哪里创建文档

你可以在与 Claude 交谈的任何地方请求文档：

- **Claude 网页版和桌面版：**在任何对话中提问，或从工件标签页开始。

- **Claude Code：**请求 Claude 将你所在的会话转变为规格说明、运行手册或报告。在桌面上，文档在侧面板中打开。在终端中，Claude 会给你一个链接以在网页上打开文档。

- **Claude iOS 和 Android 应用：**在任何对话中请求文档，稍后回来查看结果。从 **工件** 标签页打开它以全屏查看。你也可以编辑文档。

### 获得更好结果的提示

好的请求说明文档的用途、谁将阅读它以及它应该涵盖什么。“为我们销售团队提供的两页发布简报，涵盖定价、时间安排和前三个客户问题” 比 “发布简报” 能让你走得更远。如果内容存在于特定位置，请说明 Claude 应该使用的文件或连接应用的名称。

## 编辑你的文档

Claude 工作时没有任何内容被锁定。你可以随时与 Claude 一起编辑，最终决定权始终是你的。

### 直接编辑

点击进入文档并输入。你的更改会自动保存，并立即显示给所有打开该文档的人。

### 请求 Claude

在对话中请求更改，例如 “精简介绍并添加风险部分。” Claude 编辑文档并告诉你更改了什么。

### 使用注释

选择文本并为你的协作者留下注释。要请求 Claude 进行编辑，在注释中提及 @Claude。Claude 在线程中回复，进行更改，并解释它做了什么以及为什么。Claude 在起草时也会留下自己的注释，以解释其选择或向你提出问题。

### 添加图表和视觉效果

与其粘贴屏幕截图，不如请求 Claude 向你的文档添加图表、图示、图形或时间线。Claude 从你连接的应用中提取数据并在文档中构建图表。图表和图示不会自动更新，即使数据来自 Salesforce 或 Google Sheets 等连接应用。要刷新一个，请请求 Claude 拉取最新数据。

### 与你的团队一起处理文档

具有编辑权限的人可以与你和 Claude 同时处理同一文档，每个人的编辑都会实时显示。Claude 始终以提出请求的人的权限行动，所以它不能为只有查看权限的人编辑文档。

## 使用键盘操作 Claude Docs

要进入和退出工件面板，请参阅 **[使用键盘或屏幕阅读器操作工件](https://support.claude.com/en/articles/17457950)**。该文章还解释了焦点的含义、在 Mac 笔记本电脑或 Safari 中的操作方法，以及快捷键的编写方式。有关完整的快捷键列表，包括表格、图像、链接和文档标签页列表的键，请参阅 **[Claude Docs 键盘快捷键](https://support.claude.com/en/articles/17458093)**。

本部分将文档的标签页称为文档标签页，以便与 Tab 键区分。

### 打开键盘快捷键列表

Claude Docs 列出了自己的快捷键。在文档内任何位置获得焦点时，按 Cmd+/（Windows 上为 Ctrl+/）。它在你输入时以及在你只能查看的文档中工作。当焦点不在文本框中时，单独按 ? 也会打开列表。Escape 关闭它并将你返回到之前的位置。从面板的标题中，Cmd+/（Windows 上为 Ctrl+/）打开 Claude 本身的快捷键列表，其中不包括工件。

**注意：**在使用 Shift+7 输入 / 的键盘上，例如德语、意大利语和北欧语言布局，Cmd+/（Windows 上为 Ctrl+/）不会打开列表：在这些键盘上它是编号列表快捷键。按 Escape 离开文本，然后按 ?。

### 进入和退出文本

在文档的文本中，Tab 的工作方式与字处理器中的相同：它缩进列表项、移动到下一个表格单元格或在标题和正文之间移动。它不会离开文本。

要进入文本：

1. 从面板的标题中按 Tab 以到达文档的工具栏。如果你只能查看或评论文档，并且文档标签页列表显示在文本旁边，工具栏可能对你没有按钮，然后 Tab 会转到该列表。

2. 继续按 Tab。您会依次经过文档标签列表（如果显示在文本旁边）、评论（如果文档有的话），然后到达文本。需要按多少次取决于文档包含的内容。

离开文本：

1. 按 Escape。如果显示了格式工具栏或其他弹出窗口，这会关闭它。

2. 如果需要，再按一次 Escape。焦点移动到文档工具栏开始处的文档标签按钮，该按钮显示您所在的文档标签名称。如果文档标签列表显示在文本旁边，该按钮只显示 “标签”。在您只能查看或评论的文档中，显示列表时没有按钮，焦点改为进入列表：进入您所在的文档标签，或进入您上次所在的行。

3. 按 Tab 返回文本（如果文档标签列表显示在文本旁边且您还未进入，您会依次经过它和评论（如果文档有的话）），或继续按 Escape 到达工件面板。

### 格式化文本

文本中可以使用常用快捷键，例如 Cmd+B（Windows 上为 Ctrl+B）表示粗体，屏幕阅读器会宣布结果。要改用格式工具栏：

1. 选择一些文本。

2. 按 Cmd+F6（Windows 上为 Ctrl+F6）。焦点移动到格式工具栏。

3. 按左箭头或右箭头键在按钮之间移动。

4. 按 Return 或 Space 使用按钮。要打开按钮的下拉菜单（如文本样式或列表类型），按下箭头键。

5. 按 Escape 或 Tab 返回文本。您的选择会保留。

使用格式按钮后，焦点保留在工具栏中，因此您可以应用多种格式。从文本按 Tab 永远不会到达此工具栏。

在文档中，使用工具栏按钮前，用 Cmd+F6（Windows 上为 Ctrl+F6）移动到格式工具栏。如果您的屏幕阅读器光标以其他方式进入工具栏，其某些按钮（如 “评论” 和 “链接”）会要求您先按快捷键。

### 在文档中评论

要添加评论：

1. 选择您要评论的文本。

2. 按 Cmd+Option+M（Windows 上为 Ctrl+Alt+M）。“添加评论” 框打开，焦点在其中。

3. 输入您的评论。Shift+Return 创建新行，@ 可提及某人。

4. 按 Return 发布。焦点移动到您的新评论。

在框中按 Escape 放弃草稿并返回文本，您的选择会保留。在文档中 Claude 可用的地方，发送按钮前会出现 “发送给 Claude” 复选框。它默认被选中，之后会保持您在该文档中最后留下的状态。

要读取文档上的评论，按 Escape 离开文本，然后按 Tab 直到到达它们（如果文档标签列表显示在文本旁边，您会先经过它）。

您到达的内容取决于面板的宽度：

- 在对话旁边，面板通常很窄，评论显示为边距中的图标。每次按 Tab 移动到下一个图标，按 Return 打开它。评论也显示为图标，在页面宽度设置为宽的文档中，以及当文本旁边的文档标签列表没有留出空间时。

- 否则，在更宽的面板中，评论显示在文本旁边，按 Tab 一次即可进入它们。按下箭头或上箭头键在它们之间移动，按 Return 或 Space 打开一个。

在打开的评论中，Return 进入其回复字段，Escape 关闭它。

## 共享文档

文档默认仅对您私密。按照共享任何工件的方式共享文档：打开它并点击 “共享”。详细了解 **[共享工件](https://support.claude.com/en/articles/9547008)**。

文档有一些不同之处：

- **访问级别：**您共享文档的人可以查看或编辑它。查看者可以读取文档。编辑者可以读取、编辑、评论和导出文档。目前还没有仅评论的访问级别。

- **组织外：**在您的计划和组织设置允许的情况下，您可以通过电子邮件邀请人员或打开 “任何有链接的人”。您邀请的人使用您邀请的地址登录 Claude。使用链接的人登录 Claude，只能查看文档。免费计划无法发送邀请，企业计划默认关闭电子邮件邀请。

- **重命名和删除：**只有所有者可以重命名或删除文档。

### 您可以与谁共享

- **团队和企业计划：**邀请特定人员或群组，或与组织中的所有人共享。当所有者允许时，您也可以与组织外的人共享。

    **免费、Pro、Max 和 Ultra 计划：**与任何有链接的人共享。在 Pro、Max 和 Ultra 计划上，您也可以通过电子邮件邀请人员。

打开共享文档需要 Claude 账户。

### 访问级别

- **查看者**可以读取文档。

- **编辑者**可以读取、编辑、评论和导出文档。

目前还没有仅评论的访问级别。只有所有者可以重命名或删除文档。

**重要：**删除文档是永久的。没有回收站，删除后文档对您共享的所有人都不可用。

## 导出文档

要导出文档，点击 “导出” 并选择格式：

- Word (.docx)

- PDF (.pdf)

- Markdown (.md)

- Google Docs

您也可以要求 Claude 使用 Claude Slides 将文档转换为演示文稿。

## 使用情况

Claude 文档计入您计划的使用限制，就像您与 Claude 的其他工作一样。较大的请求（如从多个来源起草长文档）比典型消息使用更多限制。详细了解 **[使用和长度限制如何工作](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work)**。

## 为您的组织启用 Claude Docs

此部分适用于 Team 和 Enterprise 计划上的所有者和主要所有者。

所有者可在**[组织设置 > Artifacts](https://claude.ai/admin-settings/artifacts)**中启用或关闭 Claude Docs。在 Enterprise 计划上，所有者还可以使用自定义角色将其限制为特定群组。详见**[Team 和 Enterprise 计划的 Artifacts 管理员指南](https://support.claude.com/en/articles/16994751)**，其中还涵盖离职和合规 API。

## 当前限制

需要注意的几点：

- **版本历史记录：**当 artifact 面板过窄而无法在文本旁显示版本历史记录时，版本历史记录会在文本上方打开，且文档工具栏中的 Tab 键暂时无法到达它。

- **访问级别：**没有仅评论访问级别。

- **图表和图表：**图表和图表不会自动更新。请要求 Claude 从您连接的应用中提取最新数据。

- **合规日志记录：**文档内的活动（如编辑和评论）尚未在合规 API 中记录。

- **移动设备：**您无法在 iOS 和 Android 的 Claude 应用中更改共享设置。

- **VoiceOver 和输入：**在 Chrome 150 至 152 版本以及 Claude Desktop 中，VoiceOver 不会在您在文档中输入或移动时读出文本。请使用 Chrome 153 或更高版本。Safari 也适用于文档。
