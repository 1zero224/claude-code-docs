# 了解您的账单地址和税费计算

您的账单地址决定了如何计算 Claude 购买的税费。此地址应代表接收产品的主要营业地点。

## 按计划类型了解账单地址的工作方式

### Pro、Max、Ultra、自助 Team 和自助 Enterprise 计划

您的账单地址会自动设置为与您的付款方式的账单地址相匹配。要更新它，请导航至 **[设置 > 账单](https://claude.ai/settings/billing)**，然后点击您当前付款方式右侧的 “更新”。

### 销售协助 Team 计划和销售协助 Enterprise 计划

您可以直接在“设置”→“账单”→“账单地址”中更新账单地址。更改对未来发票立即生效。

### API（使用层级/自助）

您的账单地址与您的付款方式相关联。通过导航至 **[Claude 控制台中的“设置”>“账单”](https://platform.claude.com/settings/billing)** 并点击您当前卡号右侧的铅笔图标来更新您的付款方式，以更改您的账单地址。

### 付费 API 合同

您可以直接在 Claude 控制台的“设置”→“账单”→“账单地址”中更新账单地址。

## 请求不同的账单地址

如果您的账单地址与您的付款方式地址不匹配——例如，您使用自助计划，需要它反映不同的业务地点以用于增值税目的——您有两个选项：

- **更新您的付款方式地址。**自助计划（Pro、Max、Ultra、自助 Team、自助 Enterprise 和 API 使用层级）从付款方式获取账单地址，因此更新您的卡或 Link 钱包上的地址也会更新您的账单地址。

- **联系支持以锁定固定地址。**如果您需要一个即使更改付款方式也保持不变的地址，请联系我们的支持团队，并提供验证您主要营业地点的文件：

  - **非美国客户：**与您请求的地点相匹配的增值税登记证

  - **美国客户：**公司成立州、营业执照或税务 ID 文件

验证后，当您更改付款方式时，您的账单地址不会自动更新。
