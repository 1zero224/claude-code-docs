# 我创建了 Claude Console 组织 - 如何开始使用 Claude API？

要使用 Claude API 和 playground，请向您的组织账户余额添加使用额度。您需要填写有关您的组织和用例的一些额外信息。然后，您将输入付款详情并为您的账户充值。

Claude Max、Ultra 和 Team 计划包括 Claude API 的每月额度。如果您是 Max 或 Ultra 订阅者，或 Team 计划所有者，可以将此 Console 组织关联到您的计划以领取这些额度。领取或使用额度无需付款方式。详细了解 **[Max、Ultra 和 Team 计划的每月 API 额度](https://support.claude.com/en/articles/17154008)**。

为您的账户购买使用额度后，您就可以在商业应用中使用 API 了。您可以 **[在此查找有关预付费账单和额度的更多信息](https://support.claude.com/en/articles/8977456-how-do-i-pay-for-my-api-usage)**。

如果您需要自定义速率限制、每月发票或专业支持，请 **[联系我们](https://claude.com/contact-sales)** 了解更多信息。
