# 发布说明

## 2026年11月

### 2026年11月20日

**Claude Mobile 焕然一新**

Claude Mobile 的全新外观正在逐步推出，首先在 Claude iOS 版本上推出。您的聊天、项目和计划保持不变。无需进行任何设置。请保持应用更新，请注意新外观需要 iOS 26 或更高版本。

**Team 和 Enterprise 计划的计算机使用功能（测试版）**

计算机使用功能让 Claude 可以查看用户的屏幕并在他们允许的桌面应用中工作。它在 Claude Desktop 的新 Claude 体验中工作，以及在启用**计算机访问**的 Claude 网页版和 Claude Mobile 中工作。现在可在 Team 和 Enterprise 计划的测试版中使用，并正在逐步向各个组织推出。有关更多信息，请参阅**[为 Team 和 Enterprise 计划设置计算机使用功能](https://support.claude.com/en/articles/18483812-set-up-computer-use-for-team-and-enterprise-plans)**。

### 2026年11月17日

**在 Claude Desktop 中选择发布渠道**

您现在可以使用发布渠道来设置应用更新时获得的 Claude Desktop 版本。**稳定版**保持为默认版本，更新频率较低，经过更多测试。**最新版**大约每天获得一个新版本，因此修复和新功能可以更快地到达您。有关更多信息，请参阅**[选择发布渠道](https://support.claude.com/en/articles/10065433-install-claude-desktop#h_ac219b3bde)**。

### 2026年11月12日

**将 Claude 添加到您的会议**

Claude Meetings 正在 Claude 和 Claude Desktop 的 Team 和 Enterprise 计划中推出测试版。您可以将 Claude 作为可见参与者添加到 Google Meet 通话中，它可以记笔记、回答问题，并在通话期间构建工件，例如文档、白板和幻灯片。有关更多信息，请参阅**[使用 Claude Meetings](https://support.claude.com/en/articles/18325154-use-claude-meetings)**。

### 2026年11月6日

**使用项目标签按成本代码跟踪支出（测试版）**

符合条件的 Enterprise 组织现在可以使用他们已经使用的代码（如费用代码或客户事项编号）标记项目，并按标签查看这些项目中的大部分支出。此功能处于测试版。有关更多信息，请参阅**[使用项目标签按成本代码跟踪支出](https://support.claude.com/en/articles/18251257-track-spend-by-project-with-tags)**。

### 2026年11月5日

**Enterprise 计划的新安全和管理控制**

Claude Enterprise 具有新的安全和管理功能，包括安全中心、推理钩子、集中管理和其他访问控制，其中多项处于测试版。有关更多信息，请参阅我们的博客文章：**[提高 Claude Enterprise 的可见性和控制力，为安全团队服务](https://claude.com/resources/articles/claude-enterprise-security-updates)**。

**Claude 中的个人财务**

我们正在推出个人财务功能，这是一项测试版功能，让您可以将银行、信用卡、贷款和投资账户链接到 Claude，以便您可以在一个页面上查看余额和支出，并向 Claude 提出有关您自己资金的问题。它在 Pro、Max 和 Ultra 计划上可用，仅在美国提供。有关更多信息，请参阅我们的博客文章：**[在 Claude 中推出个人财务](https://claude.com/resources/articles/introducing-personal-finance-in-claude)**。
