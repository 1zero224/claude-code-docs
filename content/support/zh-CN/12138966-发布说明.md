### 2026年9月16日

**Claude Cowork 适用于每个对话**

我们推出了一个新的 Claude 体验，使 Claude Cowork 所做的一切都可以从任何对话中获得。提出快速问题或给 Claude 一个更大的任务，如报告、电子表格或演示文稿，无需先选择模式。您的聊天、Cowork 任务、项目、连接器和技能会保留。新体验正在逐步推出到 Web、桌面和移动设备上的 Pro 和 Max 计划。在 **[Claude Cowork 和聊天是一个 Claude](https://support.claude.com/en/articles/16761823)** 中了解更多信息。

**在任何对话中创建设计、演示文稿和文档**

您现在可以在与 Claude 的任何对话中请求设计、演示文稿或文档，包括在 Claude Code 和 **Artifacts** 标签中，并在您工作时使用 Claude 或直接编辑它。Claude Design 在您与所有功能的对话中工作，包括画布上编辑和导入您的设计系统。Claude Slides 为演示文稿提供了自己的起点，Claude Docs 是一种与 Claude 和您的团队一起编写活文档的新方式。Artifacts（包括 Claude Design、Claude Slides 和 Claude Docs）在每个计划上都可用，包括免费计划。在企业计划上，Claude Design、Claude Slides 和 Claude Docs 处于测试版。在 **[什么是 Artifacts，我如何使用它们？](https://support.claude.com/en/articles/17153992)** 和 **[开始使用 Claude Docs](https://support.claude.com/en/articles/16923645)** 中了解更多信息。
