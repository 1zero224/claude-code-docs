# 发布说明

## 2026年11月

### 2026年11月24日

**月度回顾已退出测试版**

月度回顾（设置中的“反思”）现已在网页版、Claude Desktop 以及 iOS 和 Android 版 Claude 上对免费版、专业版、最大版和超级版计划退出测试版。回顾现在可以包含您的 Claude Code 会话和云端 Claude Cowork 任务，您可以从页面中删除已保存的回顾。如需了解更多信息，请参阅**[查看您的月度回顾](https://support.claude.com/en/articles/15672559-see-your-monthly-recap)**。

**将制品安装为应用（测试版）**

您现在可以将 Claude 为您创建的制品作为应用安装到 Mac 或 Windows 计算机上。它拥有自己的窗口和图标，像任何其他应用一样打开，甚至可以像其他应用一样与操作系统交互。此功能目前处于测试版。如需了解更多信息，请参阅**[将应用安装为制品](https://support.claude.com/en/articles/18516354-install-an-artifact-as-an-app)**。

**向已连接的应用发送文件并从中保存文件（测试版）**

Claude 现在可以向您已连接的应用发送文件，或保存该应用提供的文件。连接器的文件传输正在专业版、最大版和超级版计划上逐步推出测试版，在团队版和企业版计划上，当所有者启用时也可使用。如需了解更多信息，请参阅**[向已连接的应用发送文件并从中保存文件](https://support.claude.com/en/articles/18534325)**。

### 2026年11月20日

**Claude Mobile 焕然一新**

Claude Mobile 的全新外观正在逐步推出，首先从 iOS 版 Claude 开始。您的聊天、项目和计划保持不变。无需进行任何设置。请保持应用更新，并注意新外观需要 iOS 26 或更高版本。

**计算机使用（测试版）适用于团队版和企业版计划**

计算机使用让 Claude 可以查看用户的屏幕并在他们允许的桌面应用中工作。它在 Claude Desktop 中的新 Claude 体验中工作，以及在启用了**计算机访问**的网页版 Claude 和 Claude Mobile 中工作。它现已在团队版和企业版计划上以测试版形式提供，并正在逐步向各组织推出。如需了解更多信息，请参阅**[为团队版和企业版计划设置计算机使用](https://support.claude.com/en/articles/18483812-set-up-computer-use-for-team-and-enterprise-plans)**。

### 2026年11月17日

**在 Claude Desktop 中选择发布渠道**

您现在可以使用发布渠道来设置应用更新时获得的 Claude Desktop 版本。**稳定版**保持为默认版本，更新频率较低，经过更多测试。**最新版**大约每天获得一个新版本，因此修复和新功能能更快地到达您。如需了解更多信息，请参阅**[选择发布渠道](https://support.claude.com/en/articles/10065433-install-claude-desktop#h_ac219b3bde)**。

### 2026年11月12日

**将 Claude 添加到您的会议**

Claude Meetings 正在团队版和企业版计划的 Claude 和 Claude Desktop 上以测试版形式推出。您可以将 Claude 作为可见参与者添加到 Google Meet 通话中，它可以记笔记、回答问题，并在通话期间构建制品，如文档、白板和幻灯片。如需了解更多信息，请参阅**[使用 Claude Meetings](https://support.claude.com/en/articles/18325154-use-claude-meetings)**。
