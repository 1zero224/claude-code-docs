# 购买和管理团队计划中的座位

座位管理允许团队计划所有者控制其组织的座位分配、将用户分配到不同的座位类型，以及管理账单。有关定价和账单详情，请参阅**[我的团队计划账单如何计算？](https://support.claude.com/en/articles/9267289-how-is-my-team-plan-bill-calculated)**

**权限说明：**只有所有者和主要所有者可以购买座位并访问**[组织设置 > 账单](https://claude.ai/admin-settings/billing)**。管理员及以上级别可以在**[组织设置 > 成员](https://claude.ai/admin-settings/members)**中为成员重新分配座位类型。

有关从您的组织中添加和移除成员的信息，请参阅**[在团队和企业计划中管理成员](https://support.claude.com/en/articles/13133750)**。

---

## 了解座位类型

团队计划提供两种座位类型：

| **座位类型** | **包含内容**                    |
| -------- | --------------------------- |
| 标准       | 基础功能、使用限制和 Claude Code 访问权限 |
| 高级       | 标准版的所有功能，加上更高的使用限制          |

组织可以根据团队需求混合搭配座位类型。将高级座位分配给需要更多容量的高级用户，同时让其他团队成员保持在标准座位上。

您的计划有总座位分配（例如，30 个标准座位和 10 个高级座位）。在该分配范围内，您可以根据需要将用户分配和重新分配到不同的座位类型。

**注意：**只有管理员及以上级别可以看到每个用户的座位类型，显示在**[组织设置 > 成员](https://claude.ai/admin-settings/member)**中的**等级**列中。其他用户在 Claude 中的任何地方都看不到自己的座位类型。如果您需要确认您的座位是标准还是高级，请询问您组织中的所有者或管理员。

---

## 谁可以使用座位

团队计划上的每个座位都分配给一个指定的个人，只有该人可以使用它。这意味着：

- 只有分配的用户可以登录该账户。用户不能共享登录凭证或让他人使用其账户。

- 用户不能通过另一个用户的账户转接其工作以使用该用户的剩余使用量。

- 一个座位上的未使用使用量不能转移给另一个用户。

如果用户经常需要更多容量，所有者可以将其移至高级座位或启用使用额度。了解更多关于**[为团队和基于座位的企业计划管理使用额度](https://support.claude.com/en/articles/12005970)**的信息。

重新分配座位适用于正常的团队变化，例如用户加入、离开或更改角色。它不是为了在多个活跃用户之间轮换一个座位而设计的。

## 购买新座位

**重要：**如果您想将现有成员从标准升级到高级，并且已有可用的高级座位，则无需购买新座位。请改用**[组织设置 > 成员](https://claude.ai/admin-settings/members)**中的座位等级重新分配。请参阅下面的**[将标准座位升级到高级](#h_e7a7f4f396)**。

按照以下步骤将座位添加到您的计划总分配中：

1. 使用您的所有者或主要所有者账户登录。

2. 导航到**[组织设置 > 组织和访问权限](https://claude.ai/admin-settings/organization)**。

3. 点击"总座位"下的"管理"。

4. 在"座位分配"模态框中，点击"添加或更改座位"。

5. 点击您要添加的座位类型（标准或高级）旁边的"+"。

6. 点击"下一步"以查看您的购买详情并确认账单影响。

7. 在继续之前勾选确认框。

8. 点击"确认并购买"以完成交易。

**注意：**您也可以在添加新成员时购买座位。座位类型选择器仅显示您的计划已拥有的座位类型——如果所选类型的所有座位都已分配，系统会提示您购买一个。

## 减少您的座位分配

您可以减少团队计划上的总座位数：

1. 使用您的所有者或主要所有者账户登录。

2. 导航到**[组织设置 > 组织和访问权限](https://claude.ai/admin-settings/organization)**。

3. 如果需要，移除成员或重新分配他们以释放您想要消除的座位。

4. 点击**总座位**下的"管理"。

5. 在**座位分配**模态框中点击"添加或更改座位"。

6. 点击您要减少的座位类型旁边的"**-**"。

7. 点击"下一步"以查看更改。

8. 勾选确认框并点击"确认并购买"以完成更改。

减少您的组织座位数将在您的下一次续订时生效（对于年度计划，在年度续订日期）。提交此更改时不会进行按比例退款。

## 分配和重新分配座位类型

您可以在现有分配范围内在标准座位和高级座位之间移动用户。

要重新分配用户的座位类型：

1. 转到**[组织设置 > 成员](https://claude.ai/admin-settings/members)**。

2. 找到您要重新分配的成员。

3. 点击**等级**下的下拉菜单。

4. 选择"标准"或"高级"。

从高级移至标准的成员将有更低的使用限制，反之亦然。

要将多个成员从高级移至标准，请不要使用每个成员的**等级**下拉菜单。而是打开**组织和访问权限**，点击**总座位**下的"管理"，然后点击"添加或更改座位"，并在一次提交中设置高级和标准总数。您可以将高级数设置为低于当前分配给它的成员数：这些成员将在续订时自动移至标准座位。标准总数不能低于您当前的可计费成员数。

一次只能有一个计划的座位更改处于待处理状态。提交新的更改、添加座位或接受新邀请会替换待处理的更改。

将成员从高级移至标准将在您的下一次续订时生效（对于年度计划，在年度续订日期）。提交此更改时不会进行按比例退款。

## 将标准座位升级到高级

将成员从标准升级到高级是重新分配，而不是新购买。除非您的高级分配已满，否则无需购买额外座位。

**注意：****等级**下拉菜单仅显示您的计划已拥有的座位类型。如果您的计划有零个高级座位，高级还不会显示为选项。首先按照上面**[购买新座位](#h_f05a756e78)**中的步骤添加至少一个高级座位。一旦您的计划包含高级座位，您就可以从下拉菜单中选择"高级"。

1. 转到**[组织设置 > 成员](https://claude.ai/admin-settings/members)**。

2. 找到分配给您要升级的标准座位的成员。

3. 点击**等级**下的下拉菜单。

4. 选择"高级"。

如果您的计划包含高级座位但都已分配，此时系统会提示您购买额外的高级座位。升级将根据您的账单周期按比例计算，价格差异将立即收费。

### 如果我没有可用座位怎么办？

如果您的计划包含高级座位但都已分配，将另一个用户重新分配到高级座位将提示您购买额外的高级座位。如果您的计划根本没有高级座位，请参阅上面的**[购买新座位](#h_f05a756e78)**以先添加一个。

## 在座位类型之间交换用户

选择**未分配座位**允许您临时从座位中移除用户，而不将其从您的组织中移除。当您需要在现有分配范围内在座位类型之间交换人员时，这很有用。

**示例：**您有五个高级座位，都已分配。您想将用户 A（目前在高级座位上）移至标准座位，并将用户 B（目前在标准座位上）移至高级座位——无需购买额外座位。

1. 转到**[组织设置 > 成员](https://claude.ai/admin-settings/members)**。

2. 找到用户 A 并将其座位等级更改为"未分配座位"。这释放了一个高级座位。

3. 找到用户 B 并将其座位等级更改为"高级"。他们现在占据可用的高级座位。

4. 找到用户 A 并将其座位等级更改为"标准"。

**注意：**未分配座位的成员仍然是您的组织的一部分，但在您为其重新分配座位之前无法使用 Claude。他们不计入您的组织座位限制。待处理邀请确实计入。如果即使座位显示为可用，"添加成员"仍不可用，请撤销不会被接受的待处理邀请，或购买额外座位。

## 使用 JIT 或 SCIM 配置的座位分配

**[通过 JIT 或 SCIM 配置的用户](https://support.claude.com/en/articles/13133195-setting-up-jit-or-scim-provisioning-to-manage-user-assignments-on-team-or-enterprise-plans)**在添加时会自动分配到最高可用座位类型。管理员及以上级别可以之后在**[组织设置 > 成员](https://claude.ai/admin-settings/members)**中手动重新分配座位类型。

您也可以启用 JIT 或 SCIM 的组映射，以直接将用户配置到特定座位类型。

## 了解账单

- **新座位**根据您的账单周期按比例计算，并立即收费。

- **座位类型升级**（标准 → 高级）按比例计算，价格差异立即收费。

- **移除成员**不会触发立即信用或退款。座位变为可用，可分配给另一个成员。要减少您的账单，您需要减少您的计划总座位分配。

有关详细的账单计算和示例，请参阅**[我的团队计划账单如何计算？](https://support.claude.com/en/articles/9267289-how-is-my-team-plan-bill-calculated)**
