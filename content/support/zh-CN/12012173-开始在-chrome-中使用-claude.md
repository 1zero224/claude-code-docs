# 开始在 Chrome 中使用 Claude

Chrome 中的 Claude 是一个浏览器扩展程序，允许 Claude 与您一起读取、点击和浏览网站。您可以从 Chrome 浏览器的侧面板或通过 Claude Cowork 或 Claude Code 启动 Chrome 中的 Claude 任务。

## 可用性

Chrome 中的 Claude 在付费计划（Pro、Max、Ultra、Team 和 Enterprise）上可用，在 Chrome 侧面板、Claude Cowork 和 Claude Code 中可用。侧面板作为 Claude Cowork 会话运行。在 Enterprise 计划上，这需要所有者启用 Claude in Chrome 和云中的 Cowork；在此之前，侧面板使用经典体验。

**重要提示：**Chrome 中的 Claude 允许 Claude 代表您直接与网站交互。Chrome 中的 Claude 已通过我们的安全分类器进行增强，但仍然存在风险。请在使用前查看 **[安全使用 Chrome 中的 Claude](https://support.claude.com/en/articles/12902428-using-claude-in-chrome-safely)**。

## 您可以在哪里使用 Chrome 中的 Claude

### Claude Code 集成

Claude Code 和 Chrome 扩展程序一起工作，用于构建-测试-验证工作流：

- 在您的终端中使用 Claude Code 构建，然后部署到 Claude 可以访问的 URL。

- 使用 Chrome 扩展程序在浏览器中测试和验证。

- 使用控制台日志调试问题——Claude 可以直接读取错误、网络请求和 DOM 状态。

此集成对于设计验证（比较 Figma 模型与构建输出）、实时调试和自动化测试特别有用。

### 从 Claude Desktop 控制浏览器操作（Chat、Claude Cowork 和 Claude Code）

当您在 Claude Cowork 中启动涉及网站的聊天、任务或会话时，Claude 可以直接在 Chrome 中打开浏览器并完成工作，像人一样点击、输入和填写表单。您可以让 Claude 处理浏览器中的工作，而无需切换窗口。

**注意：**Claude Cowork 还在 Claude Desktop 应用程序中内置了浏览器，无需安装任何内容。它本周逐步推出。如果您已经使用 Chrome 中的 Claude，它将保持为 Cowork 的首选浏览器；否则 Cowork 默认使用内置浏览器。在 **Settings > Cowork > Preferred browser** 中选择其中任何一个。在 **[在 Claude Cowork 中使用内置浏览器](https://support.claude.com/en/articles/16607400)** 中了解更多信息。

按照以下步骤在您的桌面应用程序中连接 Chrome 中的 Claude：

1. 单击左下角的您的首字母，然后选择"Settings"。

2. 导航到"Customize"，然后"Connectors"。

3. 在列表中找到 **Chrome 中的 Claude**，然后单击"Configure"。

4. 打开连接器，然后下载并安装扩展程序（如果您还没有安装）。

### 在浏览器侧面板中与 Claude 聊天

打开 Claude 侧面板，在您所在的页面旁边与 Claude 一起工作。Claude 可以看到页面上的内容并对其进行操作，读取、点击、输入、导航和填写表单，因此您可以获得帮助而无需离开浏览器窗口。

在 Max、Ultra 和 Team 计划上，在 Pro 计划上（当推出到达您时），以及在您的管理员启用了它的 Enterprise 计划上，侧面板作为 Claude Cowork 会话运行，这意味着：

- **您的对话已保存。**每个侧面板会话都像任何其他 Cowork 会话一样出现在您的历史记录中。

- **会话随您移动。**在侧面板中启动会话，然后在网络、Claude Desktop 或 Claude Mobile 上继续。会话与您的 Claude 账户一起存在，而不是与您启动的机器一起存在。

- **您的技能、插件和连接器在这里工作。**它们的行为方式与在桌面上的 Cowork 中的行为方式相同。在侧面板中保存技能，并从任何表面运行它。

侧面板非常适合即时浏览任务：

- 总结或比较您的标签页中打开的内容。

- 将页面中的详细信息提取到笔记、文档或表单中。

- 在您观看时逐步完成网站上的任务。

**切换回经典侧面板：**

如果您更喜欢使用之前的侧面板，您可以随时切换回去：

1. 在 Chrome 中打开侧面板。

2. 单击右上角的三个点。

3. 选择"Switch back to classic"。

**注意：**录制的工作流仅在经典侧面板中可用。

## 安装 Chrome 中的 Claude

1. 打开 Google Chrome 浏览器窗口。

  1. **注意：**Chrome 中的 Claude 在其他基于 Chromium 的网络浏览器或移动设备上不受支持。

2. 访问 **[Chrome Web Store](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn)** 以查找 Chrome 中的 Claude。

3. 单击"Add to Chrome"以安装扩展程序。

4. 出现提示时，使用您的 Claude 账户凭据登录。

5. 通过单击拼图图标，然后单击"Claude"旁边的图钉来固定扩展程序。

6. 授予必要的权限，使 Claude 能够与您的浏览器交互。

Claude 图标将出现在您的 Chrome 工具栏中。点击它可在浏览时保持可见的侧面板中打开 Claude。

## 在 Chrome 中安装 Claude 所需的权限

您需要授予 Chrome 中的 Claude 以下权限才能安装和使用该扩展程序：

| **权限**                              | **Claude 需要此权限的原因**                                                          |
| ----------------------------------- | ---------------------------------------------------------------------------- |
| sidePanel                           | 这让 Claude 可以作为浏览器侧面的面板出现，因此您可以在浏览任何网站时与 Claude 聊天。                           |
| storage                             | 这让 Claude 可以保存您的偏好设置，以便在您关闭并重新打开浏览器时仍然存在。                                    |
| scripting                           | 这让 Claude 可以读取网页上的文本，以便帮助您完成任务。                                              |
| debugger                            | 这是允许 Claude 实际控制您的浏览器的功能——点击按钮、输入文本和截图——当您要求它为您完成任务时。                        |
| tabGroups                           | 这让 Claude 可以将它打开的标签页组织到一个具有不同颜色的单独组中，这样您可以轻松区分 Claude 使用的标签页和您的个人浏览。         |
| tabs                                | 这让 Claude 可以在为您完成任务时打开、关闭和切换浏览器标签页。                                          |
| alarms                              | 这让 Claude 可以在您选择的特定时间运行计划任务——例如每天在设定的时间检查网站上的内容。                             |
| notifications                       | 这让 Claude 可以在完成任务或需要您采取行动时向您的计算机发送通知。                                        |
| system.display                      | 这让 Claude 知道您的屏幕大小，以便在自动化任务时能够准确地点击正确的位置。                                    |
| webNavigation                       | 这让 Claude 可以在检测到您在高风险网站上时进行干预。                                               |
| declarativeNetRequestWithHostAccess | 这让扩展程序向 Anthropic 的服务器标识自己，帮助我们了解浏览器扩展程序的使用方式并排查任何问题。                        |
| offscreen                           | 这让 Claude 可以在需要您注意时在后台播放通知声音。                                                |
| nativeMessaging                     | 这将让扩展程序与您计算机上的其他 Anthropic 产品（如 Claude Desktop 或 Claude Code）无缝集成，一旦我们启用该功能。 |
| downloads                           | 这让 Claude 可以从网站下载文件并在您要求保存或处理文件作为自动化工作流的一部分时打开它们。                            |
| unlimitedStorage                    | 这让 Claude 可以在本地存储更多数据（如详细工作流的复杂说明），超过 Chrome 为扩展程序设置的正常限制。                   |

有关更多信息，请参阅 **[Google Chrome 权限文档](https://developer.chrome.com/docs/extensions/reference/permissions-list)**。

## 核心功能

### 记录工作流（经典侧面板）

在经典侧面板中，您可以通过自己记录步骤来教 Claude 一个工作流，Claude 会学会重复这些步骤。这对于遵循相同模式的重复浏览器任务很有用。当侧面板作为 Cowork 会话运行时，录制功能不可用。要在经典侧面板中记录工作流：

1. 点击扩展程序面板中的录制图标。

2. 执行您希望 Claude 学习的步骤。

3. 完成后停止录制。

4. 将工作流保存为快捷方式以供将来使用。

### 控制台日志

Claude 现在可以读取浏览器控制台输出，包括错误、网络请求和 DOM 状态。这帮助开发人员在不离开浏览器的情况下识别和调试问题。

### 计划任务

设置定期浏览器任务以按您的计划自动运行。设置一次，Claude 就会从那里处理——每天、每周、每月或每年。您可以通过点击扩展程序面板右上角的时钟图标来计划您的 Claude in Chrome 快捷方式自动运行。

### 多标签页功能

Claude 可以同时管理多个浏览器标签页。将标签页拖到 Claude 的指定标签页组中，使 Claude 能够一次查看和交互所有分组的标签页——无需手动在标签页之间切换来编译信息。

### 增强的网站导航

Claude 内置了如何导航流行平台的知识，包括 Slack、Google Calendar、Gmail、Google Docs 和 GitHub。简单的命令如"安排会议"或"更新文档"无需详细的分步说明即可工作。我们正在不断扩展 Claude 的特定网站功能。

### 使用 1Password 登录

当任务需要登录时，Claude 可以从 1Password 请求登录凭证，而不是在登录页面停止。您可以通过生物识别方式批准每个请求，1Password 会直接填充凭证，因此 Claude 永远看不到您的密码或一次性代码。1Password for Claude 在 macOS 上处于测试版。在 **[Claude 的 1Password 入门](https://support.claude.com/en/articles/15936181)** 中了解更多信息。

### 后台工作流

Claude 处理复杂的多步骤工作流，即使您切换标签页也能继续工作（只要 Chrome 保持打开）。启用通知以在 Claude 需要权限或完成任务时接收提醒，让您可以专注于其他工作，同时 Claude 在后台处理任务。

### 视觉上下文共享

通过上传图像或捕获特定屏幕区域的截图，直接与 Claude 共享视觉信息。指向 Claude 确切的按钮、字段或细节——比用文字描述复杂布局快得多。

### 图像上传

给 Claude 一张图像并告诉它上传到哪里，无论是费用报告、表单附件还是图片上传。

### 快捷方式

将您最有效的提示保存为快捷方式，并立即重复使用这些经过验证的工作流：

1. 制作出有效的提示后，将其保存为快捷方式。

2. 通过在聊天中输入"/"来访问您保存的快捷方式。

3. 选择您的快捷方式以立即应用相同的说明。

4. 通过扩展设置编辑或删除快捷方式。

您还可以安排快捷方式来自动化重复任务。

### 上下文建议

根据您访问的网站获取提示建议和有用的提示，这样您总是有一个与 Claude 的起点。

## 适用于团队和企业用户

如果您在团队或企业计划上的 Chrome 中使用 Claude，您的管理员可能已配置影响您体验的设置：

- **扩展可用性：**您的管理员控制是否为您的组织启用该扩展。

- **网站访问：**您的管理员可以使用允许列表和阻止列表限制 Claude 可以访问的网站。

如果您无法安装或使用该扩展，请联系您组织的管理员。有关管理员文档，请参阅 **[Chrome 中的 Claude 管理员控制](https://support.claude.com/en/articles/13065128-claude-for-chrome-admin-controls)**。
