# 我如何使用游乐场？

游乐场使开发者能够直接在 Claude 控制台中试用 Claude 模型和 API 功能，但不支持保存提示历史记录或评估提示。游乐场替代了之前用于在 Claude 控制台中创建和测试提示的工作台。

## 什么是游乐场？

游乐场直接基于公共 **[Messages API](https://platform.claude.com/docs/en/build-with-claude/working-with-messages)** 构建，因此您在游乐场中构建的请求与您在代码中发送的请求相同。

用它来：

- 在编写任何代码之前试用模型或新的 API 功能

- 迭代提示并检查完整响应

- 了解 API 请求和响应的结构

- 将您的工作导出为可在您自己的应用程序中运行的代码片段

游乐场不会在 Anthropic 的服务器上存储您的提示或对话。您当前的草稿保留在您的浏览器中，您可以转到 “代码” 选项卡来保存任何请求的副本。

## 打开游乐场

1. 登录到 **[Claude 控制台](https://platform.claude.com/)**。

2. 转到游乐场 (platform.claude.com/playground)。

3. 如果您的组织使用工作区，请选择您要使用的工作区。

## 编写并运行请求

1. 在提示区域中输入用户消息。您也可以添加系统提示来设置说明或上下文。

2. 点击 “运行” 来发送请求。

3. 查看 Claude 的响应，以及为请求显示的令牌计数和使用情况。

4. 编辑您的提示并再次运行它以继续迭代。

游乐场还包括您可以加载和修改的示例模板。

## 选择模型并调整设置

使用模型选择器在 Claude 模型之间切换，并打开模型设置来调整温度和最大输出令牌等参数。

使用不同的模型或设置运行相同的提示是快速查看响应如何变化的方法。当您考虑使用 Messages API 构建应用程序时，使用游乐场来了解模型的强大功能。

## 使用工具和结构化输出

将工具定义添加到您的请求以测试工具使用，并使用结构化输出让 Claude 以您定义的形状返回数据。游乐场在响应中显示工具调用和工具结果，因此您可以准确看到它们在 API 中的表示方式。

## 查看原始请求和响应

游乐场可以显示原始 API 请求和响应，包括完整的消息结构、停止原因和使用情况。这与您的应用程序发送和接收的形状相同，是尝试 Messages API 功能的实用方法。

## 将您的工作转换为代码

点击 “代码” 切换来将您当前的请求导出为代码片段。该片段准确反映您在游乐场中测试的内容，因此您可以将其粘贴到您的项目中并使用您自己的 API 密钥运行它。

我们文档中的代码示例包括 “在游乐场中打开” 选项，它将示例加载到游乐场中，以便您可以运行和修改它。

## 常见问题

### 工作台发生了什么？

**工作台现已停用。**游乐场替代它用于在控制台中试用 Claude 模型和 API 功能。  它不支持保存提示历史记录或评估提示。

### 工作台和游乐场之间有什么区别？

游乐场是在控制台中试用 Claude 模型和 API 功能的更简单、无状态的方式。主要区别是它现在：

- 它不会在 Anthropic 的服务器上存储您的工作。您当前的草稿保留在您的浏览器中，您可以将任何请求导出为代码。使用工作台（旧版本），您能够保存提示、提示历史记录和运行评估。

- 它直接基于公共 Messages API 构建并显示完整的请求和响应，因此您看到的内容与您的代码发送和接收的内容相匹配。

- 保存的提示、提示版本、评估和提示共享不是游乐场的一部分。使用旧版本中的导出功能来下载您的数据。
