# Chrome 中的 Claude 故障排除

本文帮助您解决 Chrome 中 Claude 的常见问题，并说明如何提供反馈。

## 可用性

Claude in Chrome 可在付费计划（Pro、Max、Ultra、Team 和 Enterprise）上使用，在 Chrome 侧边栏、Claude Cowork 和 Claude Code 中可用。侧边栏作为 Claude Cowork 会话运行。在 Enterprise 计划上，这需要所有者启用 Claude in Chrome 和云中的 Cowork；在此之前，侧边栏使用经典体验。

## 侧边栏的外观与以前不同

在 Pro、Max、Ultra 和 Team 计划上，以及在管理员已启用的 Enterprise 计划上，侧边栏现在作为 Claude Cowork 会话运行，因此它使用与网络和桌面上的 Cowork 相同的界面。您的对话已保存到您的历史记录中，可以在您的其他设备上重新打开。Cowork 侧边栏还默认为"自动批准"模式，因此 Claude 持续工作，仅在需要您批准的操作时暂停。

## 我看不到 Cowork 侧边栏

如果您使用的是 Enterprise 计划，Cowork 侧边栏需要您的管理员为您的组织启用云中的 Cowork 和 Claude in Chrome。请联系您的管理员，或参阅 **[Claude in Chrome 管理员控制](https://support.claude.com/en/articles/13065128)**。

## Claude 无法看到网页

- 刷新页面并确保扩展程序已启用。

- 检查您是否已为当前网站授予权限。

- 某些 JavaScript 繁重的网站可能需要一段时间才能完全加载。

## 操作无法正常工作

- 确保您使用的是最新版本的 Chrome。

- **[禁用其他扩展程序](https://support.google.com/chrome_webstore/answer/2664769?hl=en)**，这些扩展程序可能会干扰网页交互。

- 尝试刷新页面并重新开始任务。

## 扩展程序无法安装或登录

- 验证您有有效的付费计划订阅（Pro、Max、Ultra、Team 或 Enterprise）。

- 如果您使用的是 Team 或 Enterprise 计划，请与您的管理员确认已为您的组织启用该扩展程序。

- 清除 claude.ai 的浏览器缓存和 Cookie（请参阅 **[从网站删除 Cookie](https://support.google.com/chrome/answer/95647?sjid=5857968454187791521-NC#zippy=%2Cdelete-cookies-from-a-site)**）。

- 尝试登出并重新登录您的 Claude 账户。

## 性能问题

- 关闭不必要的标签页以释放浏览器资源。

- 考虑将复杂任务分解为更小的步骤。

## Claude 无法访问网站

- 检查您是否已为该网站授予权限（请参阅 **[Chrome 中的 Claude 权限指南](https://support.claude.com/en/articles/12902446-claude-for-chrome-permissions-guide)**）。

- 该网站可能属于 Claude 的默认阻止类别（金融服务、银行、投资平台、加密货币交易所、成人内容、盗版内容）。

- 如果您使用的是 Team 或 Enterprise 计划，您的管理员可能已限制对此网站的访问。请联系您的管理员了解更多信息。

## 扩展程序无法连接到 Claude Desktop 或 Claude Code

- 首先，如果 Chrome 扩展程序无法连接到 Claude Code 或 Claude Desktop，请重新启动或更新它。

- 如果 Claude in Chrome 切换在您的桌面应用 Connector 设置中未激活，请重新启动或更新 Claude Desktop。

- 如果扩展程序无法连接到 Claude Code，请重新启动或更新它。

---

## 使用限制

使用限制适用于不同的界面，因此在 Chrome 中使用 Claude 将计入适用于 Claude 或 Claude Code 的相同计划限制。浏览器交互比与 Claude 的常规聊天计算量更大，因此您可以预期该扩展程序会使用更多的限制。通过长期运行的工作流功能，任务可以继续进行较长时间，这可能会使用更多的使用配额。
