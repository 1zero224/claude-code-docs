# 使用企业搜索

企业搜索功能适用于团队计划和企业计划的用户。

企业搜索为您添加了一个专用项目，用于在您组织的知识源中进行搜索，具有优化的说明和无缝的连接器集成。

## 什么是企业搜索？

我们添加了一个预配置的“询问您的组织”**[项目](https://support.claude.com/en/articles/9517075-what-are-projects)**，它会显示在您的侧边栏中。此项目专为在您公司的工具和数据源中实现统一知识访问而设计。此专用工作区提供：

- **引导式设置：**用于连接您的工作应用的简单入门流程。

- **组织范围内的可用性：**在所有者完成初始设置流程后，可供您组织的所有成员使用。

  - 所有者可以控制哪些应用连接到该项目。

  - 用户需要先与连接的应用进行身份验证，然后才能开始使用它们。

- **优化的说明：**由 Anthropic 维护的专门系统提示，用于有效搜索。

- **统一访问：**在一个位置搜索多个数据源（Slack、Microsoft 365 等）。

## 开始使用

### 对于所有者

企业搜索项目在管理员设置中默认为所有团队和企业计划组织启用，但所有者需要完成此初始设置流程，其他成员才能使用它：

1. 在屏幕左侧的菜单中点击“询问您的组织”。

2. 点击“为您的组织设置”按钮继续，或点击“禁用”为您的团队关闭该项目。

3. 如果设置项目，系统会提示您将某些工具连接到该项目。

  1. 您需要为**文档**和**聊天**各选择一个连接器；**电子邮件**是推荐的但可选的。

  2. 只有启用的连接器才能在企业搜索项目中使用。

4. 点击“+ 添加更多”来设置您的团队需要的任何其他工具。

  1. 选择“选择另一个 MCP”打开连接器目录，或“+ 添加自定义连接器”

5. 完成后点击“下一步”。

6. 在最后一个屏幕上，您可以编辑项目的名称。格式将为“询问 [名称字段]，”因此您在此处输入的内容将影响左侧面板上显示的内容。

7. 输入描述，然后点击“完成设置。”

如果您决定在设置后停止使用该项目，所有者需要手动禁用此功能以在组织范围内将其从用户账户中删除：

1. 导航到**[组织设置 > 功能](https://claude.ai/admin-settings/capabilities)**。

2. 找到“询问您的组织”

3. 点击“禁用”按钮关闭该功能。

### 对于用户

当为您的组织启用此功能时，企业搜索项目将默认在您的侧边栏中加星标。

**首次设置：**

1. 在侧边栏中点击“询问 {org name}”项目。

2. 按照引导式入门流程连接到推荐的服务。

3. 使用您想要搜索的服务进行身份验证（Slack、Google、Microsoft 365）。

  1. 启用的连接器越多，您的搜索结果就越全面。

4. 开始向 Claude 提问有关您组织知识的问题。

## 自定义您的企业搜索项目

**连接其他工具：**

初始设置后，您可以通过在**说明**部分中点击“连接”并允许访问模态框中显示的工具和连接器，在您的搜索项目中启用其他连接器。

**取消加星标或隐藏项目：**

1. 点击侧边栏中项目旁边的“...”

2. 选择“取消加星标”

**调整连接的工具：**

1. 打开搜索项目。

2. 在左下角点击“搜索和工具”。

3. 启用或禁用特定连接器。

4. 更改适用于项目中的新对话。

## 企业搜索如何工作？

当您在组织的专用项目中提出问题时，Claude 会在所有连接的数据源中搜索，以生成全面、引用充分的响应。

**示例查询：**

- “我们公司的远程工作政策是什么？”

- “总结关于第四季度产品路线图的讨论。”

- “查找有关我们客户入职流程的信息。”

- “上周领导力会议的关键决策是什么？”

Claude 将搜索您连接的工具——例如 SharePoint 文档、Slack 对话、Gmail 线程和 Google Drive 文件——并将信息综合为一个统一的响应，包含源引用。

## 比较企业搜索与标准项目

|           | **项目**    | **企业搜索**               |
| --------- | --------- | ---------------------- |
| **系统提示**  | 用户可自定义    | 由 Anthropic 管理（针对搜索优化） |
| **用途**    | 通用工作区     | 专门用于组织知识搜索             |
| **连接器设置** | 每次手动配置    | 引导式入职，包含推荐的连接器         |
| **可用性**   | 用户创建      | 为组织自动配置                |
| **更新**    | 静态，除非手动更改 | 来自 Anthropic 的自动改进     |

## 用例

企业搜索特别适用于：

**高管简报：**

- “我不在的时候昨天发生了什么？”

- “总结整个业务的关键更新”

**项目研究：**

- “客户选择我们竞争对手的主要原因是什么？”

- “基础设施项目目前的阻碍是什么？”

**政策和流程问题：**

- “我们的休假政策是什么？”

- “我如何提交费用报告？”

**入职：**

- “我们的身份验证系统如何工作？”

- “我应该与谁交流以了解 X？”

**绩效评估：**

- “查找与 [employee] 第三季度项目相关的讨论和文档”

- “总结团队对平台计划的贡献”

## 隐私和权限

- **权限感知：**您只能看到您在原始系统中有权访问的数据的搜索结果。对于使用共享凭证的自定义连接器，结果反映该凭证可以访问的内容。

- **连接器的用户级身份验证：**每个用户使用自己的凭证进行身份验证以启用连接器，除非自定义连接器设置了共享凭证（如 API 密钥）。使用该连接器的所有人都使用相同的凭证访问服务。

- **无外部索引：**搜索结果通过进行 MCP 调用生成。来自连接服务的数据不会在我们的系统中编制索引以用于查询。

- **数据安全：**所有数据访问遵循您组织的现有安全控制和政策。

## 最佳实践

**明确指定来源：**与其说 “查找有关产品发布的信息，”不如说 “在 Slack 和 Google Drive 中搜索有关第四季度产品发布的讨论。”

**使用日期范围：**“总结上周关于预算审查的电子邮件。”

**合并多个来源：**“汇编来自 SharePoint 文档、Slack 讨论和会议记录中关于我们招聘流程的信息。”

**将复杂查询分解为步骤：**为了进行彻底的研究，请要求 Claude 一次搜索一个来源，然后综合发现。

## 故障排除

### 搜索项目未在我的侧边栏中显示

- 验证您使用的是团队或企业计划。

- 让所有者检查是否为您的组织启用了此功能。

- 尝试刷新浏览器或退出后重新登录。

### 我无法连接推荐的连接器

- 检查所有者是否在组织级别启用了连接器。

- 确认您拥有该服务的有效账户。

- 确保您的组织政策不会阻止第三方集成。

- 确保您已正确完成身份验证流程。

- 如果问题仍然存在，请联系您的管理员或 IT 部门。

### 我的搜索结果似乎不完整

- 验证您已通过入职流程连接了相关服务。

- 检查您是否已成功通过每个连接服务的身份验证。

- 确认您有权访问原始系统中的内容。

- 尝试更具体地说明要搜索的工具或所需的信息。

- 使用日期范围或特定关键词缩小搜索范围。

- 将复杂查询分解为更小、更集中的部分。

### 连接的工具无法正常工作

- 重新访问 **[设置 > 连接器](https://claude.ai/settings/connectors)** 以验证身份验证状态。

- 尝试断开连接然后重新连接有问题的连接器。

- 检查连接器是否最近在组织级别被禁用。

### Claude 在我的搜索项目中响应缓慢 – 我应该怎么办？

**可能的原因：**

- 跨多个大型数据源搜索需要时间

- 网络连接问题

- 连接服务上的负载过高

**尝试：**

- 缩小搜索范围

- 一次搜索一个工具

- 更具体地说明您要查找的内容

### 如果连接器停止工作会发生什么？

如果连接器失败：

1. 专用项目将搜索其余连接的工具。

2. 您将看到有关失败连接器的通知。

3. 尝试通过 **[设置 > 连接器](https://claude.ai/settings/connectors)** 重新连接该工具。

4. 如果问题仍然存在，请联系组织所有者。

## 常见问题

### 我可以向搜索项目添加自己的自定义连接器吗？

可以。您可以添加通过 **[设置 > 连接器](https://claude.ai/settings/connectors)** 提供的连接器，如果您的组织允许，您也可以添加自定义连接器。引导式入职会推荐一些连接器，但您不限于这些。

有关更多信息，请参阅 **[使用远程 MCP 开始使用自定义连接器](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)**。

### 我可以在移动或桌面应用上使用企业搜索吗？

搜索项目在 Claude Desktop 上完全可用，但在 Claude Mobile (iOS/Android) 上不可用。

### 使用搜索项目会计入我的使用限制吗？

是的。项目内的搜索查询计入您计划的标准使用限制，就像其他项目和对话一样。

### 此功能与使用研究有何不同？

**研究：**

- 专为特定主题的深入、多步骤研究而设计

- 自动执行广泛的网络和内部数据搜索

- 耗时较长，可能会使用更多消息

- 最适合复杂研究项目

**企业搜索：**

- 针对快速知识检索进行了优化

- 搜索您已连接的内部来源

- 更快地找到特定信息的响应速度

- 最适合日常知识访问

如需更多指导，请参阅 **[何时应使用网络搜索、扩展思考和研究？](https://support.claude.com/en/articles/11095361)**

### Claude 在我的搜索项目中可以访问哪些数据？

Claude 只能访问项目中的数据：

1. 来自您单独添加并验证的连接器。

2. 您有权在原始系统中查看。

3. 基于您的搜索查询可能相关的数据。

### 我的组织中的每个人都会看到相同的搜索结果吗？

不会。搜索结果具有权限感知功能。您只能看到您有权在每个连接系统中访问的数据。例外情况是使用共享凭证（如 API 密钥）的自定义连接器，其中每个人都可以看到该凭证可以访问的内容。

### 我的搜索历史记录对其他人可见吗？

不会。您的搜索项目中的对话仅对您私密，除非您选择手动共享，就像与 Claude 的其他对话一样。但是，在企业计划中，对话遵循您的 **[组织的数据保留政策](https://support.claude.com/en/articles/10440198-custom-data-retention-controls-for-enterprise-plans)**。

### 搜索结果保留多长时间？

搜索结果与其关联的聊天一起保留。您可以通过删除关联的对话来删除搜索数据。企业组织可能有适用于所有对话（包括搜索项目中的对话）的自定义数据保留政策。请咨询您的组织所有者了解详情。
