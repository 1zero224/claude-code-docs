# 分享和取消分享聊天

了解如何创建与 Claude 聊天的可分享链接。虽然聊天默认始终是私密的，但您可以轻松创建对话快照并通过直接链接分享。本指南将引导您完成分享和取消分享聊天的过程。

## 分享聊天

要分享聊天：

1. 点击聊天右上角的“分享”按钮。

2. 点击弹出窗口中的“分享”按钮以创建可分享链接。

聊天被分享后，任何拥有该链接的人都可以查看聊天快照。聊天快照包括分享聊天前发送的所有消息，包括任何工件。分享聊天后发送的所有消息默认将保持私密。但是，如果您取消分享聊天并再次分享，快照将更新以包含任何新消息。

**注意：**Team 和 Enterprise 计划的用户无法公开分享聊天。默认情况下，他们只能与同一组织的其他成员分享。管理员也可以允许他们邀请组织外的特定人员。详细了解**[与特定人员分享聊天](https://support.claude.com/en/articles/16762496-share-a-chat-with-specific-people#h_c3551baed0)**和**[项目可见性和分享](https://support.claude.com/en/articles/9519189-project-visibility-and-sharing)**。

### 分享包含文件或 MCP 集成的聊天

分享包含上传文件或 MCP（模型上下文协议）集成的聊天时，了解共享快照中包含的信息很重要。

**附加文件：**如果您分享包含附加文件的聊天，该文件本身不会包含在共享快照中，并保持私密。只有对话和 Claude 的回复对拥有链接的任何人可见。

**MCP 工具调用：**分享使用 MCP 集成的聊天时，从 MCP 工具调用检索的原始数据在共享快照中保持隐藏。只有最终聊天输出和对话对查看者可见。底层工具调用数据保持私密。

这样可以将您的附加文件和原始工具数据排除在快照之外。

如果 Claude 在个人财务中使用了您的关联账户，快照会显示您的消息和 Claude 的回复，包括您账户中的任何数据。它还可以显示 Claude 创建的图表或工件，包括数据。详细了解**[在 Claude 中使用个人财务](https://support.claude.com/en/articles/18185620-use-personal-finance-with-claude)**。

## 取消分享聊天

要取消分享聊天：

1. 导航到“分享”菜单。

2. 点击可见性下拉菜单。

3. 将聊天从“公开”更改为“私密”以禁用直接链接。
