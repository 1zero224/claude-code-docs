# Team 和 Enterprise 计划的 Artifacts 管理员指南

本指南适用于 Team 和 Enterprise 计划的所有者和主要所有者，说明如何为您的组织启用 artifacts、选择用户可以从哪些模板开始、控制谁有权访问，以及管理 artifacts 是否可以在组织外部共享。

## 为您的组织启用 artifacts

要更改组织设置，您需要是所有者或主要所有者，或者拥有自定义角色（Enterprise 计划）且具有相应的管理员权限。

1. 首先在 **[组织设置 > 功能](https://claude.ai/admin-settings/capabilities)** 中启用 “云代码执行和文件创建”。

2. 导航到 **[组织设置 > Artifacts](https://claude.ai/admin-settings/artifacts)**。

3. 启用 **Artifacts**。

这允许用户创建 artifacts 并将其发布到可共享的 Anthropic 托管页面，以及在您的组织内共享 artifacts。

**重要提示：**关闭 **Artifacts** 会阻止所有人在 Claude 中打开、编辑、下载或共享您组织的 artifacts，包括创建它们的用户。他们已经共享的链接将停止工作，直到您重新启用 **Artifacts**，包括公开链接和电子邮件邀请链接。关闭 **Artifacts** 不会删除任何内容，但没有人可以打开 artifact 来重新启动它。旧版 artifacts 和实时 artifacts 继续工作，已共享给它们或聊天或 Cowork 文件的链接也继续工作。通过将其中一个重新发布为 artifact 而共享的链接也会停止工作。

## 选择用户可以从哪些模板开始

模板是用户在创建 artifact 时选择的起点。

| **模板**      | **用户可以用它做什么**                                           |
| ----------- | ------------------------------------------------------- |
| 幻灯片         | 启动可以演示的演示文稿、使用设计系统重新设计样式，以及导出到 PowerPoint               |
| 设计          | 将屏幕、流程和图形布局为可手动编辑的画板                                    |
| 设计系统        | 一次性捕获颜色、字体和组件，以便 Claude 将它们应用于新演示文稿和设计                  |
| 文档          | 启动团队阅读、评论和就地编辑的文档，同时 Claude 保持其最新状态                     |
| 数据          | 从数据仓库或连接的应用程序构建仪表板、数据故事、叙述性短视频和数据信函，每个图表显示其查询和上次刷新时间    |
| Motion（测试版） | 从其内容制作动画解释器、图表和演练，并将其导出为 MP4 视频。仅限 Team 和 Enterprise 计划 |
| Sheets（测试版） | 使用 Claude 构建电子表格，具有跨选项卡的公式，并一起编辑相同的单元格                  |
| 白板（测试版）     | 在共享板上与 Claude 一起思考想法                                    |

**启用模板：**

1. 导航到 **[组织设置 > Artifacts](https://claude.ai/admin-settings/artifacts)**。

2. 在 **模板** 下，启用您想要提供的模板。

**注意：**关闭模板不会影响用户已使用该模板创建的 artifacts。

**默认值：**

- **文档、幻灯片和设计：**在 Team 计划上默认启用。在 Enterprise 计划上，它们在 2026 年 10 月 15 日默认启用。如果您不想启用它们，请在此之前关闭其中任何一个。

- **Motion：**在 Team 计划上默认启用，在 Enterprise 计划上默认关闭。

- **数据：**在 Team 计划上默认启用。在 Enterprise 计划上，它在 2026 年 11 月 20 日默认启用。您可以更早启用它。

- **Sheets 和白板（测试版）：**在 Team 计划上默认启用，在 Enterprise 计划上默认关闭，直到所有者启用它们。

## 管理 Claude Data 测试版功能

认证查询和实时共享在 **模板** 中的 **数据** 下有自己的设置。当 **数据** 关闭时，这些设置被隐藏。两者在 Team 计划上默认启用，在 Enterprise 计划上默认关闭。

| **设置**   | **它控制什么**                         |
| -------- | --------------------------------- |
| **认证查询** | 用户是否可以认证查询，以便 Claude 在您的组织中重复使用它们 |
| **实时共享** | 仪表板是否可以向您组织中没有该连接器的人显示共享编辑器的连接结果  |

启用 **认证查询** 时，选择存储认证查询的市场和插件。如果您清除该选择，现有认证将消失。如果您再次选择相同的插件，它们会恢复。

如果您关闭实时共享，打开仪表板的人会被要求自己连接数据源。

在 **[Claude Data 入门](https://support.claude.com/en/articles/17454700)** 中了解更多信息。

## 独立 Claude Design（位于 claude.ai/design）

独立的 Claude Design 在 **claude.ai/design** 将于 2026 年 12 月 14 日关闭。在此之前，它在 **[组织设置 > Claude Design](https://claude.ai/admin-settings/claude-design)** 中有自己的设置，与 **Design** 模板分开。用户现有的项目将保留在 **claude.ai/design** 中直到关闭，其中最多 60 个项目也会显示在 **Artifacts** 标签页中。

移至 Claude 的项目或设计系统会成为 artifact。要让用户移动他们的项目和设计系统，请为您的组织启用 **Artifacts** 和 **Design systems**。在具有自定义角色的企业计划中，每个用户的角色也需要这些功能。在 **[从独立 Claude Design 迁移到 Claude](https://support.claude.com/en/articles/17440474)** 中了解更多信息。

## 管理组织外部的共享

两个独立的设置控制用户可以在组织外部共享的内容。启用其中一个不会启用另一个。有关用户看到的内容以及哪些 artifact 无法离开您的组织，请参阅 **[共享 artifact](https://support.claude.com/en/articles/9547008-publish-and-share-artifacts)**。

### 外部共享

**外部共享**让用户与任何拥有链接的人共享 artifact。

1. 导航至 **[组织设置 > Artifacts](https://claude.ai/admin-settings/artifacts)**。

2. 启用 **外部共享**。

**重要提示：**关闭 **外部共享**也会停止现有公开链接的工作，直到您重新启用它，除非您单独允许的 artifact。

### 允许单个 artifact 的外部共享

当 **外部共享**关闭时，您仍然可以让特定 artifact 与任何拥有链接的人共享。

1. 导航至 **[组织设置 > Artifacts](https://claude.ai/admin-settings/artifacts)**。

2. 在 **已发布的 artifact** 下，找到该 artifact。它必须已与您的组织共享或邀请了相关人员才能显示在此处。

3. 打开 artifact 的菜单并选择 “允许外部共享。”

4. 通过选择 “允许外部共享” 来确认。

该 artifact 的所有者随后可以与任何拥有链接的人共享它。**外部共享**对您组织中的所有其他 artifact 保持关闭状态。

### 组织外部的电子邮件邀请

**组织外部的电子邮件邀请**让用户通过电子邮件邀请组织外部的特定人员访问 artifact。这是与 **外部共享**分开的设置，因此启用其中一个不会启用另一个。

1. 导航至 **[组织设置 > Artifacts](https://claude.ai/admin-settings/artifacts)**。

2. 启用 **组织外部的电子邮件邀请**。

**重要提示：**关闭 **组织外部的电子邮件邀请**会阻止用户已邀请的人员访问，直到您重新启用它。已接受的邀请不会被删除，待处理的邀请仍会在发送后 30 天过期。

被邀请访问使用 Claude Docs 创建的文档的人员也可以要求他们自己的 Claude 对其进行处理，在他们被授予的访问权限范围内。他们的 Claude 读取的内容会成为他们账户中聊天的一部分，Claude 可能会将其中的简短事实保存到他们的记忆中。这没有单独的设置：关闭 **组织外部的电子邮件邀请**会阻止这些人员和他们的 Claude 打开该文档。

### 查看和移除外部访问权限

1. 导航至 **[组织设置 > Artifacts](https://claude.ai/admin-settings/artifacts)**。

2. 在 **已发布的 artifact** 下，找到标记为 **组织外部共享**的 artifact。

3. 打开 artifact 的菜单并选择 “管理外部访问权限。”

4. 选择该人员旁边的移除按钮，然后通过 “移除访问权限”或 “移除邀请”进行确认。

所有者可以在此处移除人员，但无法更改其访问级别。

### 保留在您的组织内的内容

即使启用了这些设置，某些 artifact 也无法离开您的组织：

- 连接到其他网站的 artifact

- 包含仍在检查中或未通过检查的已上传文件的 artifact

其他 artifact（包括文档和使用连接应用或询问 Claude 问题的 artifact）在这些设置允许时可以离开您的组织：

- **通过链接：**当 **外部共享**启用或您已为该 artifact 允许时，任何拥有链接的人都可以打开它。以这种方式共享的大多数 artifact 无需 Claude 账户或登录即可打开。文档和表格仅对登录到 Claude 的人员打开，他们只能查看。从聊天共享的旧版 artifact 也需要 Claude 账户，某些其他 artifact 仅在访问者登录后才显示部分或全部内容。对于从组织外部打开链接或未登录的人员，连接的应用和 Claude 功能不起作用。

- **通过电子邮件邀请：**当 **组织外部的电子邮件邀请**启用时，您邀请的人员使用邀请地址登录到 Claude。此设置在团队计划中默认启用，在企业计划中默认关闭。某些组织无法邀请组织外部的人员，包括具有 HIPAA 就绪配置、CMEK、教育或 K-12 条款、零数据保留和编辑或混合部署的组织。

要将 artifact 保留在您的组织内，请关闭 **外部共享**和 **组织外部的电子邮件邀请**。您单独允许的 artifact 仍然可以通过链接共享。

了解有关 **[共享 artifact](https://support.claude.com/en/articles/9547008)** 的更多信息。

## 让用户查看谁在打开 artifact

**Artifact 状态**让用户查看您的组织中还有谁在打开 artifact，以及其中的实时活动。在 **[组织设置 > Artifacts](https://claude.ai/admin-settings/artifacts)** 中启用或关闭它。

它在团队和企业计划中默认启用，仅在为您的组织启用 **Artifacts** 时适用。

**注意：**关闭 **Artifact 状态**会立即应用于新页面加载，并在一小时内应用于已打开的标签页。

## 让 artifact 使用连接的应用

**启用 artifact 连接器**让用户使用从其连接的应用读取和写入的 artifact。每个用户连接自己的应用，即使在共享 artifact 中也是如此。例外是与实时共享共享的仪表板，它显示共享它的编辑者的连接结果。您可以为整个组织启用或关闭此功能，但无法限制 artifact 可以访问的应用。

1. 导航至 **[组织设置 > 功能](https://claude.ai/admin-settings/capabilities)**。

2. 在 **视觉效果**下，启用 **启用 artifact 连接器**。

## 控制将 artifact 安装为应用（测试版）

您可以在两个位置控制应用：组织设置和设备策略 (MDM)。如果它们不同，则应用更严格的设置。关闭设置时，打开的应用将关闭，它们启动的程序将停止，除了下面 **限制**中的情况。已安装的应用和人员授予的权限保持不变，如果您重新启用该设置，将再次工作。

### 组织设置（团队和企业计划）

转到 **[组织设置 > Artifacts](https://claude.ai/admin-settings/artifacts)**。如果这些设置还不存在，则测试版尚未到达您的组织。

| **设置**      | **允许的功能**                                             | **团队默认设置** | **企业默认设置** |
| ----------- | ----------------------------------------------------- | ---------- | ---------- |
| **作为应用安装**  | 用户可以将工件作为应用安装。需要**工件**功能。                             | 开启         | 关闭         |
| **应用权限**    | 应用可以请求通知、键盘快捷键、菜单栏或系统托盘项目，以及浮窗显示在其他窗口上方。需要**作为应用安装**。 | 开启         | 关闭         |
| **完全访问计算机** | 应用可以请求运行程序以及读取、修改或删除文件，无需每次都询问。需要**作为应用安装**。          | 关闭         | 关闭         |

- 更改最多需要约一小时才能生效。

- 这些设置仅在您的组织在 Claude 中被选中时适用。要同时覆盖公司计算机上的个人账户，请使用设备策略。

- 拥有客户管理的加密密钥 (CMEK) 或组织范围内零数据保留 (ZDR) 的组织从三个设置都关闭开始。零数据保留（组织范围内或仅限 Claude Code）不涵盖这些应用。

- 拥有 HIPAA 就绪配置或混合部署的组织无法启用这些设置。

- K-12 组织无法启用**完全访问计算机**，有些组织从三个设置都关闭开始。

### 设备策略 (MDM)

将密钥设置为 `false`（macOS）或 DWORD `0`（Windows）。这些密钥适用于计算机上的每个账户，只能关闭功能。

| **密钥**                            | **关闭**    |
| --------------------------------- | --------- |
| `isArtifactAppsEnabled`           | 已安装的应用    |
| `isArtifactAppPermissionsEnabled` | 应用权限和完全访问 |
| `isArtifactAppFullAccessEnabled`  | 完全访问      |

- **macOS：**在计算机级别的配置文件中使用域 `com.anthropic.claudefordesktop`。如果计算机级别和用户级别的配置文件都设置了某个密钥，计算机级别的值优先。

- **Windows：**使用 `HKLM\SOFTWARE\Policies\Claude`。一旦 `HKLM` 包含 Claude 值，Claude 将忽略 `HKCU` 下的值，因此请将所有 Claude 密钥保存在 `HKLM` 中。

- 这些密钥需要 macOS 上的 Claude Desktop 6.6395.1 或更高版本，以及 Windows 上的 6.6395.0 或更高版本。添加前请更新：在 Windows 上，不识别这些密钥的旧版本可能会关闭计算机使用功能。

- 关闭密钥最多需要约五分钟。重新启用需要重启 Claude Desktop。

- 设置任何密钥都会将计算机标记为受管理。除其他更改外，这会隐藏**发布渠道**设置，并关闭某些功能（如 WSL 会话），除非您允许它们。

了解更多关于**[Claude Desktop 企业配置](https://support.claude.com/en/articles/12622667-enterprise-configuration-for-claude-desktop)**的信息。

### 限制

- 离线的计算机可以保留其最后的组织设置。

- 应用启动的程序如果与应用分离，或当用户选择另一个组织时，可以继续运行。

- 在企业计划中，应用没有单独的功能。没有工件功能的自定义角色中的用户无法使用它们。

- 打开应用和访问检查被记录为**[合规 API](https://support.claude.com/en/articles/13015708-access-the-compliance-api)** 中的工件视图。安装、权限答案、应用在计算机上的操作以及这三个设置的更改不被记录。

- 由用户的另一个组织拥有的应用在用户选择该组织并重新安装应用之前，无法获得应用权限或完全访问。之前允许的应用权限可以保留到应用的下一个版本。

- 如果您限制登录到列出的组织（`forceLoginOrgUUID`），之前安装的应用仍会打开。

## 在企业计划中限制对特定组的访问

在企业计划中，自定义角色允许您为特定组而不是整个组织启用功能。组织设置是主开关，自定义角色是其下的按用户开关。如果功能在组织级别关闭，任何自定义角色都无法授予对其的访问权限。

涵盖工件的功能包括：

| **功能**              | **授予的权限**                                                                         |
| ------------------- | --------------------------------------------------------------------------------- |
| 工件                  | 在网页和 Claude Desktop 中从聊天创建工件，从 Claude Code 和 Cowork 创建和发布工件，以及在组织内共享聊天和 Cowork 工件 |
| 设计                  | 从设计模板开始创建工件                                                                       |
| 设计系统                | 创建和编辑设计系统                                                                         |
| 文档                  | 从文档模板开始创建工件                                                                       |
| 幻灯片                 | 从幻灯片模板开始创建工件                                                                      |
| Claude Design [独立版] | 访问 claude.ai/design 上的独立版 Claude Design                                           |
| 数据                  | 从数据模板开始创建工件                                                                       |
| 动画                  | 从动画模板开始创建工件                                                                       |
| 表格（测试版）             | 开始创建包含公式和格式的电子表格，您和 Claude 可以一起编辑                                                 |
| 白板（测试版）             | 开始创建白板，您的团队和 Claude 可以在其中一起绘制和整理想法                                                |

没有**工件**功能的用户仍然可以打开与他们共享的工件、对其进行评论，并在获得的共享级别（最高为贡献者）内更改其数据。贡献者可以使用工件、保存他们在其中输入的内容并进行评论，但无法编辑工件本身。没有该功能的用户如果被共享为编辑者，最多只能获得贡献者访问权限。他们无法创建、编辑、发布或共享工件。他们可能会在网页和 Claude Desktop 中看到“新工件”呈灰显状态，工具提示为“请联系您的管理员以请求访问此功能。”

详细了解**[在企业计划中管理自定义角色](https://support.claude.com/en/articles/13930452)**和**[在企业计划中设置基于角色的权限](https://support.claude.com/en/articles/13930458)**。

## 管理您组织的设计系统

与您组织中的所有人共享的设计系统列在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中的**设计系统**下，显示其所有者和上次更新时间。用户在开始新工件时会看到这些系统，默认系统会被预先选中。

### 限制谁可以管理设计系统

在工件中，任何有权访问设计系统的用户都可以创建一个、与特定人员共享，以及删除自己的系统，设计系统的所有者可以删除它。只有所有者或主要所有者才能与您组织中的所有人共享设计系统、设置组织默认值或删除与所有人共享的设计系统。

要与所有人共享他人的设计系统，所有者或主要所有者首先需要其创建者在共享对话框中以最高访问级别邀请他们。设计系统必须与所有人共享后才能设置为组织默认值。

在企业计划中，自定义角色控制谁可以创建设计系统。在角色的**功能**选项卡中的**工件**下打开或关闭**设计系统**。

从独立版 Claude Design 迁移的设计系统可能已与所有人共享。在那里不是私有的已发布设计系统会与您组织中的所有人共享，如果您组织的默认设计系统迁移，它也会成为工件中的默认值，除非您已经设置了一个。

**在独立版 Claude Design 中**

**Claude Design 管理员**权限仅适用于独立版 Claude Design 应用。它不允许任何人共享、设置为默认值或删除在工件中创建的设计系统。在独立版 Claude Design 中，企业计划可以为自定义角色中权限设置为“可管理”的用户保留以下功能

- **发布设计系统：**使其在整个组织中可用，以便任何人都可以将其附加到项目。

- **设置组织默认值：**选择新项目自动使用的设计系统。

- **删除设计系统：**从您的组织中永久删除它。

其他所有人仍然可以创建、编辑和使用任何已发布的设计系统。如果没有该权限的用户尝试发布、设置默认值或删除，他们会看到一条提示，指导他们联系管理员。

**要授予该权限：**

1. 导航到**[组织设置 > 角色](https://claude.ai/admin-settings/roles)**并创建或编辑自定义角色。

2. 在“管理员权限”选项卡中，在**产品管理员**下找到**Claude Design 管理员**并将其设置为“可管理。”

3. 将角色分配给一个组。该组中的用户将继承该权限。

4. 将每个用户的角色设置为“自定义。”

详细了解**[设置您的设计系统](https://support.claude.com/en/articles/14604397)**。

## 使用情况和计费

工件（包括设计、演示文稿和文档）计入每个用户的现有使用限制，与 Claude 的其余部分（包括 Claude Code）共享。没有单独的配额需要配置。

- **团队和基于座位的企业计划：**使用情况从每个用户的座位使用限制中扣除，包括会话和每周限制。管理员可以为需要更多的用户购买**[使用额度](https://support.claude.com/en/articles/12005970)**。

- **基于使用情况的企业计划：**使用情况按您组织的消费以标准 API 费率计费。组织、组和按用户支出限制适用。

## 监控使用情况

- **合规 API：**在对话和**工件**选项卡中创建的工件在工件级别记录。对于文档，文档本身的事件被记录，但文档内的活动（如编辑和评论）尚未记录。

- **Claude Data：**您可以看到每个共享的 Claude Data 工件及其所有者和可见性。在**组织设置 > 工件**中的**已发布工件**下，将**类型**筛选为**数据**。合规 API 记录 Claude Data 工件的创建、查看、编辑或删除时间，但不包括其内容。

- **分析：**这些分析仅涵盖 claude.ai/design，不包括在对话或**工件**选项卡中创建的设计。

- **审计日志：**独立版 Claude Design 不支持审计日志。

详细了解**[查看团队和企业计划的使用分析](https://support.claude.com/en/articles/12883420)**。

## 数据处理和隐私

当用户创建设计和文档时，他们可能会上传设计资源、品牌指南、截图和其他材料。

- 上传的资源会被持久存储，并遵循与其他 Anthropic 产品相同的**[数据保留和删除政策](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data)**（适用于组织）。

- 在企业计划上设置的自定义保留期可以涵盖工件，包括从独立 Claude Design 迁移的项目和设计系统。如果在该期间内没有人打开工件，可以将其永久删除。对于已迁移的项目或设计系统，该期间从迁移之日开始，并在有人打开或编辑工件时重新开始。详细了解**[为企业计划配置自定义数据保留控制](https://support.claude.com/en/articles/10440198)**。

- Claude Design 目前不支持数据驻留要求。

### 当有人离开您的组织时

从您的组织中移除某人（包括通过您的身份提供商），会同时移除他们对工件的访问权限。

当工件与某个群组共享时，访问权限遵循当前的群组成员资格。从群组中移除的人（包括通过您的身份提供商），会在更改同步后不久失去通过该群组的访问权限。如果工件还通过其他方式到达他们（例如直接与他们共享或通过另一个群组共享），他们将保留访问权限。

### 具有特殊配置的组织

- **HIPAA 就绪配置：**在接受条款后，所有者可以在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中启用 Claude Docs、Slides、Design、Data 和 Motion。这些不在您的业务关联协议 (BAA) 的保护范围内，因此请勿在其中放置受保护的健康信息 (PHI)。

- **CMEK：**工件可用。

- **Claude Code 零数据保留 (ZDR)：**大多数工件类型（Claude Docs 除外）在聊天和 Cowork 中可用，不受 ZDR 保护。它们在 Claude Code 中不可用。

- **教育和 K-12 组织：**电子邮件邀请不可用。

## 常见问题

### 如果只有部分用户需要某项功能，我是否需要为整个组织启用它？

是的。必须在组织级别启用该设置，然后自定义角色才能控制按用户的访问权限。如果在组织级别关闭某项功能，无论用户的角色如何，任何人都无法使用它。

### 我可以将模板限制为特定部门吗？

可以，在企业计划上使用自定义角色。每个模板都有自己的功能，独立 Claude Design 的功能与**Design** 模板的功能分开。

### 外部共享和电子邮件邀请有什么区别？

**外部共享**允许用户发布工件，组织外的任何人都可以通过链接打开。**组织外的电子邮件邀请**允许用户邀请组织外的特定人员访问特定工件。每个都有自己的设置。

### 谁可以与所有人共享设计系统、设置默认值或删除设计系统？

在工件中，组织所有者或主要所有者可以与组织中的所有人共享设计系统并设置或移除组织默认值。具有用户、管理员或自定义角色的成员无法执行此操作。设计系统的所有者（通常是创建者）可以删除它，组织所有者或主要所有者可以删除与所有人共享的设计系统。

**Claude Design Admin** 权限仅适用于独立 Claude Design 应用。它不允许任何人共享、设置为默认值或删除在工件中创建的设计系统。

### 用户可以导出他们创建的内容吗？

可以。有关更多信息，请参阅**[查看和导出](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them#h_71205f2c4b)**（位于**[什么是工件以及如何使用它们？](https://support.claude.com/en/articles/17153992)**中）
