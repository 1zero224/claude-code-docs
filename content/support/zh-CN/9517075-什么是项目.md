# 什么是项目？

**注意：**项目的新版本现已在测试版中推出，从 Claude Code 开始分阶段推出。我们已开始为部分 Pro、Max 和 Ultra 用户迁移现有项目到新版本。请参阅下方的**[项目的新版本（测试版）](#h_e9fb2a161e)**。

项目允许您创建自包含的工作区，每个工作区都有自己的聊天历史记录和知识库。在每个项目中，您可以上传文档、提供上下文，并与 Claude 进行有针对性的聊天。

所有用户（包括免费 Claude 账户用户）都可以使用项目。免费用户最多可以创建五个项目。

## 项目的新版本（测试版）

我们正在分阶段推出项目的新版本，从 Claude Code 开始。在新版本中，一个项目就是一次对话：您根据需要说出您的需求，Claude 会将工作分解为在云中运行的并行线程。Claude 会告诉您哪些工作已完成，哪些工作在等待您，如果您关闭笔记本电脑，这些线程会继续运行。每个线程都从项目的文件、存储库、说明和记忆开始，项目的库会收集您添加的文件和 Claude 生成的文件。

### 谁可以使用

新版本现已在测试版中提供给使用 Claude Code 的部分 Pro、Max 和 Ultra 订阅者，以及我们已将现有项目迁移到新版本的部分 Pro、Max 和 Ultra 用户。如果您有权访问，您将在 **[claude.ai/code](https://claude.ai/code)** 的侧边栏和 Claude 桌面应用的代码选项卡中看到

### 您现有的项目

我们已开始为部分 Pro、Max 和 Ultra 用户迁移现有项目到新版本。迁移过程中不会丢失或删除任何内容。您项目中的所有内容都会随之迁移：您的说明、文件、完整聊天历史记录和计划任务。您将从离开的地方继续。如果您在过去 30 天内使用过现有项目，我们会在迁移您的项目之前向您发送电子邮件。聊天和 Cowork 中的其他现有项目目前仍保留在当前版本，我们将在推出范围扩大时迁移它们。

### 使用情况

项目像 Claude 的任何其他使用一样从您的计划使用量中扣除，同时运行多个线程会更快地消耗使用量。

## 项目知识

项目的一个关键优势是能够为您与 Claude 的聊天提供上下文。您可以将相关文档、文本、代码或其他文件上传到项目的知识库，Claude 将使用这些内容来更好地理解您在该项目中进行的各个聊天的上下文和背景。

此外，您可以为每个项目定义项目说明，以进一步定制 Claude 的响应。例如，指示 Claude 使用更正式的语气或从特定角色或行业的角度回答问题。

## 使用 RAG 增强项目知识

使用 RAG 增强项目知识仅适用于拥有付费 Claude 计划（Pro、Max、Ultra、Team 或 Enterprise）的用户。

使用付费计划时，您的项目会自动扩展以通过检索增强生成 (RAG) 处理大量内容。当您的项目知识接近上下文限制时，Claude 会无缝启用 RAG 模式，将容量扩展最多 10 倍，同时保持响应质量。

有关利用扩展项目知识容量的更多信息，请参阅**[项目的检索增强生成 (RAG)](https://support.claude.com/en/articles/11473015-retrieval-augmented-generation-rag-for-projects)**。

## 协作和共享（仅限 Team 和 Enterprise 计划）

对于使用 Team 和 Enterprise 计划的用户，项目可以与您组织的其他成员共享，从而实现强大的协作和知识共享功能。共享系统包括：

**权限级别：**

- **可以查看：**成员可以查看项目内容、知识和说明，并在项目中聊天，但无法编辑。

- **可以编辑：**成员可以修改项目说明和知识、添加/删除成员、更新成员设置，并积极为项目做出贡献。

- **项目创建者可以：**

  - 与特定成员共享，而不是将项目设为完全私密或对整个组织公开。

  - 将之前创建的私密项目设为对整个组织可见。

**共享选项：**

- **个人共享：**通过电子邮件与特定团队成员共享项目。

- **批量共享：**使用电子邮件列表一次添加多个用户。

- **组织范围共享：**在创建项目时或之后将项目提供给组织中的所有人。

  - **注意：**如果所有者或主要所有者禁用公开项目，组织范围共享将在创建项目时和之后都被禁用。

- **管理员控制：**所有者可以为您的组织关闭项目共享，或在 Enterprise 计划中为特定角色关闭。关闭**共享项目**也会关闭**公开项目**。共享关闭时，用户无法与新用户或群组共享项目，现有共享保持不变。

**协作功能：**

- **与我共享选项卡：**轻松找到其他人与您共享的项目。

- **电子邮件通知：**当有人与您共享项目时获得通知。

- **访问管理：**项目创建者可以根据需要修改权限或撤销访问权限。

多个成员可以在同一项目环境中贡献文档、创建聊天和协作，使项目成为团队协作的理想选择。

有关项目入门的更多信息，请参阅**[我如何创建和管理项目？](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects)**

有关 Team 和 Enterprise 计划中私密项目和可见性设置的更多信息，请参阅**[项目可见性和共享](https://support.claude.com/en/articles/9519189-project-visibility-and-sharing)**。
