# 开始使用智能报告

**[智能报告](https://claude.com/resources/articles/smart-reports-surveys-pooled-budgets)**分析团队如何使用 Claude 并报告正在进行的工作、成本（按标价计算）、会话遇到的摩擦点，以及哪些重复模式值得打包为共享技能。本指南说明智能报告的工作原理、智能报告中显示的内容，以及如何创建、共享和删除报告。

每个组织每月最多可以免费运行 10 份报告。已排队或正在进行的报告计入此限制，失败的报告不计入。

当您的组织达到限制时，您无法创建新报告。智能报告页面显示您的限制重置的日期，即下一个日历月的第一天。如果您需要在此之前获得更多报告，请联系您的客户团队。

智能报告在 Claude Enterprise 计划中可用，默认处于关闭状态，因此必须在您的组织设置中启用。

如果 Claude Enterprise 组织使用客户管理的加密密钥 (CMEK)、HIPAA 配置或在自己的云提供商上运行推理的混合部署，则无法使用智能报告。如果您的组织对 Claude Code 使用零数据保留，智能报告将涵盖聊天和 Claude Cowork，但不包括 Claude Code。

**重要提示：**智能报告可帮助您了解采用情况并规划对 Claude 的投资。它们不是为评估个人绩效或做出就业决定而设计的，也不应用于此目的。

## 智能报告的工作原理

首先，主要所有者、所有者、管理员或具有分析查看权限的自定义角色的人员选择报告涵盖的内容：一个团队、最长 28 天的时间范围、一个或多个产品（聊天、Claude Code、Claude Cowork 或统一的聊天和 Cowork 体验）、分析的重点领域，以及您希望 Claude 在分析记录时回答的任何自定义问题。

Claude 随后读取该范围内的记录样本，将其分组为工作流和输出类型，为每个组附加支出，并写出其发现。每个图表都是交互式的。单击工作流以打开其中的会话，按成本排序，每个会话都有一段摘要、使用的产品、日期和输出类型。您可以按子类别筛选并将报告下载为 HTML，保持钻取功能完整。

Claude 识别为涉及受限主题（包括个人对话）的会话仅用于汇总分析，不包括摘要（请参阅**[隐私防护措施](#h_7b22bb48c1)**）。个人对话也不包括单个会话或姓名。管理员可以删除任何报告（请参阅**[删除智能报告](#h_765fe12f41)**）。

## 将智能报告范围限定为特定团队

将智能报告范围限定为职能团队而非整个组织时，智能报告更有用。例如，您可以将报告范围限定为销售、财务、市场营销或工程部门。团队级报告生成的集群足够具体，可以采取行动，并将分析重点放在支出和采用情况上：任务类型、使用的表面和连接器、成本。

您可以按以下方式限定范围：

- **群组：**您可以按使用基于角色的权限的群组筛选报告。群组可以在**组织设置 > 群组**中手动创建，或者如果您使用 SCIM 目录同步，可以从身份提供商 (IdP) 同步群组。

- **部门或成本中心：**如果您的身份提供商群组不能清晰地映射到职能团队，请从 IdP 传递部门和成本中心，并改为对其进行筛选。有关设置说明，请参阅**[通过 SCIM 传递部门和成本中心](#h_cde3c2c758)**部分。

## 用例

- **将成本分配给工作。**查看团队使用 Claude 进行的工作类型及其各自的成本。

- **找到您未启用的集成。**当相同的摩擦在多个会话中出现时，报告会将其命名。解决方案通常是连接器或管理员可以在几分钟内打开的设置。

- **将重复工作转变为共享技能。**报告识别团队不断重新发明的模式，并为您提供起始提示来打包它们。

- **分享示例。**将生成完整管道摘要或一批账户简报的会话指向团队其他成员，以便他们可以遵循相同的模式。

- **为续约提供证据。**进入预算对话时，带上按团队划分的采用情况、成本和产出视图，而不是混合使用数字。

## 隐私防护栏

智能报告对受限主题有两个防护栏。两者始终启用，您无法将其关闭：

- **您无法对受限主题提出自定义问题。**这适用于您自定义的模板问题和您自己编写的问题。

- **Claude 识别为涉及受限主题的会话仅用于汇总分析。**报告不会为其显示会话摘要。

受限主题包括：

- **受保护的特征：**种族、民族、国籍、宗教、性别认同、年龄、残疾、移民身份

- **健康和医疗：**身心健康、怀孕、医疗假、药物、治疗、物质使用

- **工会活动：**组织、集体谈判、同事讨论薪酬或工作条件

- **骚扰、举报人或法律：**骚扰或歧视投诉、举报人报告、关于工作场所的特权法律内容

- **政治或宗教观点**

- **个人生活：**家庭、关系、个人财务、个人法律问题、其他非工作生活

- **对人的情感：**对特定具名人士的感受，或该人士的士气
