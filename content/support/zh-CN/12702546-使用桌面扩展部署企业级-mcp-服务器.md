# 使用桌面扩展部署企业级 MCP 服务器

桌面扩展是可安装的软件包，在您的计算机上本地运行模型上下文协议 (MCP) 服务器。它们为 Claude Desktop 提供对本地资源、内部系统和个人工具的安全访问，无需复杂的远程基础设施。

通过桌面扩展，您可以部署具有细粒度管理员控制的企业级 MCP 实现。本文解释了为什么桌面扩展对组织很有价值，以及如何有效地使用它们。

## 为什么使用桌面扩展？

### 无缝身份验证

桌面扩展在您的企业网络边界内运行，使用用户现有的身份验证上下文，无需额外的防火墙规则或 VPN 配置。它们自动利用现有的 SSO 和浏览器会话，无需令牌管理——凭证安全地保留在用户设备上。

### 访问内部资源

桌面扩展连接到防火墙后的内部 wiki、JIRA、Confluence 和其他系统。它们可以查询私有数据库和 API，无需 VPN 配置，连接到 SAP、Oracle 和自定义应用程序等本地系统，并访问内部资源，而无需在公共基础设施上公开它们。

### 读取和操作本地资源

桌面扩展提供对远程连接器无法访问的本地资源的访问。这包括用于代码编辑和 Git 操作的直接文件系统访问、与本地安装的工具（如 Docker、IDE 和数据库）的集成、通过本地 API 控制桌面应用程序，以及用于专业工作流的硬件集成。

### 即时部署，基础设施开销最小

通过 Claude Desktop 一键安装，无需管理任何依赖项。内置 Node.js 运行时已包含，无需配置云基础设施，更新直接通过扩展市场分发。

### 企业级控制

组织所有者可以将自定义扩展上传到其组织，并通过桌面扩展允许列表控制用户可以访问哪些桌面扩展。要了解有关在您的组织中管理桌面扩展的更多信息，请参阅启用和使用桌面扩展允许列表。

## 企业用例

**多个企业正在构建桌面扩展以服务于各种用例：**

- 作为内部 MCP 服务器的安全代理，使他们能够完全控制访问、身份验证和审计日志，同时保持其零信任架构。

- 为 Claude 提供对内部文档和知识库的访问。

- 安全地连接到开发工具和数据库，并完全控制身份验证、授权和审计日志。

桌面扩展消除了安全性和可用性之间的传统权衡——为 Claude 提供强大的功能，同时保持您的企业安全态势。
