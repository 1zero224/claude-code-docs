# Claude 在 Chrome 中的权限指南

本指南说明如何控制在 Chrome 中使用 Claude 时 Claude 可以访问和执行的操作。了解权限有助于在生产力和安全性之间取得平衡。

## 可用性

Claude 在 Chrome 中可在付费计划（Pro、Max、Ultra、Team 和 Enterprise）上使用，位于 Chrome 侧边栏、Claude Cowork 和 Claude Code 中。侧边栏作为 Claude Cowork 会话运行。在 Enterprise 计划上，这需要所有者启用 Claude 在 Chrome 中和云中的 Cowork；在此之前，侧边栏使用经典体验。

**重要提示：**在使用 Claude 在 Chrome 中之前，请查看 **[安全使用 Claude 在 Chrome 中](https://support.claude.com/en/articles/12902428)**以了解基于浏览器的 AI 的风险。

## 权限模式

Claude 在 Chrome 中使用多层权限系统，让您可以控制 Claude 可以访问和执行的操作。在扩展侧边栏或 Claude Desktop 中，您会在聊天输入上看到一个下拉菜单。点击此菜单可在三种权限模式之间选择：

- **手动批准（Manual）**，以前称为"执行前询问"。Claude 在执行每个操作前暂停并请求批准。您审查每个请求并选择允许或拒绝。

- **自动批准（Auto）**。Claude 继续工作并审查每个操作的安全性，自动阻止它认为不安全的任何操作，并在需要时暂停询问您。

- **跳过所有批准（Skip）**，以前称为"无需询问即可执行"。Claude 不会暂停询问，也没有任何东西自动检查其操作。仅当您完全信任任务中涉及的每个操作、连接器、文件、应用等时才使用此选项。

**注意：**在 Cowork 侧边栏中，"自动批准"是默认模式。

## 手动批准

在"手动批准"中，Claude 在执行操作前会与您确认。具体情况取决于您使用的侧边栏。

### 在经典侧边栏中

Claude 根据您的提示创建一个计划，您可以在 Claude 开始前批准该计划。该计划指定您允许 Claude 访问的网站以及它将遵循的方法：

请注意，Claude 只会使用计划中列出的网站，因此您需要手动批准任何其他访问请求。

Claude 提前说明它计划访问的网站和将采取的操作，允许您审查提议的计划并确保其正确后再开始。您也可以点击"进行更改"来拒绝当前提议，然后再次提示 Claude 进行任何必要的更改。点击"批准计划"后，Claude 将能够在概述的参数范围内独立行动，但在其他敏感操作（如下载文件或在页面上输入敏感信息）前仍会与您确认。Claude 不会偏离既定计划而不先请求您的许可。出于您的安全考虑，Claude 无法执行某些操作，例如进行购买、创建账户、绕过机器人授权、执行交易或采取可能表明提示注入风险的某些操作（请参阅 **[禁止的操作](#h_e199f8f523)**）。

### 在 Cowork 侧边栏中

Claude 不会为您创建计划以在开始前批准。Claude 可能会问您一两个问题以澄清您想要什么，然后开始工作并在每个操作前请求您的批准。您审查每个请求并选择允许此网站上的所有操作、仅允许此次或拒绝。

Claude 仍会在敏感操作（如下载文件或在页面上输入敏感信息）前与您确认，某些操作无论模式如何都会被阻止。请参阅下面的 **[需要明确许可的操作](#h_b209fa12fc)**和 **[禁止的操作](#h_e199f8f523)**。

## 自动批准

当您选择"自动批准"时，Claude 继续工作而不停止询问每一步。相反，Claude 审查每个操作的安全性（例如检查数据泄露或提示注入），并自动阻止它认为不安全的任何操作。当操作被阻止时，Claude 会寻找更安全的方式来完成任务或暂停并直接询问您。如果 Claude 不断遇到阻止，它会切换回为每一步请求您的许可。"自动批准"是 Cowork 侧边栏中的默认模式。如果您切换到不同的模式，侧边栏会为将来的会话保留您的选择。

我们在发布前广泛测试了 Claude 的安全检查，包括与外部安全专家合作，他们试图让危险操作通过。它为您提供了让 Claude 不中断工作的速度，以及"跳过所有批准"没有的保护层：每个操作在发生前仍会被审查。*当然，没有防御是完美的，也没有模式可以替代您的判断。对于有真实后果的工作——金钱、以您的名义发送的消息、重要文件——请保持密切关注并审查 Claude 的操作，或考虑切换回"手动批准"。*

您会看到比"手动批准"更少的提示，但安全检查仍在后台运行。

## 跳过所有批准

当您选择"跳过所有批准"时，Claude 不会暂停询问，也没有任何东西自动检查其操作。仅当您完全信任任务中涉及的每个操作、连接器、文件、应用等时才使用此选项。

---

## Claude 何时需要请求额外权限？

有些网站上 Claude 需要为每个操作获得批准。如果您导航到这些网站之一，**需要新权限**提示将在扩展侧边栏、Claude Cowork 或 Claude Code 中出现，Claude 将在访问页面或采取任何操作前请求许可。

### 权限选项

**"允许此操作"**仅授予单个操作的权限。Claude 将在此网站上的下一个操作时再次询问。**这是使用扩展时最安全的选项**，因为您可以审查和批准 Claude 的每个操作。

**"始终允许此网站上的操作"**授予此网站的持续权限。Claude 可以执行多个操作而无需每次都询问。仅对您完全信任的网站使用此选项。授予此权限时，Claude 可能会在网站上执行意外操作。

**"拒绝"**阻止 Claude 执行此操作。您可以尝试不同的方法或跳过此任务。

### 受保护的操作

当您选择"始终允许此网站上的操作"时，Claude 仍会在以下操作前请求您的明确批准：

- 下载文件

- 在页面上输入可能敏感的信息

- 授予授权

### 管理网站权限

您可以在扩展设置中管理 Claude 对特定网站的访问权限。点击 Claude 扩展图标，然后点击侧边栏右上角的三个点。选择"扩展设置"以进入权限页面并：

- 在**您批准的网站**下查看哪些网站具有"始终允许"状态

- 撤销特定网站的权限

- 查看您的权限历史记录

## 组织级控制（Team 和 Enterprise 计划）

Team 和 Enterprise 管理员可以配置影响权限的其他控制：

- **允许列表**限制 Claude 仅访问批准的网站

- **阻止列表**阻止 Claude 访问特定网站，无论用户权限如何

如果您无法使用 Claude 访问网站，您的组织可能已限制访问。请联系您的管理员了解更多信息，或查看 **[Claude 在 Chrome 中的管理员控制](https://support.claude.com/en/articles/13065128-claude-for-chrome-admin-controls)**。

---

## 需要明确许可的操作

无论您的权限模式如何，Claude 都需要明确的用户许可才能执行以下任何操作：

- 修改权限设置

- 授予授权

- 在网站上输入可能敏感的信息

- 永久删除（清空垃圾箱、删除电子邮件、文件或消息）

---

## 禁止的操作

为了保护您，Claude 被禁止执行以下操作，无论权限如何：

- 进行购买或财务交易

- 创建账户

- 处理敏感的信用卡或身份证数据

- 从不受信任的来源下载文件

- 提供投资或财务建议

- 执行财务交易或投资交易

- 修改系统文件

- 完成来自电子邮件或网络内容的指令
