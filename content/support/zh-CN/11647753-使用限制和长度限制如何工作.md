# 使用限制和长度限制如何工作？

在使用 Claude 时，您可能会遇到两种不同类型的限制，它们以不同的方式工作：**使用限制**和**长度限制**。了解这两者之间的区别可以帮助您更有效地使用 Claude。有关您计划的使用情况的更多信息，请参考以下资源。

- **[免费 Claude](https://support.claude.com/en/articles/8114491-getting-started-with-claude#h_57262af5ae)**

- **[Pro 计划](https://support.claude.com/en/articles/8325606-what-is-the-pro-plan#h_62ccc00135)**

- **[Max 计划](https://support.claude.com/en/articles/11049741-what-is-the-max-plan#h_cfd2904008)**

- **[Ultra 计划](https://support.claude.com/en/articles/17154008)**

- **[Team 计划](https://support.claude.com/en/articles/9266767-what-is-the-team-plan#h_b59203dff2)**

- **[Enterprise 计划](https://support.claude.com/en/articles/9797531-what-is-the-enterprise-plan#h_8294bce903)**

## 什么是使用限制？

使用限制控制您在特定时间段内与 Claude 交互的频率。可以将其视为您的"对话预算"，它决定了您在需要等待限制重置之前可以向 Claude 发送多少条消息，或者可以使用 Claude Code 多长时间。付费计划有两种类型的使用限制：每五小时重置一次的会话限制，以及每周重置一次的周限制。

您的使用情况受多个因素影响，包括对话的长度和复杂性、您使用的功能、您与哪个 Claude 模型聊天，以及您选择的努力级别。不同的订阅计划（Pro、Max、Ultra、Team 等）有不同的使用额度，付费计划提供更高的限制。

请注意，您在所有不同 Claude 产品界面（claude.ai、Claude Code、Claude Desktop）上的使用都计入相同的使用限制。

了解更多关于**[更改模型、努力级别和思考设置](https://support.claude.com/en/articles/8664678)**的信息。

### 五小时限制如何工作？

五小时限制控制您在五小时内使用 Claude 的频率。该时间段从您发送第一条消息时开始，您的限制在五小时后完全重置。如果您在此之前达到限制，您可以在限制重置后再次使用 Claude。

您可以在**[设置 > 使用情况](https://claude.ai/settings/usage)**中的"当前会话"下查看您已使用的量和剩余时间。

已验证的 Ultra 账户没有五小时限制。了解更多关于**[已验证的 Ultra 账户](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan#h_ff4fcea367)**的信息。

### 周限制如何工作？

周限制适用于所有模型，某些计划还对 Fable 有单独的周限制。周限制在每周的固定时间重置，该时间分配给您的账户。无论您何时开始使用 Claude 或何时订阅开始，您的重置日期和时间都保持不变，您在每个周期都会获得完整的周额度。您可以在**[设置 > 使用情况](https://claude.ai/settings/usage)**中查看您的下一个重置时间。

### 使用限制可以改变吗？

可以。我们可能会自行调整使用限制以管理容量并确保所有用户的公平访问。例如，我们可能会通过周限制和月限制或模型和功能使用来限制您的使用。我们不保证不间断的服务。

根据您的计划，有几种不同的方式来增加您的使用：

- 如果您使用付费计划，包括 Pro、Max、Ultra、Team 或基于座位的 Enterprise 计划，请参阅这些文章了解购买使用额度的详细信息：

  - **[管理付费 Claude 计划的使用额度](https://support.claude.com/en/articles/12429409-)**

  - **[管理 Team 和基于座位的 Enterprise 计划的使用额度](https://support.claude.com/en/articles/12005970-)**

- 如果您的组织有基于使用量的 Enterprise 计划，您的使用基于消费。请参阅此文章了解更多信息：**[我的 Enterprise 计划如何计费？](https://support.claude.com/en/articles/11526368-how-am-i-billed-for-my-enterprise-plan)**

## 什么是长度限制？

长度限制与 Claude 的上下文窗口有关——Claude 在单个聊天中可以处理的信息量。可以将上下文窗口视为 Claude 的工作记忆，它决定了它一次可以处理和记住多少内容。

**注意**：上下文窗口大小取决于您使用的模型。在付费计划上，最新的模型支持高达 1M 令牌的上下文窗口，而其他模型支持 500K 或 200K 令牌。上下文窗口的一部分始终为 Claude 的响应保留，因此最长的对话略小于完整窗口。有关当前的按模型细分，请参阅**[付费 Claude 计划上的上下文窗口有多大？](https://support.claude.com/en/articles/8606394-how-large-is-the-context-window-on-paid-claude-plans)**

## 自动上下文管理

对于启用了代码执行的用户，Claude 现在自动管理长对话。当您的对话接近上下文窗口限制时，Claude 会总结早期消息以继续对话。这意味着您可以进行更长、更自然的对话，中断更少。

您的完整聊天历史记录被保留，因此 Claude 即使在总结后也可以参考它。在长对话期间，您可能偶尔会看到 Claude"整理思路"——这表示自动上下文管理正在工作。

触发自动上下文管理的较长对话会消耗更多的使用限制。如果您在较长的聊天中接近使用限制，请尝试开始新对话。

**注意：**自动上下文管理需要**[启用代码执行](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude#h_1c99382190)**。罕见的边界情况（例如非常大的第一条消息）可能仍会遇到上下文限制。

## 我如何增加 Claude 上下文窗口的大小？

虽然您无法增加计划的固定上下文窗口大小，但您可以使用这些策略来最大化可用上下文空间，并优化您的上下文窗口和使用限制：

- **有效利用项目：**项目使用检索增强生成 (RAG)，它允许 Claude 通过仅将相关内容加载到上下文窗口中来更有效地处理更大量的信息。

- **缩短项目说明：**保持您的项目说明简洁，专注于基本信息。Claude 在您使用项目说明来提供项目的一般背景、关键指南和 Claude 的角色时表现最佳。为聊天本身保留特定于任务的说明。

- **删除未使用的项目文件：**定期清理您在项目中不再积极使用的文件。

- **关闭思考：**在提供思考切换的模型上，当您不需要 Claude 的增强推理时关闭它。在思考始终打开的模型上，例如 Claude Opus 5.5 和 Sonnet 5.5，请改为选择较低的努力级别。

- **降低努力级别：**对于不需要 Claude 最彻底响应的日常任务，选择较低的努力级别。更高的努力使用更多令牌。

- **关闭您不需要的工具：**当对话不需要时关闭您已连接的应用，并在您不需要当前信息时要求 Claude 不要搜索网络。

**注意：**工具和连接器是令牌密集型的，因此管理它们有助于最大化您的可用上下文窗口并优化您的使用限制。

## 关键区别

主要区别是使用限制控制您在所有对话中使用 Claude 的*频率*，而长度限制控制任何单个对话可以变得多*长*。使用限制是关于一段时间内的数量，而长度限制是关于单个对话的深度和复杂性。

如果您达到会话限制或周限制，您可以等待其重置或升级您的计划。如果您升级，您的新计划的限制会立即应用。启用使用额度后，您的工作继续使用使用额度而不是停止。如果您达到长度限制，您可以开始新对话或使用**[项目等功能](https://support.claude.com/en/articles/9517075-what-are-projects)**来更有效地处理更大量的信息。
