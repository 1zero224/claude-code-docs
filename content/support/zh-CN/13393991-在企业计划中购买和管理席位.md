# 在企业计划中购买和管理席位

本文介绍如何在企业计划中添加席位、管理席位分配和处理成员访问权限。有关定价和账单详情，请参阅 **[我的企业计划如何计费？](https://support.claude.com/en/articles/11526368-usage-based-enterprise-plans)**

**权限说明：**只有所有者和主要所有者可以购买席位并访问 **[组织设置 > 组织和访问权限](https://claude.ai/admin-settings/organization)**。管理员及以上级别可以在 **[组织设置 > 成员](https://claude.ai/admin-settings/members)** 中为成员重新分配席位类型。要检查您的角色，请点击左下角的您的名字或首字母——您的角色会显示在您的组织计划类型旁边。

有关从您的组织中添加和删除成员的信息，请参阅 **[在团队和企业计划中管理成员](https://support.claude.com/en/articles/13133750-managing-members-on-team-and-enterprise-plans)**。

**重要提示：**本文的主要部分介绍当前的企业席位模型，适用于所有新的企业计划。

- 如果您的组织是在过渡到单一企业席位之前配置的，并且您在 **[组织设置 > 成员](https://claude.ai/admin-settings/members)** 中看到 **Chat** 和 **Chat + Claude Code** 席位类型，请参阅 **[Chat 和 Chat + Claude Code 计划的信息](#h_2673e097fb)**。

  - **[符合 HIPAA 的企业组织](https://support.claude.com/en/articles/13296973-hipaa-ready-enterprise-plans)**是例外：它们配置有单独的 Chat 和 Chat + Claude Code 席位类型，不符合单一企业席位计费模型的条件。

- 如果您看到 **标准** 和 **高级** 席位类型，请参阅 **[基于席位的企业计划信息](#h_6a78e30e26)**。

- 仅限聊天的席位和标准/高级席位不再适用于新合同——两种旧版计划类型都将在下次续订时过渡到单一企业席位。

---

## 您的席位类型

基于使用量的企业计划使用单一席位类型：**企业席位**，按用户每月计费（按年计费）。此席位包括在网络、桌面和移动设备上访问 Claude，以及 Claude Code 的权限。

企业计划至少需要 20 个席位。

---

## 谁可以使用席位

每个企业席位分配给一个指定的个人，只有该人可以使用它。这适用于每个企业席位类型，包括旧版 Chat、Chat + Claude Code、标准和高级席位。这意味着：

- 只有分配的用户可以登录该账户。用户不能共享登录凭证或让他人使用他们的账户。

- 用户不能使用另一个用户的账户来规避自己的支出限制或使用限制。

重新分配席位用于正常的团队变化，例如用户加入、离开或改变角色。它不是为了在多个活跃用户之间轮换一个席位而设计的。要给其他人访问权限，请为他们分配自己的席位。

---

## 购买新席位

您可以在年度期限内的任何时间向您的企业计划添加席位。新席位按计费周期的剩余时间按比例计费，并立即收费。

1. 使用您的所有者或主要所有者账户登录。

2. 转到 **[组织设置 > 组织和访问权限](https://claude.ai/admin-settings/organization)**。

3. 点击 **总席位数** 下的"管理"。

4. 点击"添加或更改席位"。

5. 输入您想添加的席位数。

6. 在确认前查看您的更改和按比例计费的费用。

7. 点击"确认并购买"以完成。

**注意：**您也可以在添加新成员时购买席位。如果在邀请某人时没有可用的席位，系统会提示您购买一个。

有关席位添加如何计费的详情，请参阅 **[我的企业计划如何计费？](https://support.claude.com/en/articles/11526368-how-am-i-billed-for-my-enterprise-plan)**

---

## 删除席位

**自助企业计划：**在您的年度期限内无法删除席位。您可以随时添加席位，但席位数量的减少仅在续订时生效。如果您需要例外处理，请联系 **[我们的销售团队](https://claude.com/contact-sales)** 讨论转换为销售协助计划。

**销售协助企业计划：**请联系您的账户经理讨论席位分配的更改。

从您的组织中删除成员不同于减少席位数量。当您删除成员时，他们的席位变为可用，可以分配给其他人，因此您的总席位分配和账单不会改变。要减少您的账单，您需要减少总席位分配。有关删除成员的说明，请参阅 **[在团队和企业计划中管理成员](https://support.claude.com/en/articles/13133750-managing-members-on-team-and-enterprise-plans)**。

---

## 临时删除成员的访问权限

**未分配席位**选项让您可以临时删除成员对 Claude 的访问权限，而无需从您的组织中删除他们。这对于需要间歇性访问权限的承包商或团队成员很有用。

要取消分配成员：

1. 转到 **[组织设置 > 成员](https://claude.ai/admin-settings/members)**。

2. 找到您想取消分配的成员。

3. 点击 **层级** 下的下拉菜单。

4. 选择"未分配席位"。

要恢复他们的访问权限，请重复该过程并选择"企业席位"。

**注意：**未分配席位的成员仍然是您的组织的一部分，但在您为他们重新分配席位之前无法使用 Claude。他们不计入您的组织席位限制。待处理邀请确实计入。如果即使席位显示为可用，"添加成员"仍不可用，请撤销不会被接受的待处理邀请，或购买额外席位。

## 使用 JIT 或 SCIM 配置的席位分配

**[通过 JIT 或 SCIM 配置的用户](https://support.claude.com/en/articles/13133195-setting-up-jit-or-scim-provisioning-to-manage-user-assignments-on-team-or-enterprise-plans)**在添加时会自动分配一个企业席位，前提是您的分配中有可用的席位。如果没有可用的席位，配置将不会完成，直到所有者购买额外席位。

管理员及以上级别之后可以在 **[组织设置 > 成员](https://claude.ai/admin-settings/members)** 中手动调整成员的状态（例如，删除他们的席位分配）。

---

## 取消您的企业计划

**自助企业计划：**所有者或主要所有者可以从 **[组织设置 > 账单](https://claude.ai/admin-settings/billing)** 取消您的计划。取消在您当前年度计费周期结束时生效——您的组织将继续拥有访问权限直到那时。

**销售协助企业计划：**请联系您的 Anthropic 联系人或 **[我们的销售团队](https://claude.com/contact-sales)** 讨论取消事宜。

## Chat 和 Chat + Claude Code 计划的信息

**重要提示：**Chat 和 Chat + Claude Code 是不再适用于新企业合同的旧版席位类型。本部分仅适用于在过渡到单一企业席位之前使用这些席位类型配置的组织。如果您最近签署了新的企业合同，本文的主要部分适用于您——您的计划使用单一企业席位，为所有成员包括 Claude Code 访问权限。

一些现有的基于使用量的企业组织目前有两种席位类型：**Chat** 和 **Chat + Claude Code**。如果您在 **[组织设置 > 成员](https://claude.ai/admin-settings/members)** 中看到这些席位类型，本部分适用于您。您的计划将在下次合同续订时过渡到单一企业席位模型——请参阅下文了解更多信息。

### 座位类型

| **座位类型**           | **包含内容**                       |
| ------------------ | ------------------------------ |
| Chat               | Claude 网页版、桌面版和移动应用            |
| Chat + Claude Code | Chat 的所有功能，加上 Claude Code 访问权限 |

您可以根据团队需求混合搭配座位类型。为需要编码工作流的团队成员分配 Chat + Claude Code 座位，同时让其他成员保持 Chat 座位。

### 在座位类型之间重新分配用户

您可以在现有配额内的 Chat 和 Chat + Claude Code 座位之间移动用户。

1. 转到 **[组织设置 > 成员](https://claude.ai/admin-settings/members)**。

2. 找到要重新分配的成员。

3. 点击 **等级** 下的下拉菜单。

4. 选择"Chat"或"Chat + Claude Code"。

从 Chat + Claude Code 移至 Chat 的成员将失去 Claude Code 访问权限，反之亦然。

**等级** 下拉菜单仅显示您的计划已拥有的座位类型。如果您的计划包含 Chat + Claude Code 座位但已全部分配，系统会提示您购买一个。如果您的计划没有该类型的座位，请参阅上面的 **[购买新座位](#h_91344d9191)** 以先添加一个。

### 在座位类型之间交换用户

如果您的所有 Chat + Claude Code 座位都已分配，且需要将一个用户移至该类型，同时将另一个用户移出，请先使用 **未分配座位** 来释放一个座位。

**示例：**您有十个 Chat + Claude Code 座位，全部已分配。您想将用户 A（目前在 Chat + Claude Code 上）移至 Chat，并将用户 B（目前在 Chat 上）移至 Chat + Claude Code，而无需购买额外座位。

1. 转到 **[组织设置 > 成员](https://claude.ai/admin-settings/members)**。

2. 找到用户 A 并将其座位类型更改为"未分配座位"。这将释放一个 Chat + Claude Code 座位。

3. 找到用户 B 并将其座位类型更改为"Chat + Claude Code"。他们现在占用已释放的座位。

4. 找到用户 A 并将其座位类型更改为"Chat"。

### 使用 JIT 或 SCIM 配置的座位分配

通过 JIT 或 SCIM 配置的用户在添加时会自动分配到最高可用座位类型（如果可用，则为 Chat + Claude Code）。管理员及以上级别可以之后在 **[组织设置 > 成员](https://claude.ai/admin-settings/members)** 中手动重新分配座位类型。

您也可以将高级组映射与 JIT 或 SCIM 一起使用，以直接将用户配置到特定座位类型。

### 过渡到单一企业座位

**注意：[符合 HIPAA 的组织](https://support.claude.com/en/articles/13296973-hipaa-ready-enterprise-plans)** 配置有单独的 Chat 和 Chat + Claude Code 座位类型，不符合统一座位类型的条件。

在下次续订时，您将在签署新合同后切换到单一企业座位模式。此座位包括 Claude Code、Cowork、Chat 等功能。

如有关于即将续订的问题，请联系您的 Anthropic 联系人或 **[我们的销售团队](https://claude.com/contact-sales)**。

## 基于座位的企业计划信息

**重要提示：**Standard 和 Premium 是不再适用于新企业合同的旧座位类型。本部分仅适用于在过渡到基于使用量的计费之前配置了这些座位类型的组织。如果您最近签署了新的企业合同，本文的主要部分适用于您。

某些企业组织使用的是旧的基于座位的计划，其计费结构与上述基于使用量的模式不同。如果您在 **[组织设置 > 成员](https://claude.ai/admin-settings/members)** 中看到 **Standard** 和 **Premium** 座位，本部分适用于您。

### 座位类型

| **座位类型** | **包含内容**                 |
| -------- | ------------------------ |
| Standard | 核心企业功能和使用限制              |
| Premium  | Standard 的所有功能，加上更高的使用限制 |

**注意：**只有管理员及以上级别可以看到每个用户的座位类型，显示在 **[组织设置 > 成员](https://claude.ai/admin-settings/member)** 中的 **等级** 列。其他用户在 Claude 中的任何地方都看不到自己的座位类型。如果您需要确认您的座位是 Standard 还是 Premium，请询问您组织中的所有者或管理员。

### 在座位类型之间重新分配用户

您可以在现有配额内的 Standard 和 Premium 座位之间移动用户。

1. 转到 **[组织设置 > 成员](https://claude.ai/admin-settings/members)**。

2. 找到要重新分配的成员。

3. 点击 **等级** 下的下拉菜单。

4. 选择"Standard"或"Premium"。

从 Premium 移至 Standard 的成员将拥有更低的使用限制，反之亦然。

**等级** 下拉菜单仅显示您的计划已拥有的座位类型。如果您的计划包含 Premium 座位但已全部分配，将另一个用户重新分配到 Premium 将提示您购买额外座位。如果您的计划没有该类型的座位，请参阅上面的 **[购买新座位](#h_91344d9191)** 以先添加一个。

### 在座位类型之间交换用户

如果您的所有高级席位都已分配，需要将一个用户移至高级席位，同时将另一个用户移至标准席位，请先使用**未分配席位**来释放一个席位。

**示例：**您有十个高级席位，全部已分配。您想将用户 A（当前使用高级席位）移至标准席位，并将用户 B（当前使用标准席位）移至高级席位——无需购买额外席位。

1. 转到**[组织设置 > 成员](https://claude.ai/admin-settings/members)**。

2. 找到用户 A，将其席位类型更改为"未分配席位。"这将释放一个高级席位。

3. 找到用户 B，将其席位类型更改为"高级。"他们现在占用已释放的席位。

4. 找到用户 A，将其席位类型更改为"标准。"

### 账单和使用额度

基于席位的企业计划按每个席位收取固定月费，包括使用限额。所有者可以启用使用额度，允许团队成员在达到其席位的使用限额后继续工作。有关详情，请参阅**[为团队和基于席位的企业计划管理使用额度](https://support.claude.com/en/articles/12005970-)**。

如需了解基于席位的企业定价的具体信息，请联系您的 Anthropic 联系人或**[我们的销售团队](https://claude.com/contact-sales)**。

### 过渡到单一企业席位

在您的下一个合同续期时，您的计划将过渡到本文主要部分中描述的基于使用量的单一企业席位模式。如果您想在续期前迁移，请联系您的 Anthropic 联系人或**[我们的销售团队](https://claude.com/contact-sales)**。
