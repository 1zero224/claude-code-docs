# 开始使用 Claude Sheets

Claude Sheets 是内置于 Claude 的电子表格。您可以要求创建跟踪器、预算或模型，Claude 会构建一个工作表，您、您的团队和 Claude 都可以一起编辑。本指南涵盖创建表格、与 Claude 一起在其中工作、导入和导出数据以及共享表格。

Claude Sheets 在 Pro、Max、Ultra、Team 和 Enterprise 计划中以测试版形式提供。在 Team 计划中默认启用。在 Enterprise 计划中，默认关闭，直到在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中启用。

## Claude Sheets 的工作原理

表格是您和 Claude 在同一单元格中编辑的工件。Claude 可以添加标签页、编写跨标签页的公式、应用格式和条件格式，以及添加下拉菜单、复选框和图表。公式保留在单元格中，因此您可以查看和检查每个数字的计算方式。

当 Claude 更改表格时，每次编辑都会在显示时突出显示，因此您可以看到发生了什么变化。当其他人在表格中时，您都在同一时间在同一单元格中工作。

您创建的每个表格都保存在**工件**标签中。了解更多关于**[工件及其使用方法](https://support.claude.com/en/articles/17153992)**。

## Claude Sheets 与 Claude for Excel 的区别

Claude Sheets 将电子表格放在 Claude 中。Claude for Excel 和 Claude for Google Workspace 将 Claude 引入您已在这些应用中保存的文件。

使用 Claude Sheets 创建您和您的团队与 Claude 一起构建和更新的跟踪器、预算、计划和模型。如果您的文件必须保留在 Excel 或 Google Sheets 中，请在那里使用 Claude for Excel 或 Claude for Google Workspace。您也可以将文件导入到 Claude Sheets 中，并将其导出为 .xlsx。

## 创建表格

### 从聊天中

在任何聊天中向 Claude 要求一个表格。例如：

- “构建一个包含所有者、日期和状态的活动跟踪器。”

- “按团队和季度制作招聘预算。”

- “根据这些交易预测下一季度，并标记有风险的项目。”

### 从工件标签中

1. 转到**工件**标签。

2. 选择“表格”磁贴。

3. 描述您想要的表格，或从空白表格开始。

### 获得更好结果的提示

说明表格的用途以及您想要跟踪的内容。如果您已经有数字，请将其提供给 Claude，以便从您自己的数据构建表格。

## 在您的表格中工作

- **询问 Claude：**要求进行更改，例如“添加预算剩余列”或“突出显示任何逾期项目。”

- **询问范围：**选择单元格并询问 Claude 相关问题，例如“为什么这个总数比上个月高？”

- **直接编辑：**在单元格中输入、编写公式并自己格式化数据。Claude Sheets 包含超过 250 个函数。

- **评论：**为您的团队在单元格上添加评论。

## 自己编辑表格

您可以在不询问 Claude 的情况下完成日常电子表格工作：

- **排序：**右键单击单元格并打开排序菜单。要按多列排序，请选择“自定义排序。”您可以为自己或为表格的所有用户排序。

- **筛选：**右键单击表格中的单元格并选择“筛选。”您可以为自己或为表格的所有用户筛选。

- **查找和替换：**按 Ctrl+H（Mac 上为 Cmd+Shift+H）在当前标签页或选定单元格中查找和替换文本。公式结果、下拉菜单和复选框无法通过此方式更改。

- **图表：**选择包含数字的单元格，然后在工具栏中选择“插入图表”，或右键单击并选择“制作图表。”选择图表类型将其添加到您的表格中。

- **条件格式：**选择单元格，然后在工具栏或右键菜单中选择“条件格式”以按规则为单元格着色。

- **人员：**在 Team 和 Enterprise 计划中，在单元格中输入 @，然后从您的组织中选择一个人。一个单元格可以包含多个人：单击单元格以添加更多。

- **下拉菜单、复选框和日期：**右键单击单元格，选择“插入，”然后选择“下拉菜单，”“复选框，”或“日期。”双击日期以在日期选择器中更改它，除非公式计算它。

- **行和列：**右键单击行号或列字母以冻结、分组、移动或调整其大小。要合并单元格，请选择它们，右键单击，然后选择“合并单元格。”

- **数字格式：**在工具栏中选择“数字格式”以将数字显示为货币、百分比、日期等。

- **表格：**当 Claude Sheets 识别具有标题行的单元格块为表格时，它会为该块提供表格外观，并在您滚动时保持标题可见。

- **单元格历史记录：**右键单击单元格并选择“查看历史记录”以查看对该单元格或其行的最近编辑、编辑者和编辑时间。

- **键盘快捷键：**选中单元格后，按 Ctrl+/（Mac 上为 Cmd+/）查看完整列表。

## 从表格内部询问 Claude

如果您可以编辑表格，则无需为每次更改都使用聊天：

- **用简单语言编写公式：**在单元格中输入 =，描述您想要的内容，然后选择“编写此公式。”看到结果后，选择“保留”或“放弃”。对于简单的内容，例如“=sum B2 to B5，”公式可能会立即出现，您可以选择它。

- **修复错误：**选择显示错误的单元格，然后选择“使用 Claude 修复。”看到修复后，选择“保留”或“放弃”。如果您看到“要求 Claude 修复”，它会打开聊天。

- **描述图表：**选择您的数据，选择“插入图表，”描述您想要的图表，然后选择“制作此图表。”

- **描述规则：**选择“条件格式，”输入规则，例如“超出预算时为红色，”然后选择“编写规则。”

- **描述筛选器：**右键单击表格中的单元格，选择“筛选，”然后输入要显示的行，例如“逾期”或“按收入排名前 10。”

- **询问单元格：**选择单元格，右键单击，然后选择“询问 Claude。”

- **向 Claude 发送评论：**编写评论时，确保“发送给 Claude”已选中。

**注意：**当 Claude 完成工作时，它会计入使用限制。在 Team 和 Enterprise 计划中，管理员可以在**[组织设置 > 功能](https://claude.ai/admin-settings/capabilities)**中关闭 Sheets。某些选项（包括评论）对来自组织外部的人员不可用。

## 撤销 Claude 的更改

Claude 完成后，卡片会显示 Claude 更新的内容。如果显示“撤销，”选择它以仅撤销该更改。卡片会在您返回表格后几秒钟消失，或在您在单元格中工作时立即消失。之后，使用**版本历史记录**恢复较早的版本，这也会删除之后所做的编辑。

## 导入和导出

要将数据导入表格，您可以：

- 导入 CSV 文件

- 从 Google Sheets 导入

- 从 Excel 导入

- 从空白表格开始

也可以从 Excel 或 Google Sheets 粘贴。要下载表格，请将其导出为 .xlsx 或 CSV 文件。要继续在另一个工具中工作，请使用“发送至。”

## 共享表格

表格默认仅对您私密。要共享一个，请打开它并单击“共享。”您与之共享且具有“可编辑”访问权限的人可以与您和 Claude 一起处理它。来自组织外部的人员无法添加评论。使用“任何拥有链接的人，”表格仅对登录到 Claude 的人打开，他们只能查看它。了解更多关于**[共享工件](https://support.claude.com/en/articles/9547008)**。

## 使用情况

Claude Sheets 计入您计划的使用限制，就像您与 Claude 的其他工作一样。了解更多关于**[使用和长度限制如何工作](https://support.claude.com/en/articles/11647753)**。

## 为您的组织启用 Claude Sheets

本部分适用于 Team 和 Enterprise 计划中的所有者和主要所有者。

在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中的**模板**下启用或禁用 Claude Sheets。在 Team 计划中默认启用，在 Enterprise 计划中默认禁用。工件也必须为您的组织启用。在 Enterprise 计划中，一旦启用 Claude Sheets，自定义角色可以将其限制为特定组。在**[Team 和 Enterprise 计划的工件管理员指南](https://support.claude.com/en/articles/16994751)**中了解更多。

## 当前限制

Claude Sheets 处于测试阶段，涵盖常见的电子表格工作。我们会随着时间的推移添加更多功能。

- **大小：**表格可以容纳超过 500,000 个填充单元格。

- **图表：**可用条形图、折线图和饼图，以及 Claude 可以生成的各种其他图表类型。

- **尚不可用的功能：**多选下拉菜单和 PDF 导出。

- **不支持的 Excel 功能：**宏、VBA、Power Query、DAX 和打印布局。

- **实时数据：**表格无法从连接的应用中提取实时数据，文档、演示文稿和仪表板无法使用表格作为数据源。

- **平台：**Web、桌面、Claude for iOS 和 Claude for Android。

- **数据控制：**Claude Sheets 是测试版产品。它尚不适用于具有 HIPAA 就绪配置或 Claude Code 零数据保留的组织。表格不受零数据保留保护。
