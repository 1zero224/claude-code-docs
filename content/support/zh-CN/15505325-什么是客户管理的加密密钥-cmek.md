# 什么是客户管理的加密密钥 \(CMEK\)?

客户管理的加密密钥可供符合条件的企业计划和 Claude 平台上的组织使用。

客户管理的加密密钥 (CMEK) 允许您的组织在自己的 AWS KMS、Google Cloud KMS 或 Azure Key Vault 中配置加密密钥，并让 Anthropic 使用它来加密 Claude 中的某些数据，例如您团队的聊天、项目和文件。您对密钥拥有完全控制权，Anthropic 使用您的密钥执行的每项操作都会记录在您的云提供商的审计日志中。CMEK 是可选的，您的组织可以选择启用它来替代 Anthropic 提供的默认加密。

有关完整详情，包括加密内容、禁用或更改的内容、限制和每个云提供商的设置指南，请参阅 **[Claude API 文档中的客户管理加密密钥](https://platform.claude.com/docs/en/manage-claude/cmek)**。
