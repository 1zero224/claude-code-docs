# 聊天和 Cowork 中的自定义视觉效果

Claude 可以直接在您的对话中生成自定义图表、图形和交互式视觉效果。当视觉效果比文字更能说明问题时，Claude 会从头开始构建一个——根据您的具体问题定制，并作为响应的一部分内联呈现。

**注意：**自定义视觉效果目前处于测试阶段，可供网页和桌面版 Claude 的所有用户在聊天和 Cowork 中使用。

## 工作原理

您无需打开任何设置。Claude 会根据您的问题内容判断何时使用视觉效果会有帮助。您也可以直接要求——尝试使用"将其绘制为图表"、"向我展示这如何随时间变化"或"将此数据制成图表"等短语。

视觉效果出现后，您可以与其交互——点击按钮、调整滑块、将其展开为全屏——并继续提出后续问题。Claude 可以在对话继续进行时更新或重建视觉效果。

以下是 Claude 可能生成的一些示例：

- 向我展示此流程的工作原理"→ Claude 通过创建流程图来展示。"

- 上传 CSV 文件并询问"数据显示了什么？"→ Claude 生成交互式图表。

- 帮我在两个不同的选项之间做出决定"→ Claude 输出并排比较。"

- 将此系统或概念可视化"→ Claude 在解释旁边构建图表。"

### Cowork 中的自定义视觉效果

自定义视觉效果在 Cowork 会话中的工作方式相同，除了几个差异：

- **无法共享。**Cowork 会话在本地运行，因此视觉效果不会通过共享链接为他人呈现。

- **无点击后续。**在聊天中，点击视觉效果内部会向 Claude 发送后续提示（例如，"深入查看 Q3"）。该快捷方式在 Cowork 中尚不可用，但您仍然可以通过输入来提出后续问题。

## 保留视觉效果

自定义视觉效果默认是临时的。它们作为 Claude 响应的一部分内联存在，当对话继续时不会单独保存。可以将其视为更像是白板草图而不是完成的文件。

但是，如果您确实想保留视觉效果，您有几个选项：

- **复制为图像**——获取静态快照用于笔记、幻灯片或快速粘贴。

- **下载**——将视觉效果保存为 .svg 或 .html 文件。

- **保存为工件**——将其转换为可以保留、发布和随时间迭代的工件。

这是与工件的主要实际区别：工件从一开始就是持久的和可共享的，而自定义视觉效果可以帮助您实时思考，只有在您选择保留时才会保留。如果您想构建持久的东西——工具、应用程序、要共享的文档——请要求 Claude 创建工件。有关更多信息，请参阅 **[什么是工件以及如何使用它们？](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them)**

## 自定义视觉效果是如何构建的？

自定义视觉效果不是照片或插图。Claude 使用 HTML（与网页相同的构建块）构建它们，因此它们是交互式的，特定于您的问题，而不是静态图像。

---

## 限制

- 自定义视觉效果仅在 Claude 网页和桌面应用程序的聊天中可用。它们不会在 Claude for iOS 或 Claude for Android 上呈现。

- 如果您共享聊天，视觉效果仅在网页和桌面上为接收者呈现，他们必须登录才能查看。

- 视觉效果不会自动保存。要保留一个，请使用上述选项之一。

- 此功能处于测试阶段。视觉质量和复杂性会有所不同，Claude 可能不会总是在您期望的时候选择生成视觉效果。

---

## 提示

- **要求您想要的。**如果 Claude 在您更喜欢视觉效果时给出文本输出，请尝试重新表述——"向我展示此工作原理的图表"或"为我制作此图表"。

- **更聪明更好。**Opus 在可视化任务中表现最佳，因此如果您要处理复杂的内容，我们建议选择更智能的模型。

- **个性化您的视觉效果。**如果您告诉 Claude"让我所有的可视化都是粉红色"，Claude 会记住。

- **在对话中迭代。**您可以要求 Claude 调整视觉效果，就像要求它修改文本一样——"使图表显示每月而不是每年"或"向比较中添加第三个选项"。
