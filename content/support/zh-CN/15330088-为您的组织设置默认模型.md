# 为您的组织设置默认模型

本指南说明如何选择 Claude 模型，使您组织内的新对话都在该模型上启动。您可以为整个组织设置一个默认模型，也可以为特定的自定义角色设置不同的默认模型。您还可以让每个新对话都在您的默认模型和工作量级别上启动，即使用户之前选择了不同的模型。

默认模型设置适用于企业计划组织。主要所有者、所有者和自定义角色授予身份和访问权限的成员可以在 **[组织设置 > 模型](https://claude.ai/admin-settings/models)**中管理这些设置。

您还可以设置新对话启动时的默认工作量级别，或将其保留在 Anthropic 推荐的默认工作量级别。要控制成员可以使用哪些模型并限制他们可以选择的工作量级别，请参阅 **[为您的组织管理模型访问权限](https://support.claude.com/en/articles/15694740)**。

---

## 默认模型的工作原理

当您设置或更改默认模型时，它会替换每个成员的模型选择器中当前选定的模型。之后，聊天、Cowork、Claude Code、Claude for Office、Claude Design 和 Claude Science 中的新对话将在您选择的模型上启动。

**注意：**并非所有模型都在每个产品中可用。如果选定的模型在该产品中不可用，将使用 Anthropic 的推荐作为默认值。

用户仍然可以为任何对话选择不同的模型。默认情况下，Claude 会记住每个用户的最后选择，因此他们的下一个对话将在他们最后使用的模型上启动。当您再次更新默认值时，新的默认值会替换他们的选择。要让每个新对话都在默认值上启动，请参阅下面的 **[始终在默认模型上启动新聊天](#h_bc399beba0)**。

例如：您将组织默认值设置为 Claude Sonnet 4.6，每个成员的新对话都在 Sonnet 4.6 上启动。一个成员将对话切换到 Claude Opus 4.7，因此他们的下一个对话在 Opus 4.7 上启动。当您稍后更改组织默认值时，新的默认值再次替换他们的选择。如果您打开**始终使用默认模型和工作量级别启动**，无论他们最后使用了哪个模型，他们的下一个聊天都将在 Sonnet 4.6 上启动。

您可以在两个级别设置默认值：

- 组织默认值：适用于您组织的每个成员。

- 自定义角色默认值：适用于分配给该角色的成员，优先于组织默认值。

除了默认模型外，您还可以设置默认工作量级别。在默认模型上的新对话将在该工作量级别启动。成员仍然可以为任何对话更改工作量级别，但受组织对该模型的工作量上限和其自定义角色设置的上限的限制。如果默认工作量高于适用于成员的上限，他们的对话将在允许的最高级别启动。

**注意：**Claude Code CLI 版本早于 2.1.199 的成员不会获取组织默认值。版本 2.1.196 至 2.1.198 也存在一个错误，即设置特定的组织默认值会导致其他启用的模型从 CLI 和 VS Code 扩展中的模型选择器中消失；更新到 2.1.199 或更高版本可以解决这两个问题。

有关面向成员的 CLI 说明，请参阅 **[Claude Code 模型配置](https://support.claude.com/en/articles/11940350)**。

有关面向成员的切换模型说明，请参阅 **[更改模型、工作量和思考设置](https://support.claude.com/en/articles/8664678-change-the-model-effort-and-thinking-settings)**。

## 设置组织默认模型

组织默认值适用于每个成员。要设置它：

1. 导航到 **[组织设置 > 模型](https://claude.ai/admin-settings/models)**。

2. 在**默认模型**下，从模型下拉列表中选择一个选项：

  1. 使用 Anthropic 的推荐默认值"：Anthropic 推荐的模型，在发布新模型时自动更新。"

  2. 选择特定模型"：发布新模型时不会更改的特定模型。"

3. 如果您选择"选择特定模型"，请从列表中选择一个模型。只能选择在同一页面上的**模型访问权限**下启用的模型。

4. 点击"保存更改"。

## 设置默认工作量级别

默认工作量级别适用于组织默认模型上的新对话。要设置它：

1. 导航到 **[组织设置 > 模型](https://claude.ai/admin-settings/models)**。

2. 在**默认模型**下，从工作量级别下拉列表中选择一个选项：

  1. 使用 Anthropic 的推荐默认工作量"：Anthropic 推荐的默认模型工作量级别，在建议更改时自动更新。"

  2. 从列表中选择一个级别。可用的工作量级别因模型而异，某些模型根本不支持工作量级别设置。

3. 点击"保存更改"。

默认工作量级别不能高于组织对默认模型的工作量上限。如果您将该上限降低到低于当前默认工作量，默认工作量将被降低以匹配。

## 始终在默认模型上启动新聊天

默认情况下，每个用户的下一个对话在他们最后使用的模型上启动。打开此设置可让每个新对话在您组织的默认模型和默认工作量级别上启动。

1. 导航到 **[组织设置 > 模型](https://claude.ai/admin-settings/models)**。

2. 打开**始终使用默认模型和工作量级别启动**。

3. 点击"保存"。

启用此设置后：

- 每个新对话都在默认模型上以默认工作量级别启动。

- 用户仍然可以在对话中更改模型和工作量级别。他们的下一个对话再次在默认值上启动。

- 当默认模型更改时，新对话将移至新的默认值。例如，如果您使用 Anthropic 的推荐默认值，而推荐更改为较新的模型，每个用户的下一个对话将在较新的模型上启动。

此设置适用于聊天、Cowork、Claude Code、Claude for Office、Claude Design 和 Claude Science。

### 在项目中

项目保持自己的模型选择。Claude 会记住每个用户在每个项目中最后选择的模型，此设置不会覆盖现有聊天项目中的该选择。启用**始终使用默认模型和工作量级别启动**后：

- 新项目在默认模型上启动。

- 现有聊天项目在用户在该项目中最后选择的模型上启动。

- 项目中的新 Cowork 任务在默认模型上启动。

### 对于自定义角色

设置自己的默认模型的自定义角色在角色编辑器中有相同的开关。

1. 导航到 **[组织设置 > 角色](https://claude.ai/admin-settings/roles)**。

2. 点击您要编辑的角色。

3. 选择"模型"选项卡并为该角色选择默认模型。

4. 打开**始终使用默认模型和工作量级别启动**。

5. 点击"保存角色"。

## 为自定义角色设置默认模型

自定义角色默认值允许您为不同的团队设置不同的启动模型。例如，您可以将组织的大部分保留在推荐的默认值上，而特定的组在不同的模型上启动。

1. 导航到 **[组织设置 > 角色](https://claude.ai/admin-settings/roles)**。

2. 点击您要编辑的角色，或创建新角色。

3. 选择**模型**选项卡，然后在**默认模型**下选择一个模型。除非您选择特定模型，否则角色设置为"组织默认值"。只能选择该角色有权访问的模型。

4. 点击"保存角色"以保存您的更改。

角色的默认模型优先于分配给该角色的成员的组织默认值。

如果成员属于多个自定义角色设置不同默认模型的组，最强大的模型将是默认值。能力首先由模型系列（Haiku、Sonnet、Opus）确定，然后由发布日期确定，因此更强大的模型系列优先，同一系列中的较新模型优先。

角色对默认模型的工作量上限（如果有）仍然适用。角色不能设置高于组织对该模型的上限的工作量上限。有关详细信息，请参阅 **[限制自定义角色的最大工作量级别](https://support.claude.com/en/articles/15694740-manage-model-access-for-your-organization#h_e693614582)**。

**注意：**自定义角色仅影响角色设置为"自定义"的成员。具有用户、管理员或所有者角色的成员从组织设置获取默认模型，而不是从自定义角色获取。

有关创建角色和将其分配给组的详细信息，请参阅 **[在企业计划上管理自定义角色](https://support.claude.com/en/articles/13930452)**。

## 为自定义角色设置默认工作量级别

默认工作量级别适用于角色默认模型上的新对话。要设置它：

1. 导航到 **[组织设置 > 角色](https://claude.ai/admin-settings/roles)**。

2. 点击您要编辑的角色，或创建新角色。

3. 选择**模型**选项卡，然后在**默认模型**下选择一个模型。除非您选择特定模型，否则角色设置为"组织默认值"。只能选择该角色有权访问的模型。

4. 在**默认模型**下，从工作量级别下拉列表中选择一个选项：

  1. **使用 Anthropic 的推荐默认工作量：**Anthropic 推荐的默认模型工作量级别，在建议更改时自动更新。

  2. **从列表中选择一个级别。**可用的工作量级别因模型而异，某些模型根本不支持工作量级别设置。

5. 点击"保存更改"。

默认工作量级别不能高于组织对默认模型的工作量上限。如果您将该上限降低到低于当前默认工作量，默认工作量将被降低以匹配。

## 默认模型和 Claude Code 托管设置

如果您的组织还通过 `managed-settings.json` 配置 Claude Code，该处的模型设置优先。当在托管设置中设置模型时，Claude Code CLI 和 IDE 在该模型上启动，并忽略您在 **[组织设置 > 模型](https://claude.ai/admin-settings/models)**中设置的默认值。

如果 `managed-settings.json` 指定的 `availableModels` 不包含默认模型，Claude CLI 会绕过 `availableModels` 并在选定的默认模型上启动，除非设置了 `enforceAvailableModels`。

模型的托管设置仅适用于终端或 IDE 中的本地 Claude Code 会话，不适用于云会话或 Claude Desktop 中的 Claude Code。为了在所有 Claude Code 表面上实现一致的行为，我们建议仅在此处设置默认值。有关托管设置的更多信息，请参阅 **[Claude Code 设置](https://code.claude.com/docs/en/settings#settings-files)**。
