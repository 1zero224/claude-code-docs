## Claude 如何标记内容

Claude 使用两种互补技术来标记由 Claude 生成和处理的内容：(1) 嵌入在文本中的水印，以及 (2) 附加到文件的内容凭证 (C2PA)。

### 1. 文本中的嵌入式水印

当受支持的 Claude 模型生成文本时，它会将一个难以察觉的水印直接编织到文本本身中。您看不到它，它不会改变 Claude 响应的含义、质量或可读性。

由于水印是文本的一部分，当文本被复制和粘贴到其他地方时，它会随之传播，并可能在某些编辑后保留。水印将在模型级别应用，这意味着无论文本来自哪个 Claude 产品或界面，它都会存在。

### 2. 内容凭证 (C2PA)

当 Claude 生成受支持的文件类型（如 PNG 或 JPEG）时，它会附加已签名的来源元数据。此元数据称为内容凭证，遵循内容来源和真实性联盟 (C2PA) 开放标准，该标准在整个行业中用于记录内容来源信息。如果存在已签名的元数据标签，则表示文件已由 Claude 处理。

## 检测 Claude 的标记

检测检查一段文本或文件是否携带受支持的 Claude 标记。如果找到受支持的标记，则表示内容可能已由 Claude 生成或处理。

要检查文件是否包含 Claude 颁发的内容凭证，请使用免费的 **[Claude 内容检查器](https://claude.com/check-content)**。要了解有关 Claude 如何标记文件以及如何验证 Claude 颁发的内容凭证的更多信息，请参阅 **[生成文件上的内容凭证](https://platform.claude.com/docs/en/agents-and-tools/tool-use/code-execution-tool#content-credentials-on-generated-files)**。

水印检测目前处于私密预览阶段，可供根据欧盟法律（如监管机构、执法部门、媒体、事实核查机构、独立研究人员、教育机构和欧盟民间社会组织）要求的符合条件的组织使用。它也可供同样有义务为自己遵守《法案》而验证水印的企业使用。我们计划随着时间的推移扩大对检测 API 的访问权限。您可以在此处注册访问权限的兴趣：**[Claude 水印检测器访问请求表](https://forms.gle/9tGA33hPJJwtHsMk9)**。

## 限制

机器可读标记提供了关于内容的重要信号，但值得理解它们在所有内容类型中的局限性。

- **检测到的标记表明内容已由 Claude 处理，但并非完全确定。**检测到 Claude 标记表明内容可能已由 Claude 处理。这本身并不能确认内容的完整来源。例如：

  - Claude 可能不是原始作者。人们经常使用 Claude 进行校对、翻译、总结或转换文件。即使基础思想、文本或数据来自其他来源，输出也可能带有 Claude 标记；

  - 内容在 Claude 处理后可能已更改。标记的内容在 Claude 处理后可能被修改、摘录或与其他材料合并。

- **未检测到标记并不意味着内容不是由人工智能生成或处理的。**由 Claude 生成的内容可能不会带有可检测的标记，例如：

  - 它由该模型支持标记之前的模型生成；

  - 文本经过大量编辑、改写、翻译或混入其他文字；

  - 段落非常短，文本太少而无法提供可靠的信号；

  - 文件的元数据通过格式转换、重新保存、屏幕截图或其他方式被删除；

  - 它通过不支持特定标记类型的平台、功能或文件类型生成。

  - 它由 Claude Sonnet 4.6 使用非默认 `temperature`、`top_p` 或 `top_k` 生成。
