# Max、Ultra 和 Team 计划的每月 API 额度

Max、Ultra 和 Team 计划包括 Claude 平台的每月额度。使用这些额度通过 Claude API 将 Claude 集成到您自己的应用和代理中。本文介绍了谁有资格获得、如何领取额度、额度涵盖的内容以及额度用尽后会发生什么。

适用于 Max、Ultra 和 Team 计划，包括折扣 Team 计划。Free、Pro 和 Enterprise 计划不符合条件。

## 按计划分类的每月额度

| **计划**                | **每月额度**                         |
| --------------------- | -------------------------------- |
| Max                   | $100                             |
| Ultra                 | $200                             |
| Team（标准席位）            | 每席位 $20\*                        |
| Team（高级席位）            | 每席位 $100\*                       |
| 折扣 Team 计划（非营利组织、科学家） | 每个标准席位 $20 USD，每个高级席位 $100 USD\* |

*在 Team 计划中，所有席位的额度汇总为一个每月余额，上限为 $500。例如，拥有三个标准席位和两个高级席位的团队每月获得 $260。该池根据授予额度时计划中的席位数计算。

## 资格要求

- **有效计划。**您的 Max、Ultra 或 Team 订阅必须处于活跃状态且信誉良好。

- **在计划上已有七天。**新订阅者在符合条件的计划上已有七天后可以领取。

- **移动订阅。**您可以在网络、iOS 或 Android 上订阅。在网络浏览器中的 claude.ai 上领取您的额度。

- **无需支付方式。**您无需在 Claude 平台上添加卡即可领取或使用额度。

## 如何领取您的额度

要领取您的额度，您需要将 Claude Console 组织链接到您的计划。每个月额度都会进入该组织。

开始前，您需要：

- **在您的 Claude 计划上：**

  - **Max 或 Ultra：**成为订阅者

  - **Team：**成为主要所有者或所有者

- **在 Console 组织中：**拥有所有者、管理员或账单角色。如果您还没有 Console 组织，可以在领取流程中或在 **[platform.claude.com](https://platform.claude.com)** 创建一个。

要领取您的额度：

1. 在 claude.ai 上，作为 Max 或 Ultra 订阅者，转到 **[设置 > 账单](https://claude.ai/settings/billing)**，或作为 Team 所有者或主要所有者，转到 **[组织设置 > 账单](https://claude.ai/admin-settings/billing)**。

2. 在 **API 额度**部分，选择"链接组织"。

3. 选择您想要接收额度的 Console 组织，或创建一个新的。

4. 查看 **[补充额度条款](https://www.anthropic.com/legal/credit-terms)**，然后链接组织。

您的额度将出现在该组织的余额中，可以立即使用。

**重要提示：**您只能链接一个 Console 组织，每个 Console 组织只能从一个计划接收额度。您无法自己更改链接的组织，因此请选择您计划在其中构建的组织。要稍后更改，请 **[联系支持](https://support.claude.com/en/articles/9015913-how-to-get-support)**。

**提示：**使用您在 claude.ai 上使用的相同电子邮件登录 Claude Console。如果您在链接流程中看到错误，请在几小时后重试。

## 额度涵盖的内容

额度适用于 Claude 平台上的任何可用 Claude 模型，包括：

- Claude API（Messages API 和 Message Batches API）

- Claude Console 中的 Playground

- Claude 托管代理

- Claude Agent SDK

额度不适用于：

- 终端、IDE、桌面或网络中的交互式 Claude Code

- Claude、Claude Code 或 Claude Cowork 中的额外使用

- Amazon Bedrock、Google Cloud Vertex AI 或 Microsoft Foundry 上的 Claude

## 额度如何运作

- **每个计费周期刷新。**您的计划付款处理后不久，新额度就会到达。在年度计划中，额度每月到达。

- **不会结转。**未使用的额度在每个计费周期结束时过期。

- **优先使用。**您的每月额度在您购买的任何额度之前使用。

- **在组织中共享。**链接组织中拥有 API 密钥的每个人都从同一余额中提取。

- **与您的计划限制分开。**额度不会改变您在 Claude、Claude Code 或 Claude Cowork 中的使用限制。

- **在 Console 中可见。**所有额度都显示在 Claude Console 的 **账单**页面（platform.claude.com/settings/billing）上，包括其金额和过期日期。

## 当您的额度用尽时会发生什么

- **如果组织已购买额度或启用自动充值，**使用将继续并从这些额度中提取。

- **如果组织没有其他额度，**API 请求将停止，直到您的下一个每月额度到达。使用永远不会被计入您的 Claude 计划。要继续，请购买额度或在 Console 中启用自动充值。

- **如果您的组织通过 Anthropic 销售部门开具发票，**超出额度的使用将照常计费。

## 如果您的计划发生变化

- **取消、降级到不符合条件的计划或退款。**新额度停止。您已有的额度在过期前仍可使用。

- **从 Max 升级到 Ultra。**您立即获得按比例分配的额度，然后之后每个计费周期获得 $200。

- **从 Max 或 Ultra 移至 Team。**您的 Max 或 Ultra 链接结束。Team 所有者或主要所有者可以在 Team 计划激活七天后领取团队的额度。

## 对于 Team 所有者和主要所有者

**整个团队的一次领取。**一个所有者链接一个 Console 组织并领取汇总额度，每月最多 $500。

**该池遵循您的席位数。**每次存入额度时，根据您计划中的席位数计算。例如，拥有三个标准席位和两个高级席位的团队每月获得 $260。添加另一个高级席位会将下一个周期的额度增加到 $360。

**控制谁花费它。**链接组织中拥有 API 密钥的每个人都可以使用该余额。要按项目或队友限制使用，请在 Console 中设置 **[工作区支出限制](https://platform.claude.com/docs/en/api/rate-limits#setting-lower-limits-for-workspaces)**。

## 常见问题

### 为什么我不能将额度用于 Claude Code？

额度用于在 Claude 平台上构建您自己的应用和代理。它们不涵盖交互式 Claude Code 会话或超过您计划限制后的额外使用。

### 为什么我还看不到该优惠？

我们正在几天内推出 API 额度，所以我们可能还没有到达您。在您已有符合条件的计划七天后，该优惠就会出现。如果您已经超过七天但仍然看不到它，请检查您是否在 Max、Ultra 或 Team 计划上，以及您是否拥有所需的角色之一。如果您认为您应该符合条件但看不到 API 额度，请 **[联系支持](https://support.claude.com/en/articles/9015913-how-to-get-support)**。

### 这与六月宣布的 Agent SDK 额度相同吗？

不是。该额度不可用。API 额度涵盖 Claude API、Claude 托管代理和 Claude Agent SDK，您将其领取到 Console 组织中。

### 我可以将我的额度分散到多个组织中吗？

不可以。额度进入单个 Console 组织。

### 我在 Pro 计划上。我可以获得此额度吗？

不可以。额度仅在 Max、Ultra 和 Team 计划上可用。

### 这涵盖 `claude -p` 吗？

API 额度涵盖 `claude -p` 和 Claude Agent SDK，当您使用来自链接的 Claude Console 组织的 API 密钥自己运行它们时，因为该使用被计为 Agent SDK 使用。当您改为使用 Claude 计划登录时，`claude -p` 和 Agent SDK 使用仍然从您计划的使用限制中提取，不使用您的 API 额度。由 Claude Code GitHub Action、IDE 扩展或 Claude 桌面应用启动的运行计为 Claude Code 使用，因此 API 额度不涵盖它们，即使使用 `-p`。
