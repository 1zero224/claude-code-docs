# Claude 控制台角色和权限

Claude 控制台使用基于角色的访问系统，包含六个不同的角色：用户、Claude Code 用户、受限开发者、开发者、账单和管理员。每个角色都具有特定的权限和功能，旨在帮助团队安全地管理其 API 访问。

## 角色类型和权限

### 用户

- 只能使用 Workbench

- 可以查看 MCP 隧道

- 无法查看 API 密钥、使用日志或账单详情

### Claude Code 用户

- 可以使用 Workbench 和 **[Claude Code](https://code.claude.com/docs/en/overview)**

- 可以访问组织中的 Claude Code 工作区

- 可以查看 MCP 隧道

### 受限开发者

- 可以使用 Workbench 和 Claude Code

- 可以管理 API 密钥和 webhook 端点

- 可以查看使用情况和成本数据

- 可以管理保险库和凭证

- 可以查看 MCP 隧道
​

### 开发者

- 可以使用 Workbench 和 Claude Code

- 可以管理 API 密钥和 webhook 端点

- 可以查看使用情况和成本数据

- 可以管理保险库和凭证

- 可以查看会话跟踪

- 可以下载文件

- 可以查看 MCP 隧道

### 账单

- 可以使用 Workbench

- 可以管理账单详情

- 可以查看使用情况和成本数据

- 可以查看 MCP 隧道

- 无法访问组织中的 Claude Code 工作区

### 管理员

- 可以执行用户、开发者和账单角色可用的所有操作

- 可以管理用户及其角色分配

- 可以向活跃（未归档）会话发送事件

- 可以创建 MCP 隧道

## 工作区级权限

- 组织管理员自动在所有工作区中获得工作区管理员权限。

- 组织账单角色持有者可以查看所有工作区的成本、使用情况和限制值。

- 组织级角色作为基线，而工作区角色可以授予额外权限。

  - 例如，组织级别的用户可以在特定工作区内被授予管理员权限

## 重要说明

- 删除管理员或账单角色不会自动更新我们支付处理器中的账单电子邮件。

- 要修改主账单电子邮件地址或添加其他账单联系电子邮件，请 **[联系我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)**。
