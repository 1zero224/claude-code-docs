# 在第三方应用中使用您的 Claude Platform 账户

本文介绍了关联账单功能，它允许管理员（Admin 或 Billing 成员）将您的 Claude Console 组织关联到应用。您直接向 Anthropic 支付在该应用中的使用费用，无需共享 API 密钥。

关联账单功能处于测试阶段，并非所有应用都支持。

## 关联账单的工作原理

某些应用为您运行 Claude，您可能已与其中一个共享了 API 密钥。使用关联账单，您可以改为批准连接。应用永远不会收到您的 API 密钥或 Claude 密码。Anthropic 直接向您的组织收费，用于该应用中的 Claude 使用。

应用在其自己的组织中运行 Claude，而不是在您的组织中。只有账单转到您。您组织中的设置（如 IP 允许列表、加密密钥和数据保留（包括零数据保留））不适用于这些请求。

此连接改变了此使用的计费方式。它不改变适用于您组织在应用中使用 Claude 的条款或数据安排。

## 谁可以关联应用

您的组织必须由 Anthropic 直接计费，只有您组织中具有 Admin 或 Billing 角色的用户才能批准连接。如果您没有这些角色之一，请将请求转发给有权限的人。了解更多关于 **[Claude Console 角色和权限](https://support.claude.com/en/articles/10186004-claude-console-roles-and-permissions)**。

以下内容无法关联：

- 通过云提供商（如 Bedrock、Vertex AI 或 Foundry）获取 Claude 的组织无法关联

- Claude 订阅计划（Pro、Max、Ultra、Team 和 Enterprise）无法关联

- 通过 AWS、Google Cloud 或 Azure 市场付款的 Claude Console 组织无法使用关联账单

如果您还没有 Claude 账户或 Claude Console 组织，可以在关联时免费创建它们。在应用发出请求之前添加额度。

一次批准涵盖您的整个组织。链接属于组织，因此如果批准者离开，它仍保持活跃。您的组织每个应用可以有一个链接。

## 关联应用

要关联应用：

1. 在应用中，点击按钮关联您的 Claude 组织。

2. 登录 Claude。如果您有多个组织，请选择要关联的组织。

3. 阅读账单工作原理，然后设置每月支出限额或选择 “继续不设限额。” 如果应用仍在测试中，您必须设置 $50 或更低的限额。

4. 查看批准屏幕。它显示应用的名称，并请求权限向您的组织收费以支付应用为您发出的 Claude 请求。它还说明使用费用将按照您组织现有的账单条款计费。

5. 选择 “关联并授权。” 您将返回应用。

您组织的 Admin 和 Billing 成员通常会收到确认链接的电子邮件。

## 设置支出限额

在 Claude Console 的 **[关联平台](https://platform.claude.com/linked-platforms)** 页面上为每个应用设置每月限额（Console 称之为支出上限）。您也可以设置默认限额，该限额分别适用于每个应用。这不是跨应用的共享上限。

要为一个应用设置限额，请在 **关联平台** 下打开其页面。在那里设置的限额将替换您的默认限额。您组织自己的每月限额在 **支出限额** 下。

限额是可选的，以美元为单位。例外是处于测试中的应用，需要 $50 或更低的限额。设置从 $1 开始的整数金额，或设置 $0 以拒绝来自应用的所有请求。您组织自己的每月限额仍然适用，当您达到任一限额时，请求将被拒绝。

当您达到限额时，来自该应用的请求将被拒绝，直到您提高限额或月份在 1 日（UTC）重置。

限额不是精确的。超过限额的请求仍会被处理，已运行的调用也会完成，因此您的总额可能会略高于限额。

当应用中的使用达到限额的 80% 时，您组织的管理员会收到一封电子邮件，在 100% 时再收到一封。$0 限额不发送电子邮件。某些组织不会收到这些电子邮件。

使用按列表价格计算。它包括令牌和网络搜索。计算的金额可能与您发票上的金额不同。

## 取消关联应用

具有 Admin 或 Billing 角色的用户可以在 **[关联平台](https://platform.claude.com/linked-platforms)** 页面上取消关联应用。应用也可能允许您从应用内部取消关联。应用的团队可以从他们的一方取消关联。无论链接如何结束，应用随后在该页面上显示为 **已取消关联**。

如果您取消关联应用，您组织的 Admin 和 Billing 成员通常会收到电子邮件。如果应用的团队取消关联，他们可能不会收到。

新调用通常在约 10 秒内停止。已运行的调用会完成并向您的组织计费。过去的使用情况保留在 **使用情况** 和 **账单** 中。要再次关联应用，请批准连接。

## 关联使用如何计费

Anthropic 对关联使用计费，而不是应用。应用收取的任何订阅费用由应用单独计费。了解更多关于 **[如何支付您的 Claude API 使用费用](https://support.claude.com/en/articles/8977456-how-do-i-pay-for-my-claude-api-usage)**。

关联使用计费到您组织的预付余额或发票。某些促销额度无法使用。

### 可以支付的内容

- 您购买的额度（您的预付余额）

- 您的发票（如果您按月计费）

- 来自 Anthropic 的账单更正

- 写入您协议中的额度

### 无法支付的内容

- **[Max、Ultra 和 Team 计划附带的每月 API 额度](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-ultra-and-team-plans)**

- 限制用于特定产品的注册额度

- 来自 Anthropic 的合作伙伴、风险投资和初创公司计划的额度（我们仍在推出）

### 预期情况

- 如果您账户上没有任何内容可以支付，应用的请求可能会被拒绝。添加资金后，购买可能需要一些时间才能应用。

- 您的购买余额可能会下降，而促销余额保持不变。

- 随着我们的额度计划变化，我们可能会更新此列表。

## 查看关联使用

Console 中的 **关联平台** 页面列出了每个关联的应用，您可以在那里设置限额和取消关联。该页面还显示每个应用本月的成本。

## 常见问题

### 如果我的组织有 HIPAA、FERPA 或 CMEK 要求，它可以关联吗？

在测试期间不能。关联请求在应用的组织中运行，因此您组织的业务关联协议 (BAA)、加密密钥和保留设置（包括零数据保留）不适用。

## 获取帮助

有关应用的问题，请联系应用的团队。有关您的组织或账单的问题，请联系 **[我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)**。
