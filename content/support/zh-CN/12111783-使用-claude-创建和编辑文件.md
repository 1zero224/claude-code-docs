# 使用 Claude 创建和编辑文件

Claude 可以执行代码，直接在您的对话中创建和处理文件。使用自然语言提示 Claude 生成 Excel 电子表格、PowerPoint 演示文稿、Word 文档和 PDF 文件，您可以立即下载并使用。

代码执行和文件创建功能适用于所有 Claude 用户（免费版、专业版、Max、Ultra、Team 和企业版），可在网页版、Claude Desktop 和 Claude Mobile 上使用。

这些功能使您可以通过与 Claude 聊天轻松生成专业文档。您可以在 Excel 中创建包含工作公式的财务模型、对上传的数据进行高级分析、生成包含图表和可视化的报告，以及从文档生成演示文稿——所有这些都无需专业软件技能。

---

## 可用性

**免费版、专业版、Max 和 Ultra 计划：**

- 代码执行和文件创建默认启用

- 网络访问已启用，允许 Claude 从批准的来源安装软件包

**Team 计划：**

- 对于 Team 计划组织，代码执行和文件创建默认启用

- 组织所有者可以在组织设置中禁用它

- 网络访问默认禁用；所有者可以在组织设置中启用它

**企业计划：**

- 对于新的企业计划组织，代码执行和文件创建默认启用

- 组织所有者可以在组织设置中禁用它

- 网络访问默认禁用；所有者可以在组织设置中启用它

- 所有者可以配置网络访问控制，包括域名白名单

## 禁用网络访问如何解决代码执行和文件创建的安全问题？

禁用网络访问可防止 Claude 沙箱环境中的代码向外发送数据。连接器仍然可以发送数据。

### 工作原理

当 Claude 执行代码或创建文件时，它在隔离的沙箱容器中运行。这意味着工作在与您的系统分离的受控环境中进行。但是，如果启用了网络访问，就存在潜在风险：通过提示注入或其他攻击，Claude 可能被诱骗向外部服务器发送数据。

禁用网络访问可以降低这种风险。您的团队仍然可以获得 Claude 的完整代码执行和文件创建功能——构建 Excel 模型、创建演示文稿、分析数据——沙箱中的代码无法向外发送数据，但连接器仍然可以。

### 网络访问的分阶段方法

启用网络访问时 Claude 功能最强大，允许它安装新软件包和依赖项、获取实时数据并与网络服务交互。对于能够接受该风险的组织，启用对经过审查的可信域的访问可以充分发挥代码执行和文件创建的潜力。对于采取更谨慎方法的组织，我们建议从禁用网络访问开始，并随着您的团队建立信心而进行调整：

1. **从禁用网络访问开始。**这是最安全的配置。Claude 可以执行代码和创建文件，但沙箱中的代码无法进行外部通信。连接器仍然可以。

2. **启用软件包管理器。**解锁 pip、npm 和其他软件包管理器以安装依赖项——大大扩展了 Claude 可以构建的内容。

3. **根据需要扩展网络访问。**根据业务需求将特定域添加到允许列表，保持对允许内容的可见性。

这种方法提供了深度防御——即使沙箱中存在漏洞或提示注入成功，禁用的网络访问也有助于防止沙箱中的代码向 Anthropic 基础设施外发送数据。连接器仍然可以发送数据。

**注意：**如果启用了 MCP（模型上下文协议）集成，无论网络出站设置如何，网络通信仍可能通过这些连接进行。这包括与连接器的文件传输。组织应单独评估 MCP 配置。

## 使用代码执行和文件创建

启用后，只需在您的消息中描述您需要的内容。例如，您可能会说“创建一个 Excel 电子表格来跟踪每月支出”或“将此文档转换为 PowerPoint 演示文稿。”Claude 将生成该文件，您可以直接从对话中下载。

从简单任务开始以熟悉 Claude 的功能，然后进行更复杂的工作流程。在您的请求中要具体——描述您想要的结构、内容和格式。您可能需要查看和完善 Claude 的输出以满足您的确切要求。

### 支持的文件类型

Claude 可以创建 Excel 电子表格 (.xlsx)、PowerPoint 演示文稿 (.pptx)、Word 文档 (.docx) 和 PDF 文件。您可以下载 Claude 创建的文件或直接将其保存到 Google Drive。

使用此功能，Claude 还可以进行更高级的数据分析和数据科学工作。Claude 可以为数据分析创建 Python 脚本。Claude 可以在 PNG 等图像文件中创建数据可视化。您还可以上传 CSV、TSV 和其他文件进行数据分析和可视化。

上传和下载的每个文件的最大文件大小为 30MB。从连接的应用发送或保存的文件有不同的限制。详细了解**[连接应用的文件限制](https://support.claude.com/en/articles/18534325)**。

## 安全性和网络访问

### 工作原理

代码执行和文件创建为 Claude 提供了一个沙箱计算环境。Claude 的互联网访问将根据您的网络出口设置而有所不同。

**网络访问允许 Claude：**

- 从批准的包管理器（npm、PyPI 等）下载和安装包

- 访问文件创建和分析所需的资源

## 安全考虑

恶意行为者可能会通过外部文件或网站隐蔽地添加指令，诱骗 Claude：

1. 在沙箱环境中下载并运行不受信任的代码以实现恶意目的

2. 从已连接的知识源（例如 Remote MCP、项目）读取敏感数据，并使用沙箱环境进行外部网络请求以泄露数据

这意味着 Claude 可能被诱骗将其上下文中的信息（例如提示、项目、通过 MCP 的数据、Google 集成）发送给恶意第三方。为了降低这些风险，我们建议您在使用该功能时监控 Claude，如果看到它意外使用或访问数据，请停止它。您可以直接在 Claude 中使用向下拇指功能向我们报告问题。

根据我们的 **[安全可信代理框架](https://www.anthropic.com/news/our-framework-for-developing-safe-and-trustworthy-agents)**，我们采取了以下缓解措施：

- 为您提供对该功能的完全控制。您可以随时打开或关闭它。

- 设计 Claude 为您提供其操作的用户友好摘要，以便您可以看到它在做什么。您可以随时停止 Claude 的操作，我们建议在使用该功能时监控 Claude 的工作。

- 为您提供审查和审计 Claude 在沙箱环境中采取的操作的能力。

- 对于免费、专业、最大和超级用户，禁用了包含代码执行和文件创建功能中任何文件工件的对话的公开共享。

- 限制了 Claude 可以完成的任务持续时间和您可以使用单个沙箱容器的时间长度，以避免恶意活动循环。

- 实现了沙箱隔离，使得沙箱环境永远不会在用户之间共享。

- 有意限制了网络、容器和存储资源。

- 实现了提示注入分类器以检测恶意提示操纵并在检测到时停止执行。

我们对此功能进行了红队测试和安全测试。我们有一个持续的流程用于进行中的安全测试和红队测试。我们鼓励组织在决定是否启用此功能时，根据其特定的安全要求评估这些保护措施。

### 对于团队和企业所有者

团队和企业所有者对此功能拥有完全控制权，包括：

- 在整个组织范围内启用或禁用该功能

- 控制网络访问设置

- 配置域名白名单以仅允许访问特定的批准域

**注意：**Claude 只能被诱骗泄露它在通过个人用户的提示、项目或已激活的连接在对话中可以访问的数据。

```

```

Claude 将生成一个 Excel 文件，包含适当的公式、格式设置，甚至图表来可视化您的数据。

通过提供您的信息和要求来结合数据分析和文档创建。尝试：

```
Explain this Excel spreadsheet in a Word report with commentary.
```

## 常见问题

### 文件创建如何工作？

我们为 Claude 提供了直接在 claude.ai 中的私有计算环境。这允许 Claude 编写和运行代码（例如 Python 或 Javascript）。它使用常见的代码包来创建文档、电子表格和幻灯片。用户还可以让 Claude 使用其计算环境进行其他操作，如数据分析、调试代码片段和有趣的任务，如 gif 创建。

### Claude 的文件创建功能如何影响使用限制？

使用此功能会从您的计划提供的相同使用限制中扣除。请注意，创建文件将比与 Claude 的正常聊天使用更多的限制。

### Claude 可以同时处理多个文件吗？

Claude 可以在单个聊天中处理多个文件，允许您创建全面的多文件报告和分析。在您的对话过程中，文件始终可供下载。

### Claude for iOS 或 Android 是否支持文件创建？

Claude for iOS 和 Android 支持文件创建。请注意，当您在 Claude Mobile 上点击“下载”时，文件将在系统预览或单独的应用程序中打开（例如，.docx 文件的 Word 应用程序）。

### Claude 可以在使用我的关联账户的聊天中创建文件吗？

Claude 可以创建纯文本文件（如 .csv、.md 和 .html）并在聊天中显示文本和表格。在 Claude 在聊天中使用您的关联账户进行个人财务后，它可能无法运行代码、创建其他文件（Word、Excel、PowerPoint 或 PDF）或发布工件。在**[在 Claude 中使用个人财务](https://support.claude.com/en/articles/18185620-use-personal-finance-with-claude)**中了解更多信息。

### 工件是否适用于文件创建？

是的，启用文件创建后，您仍然可以创建工件（例如 HTML 或 React 应用程序、Markdown 文档、Mermaid 图表、SVG）。Claude 现在使用计算环境来创建工件，因此用户体验可能看起来与用户习惯的略有不同。请使用与 Claude 聊天时的竖起大拇指/竖起大拇指功能报告任何问题或反馈。
