# 导出您组织的数据

组织数据导出仅适用于 Team 和 Enterprise 计划的主要所有者。数据导出包括对话数据和您组织的用户数据。主要所有者和所有者也可以让用户导出他们自己的数据。在下面的**[让用户导出他们自己的数据](#h_68f7c2a1e0)**部分了解更多信息。

如果您是使用 Free、Pro、Max 或 Ultra 计划的个人 Claude 用户，想要导出您的数据，请参阅**[导出您的 Claude 数据](https://support.claude.com/en/articles/9450526)**。

Team 和 Enterprise 计划的主要所有者可以从网络应用或 Claude Desktop 上的**[组织设置 > 数据和隐私](https://claude.ai/admin-settings/data-privacy-controls)**导出组织数据。

**重要提示：**数据导出不包括 Claude 创建的 Word、Excel、PowerPoint 或 PDF 文件。用户可以在聊天中下载这些文件（如果仍可用）。使用 Compliance API 的 Enterprise 组织也可能能够检索它们。导出也不包括安全中心证明数据。

按照以下步骤导出您组织的数据：

1. 点击您账户左下角的首字母缩写。

2. 从菜单中选择“组织设置”。

3. 点击“数据和隐私”打开该部分。

4. 点击“导出数据”按钮。

导出处理完成后，您将通过电子邮件收到下载链接。

**重要提示：**从您的账户中删除的消息、文件和项目（由个人用户手动删除或通过企业保留设置删除）将不会包含在删除后启动的数据导出中。

请注意：

- 生成导出时可能会有轻微延迟。

- 电子邮件将发送到与您账户关联的地址。

- 您必须登录到您的账户才能使用此链接下载您的数据。

- 下载链接将在创建后 24 小时过期，且可能只能使用一次，因此请立即下载该文件。

- 如果您的链接过期或无法打开，您可以通过重复导出过程来请求新链接。

如果您是想要导出审计日志的 Enterprise 主要所有者，请参阅**[如何访问审计日志](https://support.claude.com/en/articles/9970975-how-to-access-audit-logs)**。

## 让用户导出他们自己的数据

所有者和主要所有者可以让您组织中的用户导出他们自己的聊天，而无需导出整个组织。

要启用此功能：

1. 导航到**[组织设置 > 数据和隐私](https://claude.ai/admin-settings/data-privacy-controls)**。

2. 在“数据管理”部分中，启用“允许成员导出他们自己的数据。”

启用该设置后，用户可以从 Claude 网络版或 Claude Desktop 上的**[设置 > 隐私](https://claude.ai/settings/data-privacy-controls)**导出他们的数据。Claude iOS 版或 Claude Android 版中不提供导出功能。每次导出涵盖用户自己的聊天，不包括上传文件的内容。了解更多关于**[导出您的 Claude 数据](https://support.claude.com/en/articles/9450526)**的信息。

**注意：**主要所有者看不到个人“导出数据”按钮，即使启用了此设置。这些角色使用上述步骤导出整个组织的数据。
