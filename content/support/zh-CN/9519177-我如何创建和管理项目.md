# 我如何创建和管理项目？

所有用户（包括拥有免费 Claude 账户的用户）都可以使用项目。免费用户最多可以创建五个项目。

## 如何创建项目

1. 将鼠标悬停在账户左侧，然后点击

2. 点击右上角的"+ 新建项目"。

3. 为您的项目命名并添加描述（请注意 Claude 无法访问这些详细信息）。

4. 如果您使用的是团队或企业计划，请选择可见性设置：

  - **保持私密：**只有您和您邀请的成员可以查看或使用此项目。

  - **与您的整个组织共享：**您组织中的所有人都可以查看和使用此项目（如果管理员启用）。

5. 如果您使用企业计划，且您的组织要求项目标签（测试版），请为每个必需标签设置值。请参阅**[使用项目标签按成本代码跟踪支出](https://support.claude.com/en/articles/18251257-track-spend-by-project-with-tags)**。标签名称和值对您组织中的所有用户可见，因此请勿在其中包含敏感信息。

项目设置完成后，您可以在项目内与 Claude 开始聊天。

## 向项目知识库添加内容

您可以在项目主页的右侧找到项目知识库。您上传到此空间的任何内容都将在该项目内的所有聊天中使用。

### 向项目知识库添加内容

1. 点击"+"按钮向项目添加内容。

2. 上传相关文档、文本文件或代码片段。

3. Claude 将处理此信息并在您的项目聊天中将其用作上下文。

4. 如果您使用付费 Claude 计划，当您的项目知识接近上下文窗口限制时，**[Claude 将自动启用 RAG 模式以扩展您的项目容量](https://support.anthropic.com/en/articles/11473015-retrieval-augmented-generation-rag-for-projects)**。

### 向项目知识库添加项目说明

1. 点击"设置项目说明"。

2. 添加关于您希望 Claude 如何表现和响应的说明，然后点击"保存说明"。

3. Claude 将在项目内的所有聊天中使用这些说明。

**注意：**除非信息被添加到项目知识库中，否则上下文不会在项目内的聊天之间共享。

---

## 共享项目

如果您使用的是团队或企业计划，您可以与组织中的其他用户共享项目，除非您的管理员已关闭项目共享。请参阅**[如果您无法共享项目](https://support.claude.com/en/articles/9519189-manage-project-visibility-and-sharing#h_d5a68ef397)**了解预期情况。

### 共享项目

1. 打开您要共享的项目。

2. 点击项目名称右侧的"共享项目"按钮。

3. 使用成员的名称或电子邮件地址添加个人成员，或复制并粘贴电子邮件地址列表以进行批量共享。

4. 为每个成员选择适当的权限级别：

  - **可以查看：**成员可以查看项目内容、知识和说明，以及在项目内聊天，但无法编辑。

  - **可以编辑：**成员可以修改项目说明和知识、更新成员设置、在企业计划上添加项目标签（测试版），以及积极为项目做出贡献。

5. 点击"共享"发送邀请。

### 管理共享项目访问权限

- **更改权限：**打开共享菜单并为成员选择新角色。

- **查看谁有权限：**共享菜单显示所有当前成员及其权限级别。

- **移除访问权限：**项目创建者可以点击成员的当前角色并选择"移除访问权限"。

### 查找共享项目

您的**[项目页面](https://claude.ai/projects)**有三个选项卡："您的项目"、"组织"和"与您共享"。"您的项目"列出您创建的项目，"组织"列出其他成员与您的组织共享的项目。如果您找不到项目，请检查所有三个选项卡。

## 为项目加星标以快速访问

为项目加星标可以从您的项目和聊天列表中快速访问，在将鼠标悬停在账户左侧时可见。您可以从两个不同的区域为项目加星标：

### 从"项目"页面

1. 在"项目"页面上找到该项目。

2. 点击项目右上角的三个点（"..."按钮）。

3. 从出现的菜单中选择"加星标"。

### 从项目

1. 打开相关项目。

2. 点击右上角的星形图标。

3. 该项目现在将出现在您账户左侧面板的加星标项目中。

## 在项目中管理 Claude 的记忆

在网络、Claude Desktop 和 Claude Mobile 上，免费、专业、最大和超级计划默认启用记忆。在团队和企业计划上，所有者控制记忆是否可用。

每个项目都有自己的记忆。在项目中工作时，Claude 使用项目的记忆以及您来自项目外聊天的记忆，但不使用来自其他项目的记忆。新记忆被保存到项目中，如果您启用了记忆，Claude 也可以在项目外的聊天中引用它。要保持项目的记忆完全分离，请在项目页面的**记忆**下关闭"使用账户记忆"。

您可以通过在发送第一条消息之前在"+"菜单中关闭"记忆"，为单个聊天（项目内或项目外）关闭记忆。以这种方式启动的项目聊天不使用或添加到项目的记忆中。

有关更多信息，请参阅我们关于聊天搜索和记忆的文章：**[什么是 Claude 的记忆？](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context#h_82126ebcc9)**

## 如何存档项目

存档是组织项目和整理项目列表的一种方式。它对于已完成的项目或您不积极处理但将来可能需要参考的项目特别有用。

**重要：**存档项目不会重置其共享权限或移除成员。所有成员、权限级别和项目知识都会保留，当您取消存档项目时，一切都会完全恢复。要撤销某人的访问权限，请在项目的共享设置中移除他们。

以下是您需要了解的关于存档的信息：

- 已存档的项目将出现在您主项目列表的底部。

- 您仍然可以访问已存档项目中的对话。

- 目前无法删除已存档的项目（您必须先取消存档）。

### 要存档项目，请按照以下步骤操作

1. 导航到您要存档的项目。

2. 点击右上角的三个点（"..."按钮）。

3. 确认您要存档该项目。

### 如何访问已存档的项目

您可以在**[项目页面](https://claude.ai/projects)**上的已存档项目选项卡中访问已存档的项目。

## 如何取消存档项目

有两种方法可以使已存档的项目再次活跃：

### 从已存档项目选项卡

1. 找到已存档的项目。

2. 点击右上角的三个点（"..."按钮）。

3. 从出现的菜单中选择"取消存档"。

### 从项目

1. 导航到已存档的项目。

2. 点击右上角的三个点（"..."按钮）。

3. 确认您要取消存档该项目。

---

## 删除项目

**注意：**无法删除已存档的项目。要查看删除已存档项目的选项，您必须先取消存档。

### 从"项目"页面

1. 在**[项目页面](https://claude.ai/projects)**上找到该项目。

2. 点击项目右上角的三个点（"..."按钮）。

3. 从出现的菜单中选择"删除"。

4. 通过点击"是，删除"在弹出窗口中确认删除。

### 从项目

1. 导航到项目

2. 点击星形旁边的三个点（"..."按钮）。

3. 选择"删除"。

4. 通过点击"是，删除"在弹出窗口中确认删除。
