# 我遇到了API连接错误。我该如何修复它?

此错误通常表示您这一端存在问题，可能与您的防火墙、网络或 VPN 有关。请尝试以下步骤：

- 检查是否有任何防火墙规则或网络限制阻止了与 Claude API 端点的连接。

- 配置您的防火墙或网络设置以允许连接。

- 确保在运行请求时未使用 VPN。

如果您需要[联系我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)以获得进一步帮助，您可以点击帮助中心右下角的消息图标，或点击您的 Claude Console 账户左下角的首字母缩写，然后选择"获取帮助"。
