# 使用连接器扩展 Claude 的功能

本指南说明如何启用和使用连接器与 Claude 配合，以增强其功能。

网络连接器适用于 Claude、Cowork、Claude Desktop 和 Claude Mobile（iOS 和 Android）上的所有用户。桌面扩展适用于 Claude Desktop 上的所有用户。

**注意：**Plaid 是个人财务的一部分，有其自己的要求和限制。详细了解如何**[在 Claude 中使用个人财务](https://support.claude.com/en/articles/18185620-use-personal-finance-with-claude)**。

## 什么是连接器？

连接器让 Claude 可以访问您的应用和服务、检索您的数据，并在连接的服务中执行操作。Claude 从连接的服务继承每个人的权限。如果某人无法在源系统中访问特定文件、频道或记录，连接器也无法从 Claude 访问它。使用共享凭证的自定义连接器可以访问该凭证能访问的任何内容。

例如，您可以将 Claude 连接到 Linear 以创建问题、连接到 Slack 以发送消息，或连接到 Google Drive 以搜索您的文件。连接器可在 Claude、Claude Desktop、Claude Code 和 API（通过**[MCP 连接器](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector)**）中使用。各个预构建连接器的设置详情在**[Claude 文档：连接器](https://claude.com/docs/connectors/overview)**中。

您可以在**[连接器目录](https://claude.ai/connectors)**中找到可用的连接器，其中每个连接器都有一个页面，详细说明其用例、读/写功能和可用性。您也可以添加自定义连接器或连接到任何支持 MCP 的服务。

## Claude 如何建议连接的应用

连接应用后，当 Claude 认为适合您的需求时，它可以自动将其引入对话中——您不必每次都提及它。有关其工作原理的详情，包括多个应用可能有帮助时会发生什么，请参阅**[Claude 如何建议连接的应用](https://support.claude.com/en/articles/14730684-how-claude-suggests-connected-apps)**。

## 浏览可用的连接器

您可以在 Claude、Claude Desktop 和 Claude for iOS/Android 上浏览连接器目录。

您可以从两个区域浏览目录：

**从聊天中**

1. 点击聊天左下角的"+"按钮，或输入"/"打开菜单。

2. 将鼠标悬停在"连接器"上。

3. 选择"管理连接器"。

4. 点击**连接器**旁边的"+"按钮。

5. 这将打开一个**连接器**模态框，您可以按类别查看可用的连接器或滚动浏览完整列表。

**从设置中**

1. 导航到**[自定义 > 连接器](https://claude.ai/customize/connectors)**。

2. 点击**连接器**旁边的"+"按钮。

3. 按类别浏览可用的连接器或滚动浏览完整列表。

## 将服务连接到 Claude

您可以在 Claude、Claude Desktop 和 Claude for iOS 和 Android 上将 Claude 连接到新服务。在移动设备上安装连接器目前处于测试阶段——Claude Desktop 和网络仍然是自定义连接器的主要途径。

要从目录连接服务：

1. 点击您要添加的连接器。

2. 查看连接器的描述和功能。

3. 点击"连接"或"安装"以开始设置过程。

4. 按照身份验证提示授予 Claude 访问您账户的权限。

5. 根据需要配置任何特定的设置或权限。

**重要：**连接到服务时，您授予 Claude 权限以根据您的账户权限访问和可能修改该服务中的数据。仅连接您信任且工作流中需要的服务。

## 在团队和企业计划上连接服务

在团队和企业计划的成员可以使用连接器之前，所有者或主要所有者需要为组织启用它们。启用连接器使其对您的团队可用，但不会自动授予任何人访问权限。每个人在使用之前仍需要单独进行身份验证。

**注意：**使用企业托管身份验证，您可以为整个组织授权一次连接器，您的团队在首次登录时自动继承访问权限。企业托管身份验证在 Claude 上的团队和企业计划中处于测试阶段。了解**[为整个组织授权 MCP 连接器](https://support.claude.com/en/articles/15537633)**。

1. 导航到**[组织设置 > 连接器](https://claude.ai/admin-settings/connectors)**。

2. 点击页面底部的"浏览连接器"。

3. 从列表中选择连接器，然后点击"添加到您的团队"。

4. 然后，各个用户可以使用连接器进行身份验证，以开始与 Claude 一起使用它。

在组织级别启用后，各个用户按照上述相同步骤进行连接和身份验证。

**注意：**在企业计划上，所有者和主要所有者可以防止其验证域上的服务连接到组织外的 Claude 账户。详细了解**[将验证域连接器限制到您的企业](https://support.claude.com/en/articles/15402193-restrict-verified-domain-connectors-to-your-enterprise)**。

### 让用户请求连接器

无法自己添加连接器的用户可以要求所有者添加一个。他们在连接器目录中的连接器页面上选择"请求"。

在团队计划上，连接器请求默认启用。在企业计划上，它们默认关闭，在所有者打开它们之前不会发生任何变化：

1. 导航到**[组织设置 > 连接器](https://claude.ai/admin-settings/connectors)**。

2. 打开**让成员请求连接器**。

只有所有者和主要所有者可以更改此设置。其他管理员可以看到它但无法更改它。

请求出现在**[组织设置 > 通知](https://claude.ai/admin-settings/notifications)**中的**请求**选项卡上。对于每个请求，所有者或主要所有者可以：

- 批准它，这会为您的组织添加连接器

- 拒绝它

- 拒绝它并阻止连接器，这样在所有者添加它之前，其他人都无法请求它

### 限制连接服务中的操作

Team 和 Enterprise 计划的所有者可以限制连接服务在整个组织中可以执行的操作。例如，您可以允许连接器从服务读取数据，同时防止它写回任何更改。这对使用该连接器的所有人都适用于整个组织——个人用户无法覆盖它。

常见用例：

- 允许 Claude 搜索和总结电子邮件，但防止它发送消息。

- 允许 Claude 读取 Google Drive 中的文件，但防止它创建或编辑文档。

- 允许 Claude 查看 Linear 问题，但防止它创建新问题或更改状态。

配置操作限制：

1. 导航到 **[自定义 > 连接器](https://claude.ai/customize/connectors)。**

2. 选择连接器以查看 **工具权限**。

3. 权限将按类型分类（例如，只读工具、写入/删除工具）。

4. 对于每个权限类别或单个权限，选择

**注意：**操作限制与源系统权限一起工作。即使您在 Claude 中允许写入操作，用户仍然需要在源系统中拥有基础权限才能进行该更改。在 Claude 中限制操作永远不会授予比源系统允许的更多访问权限——它只会缩小范围。

## 安全和隐私

所有数据传输都是加密的。使用连接器时，您只能将您有权在原始源中查看的内容同步到 Claude。

连接的服务在其自己的基础设施上处理数据，根据其自己的条款，可能位于美国以外。控制 Claude 推理运行位置的设置（如 Enterprise 计划上的仅美国推理设置）不会改变第三方服务的运行位置。

从目录连接到服务时，查看该服务在连接过程中请求的访问权限。断开您不再需要或使用的服务。

**对于 Team 和 Enterprise 计划：**

- 访问权限在用户级别强制执行。用户在首次使用连接器时需要向第三方服务进行身份验证，即使所有者或主要所有者已启用该连接器，除非该连接器使用共享凭证。

- 如果您的组织关闭了**共享使用连接器的聊天**，用户将无法共享使用连接器或同步内容的聊天。这包括具有同步内容的项目中的每个聊天。

## 排查连接问题

如果您在连接到服务时遇到问题，请尝试以下步骤：

1. 检查您是否有稳定的互联网连接。

2. 验证您是否拥有该服务的有效账户。

3. 查看该服务的任何权限或账户类型要求。

4. 如果身份验证失败，请尝试从**[自定义 > 连接器](https://claude.ai/customize/connectors)**断开连接并重新连接。

5. 有关连接器特定要求和已知问题（Slack、GitHub、Google Drive、Gmail、Google Calendar、Microsoft 365），请参阅**[Claude 文档：连接器](https://claude.com/docs/connectors/overview)**中的连接器页面。

### 看到显示"此企业身份属于通过自己的 Claude 账户管理访问权限的企业"的消息？

您尝试连接的服务使用企业组织已验证的域上的电子邮件地址，该组织仅限制连接到其自己的 Claude 账户。要使用此连接，请登录您组织的 Claude 账户并在那里连接该服务。如果您在该组织中没有 Claude 账户，请联系您的管理员以获取访问权限。

管理员可以详细了解**[将已验证域连接器限制到您的企业](https://support.claude.com/en/articles/15402193-restrict-verified-domain-connectors-to-your-enterprise)**。

### 自定义连接器无法连接或超时？

自定义连接器（远程 MCP 服务器）从 Anthropic 的云基础设施访问，而不是从您的本地计算机访问。即使您使用在计算机上本地运行的 Cowork 或 Claude Desktop，情况也是如此。如果您的 MCP 服务器位于公司防火墙后、专用网络上或无法通过公网访问，连接将失败。

要解决此问题，您可以在防火墙中将 Anthropic 的 IP 范围加入白名单，以从您的网络创建安全的仅出站连接。有关详细指导，请参阅**[开始使用远程 MCP 的自定义连接器](https://support.claude.com/en/articles/11175166)**中的网络要求部分。
