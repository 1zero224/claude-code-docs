# 在 Claude 中使用个人财务

个人财务功能让你可以将银行账户、信用卡、贷款和投资账户关联到 Claude，这样你就可以在一个页面上查看余额和支出，并向 Claude 提问关于你自己的财务问题。本文将向你展示如何设置个人财务、关联和取消关联银行，以及查看 Claude 可以访问的内容。

此功能在美国的 Pro、Max 和 Ultra 计划中处于测试阶段。它在 Claude、Claude Desktop、Claude for iOS 和 Claude for Android 上可用，但在免费版、团队版或企业版计划上不可用。我们正在逐步推出，所以你可能还看不到它。

个人财务只能读取你的账户。它无法移动、管理或投资你的资金。Claude 使用 Plaid（一个将应用程序连接到银行的网络）。通过 Plaid，你可以验证你的财务账户，所以 Claude 不会要求或看到你的银行密码。在**[你的数据如何被使用](#h_6b21c7ac44)**中了解更多。

**注意：**Claude 是 AI，可能会出错。在**[Claude 如何回答关于你的资金的问题](#h_b6a51ba950)**中了解更多。

## 你可以在个人财务中做什么

- **在一个页面上查看你的资金。**小部件显示你的支出、现金流、账户、订阅、即将到期的账单和来自 Claude 的简短见解。你可以添加、编辑、删除和重新排列它们。

- **询问 Claude。**在个人财务页面上输入问题、选择建议的问题或在常规聊天中提问。例如，“我上个月的钱去哪了？”或“我在支付哪些订阅？”

## 设置个人财务并关联你的银行

按照以下步骤设置个人财务并与 Claude 共享你的账户：

1. 在网络上、Claude Desktop 或移动应用上打开 Claude。

2. 在侧边菜单中打开“个人财务”。如果你看不到它，请将鼠标悬停在**更多**上。

3. 选择“开始使用。”

4. 选择你的目标，或跳过它们。

5. 选择“继续。”

6. 选择“使用 Plaid 关联账户。”

7. 在“将 Plaid 连接到 Claude”上，查看 Claude 将能够访问的内容。

8. 选择“继续。”

9. 在 Plaid 中，选择你的银行，登录，然后选择你想要共享的账户。

10. 回到 Claude，等待你的账户显示，然后选择“关联另一个账户”或“完成。”

**注意：**Plaid 在新窗口（网络）、你的默认浏览器（Claude Desktop）、应用内（iOS）或浏览器标签页（Android）中打开。在 10 分钟内完成，然后立即返回 Claude。交易可能需要几分钟才能同步。

## 关联另一个银行

你最多可以关联 16 个银行。达到限制后，你需要取消关联一个银行才能关联另一个。

- **网络和 Claude Desktop：**点击页面顶部的“关联另一个账户”。

- **iOS 和 Android：**点击页面右上角的齿轮图标，然后点击“关联另一个账户。”

要在已关联的银行添加账户，请再次关联该银行并共享你希望 Claude 读取的每个账户。

## 如果 Claude 说银行已经关联

选择以下选项之一：

- **切换到新链接：**新登录替换旧登录，Claude 仅读取你这次共享的账户。选择此选项以添加账户或修复银行。

- **保持原样：**Claude 保持你现有的链接，不关联任何新内容。

- **保留两者：**为同一银行的第二次登录选择此选项，例如联合账户或商业账户。如果一个账户在两个登录中，当你的银行在每个登录下以相同方式显示它时，Claude 只计算一次。如果你的银行显示方式不同，它可能在你的总数中被计算两次。

## Claude 可以访问什么

对于你选择共享的账户，Claude 可以读取：

- 银行名称

- 账户名称、类型和最后四位数字

- 余额和信用额度

- 最多 24 个月的交易，包括金额、日期、商户、类别和你的银行的描述

**账户号码：**Plaid 仅向 Claude 提供每个账户号码的最后几位数字（通常是四位）。如果你的银行在账户名称或交易描述中写入完整号码，Claude 可能会在那里看到。

**投资、贷款和信用卡：**Claude 可以读取你的信用卡和贷款（包括抵押贷款和学生贷款）的详细信息，例如利率、对账单余额、最后和下一次付款、到期日期、付款是否逾期，以及贷款的开始日期、原始金额和计划还款日期。对于学生贷款，Claude 还可以读取其状态（例如在校或逾期）和还款计划类型（例如基于收入）。对于投资和退休账户，Claude 还可以读取交易，例如交易、股息、贡献、提取、费用和预扣税款。此外，Claude 可以读取这些账户持有的内容，包括每项持有的名称、数量、价格、价值和成本。Plaid 自己的屏幕也可能要求你同意共享投资、信用和贷款数据。

## 你的数据如何被使用

- **你的许可：**通过连接 Plaid，你授予与 Claude 共享某些数据的许可。列表在上面的**[Claude 可以访问什么](#h_fa85d6ccb2)**部分中。

- **你的银行登录：**Claude 使用 Plaid 连接到你的银行。你通过 Plaid 登录，所以 Claude 不会要求或看到你的银行密码。

- **Claude 如何使用你的财务数据：**我们使用此数据来响应你的请求。当你在个人财务中心与 Claude 聊天时，这些对话不会用于训练我们的模型。对于你在中心外与 Claude 共享的任何内容，你的隐私设置适用。数据显示在你的对话中，并保留在你的聊天历史中，直到你删除聊天，受我们的数据保留实践约束。为我们托管 Claude 的服务提供商也处理银行数据。Plaid 根据其自己的条款和隐私政策处理它。

- **如何停止：**取消关联一个银行，Claude 就会停止读取它（请参阅**[取消关联银行](#h_8c27edcfa3)**）。你也可以在**[my.plaid.com](https://my.plaid.com)**断开 Claude 的连接。

有关更多信息，请参阅**[Anthropic 隐私政策](https://www.anthropic.com/legal/privacy)**和**[Plaid 隐私政策](https://plaid.com/legal/#end-user-privacy-policy)**。了解更多关于我们的**[数据处理和保留](https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data)**。

## Claude 如何回答关于你的资金的问题

- **Claude 读取什么：**Claude 使用 Plaid 从你的关联账户读取数据，例如余额和交易（请参阅上面的**Claude 可以访问什么**）。它使用该数据来回答你关于你的资金的问题。

- **个人财务只能读取你的账户。**它无法移动、管理或投资你的资金。

- **Claude 是 AI，可能会出错。**根据你的银行自己的应用或对账单检查重要数字。了解更多关于**[不正确或误导性回应](https://support.claude.com/en/articles/8525154-claude-is-providing-incorrect-or-misleading-responses-what-s-going-on)**。

- **一个数字可能与你的银行的不同。**余额可能已有一两天。你通过两个登录关联的账户可能被计算两次。虽然 Claude 无法读取银行，但页面的支出数字会排除该银行，所以预算可能显示你拥有的钱比实际更多。

个人财务帮助您了解您的资金，但它不是为了提供投资建议而设计的。

## 在聊天中使用您的账户

- Claude 会读取您链接的账户，无需每次都询问，除非您更改此设置（请参阅下面的**为聊天打开或关闭 Plaid**）。在聊天中链接或取消链接银行时，它会先询问。

- Claude 在聊天中使用您的账户后，它的设计目的是不将该聊天中的任何内容保存到记忆中，也不会在之后搜索该聊天。它也会将其排除在您的月度回顾之外，包括标题。在该聊天中，Claude 仍然可以显示文本和表格，并制作纯文本文件，例如 .csv 文件。它可能无法运行代码或处理 Word、Excel、PowerPoint 或 PDF 文件。

- Claude 在发布来自使用了您链接账户的聊天的工件之前会先询问。该工件可能包含来自您银行账户的数据。它会一直保留，直到您删除它，即使您删除了聊天。

- 共享聊天链接会显示您的消息和 Claude 的回复，包括来自您账户的任何数据。它还可以显示 Claude 制作的图表或工件。

- 如果打开工件的人拥有个人财务并允许 Plaid，工件可以读取该人链接的账户。工件中的任何数据（包括已保存的数据）都会显示给打开它的所有人。

## 为聊天打开或关闭 Plaid

- **网页和 Claude Desktop：**在消息框中点击 “+”，点击 “连接器，”然后打开或关闭 Plaid。

- **iOS 和 Android：**点击消息框旁的 “+”，然后点击 “连接器，”再点击 “Plaid。”在 “所有工具”（在 Android 上为 “设置所有工具”）下，选择 “已阻止”以关闭 Plaid，或选择 “始终允许”以重新打开。使用 “需要批准，”Claude 会在每次读取前询问，除非聊天设置为 “自动批准。”您的选择也适用于新聊天。

## 重新登录银行

银行有时会终止 Claude 的访问权限。银行随后会显示 “登录已过期”或 “Claude 对此银行的访问权限已结束。”要恢复访问权限：

1. 导航到**[个人财务](https://claude.ai/personal-finance)**。

2. 打开您链接的账户。在网页和 Claude Desktop 上，点击页面顶部的三点菜单 (“...”)，然后点击 “管理链接的账户。”在 iOS 和 Android 上，点击齿轮图标。

3. 在银行上选择 “重新登录。”

4. 使用您用来链接它的相同银行登录信息登录。

成功后，您会看到 “Claude 可以再次读取 [银行]”，您的仪表板保持原样。

## 取消链接银行

按照以下步骤取消链接银行：

1. 导航到**[个人财务](https://claude.ai/personal-finance)**。

2. 打开您链接的账户。在网页和 Claude Desktop 上，点击页面顶部的三点菜单 (“...”)，然后点击 “管理链接的账户。”在 iOS 和 Android 上，点击齿轮图标。

3. 在银行上选择 “取消链接。”在 iOS 和 Android 上，先点击银行以打开它。

4. 再次选择 “取消链接”以确认。

当您取消链接银行时：

- Claude 停止读取此银行的您的账户。

- 您使用该银行登录链接的每个账户都会被取消链接。您无法取消链接单个账户。

- Claude 已经说过的内容会保留在您的聊天中，以及任何工件或共享链接中，直到您删除它们。您可以稍后重新链接该银行。

**重要：**如果这是您最后链接的银行，您的仪表板也会重置。您的小部件、它们的设置（例如预算）和您的设置答案将被删除，这无法撤销。

## 停止使用个人财务

要停止使用个人财务，请取消链接每家银行：

1. 导航到**[个人财务](https://claude.ai/personal-finance)**。

2. 在网页和 Claude Desktop 上，点击页面顶部的三点菜单 (“...”)，然后点击 “管理链接的账户。”在 iOS 和 Android 上，点击齿轮图标。

3. 选择 “取消链接所有银行。”

您也可以在 Plaid 自己的连接网站**[my.plaid.com](https://my.plaid.com)**断开 Claude 的连接。在**[Plaid 的步骤](https://support-my.plaid.com/hc/en-us/articles/4420193428503-How-do-I-disconnect-my-financial-accounts-from-an-app)**中了解更多信息。

如果您丢失了设备，请将其注销。了解更多关于**[管理您的活跃会话](https://support.claude.com/en/articles/13124001-managing-your-active-sessions)**的信息。

## 如果您的计划结束或您删除您的账户

当您的付费计划结束时，您无法打开个人财务，Claude 也无法在聊天中读取您的账户。您的银行保持链接状态，直到您取消链接它们。

- **在您的计划结束之前：**如果您不打算回来，请取消链接您的银行。

- **如果您重新订阅：**您的银行和仪表板保持原样。银行可能会要求您重新登录。

- **如果您移至团队或企业组织：**当您开始移动时，Claude 会取消链接您的银行。

## 在您的计划结束后取消链接您的银行

1. 在网页上，点击侧边栏中的 “自定义。”如果您看到 “插件”，请转到 claude.ai/customize/connectors/yours 并跳过第 2 步。

2. 点击 “连接器，”然后点击 “您的。”

3. 如果列出了 “Plaid，”打开它，点击以 “取消链接”开头的按钮，然后确认。

4. 如果未列出 “Plaid，”请在**[my.plaid.com](https://my.plaid.com)**断开 Claude 的连接或联系支持。在**[Plaid 的步骤](https://support-my.plaid.com/hc/en-us/articles/4420193428503-How-do-I-disconnect-my-financial-accounts-from-an-app)**中了解更多信息。

## 如果您计划删除您的 Claude 账户

当您删除您的账户时，Claude 会自动取消链接您的银行。这在删除处理后发生。

## 当前限制

- 您只能链接美国银行。

- Claude 无法在计划任务、协作任务或 Claude Code 中使用您链接的账户，可能也无法在项目中使用它们。

- Personal Finance 在 Claude Duet 中不可用。

- 数据导出尚不包括您保存的 Personal Finance 仪表板。

## 故障排除

| Claude 在聊天中不使用您的账户                | 在 iOS 或 Android 上，更新应用。然后要求 Claude 使用您的关联账户，并**[检查 Plaid 是否已启用](#h_78c4f737c1)**。您也可以在项目外启动新聊天：已运行代码或创建文件的聊天，或从工件开始的聊天无法使用您的账户。如果在应用中仍然不起作用，请在浏览器中访问 claude.ai 并使用同一账户启动新聊天。 |

## 获取帮助

在网络上，点击左下角的您的首字母或名字，然后点击 “获取帮助。”了解**[如何获取支持](https://support.claude.com/en/articles/9015913-how-to-get-support)**。

**重要提示：**不要与任何人（包括支持团队）分享您的银行登录或完整账户号码。
