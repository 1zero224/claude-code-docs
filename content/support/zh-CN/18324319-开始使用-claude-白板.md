# 开始使用 Claude 白板

Claude 白板是一个共享板，用于与 Claude 一起思考想法。您可以交谈、输入或草绘，Claude 会将您的想法组织成图表、流程和板上的分组。本指南涵盖启动白板、与 Claude 和您的团队一起使用、在通话中使用以及将其转换为文档或演示文稿。

Claude 白板在 Pro、Max、Ultra、Team 和 Enterprise 计划中以测试版形式在网络、Claude Desktop 和 Claude Mobile 上提供。在 Team 计划中默认启用。在 Enterprise 计划中，默认关闭，直到在**[组织设置 > 工件](https://claude.ai/admin-settings/artifacts)**中启用。

Claude 白板在 Claude for Teachers 中尚不可用。

## Claude 白板的工作原理

白板是您、您的团队和 Claude 一起处理的工件。Claude 使用形状、箭头和部分绘制您描述的内容，板上的任何人都可以重新排列其中的内容。

在您知道最终版本应该是什么样子之前，白板很有用：规划发布、列出决策选项或进行回顾。当结构确定后，Claude 可以将白板转换为文档或演示文稿。

您创建的每个白板都保存在**工件**选项卡中。了解更多关于**[工件及其使用方法](https://support.claude.com/en/articles/17153992)**。

## 启动白板

### 从聊天开始

在任何聊天中向 Claude 请求白板。例如：

- “启动白板来规划我们的产品发布。”

- “将此决策的选项放在白板上，包括每个选项的权衡。”

- “在白板上绘制从开始到结束的流程。”

### 从工件选项卡

1. 转到**工件**选项卡。

2. 选择白板磁贴。该磁贴标记为“白板。”

3. 描述您想要处理的内容，或将其听写到聊天框中并发送。

## 大声说出来

听写一个头脑风暴，如计划、选项列表或混乱的流程。Claude 将相关想法分组，按顺序排列步骤，并连接相互依赖的步骤。您也可以输入或草绘。要听写，请选择聊天框中发送按钮旁边的麦克风。要停止，再次选择麦克风或按 Escape，您的话语将保留在框中。选择发送按钮或按 Return 将其发送给 Claude。

听写遵循您的浏览器语言，支持阿姆哈拉语、中文（简体）、捷克语、丹麦语、荷兰语、英语、法语、德语、希腊语、希伯来语、印地语、印度尼西亚语、意大利语、日语、韩语、挪威语、波兰语、葡萄牙语、俄语、西班牙语、斯瓦希里语、瑞典语、泰语、土耳其语和乌克兰语。

## 与 Claude 一起在白板上工作

- **重新组织白板：**要求 Claude 按主题重新分组白板或将其转换为时间线。

- **找出差距：**询问两个步骤之间缺少什么。Claude 将其建议添加到白板供您检查。

- **专注于一个区域：**在白板的一个区域上拖动以询问 Claude 关于该部分的信息。

## 一起工作

白板上的每个人都可以实时处理它，并可以重新排列其中的内容。要查看团队成员正在查看的内容，请在白板上跟随他们。

要将人员添加到白板，请打开它并单击"共享"。如果您通过电子邮件邀请组织外的人员，他们可以加入。在 Team 和 Enterprise 计划中，**组织外的电子邮件邀请**需要在**组织设置 > 工件**中启用。了解更多关于**[共享工件](https://support.claude.com/en/articles/9547008)**。

## 将您的白板转换为其他内容

思考完成后，要求 Claude 将白板转换为文档或演示文稿。例如："将此白板转换为项目计划。"要在另一个工具中继续工作，请使用"发送到"。您可以将白板发送到 Lucid、Miro 和 Zoho Vani，我们会随着时间的推移添加更多。要将白板保存为文件，请单击"共享"，转到"导出"，然后选择 PNG。您可以向白板添加图片和视频，但无法从文件导入白板。

## 使用情况

Claude 白板计入您的计划使用限制，就像您与 Claude 的其他工作一样。

了解更多关于**[使用情况和长度限制如何工作](https://support.claude.com/en/articles/11647753)**。

## 当前限制

Claude 白板处于测试阶段。在推出时：

- **连接的应用：**Claude 从白板上的内容工作，不使用来自您连接的应用的上下文。

- **数据控制：**Claude 白板不适用于具有 HIPAA 就绪配置的组织。在具有 Claude Code 零数据保留的组织中，它在聊天和 Cowork 中可用，不受零数据保留覆盖，在 Claude Code 中不可用。
