# 在 Claude Cowork 中使用项目组织任务

Claude Cowork 中的项目让你可以将相关任务分组到专用工作区中，每个工作区都有自己的文件、上下文、说明和记忆。项目在 Cowork 和 Claude 中的工作方式相同。你在 Cowork 中创建的新项目会保存到你的 Claude 账户，因此你可以从其他设备上访问它们。Claude Desktop 还会自动将你从计算机上的文件夹创建的项目移到你的 Claude 账户中，其文件夹和文件保留在你的计算机上。详细了解**[移到你的 Claude 账户的本地项目](#h_6a11f1ee1d)**。

## 可用性

Cowork 中的项目需要最新版本的 Claude Desktop。请在 **claude.com/download** 下载或更新。

Claude Cowork 在桌面上适用于所有付费计划（Pro、Max、Ultra、Team 和 Enterprise）。在网页和移动设备上，它适用于 Pro、Max、Ultra 和 Team 计划（Team 计划处于测试阶段），以及当所有者启用时的 Enterprise 计划。

新的 Claude 体验（结合了聊天和 Cowork）正在向 Pro、Max 和 Ultra 计划推出。在 Team 和 Enterprise 计划上，当**聊天和 Cowork 统一**已启用时可用。如果你的消息框不再显示“聊天”和“Cowork”选项，说明你已拥有新体验，本文中的某些步骤可能看起来不同。详细了解**[Claude Cowork 和聊天是一个 Claude](https://support.claude.com/en/articles/16761823)**。

## 项目包含的内容

每个项目都有自己的：

- **说明** — 添加语气、格式或规则以帮助指导 Claude 如何处理项目中的所有任务。

- **计划任务** — 设置特定于项目的重复任务。

- **上下文** — 添加本地文件夹、链接聊天项目或粘贴 URL 供 Claude 参考。

- **记忆** — Claude 会记住你在项目中的工作上下文。

---

## 项目中的记忆

Cowork 项目已启用记忆功能。这意味着 Claude 可以记住你在项目中运行的任务的上下文，并将其应用于同一项目中的未来任务。Claude 在一个项目中学到的内容不会转移到其他项目。

项目还与你项目外的聊天共享记忆。要使项目的记忆完全独立，请在项目页面的**记忆**下关闭“使用账户记忆”。

有关记忆工作原理的更多信息，请参阅**[使用 Claude 的聊天搜索和记忆来建立在之前的上下文基础上](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context#h_4eff35bd6a)**。

## 共享项目

项目共享适用于 Team 和 Enterprise 计划。

Cowork 项目的共享方式与 Claude 中的项目相同。你可以给组织中的人员“可查看”或“可编辑”访问权限，并可以稍后更改或移除该访问权限。详细了解**[共享项目](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects#h_551239a4d4)**。

群组共享也在 Enterprise 计划的测试阶段；有关更多信息，请参阅**[管理项目可见性和共享](https://support.claude.com/en/articles/9519189-manage-project-visibility-and-sharing#h_ee7fbc143e)**。

## 归档项目

在 Cowork 中归档项目时：

- 项目的元数据从 UI 中移除，但不会在本地移除。

- 存储在计算机上的任何相关文件或文件夹都不受影响。

## 移到你的 Claude 账户的本地项目

Claude Desktop 会自动将你从计算机上的文件夹创建的项目移到你的 Claude 账户中，每个项目保留其名称。在 Pro、Max 和 Ultra 计划上，这在 Claude Desktop 中进行。在 Team 和 Enterprise 计划上，当**聊天和 Cowork 统一**对你启用时进行。

移到你的 Claude 账户的内容：

- 项目的名称、描述和说明，包括任何 Google Drive 链接。如果项目链接到 Claude 中的项目，其描述和说明将进入该项目。

- 项目记忆的副本（如果你的账户启用了记忆）。

保留在你的计算机上的内容：

- 项目的文件夹和文件。不会上传或删除任何内容。

- 此计算机上的早期会话，这些会话在 Claude Desktop 中的项目下保持列出。

移动后，原始本地项目不再出现在你的项目列表中。

---

## 当前限制

- 项目仅在 Cowork 中可用，在 Claude Code 中不可用。计划在未来更新中支持 Claude Code。

- 在没有**聊天和 Cowork 统一**的 Team 和 Enterprise 计划上，你从计算机上的现有文件夹创建的项目保留在该计算机上，不会保存到你的 Claude 账户。
