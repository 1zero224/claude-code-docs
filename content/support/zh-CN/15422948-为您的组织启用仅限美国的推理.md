# 为您的组织启用仅限美国的推理

本文介绍了**仅限美国的推理**设置的作用、如何启用它，以及它如何影响您的企业组织的计费。

仅限美国的推理适用于基于使用量的企业计划。主要所有者、所有者和隐私权限设置为"可管理"的自定义角色可以管理此设置。

## 什么是仅限美国的推理？

仅限美国的推理将您的组织的推理（Claude 生成响应时发生的模型处理）保持在美国境内。

启用此设置后，您的组织的所有推理都在位于美国的服务器上运行。这适用于所有 Claude 应用（包括 Claude Code、Claude Desktop 等）的使用，并包括后台处理，如对话标题和记忆。使用仅限美国的推理会产生额外成本。请参阅下面的**[计费方式](#h_8f4f5c2b9d)**。

禁用此设置时，推理可能会被路由到其他地区的服务器以提高速度和可用性。

## 启用仅限美国的推理

1. 导航至**[组织设置 > 数据和隐私](https://claude.ai/admin-settings/data-privacy-controls)**。

2. 找到**仅限美国的推理**。

3. 打开切换开关。

此设置适用于您的整个组织。更改应立即生效，但根据您使用的 Claude 应用可能会有一些延迟。

**注意：**如果您的组织之前选择退出全球路由或在其合同中有仅限美国的推理要求，该设置已启用且无法更改。您现有的定价条款继续适用。如有疑问，请联系您的客户团队。

## 计费方式

启用仅限美国的推理后，您的组织的使用量按 Claude Opus 4.6、Claude Sonnet 4.6 及更新版本的标准 API 费率的 1.1 倍计费。您的座位费用不变，1.1 倍费率仅适用于使用量。Claude Opus 4.5、Claude Sonnet 4.5、Claude Haiku 4.5 或更早版本的请求按标准费率计费。

详细了解**[您的企业计划如何计费](https://support.claude.com/en/articles/11526368-how-am-i-billed-for-my-enterprise-plan)**。

## 仅限美国的推理不涵盖的内容

仅限美国的推理仅适用于推理，即 Claude 的模型处理您的请求的地方。

它不控制：

- **连接器和第三方服务。**当 Claude 与 Slack 或 Google Drive 等连接的服务配合使用时，该服务在其自己的基础设施上处理数据，该基础设施可能位于美国以外。仅限美国的推理设置不会改变第三方服务的运营地点。

- **数据存储。**您的组织数据的存储位置与推理运行的位置是分开的。

## 常见问题

### 谁可以查看和更改此设置？

主要所有者、所有者和隐私权限设置为"可管理"的自定义角色成员可以更改此设置。隐私权限设置为"可查看"的成员可以查看它，但无法更改它。

### 此设置是否适用于 Claude API？

此设置适用于您的 Claude 企业组织。有关 Claude API 上的推理位置选项，请参阅**[Claude API 文档上的数据驻留文档](https://platform.claude.com/docs/en/manage-claude/data-residency)**。

### 为什么我看不到此设置？

仅限美国的推理仅适用于基于使用量的企业计划。如果您的组织使用的是团队计划或旧版基于座位的企业计划，该设置将不会显示。
