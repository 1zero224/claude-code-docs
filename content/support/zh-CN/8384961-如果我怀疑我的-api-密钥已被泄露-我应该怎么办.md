# 如果我怀疑我的 API 密钥已被泄露，我应该怎么办？

如果您怀疑您的 API 密钥可能已被泄露，我们建议您立即撤销该密钥。您可以通过登录 Claude Console 账户、转到 **API 密钥**页面 (platform.claude.com/settings/keys)、点击相关密钥旁边的菜单（即三个水平点）并选择 “删除 API 密钥”来完成此操作。

您可以通过点击同一页面上的 “创建密钥”按钮来生成新的 API 密钥；请确保将此密钥保存在安全的地方，例如密钥管理系统，并避免将密钥保存在版本控制中。如果您继续看到任何可疑的 API 活动或有其他疑虑，请 **[联系我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)**。
