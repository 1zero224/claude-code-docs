# 在 Cowork 中让 Claude 使用您的计算机

Claude 现在可以使用您的计算机在 Claude Cowork 和 Claude Code 中完成任务（有关此功能的更多信息，请参阅我们的 **[Claude Code 文档](https://code.claude.com/docs/en/desktop#let-claude-use-your-computer)**）。启用计算机使用后，当 Claude 没有连接器或工具来满足您的需求时，它可能会直接导航到您的屏幕——点击、输入和打开应用程序，就像您一样。它可以在浏览器中工作、打开文件并自动运行开发工具，除了启用外无需其他设置。

计算机使用功能对 Pro、Max 和 Ultra 计划处于测试阶段。它在 Claude Desktop 应用程序中的 Cowork 和 Claude Code 中可用，支持 macOS 和 Windows。此功能存在风险——使用前请查看 **[安全使用 Claude Cowork](https://support.claude.com/en/articles/13364135-use-cowork-safely)**。

## 计算机使用如何与 Cowork 配合工作

在 Cowork 中，Claude 首先使用最精确的工具。分配任务时，Claude 遵循以下顺序：

1. **连接器。**如果有可用的连接器（如 Gmail、Google Drive、Microsoft 365 或 Slack），Claude 会使用它。这是最快和最可靠的方式。

2. **浏览器。**当您需要的工具没有连接器时，Claude 可能会在 Claude Desktop 应用程序中内置的浏览器中处理您的任务，或者如果您更喜欢 Chrome 浏览器，可以通过 Claude in Chrome 在您自己的 Chrome 浏览器中处理。在 **[在 Claude Cowork 中使用内置浏览器](https://support.claude.com/en/articles/16607400)** 中了解更多信息。

3. **屏幕交互。**Claude 使用计算机使用功能直接与您的屏幕交互：点击、输入和导航您的桌面应用程序。

Claude 通常优先选择最快的方法。例如，通过 Slack 连接拉取消息需要几秒钟，但通过屏幕导航 Slack 需要更长时间，且更容易出错。

## 您可以做什么

计算机使用让 Claude 可以使用您计算机上的应用程序和文件。例如：

- 使用本地文件和连接的工具汇总竞争分析，然后将其编译成格式化报告。

- 打开您的手机模拟器，与您开发的应用程序交互，并找到用户体验问题。

- 导航没有连接器的应用程序——如内部仪表板或您的团队使用的专用工具。

如果您的工作涉及物理机器，Claude 会在您离开时继续工作。您的计算机只需要处于开启状态。

在 macOS（15 版本或更高版本）上，Claude 在后台窗口中工作，因此您可以在它运行时继续使用您的计算机。Claude 不会接管您的指针或键盘，如果您正在输入中，它通常会等待。Claude 会在每个会话中第一次需要全屏时请求您的许可，然后才会接管。

**注意：**在 macOS 15 或更高版本上，后台工作是默认设置。如果您希望 Claude 在工作时接管屏幕，请转到 **设置 > 功能** 中的 **计算机使用** 部分（或者如果不存在，请转到 **设置 > 系统**，在 **此计算机** 下），并将 **Claude 如何使用您允许的应用程序** 设置为"完全控制"。

## 权限和访问

Claude 在访问每个应用程序之前会请求您的许可。您会看到一个提示，必须批准后 Claude 才能与该应用程序交互。某些应用程序默认被禁用。

Claude 经过训练可以避免风险操作——如转账、修改或删除文件或处理敏感数据——并标记提示注入的迹象。但是，这些保护措施并不完美，Claude 可能偶尔会超出这些界限。

## 保护个人数据

当 Claude 使用计算机使用功能时，Claude 会对您的计算机进行屏幕截图，以了解如何导航屏幕和您已授予权限的应用程序。这意味着 Claude 可以看到屏幕或这些应用程序上可见的任何信息，包括个人数据、敏感文档或属于您或他人的私人信息。

使用 Claude 时要注意屏幕上的可见内容，特别是在包含机密信息的应用程序上。在使用计算机使用功能之前，关闭包含敏感信息的文件或应用程序。

### Claude 经过训练可以避免

- 从事股票交易或投资交易

- 输入敏感数据

- 收集或抓取面部图像

这些护栏是 Claude 训练和指导方式的一部分，但它们并不是绝对的。不要将其作为阻止访问敏感应用程序的替代品。

### 建议

- 不要向计算机使用权限授予对敏感应用程序（如银行、医疗保健、政府）的访问权限。

- 从简单任务（如研究或组织）开始，而不是复杂的多步工作流程。

- 确保您的提示具体且精心定制，以避免 Claude 执行您不打算执行的操作。

### 要避免的事项

我们强烈建议不要使用计算机使用功能来管理或对敏感信息采取行动，包括但不限于：

- 管理财务账户或投资

- 处理法律文件或合同

- 处理医疗或健康信息

- 与包含他人个人信息的应用程序交互

### 记忆

云中的 Cowork 共享您在聊天中使用的记忆，因此 Claude 可以从它已经了解的关于您如何工作的内容开始。默认情况下，Claude 不会保存某些人认为敏感的主题（如健康信息），除非您在 **设置 > 您的 Claude**（或旧设置布局中的 **设置 > 记忆**）中打开 **在记忆中包含敏感主题**。某些信息永远不会被保存，包括政府身份证号码、犯罪历史、财务账户号码和移民身份。您可以随时查看、编辑和删除 Claude 记住的内容。在 **[Claude 的记忆](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context#h_82126ebcc9)** 中了解更多信息。

## 安全

计算机使用在 Claude 和您的应用程序之间没有沙箱。Claude 直接与您的桌面、应用程序和浏览器交互——点击、输入和导航您的屏幕。我们为此构建了保护措施：

- **按应用程序权限。**Claude 在访问每个应用程序之前会请求许可，某些敏感应用程序（投资和交易平台、加密货币）默认被阻止。

- **应用程序黑名单。**通过将应用程序添加到黑名单来防止 Claude 访问某些应用程序。来自 Claude 使用被阻止应用程序的任何请求都将被自动拒绝。

- **操作审查。**当 Claude 使用您的计算机时，我们的系统会扫描提示注入的迹象，Claude 会在访问新应用程序之前请求许可。您可以随时停止 Claude。但此功能仍处于早期阶段，攻击不断演变——保持谨慎。

也就是说，计算机使用是一项新功能，它防御的威胁不断演变。Claude 会犯错误，没有保护措施是完美的。从您信任的应用程序开始并监控 Claude 的工作——特别是在早期。请注意，在一个应用程序中采取的操作可能会影响其他应用程序。例如，点击电子邮件应用程序中的链接可能会在 Chrome 中打开它，即使您没有明确授予 Claude 使用 Chrome 的权限（我们可以防止 Claude 看到 Chrome 窗口，但无法阻止链接打开）。我们不建议在包含与您的医疗保健、财务或其他个人记录相关的敏感数据的应用程序上使用。

有关详细的安全指导，请参阅 **[安全使用 Cowork](https://support.claude.com/en/articles/13364135-use-cowork-safely)**。

## 当前限制

计算机使用处于测试阶段。请记住以下几点：

- 您的桌面必须处于活动状态。您的计算机需要处于唤醒状态，Claude Desktop 应用程序需要打开才能使计算机使用功能正常工作。

- 复杂任务有时需要重试。计算机使用适用于许多任务，但可能在复杂的多步工作流程中遇到困难。

- 屏幕交互比连接器慢。当 Claude 通过屏幕而不是直接集成工作时，任务需要更长时间。尽可能连接您最常使用的工具。

- 仅适用于 Pro、Max 和 Ultra 计划。团队和企业计划目前无法访问计算机使用功能。

## 开始使用计算机使用功能

要开始使用计算机使用功能：

1. 确保您拥有最新版本的 Claude Desktop。在 claude.com/download 下载或更新。

2. 打开桌面应用程序并转到 **设置 > 功能**。如果那里没有 **计算机使用** 部分，请转到 **设置 > 系统**，在 **此计算机** 下。

3. 找到 **启用计算机使用** 切换开关并将其打开。

4. 在桌面应用程序中打开 Cowork 或 Claude Code 并开始会话。

5. 要求 Claude 执行涉及您计算机上的应用程序的操作。Claude 会在继续之前请求访问该应用程序的权限。

我们之所以尽早分享这一点，是因为这是一种通过实际使用而变得更好的功能。如果某些功能不按预期工作，请使用应用内反馈按钮或联系 <usersafety@anthropic.com>。
