# 了解您的 Claude API 发票

本文介绍了您将收到的 Claude API 和控制台使用情况的发票和收据、查找位置以及如何阅读其中的行项目。

## 您可能收到的发票类型

**使用发票。**如果您的组织采用付费使用合同，我们会汇总您在 API 调用、playground 聊天和账户中其他服务的使用情况，您将在每个日历月末从 Stripe 收到一份发票。

**信用额度购买收据。**如果您的组织使用预付费账单，您将为每次使用信用额度购买（包括自动充值自动进行的购买）收到一份收据。

有关账单工作原理的详细信息，请参阅 **[我如何支付 Claude API 使用费用？](https://support.claude.com/en/articles/8977456)**

## 查找您的发票

每次收费后，我们会自动将发票发送到您注册的账单电子邮件地址。要在收件箱中查找过去的发票，请搜索主题行"您来自 Anthropic 的收据"。

具有管理员或账单角色的用户也可以在控制台中查看发票：

1. 使用管理员或账单角色登录控制台。

2. 在控制台中转到**账单**页面 (platform.claude.com/settings/billing)。

3. 找到**发票历史记录**部分。

4. 点击"下载"直接保存发票，或点击"查看"在新的 Stripe 标签页中打开它并从那里下载。

过期的信用额度赠款也会出现在**发票历史记录**中，尽管它们不是费用。如需帮助访问控制台中不可用的较旧收据和发票，请**[联系我们的支持团队](https://support.claude.com/en/articles/9015913)**。

## 阅读您的发票

**已应用余额。**"已应用余额"行表示您账户上的现有余额已自动应用于发票，减少了应付金额。负的已应用余额是正在使用的信用额度，不是新费用或折扣。它来自以下两个地方之一：

- 上一张发票的总额少于我们账单系统可以收费的最低金额 ($0.50)，因此它被结转到本发票。

- 您的账户有信用额度（例如来自信用额度单或超额支付），它已自动应用。

**应付金额。**发票总额减去任何已应用余额。这是您的支付方式被收费的金额，或者如果您的组织通过银行转账支付的金额。

## 发票上的账单详情

发票上的名称、地址和税务信息来自发票签发时的账单详情。如果您更新账单详情，更改将应用于未来的发票——已签发的发票无法修改。要更新您的详情，请在控制台中转到**账单**页面 (platform.claude.com/settings/billing)。

## 常见问题

### 为什么我支付后发票仍然逾期？

如果您通过银行转账支付，付款必须与发票金额完全匹配。即使少支付几分钱，付款也不会被应用，发票将保持逾期状态，直到收到剩余金额。收到全额后，发票会自动标记为已支付——这可能需要大约五个工作日来处理。

### 为什么我没有收到少量使用费的发票？

低于 $0.50 的发票不会单独收费。金额会结转并显示为下一张发票上的已应用余额。

### 您能更正我已收到的发票上的详情吗？

不能。已签发的发票无法更改。在控制台中的**账单**页面 (platform.claude.com/settings/billing) 上更新您的账单详情，更改将出现在未来的发票上。
