# 我如何在 Amazon Bedrock 中获得 Claude 的访问权限？

通过访问 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock/)开始使用 Amazon Bedrock 中的 Claude。有关如何在 Amazon Bedrock 控制台中请求 Claude 模型访问权限的分步演练，请[查看此博客](https://aws.amazon.com/blogs/aws/anthropics-claude-3-5-sonnet-model-now-available-in-amazon-bedrock-the-most-intelligent-claude-model-yet/)。
