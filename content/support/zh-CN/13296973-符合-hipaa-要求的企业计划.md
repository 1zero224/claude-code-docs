# 符合 HIPAA 要求的企业计划

此功能仅适用于企业计划（包括自助服务和销售协助）。

我们为企业计划中的组织提供符合 HIPAA 要求的 Claude 版本，这些组织可以选择通过 Claude 处理受保护的健康信息 (PHI)。本文介绍了该产品包含的内容、可用的功能以及如何开始使用。

## 概述

符合 HIPAA 要求的企业产品专为受 HIPAA 要求约束的医疗保健提供商、健康计划、医疗保健数据处理商及其业务关联方而设计。该产品包括业务关联协议 (BAA)、功能和保障措施，旨在支持组织的 HIPAA 合规要求。

## 此产品适用于谁？

此产品专为 HIPAA 覆盖实体及其业务关联方而设计，包括：

- 医疗保健提供商（例如医院、诊所、医生）

- 健康计划和保险公司

- 医疗保健数据处理商

- 代表覆盖实体处理 PHI 的业务关联方

- 其他受 HIPAA 监管的实体

如果您不确定您的组织是否受益于符合 HIPAA 要求的产品，请问自己：您是否会通过 Claude 处理受保护的健康信息？如果是，您需要符合 HIPAA 要求的产品和 BAA。

## 功能可用性

符合 HIPAA 要求的企业产品包括**[标准企业计划](https://support.claude.com/en/articles/9797531-what-is-the-enterprise-plan)**上提供的许多功能——但启用 HIPAA 并不会将每项功能纳入您的 BAA。功能分为三类：由您的 BAA 覆盖、可用但不覆盖和已禁用。PHI 应仅通过覆盖的功能进行处理，因此管理员必须了解哪些功能属于哪一类，并相应地配置其工作区。Anthropic 信任中心上的**[HIPAA 实体实施指南](https://trust.anthropic.com/resources?s=rgirr4qe8u7ek8c2igx3&name=claude-for-enterprise-hipaa-ready-offering-implementation-guide)**列出了每项功能的状态，是权威来源。

**重要提示：**仅启用 HIPAA 不会将 Claude Code 或 Cowork 纳入您的 BAA。主所有者还必须将 HIPAA 配置应用于 Claude Code（本地模式）和 Cowork（本地模式）。此配置目前仅适用于拥有 Anthropic 账户团队的组织。Claude Code（本地模式）是终端中的 Claude Code 和 Claude Desktop 的代码选项卡中的 Claude Code。Cowork（本地模式）是 Claude Desktop 中的 Cowork。

- **在主所有者应用配置之前：**Cowork 可用但不在您的 BAA 覆盖范围内。Claude Code 仅在启用零数据保留 (ZDR) 的情况下才被覆盖，这仅在符合条件的账户上可用。如果没有 ZDR，Claude Code 也可用但不被覆盖。不要将 PHI 用于未被覆盖的产品。

- **在主所有者应用配置之后：**您的 BAA 覆盖 Claude Code（本地模式）和 Cowork（本地模式）。云功能（如 Claude Code 云会话、Claude Code 远程控制和云中的 Cowork）不可用。主所有者无法移除该配置。

在**[在符合 HIPAA 要求的企业计划上使用 Claude Code（本地模式）和 Cowork（本地模式）](https://support.claude.com/en/articles/17318731)**中了解如何获取配置以及如何准备。

## 开始使用

符合条件的企业组织可以直接从组织设置启用 HIPAA——无需销售或法律流程。业务关联协议 (BAA) 作为点击接受的形式包含在流程中，因此无需单独签署和返回文件。点击“接受并启用 HIPAA”即表示接受 BAA。

### 资格要求

您的组织必须在企业计划上才能启用 HIPAA。某些企业组织无法从组织设置启用 HIPAA。如果您是主所有者且“启用”呈灰显状态，请将鼠标悬停在其上方以查看后续操作。如果显示联系 Anthropic 支持，请联系以请求 HIPAA。在您看到“确认”下描述的复选标记之前，它不会被启用。团队计划和个人计划（免费、专业、最大和超级）无法启用 HIPAA。

只有组织的**主所有者**可以接受 BAA 并启用 HIPAA。其他所有者或管理员无法代表组织完成此流程。如果您是管理员但不是企业组织的主所有者，请要求您的主所有者登录并完成启用。

### 开始之前

需要提前了解两件事：

- **启用 HIPAA 会重置整个组织的某些设置。**作为过渡到符合 HIPAA 要求状态的一部分，某些配置会恢复为默认值。入职模式和实施指南（在流程中可下载）详细说明了哪些内容会发生变化。

- **这是一个单向决定。**启用 HIPAA 并接受 BAA 后，无法从组织设置中撤销此更改。

您必须在接受前查看 BAA 和实施指南，因为这是一个不可逆的组织过渡。

**注意：**通过自助服务流程提供的 BAA 是标准协议，无法修改。

### 启用 HIPAA

1. 以主所有者身份登录 Claude，然后转到**[组织设置 > 数据和隐私](https://claude.ai/admin-settings/data-privacy-controls)**。

2. 转到**HIPAA 合规性。**

3. 点击“启用”打开同意流程。如果“启用”呈灰显状态，请参阅资格要求。

4. 下载业务关联协议，查看后，点击“下一步。”

5. 下载实施指南，查看后，点击“下一步。”

6. 点击“接受并启用 HIPAA。”

### 确认

启用后，您将在组织设置的 **HIPAA 合规性**部分看到一个复选标记，确认您的组织已配置为根据 HIPAA 通过 Claude 处理 PHI。如果您没有看到此复选标记，则您的组织未启用。仅启用 HIPAA 不会将 Claude Code 或 Cowork 纳入您的 BAA。主所有者还必须将 HIPAA 配置应用于 Claude Code（本地模式）和 Cowork（本地模式）。请参阅**[在符合 HIPAA 要求的企业计划上使用 Claude Code（本地模式）和 Cowork（本地模式）](https://support.claude.com/en/articles/17318731)**。

入职模式将指导您完成团队的后续步骤。

如需有关 BAA、实施指南或启用后问题的帮助，请联系您的 Anthropic 账户团队或**[我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)**。

## 如果您有现有的 API BAA

如果您的组织在 2025 年 12 月 2 日之前为 Claude API 使用签署了 BAA，该协议仅涵盖 API 使用——不适用于符合 HIPAA 要求的企业计划。要添加此企业计划访问权限，您需要与您的账户团队签署新的 BAA。

2025 年 12 月 2 日之后签署的 BAA 可以在单一协议下同时涵盖 API 使用和企业计划。

如果您使用 Claude API，请详细了解**[符合 HIPAA 要求的 Claude API 访问以及如何设置](https://platform.claude.com/docs/en/manage-claude/api-and-data-retention#hipaa-readiness)**。
