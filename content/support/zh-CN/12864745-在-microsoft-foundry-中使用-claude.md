# 在 Microsoft Foundry 中使用 Claude

Claude 在 Microsoft Foundry 中已正式推出，Azure 客户可以在其中构建生产应用程序和企业代理。您可以为每个部署选择一个托管选项：托管在 Azure 上，提供部分 Opus、Sonnet 和 Haiku 模型，支持全球标准或美国数据区标准部署；或托管在 Anthropic 上，提供更广泛的 Claude 模型选择，仅支持全球标准部署。有关当前模型，请参阅 **[我们的 Claude 文档](https://platform.claude.com/docs/en/build-with-claude/claude-in-microsoft-foundry#api-model-ids-and-deployments)**。

此集成使开发人员能够：

- **立即开始构建：**通过 Foundry 的 API、工具和工作流部署 Claude。

- **使用现有的 Azure 协议：**Claude 符合 Microsoft Azure 消费承诺 (MACC) 的条件，可与当前的 Azure 协议和计费配合使用，无需单独的供应商批准。

- **使用您偏好的语言进行构建：**通过 Python、TypeScript、C#、Go、Java、PHP 和 Ruby SDK 使用 Claude，支持 Microsoft Entra 身份验证。

如果您在通过 Microsoft Foundry 使用 Claude 时需要支持，请查看 **[Azure AI 服务支持和帮助选项](https://learn.microsoft.com/en-us/azure/ai-foundry/foundry-agent/ask-foundry-agent)**。有关具体详情（包括支持渠道、SLA、升级协议等），请参阅您的 Foundry 协议。

有关更多信息，请参阅 **[我们的 Claude 文档](https://platform.claude.com/docs/en/build-with-claude/claude-in-microsoft-foundry)**。
