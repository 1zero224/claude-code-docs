# 在 Microsoft Foundry 中使用 Claude

Claude Haiku 4.5、Sonnet 4.5 和 Opus 4.1 模型现已在 Microsoft Foundry 中以公开预览版提供，Azure 客户可以在其中构建生产应用程序和企业代理。

此集成使开发人员能够：

- **立即开始构建：**通过 Foundry 的 API、工具和工作流部署 Claude。

- **使用现有的 Azure 协议：**Claude 符合 Microsoft Azure 消费承诺 (MACC) 的条件，与现有 Azure 协议和计费配合使用，无需单独的供应商批准。

- **使用首选语言构建：**通过 Microsoft Entra 身份验证使用 Python、TypeScript 和 C# SDK 访问 Claude。

如果您在通过 Microsoft Foundry 使用 Claude 时需要支持，请查看 **[Azure AI 服务支持和帮助选项](https://learn.microsoft.com/en-us/azure/ai-foundry/foundry-agent/ask-foundry-agent)**。有关具体详情（包括支持渠道、SLA、升级协议等），请参阅您的 Foundry 协议。

有关更多信息，请参阅 **[我们的 Claude 文档](https://docs.claude.com/en/docs/build-with-claude/claude-in-microsoft-foundry)**。
