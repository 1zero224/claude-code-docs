# 我可以同时拥有 Claude 账户和 Console 账户吗？

可以。您可以使用同一个电子邮件地址拥有 Claude 账户（免费版、Pro、Max、Ultra、Team 或 Enterprise）和 Console 账户（用于访问 Claude API）。这两个账户将独立运行。

Claude Max、Ultra 和 Team 计划包括 Claude API 的每月额度。要领取您的额度，请将 Claude Console 组织关联到您的计划。详细了解 **[Max、Ultra 和 Team 计划的每月 API 额度](https://support.claude.com/en/articles/17154008)**。

**提示：**使用与 Claude 账户相同的电子邮件地址登录 Claude Console。
