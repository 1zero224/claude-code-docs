# 视觉和交互式内容

Claude 可以直观地显示某些类型的信息——如地图、天气预报和食谱——并使用交互式内容而不是纯文本向您提出结构化问题。这些功能旨在使对话更快、更容易付诸行动。

所有 Claude 用户都可以使用视觉响应和交互式内容。数据显示小部件（地图、天气、食谱）需要启用网络搜索。有关设置说明，请参阅**[启用和使用网络搜索](https://support.claude.com/en/articles/10684626-enabling-and-using-web-search)**。

# 视觉内容

当您向 Claude 询问某些主题时，它可能会用视觉内容而不是（或连同）文本响应来回答。此内容专为一目了然更容易理解的信息而设计。

## 地图

当您询问地点——餐厅、方向、附近的商家——时，Claude 可以显示一个交互式地图，其中标记了相关位置。点击标记可查看更多信息，包括方向链接、联系方式和图像。

## 天气

**注意：**视觉天气内容在网络和桌面上可用。在移动设备（iOS 和 Android）上，Claude 在对话中以文本形式提供天气信息。

当您询问特定位置的天气时，Claude 可以显示当前天气条件和预报。您可以直接提问——"东京的天气怎么样？"——或更随意地提问，如"我今天需要带伞吗？"或"丹佛这个周末天气如何？"

Claude 自动为美国地点显示华氏温度，为其他地方显示摄氏温度。

## 食谱

当您询问食谱时，Claude 可以显示格式化的食谱卡片，比文本块更容易遵循。在食谱卡片中，您会看到多种交互方式：更改份数或测量单位，或点击"开始烹饪"以启动分步界面，引导您完成食谱。

**注意：**视觉食谱卡片仅在网络和桌面上可用。在移动设备上，Claude 在对话中以文本形式提供食谱信息。

# 体育比分

当您询问体育信息时，Claude 可以提供当前比分、排名和详细的比赛统计数据。

Claude 可以查找以下联赛和运动的数据：

- **美国职业联赛：**NFL、NBA、NHL、MLB、WNBA、MLS

- **美国大学体育：**NCAA 橄榄球、NCAA 男子篮球、NCAA 女子篮球

- **国际足球：**英超、西甲、意甲、德甲、法甲、欧冠

- **个人运动：**网球、高尔夫、NASCAR、板球、MMA

根据您的提问，Claude 可以提供最近的比赛结果和实时比分、即将进行的比赛、联赛排名和排行榜，以及详细的比赛统计数据，包括比分统计和球员统计。

**注意：**高尔夫和 NASCAR 不提供详细的比赛统计数据。体育数据目前在所有平台上都显示为文本，而不是视觉小部件。

# 交互式输入

Claude 有时会在响应前向您请求更多信息。Claude 可能会呈现您可以点击或轻触的交互式选项——如多项选择题、多选选项或排名界面——而不是要求您输入响应。

例如，如果您要求 Claude 帮助您规划旅行，它可能会要求您：

- 从一组选项中选择您的预算范围

- 从列表中选择您感兴趣的活动

- 对您的优先事项进行排名（如成本与舒适度与位置）

此内容显示在聊天的底部。如果您愿意，您仍然可以输入响应。

# 限制

- 视觉天气和食谱内容在移动设备上无法呈现（Claude for iOS 和 Android）。您仍然会看到相同的信息，但它将仅为文本。

- 体育数据仅以文本形式提供，不作为视觉内容。

- 交互式内容的可用性可能因问题类型和可用信息而异。

- 数据显示内容需要活跃的互联网连接，可能受到连接问题的影响。

---

# 隐私

- 地图和天气内容由 Google Maps 提供支持（[Google 隐私政策](https://policies.google.com/privacy)）。

- 食谱图像由必应图像搜索提供支持（[Microsoft 隐私声明](https://privacy.microsoft.com/en-us/privacystatement)）。

- 交互式输入不涉及第三方服务。

---

# 提示

- **您无需执行任何特殊操作即可显示视觉内容。**Claude 根据您的问题决定何时适合进行视觉响应。只需自然地提问。

- **您始终可以输入。**如果 Claude 向您呈现交互式内容，您不需要使用它。您可以像往常一样在聊天中输入您的响应。

- **要求您需要的内容。**如果 Claude 给您一个文本响应，而您更喜欢视觉响应，请尝试重新表述——例如，"向我显示市中心附近咖啡店的地图"而不是"市中心附近有咖啡店吗？"
