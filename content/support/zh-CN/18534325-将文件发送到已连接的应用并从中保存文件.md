# 将文件发送到已连接的应用并从中保存文件

Claude 可以将文件发送到您已连接的应用，也可以保存该应用提供的文件。例如，Claude 可以将刚制作的演示文稿上传到您的云存储，或导入合同供您一起审阅。本文介绍了文件传输的工作位置、使用方法以及文件的处理方式。

连接器文件传输处于测试阶段。它们正在 Pro、Max 和 Ultra 计划中逐步推出，在 Team 和 Enterprise 计划中默认关闭，直到所有者启用。免费计划将随后推出。它们适用于网页版 Claude、Claude Desktop、Claude for iOS、Claude for Android 和 Claude Code。

---

## 文件传输的工作位置

文件传输适用于：

- 网页版新 Claude 体验、Claude Desktop 以及 Claude for iOS 和 Android 中的聊天

- 您的终端、VS Code 和网页版中的 Claude Code

文件传输不适用于：

- 无痕聊天

- 计划任务

- 使用远程控制启动的 Claude Code 会话

### 您可以使用的应用

应用需要在**[连接器目录](https://claude.ai/directory)**中，且其开发者需要添加文件支持。您自己添加的自定义连接器和 MCP 服务器不支持文件传输。

---

## 将文件发送到应用

要发送文件：

1. 从**[连接器目录](https://claude.ai/directory)**连接应用。

2. 拖入或附加文件，或告诉 Claude 要发送哪个文件。可以是 Claude 制作的文件。

3. 告诉 Claude 文件的去向。例如，“将其放在我的收据文件夹中。”

4. 如果 Claude 要求批准，请在允许前检查文件和应用。

### Claude 何时在发送前询问

Claude 在将第一个文件发送到每个应用前会询问，即使在自动模式下或连接器的工具设置为“始终允许”也是如此。之后，Claude 可能会根据您的权限设置在不询问的情况下发送文件。

---

## 从应用保存文件

要保存文件，请向 Claude 请求。例如，“从我的财务文件夹获取 Q3 报告。”保存遵循您为该连接器工具设置的权限。

### 您在聊天中保存的文件

文件保存到该聊天中，Claude 可以打开它。您可以从聊天中打开或下载它。

### 您在计算机上的 Claude Code 中保存的文件

文件保存在 ~/.claude/projects 下的 connector-downloads 文件夹中，Claude Code 会显示路径。要在项目中使用该文件，请要求 Claude 将其复制到那里。

默认情况下，Claude Code 会在 30 天后删除已保存的文件，因此请复制您想保留的任何内容。计划模式下不保存任何内容。

---

## 文件限制

### 您发送的文件

- **您计算机上的 Claude Code：**您可以发送每个最大 500 MB 的文件，一次最多 8 个文件。

- **聊天和网页版 Claude Code：**您一次最多可以发送 10 个文件，总计最多 500 MB。您附加的文件每个最大 400 MB。

如果多个文件合在一起太大，请要求 Claude 一次发送一个。Claude 可以发送文件但不能发送文件夹。您附加的照片可能会作为较小的副本发送。

### 您保存的文件

您可以保存每个最大 500 MB 的文件，一次最多 10 个文件。大多数文件有 5 分钟的下载时间。

Claude Code 会为某些文件类型（如 .html）添加 .bin 或 .txt。要打开文件，请重命名它。

### 应用设置的限制

应用可以设置较低的大小限制或仅接受某些文件类型。

### Claude Code 在发送前检查的文件

- **名称类似凭证的文件：**Claude Code 拒绝大多数此类文件，如 .env 或 .pem，除非您自己附加了它们。

- **工作文件夹外的文件：**Claude Code 在发送前会询问，即使在自动模式下或工具设置为始终允许也是如此，除非您绕过权限。要从主文件夹或临时文件夹外发送文件，请先使用 `/add-dir` 添加其文件夹。

## 您的文件如何处理

您在聊天或云会话中附加或保存的文件保留在该聊天或会话中。它们根据我们的数据保留实践进行保留和删除，适用于**[消费者计划](https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data)**或**[Team 和 Enterprise 计划](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data)**。Claude Code 保存到您计算机的文件存储在您的计算机上。

请记住，照片和视频可能包含其他元数据，如拍摄地点。已连接的应用根据其自己的条款和隐私政策或您的组织与该应用的协议处理文件。从 Claude 删除您的聊天或会话不会从已连接的应用中删除文件。

文件通过 Anthropic 的服务器传递，我们保留您发送的文件的临时加密副本。我们还可能保留某些图像和视频的临时副本以进行安全扫描。删除您的聊天或会话不会删除扫描副本，该副本通常在两周内删除，除非我们需要出于安全或法律原因保留更长时间。

**重要提示：**来自应用的文件可能包含旨在误导 Claude 的文本。仅连接您信任的应用。

## 文件传输故障排除

### Claude 无法发送或保存文件

- 将 Claude Code 或 Claude 应用更新到最新版本，然后启动新会话或聊天。某些聊天（包括许多较旧的聊天）无法发送或保存文件。

- 在 Claude Code 中，使用您的 Claude 账户登录。文件传输不适用于 API 密钥或通过云提供商。

- 在 Claude Code 中，检查 `DISABLE_TELEMETRY`、`DO_NOT_TRACK` 和 `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` 是否未设置。每一个都会关闭 Claude Code 中的文件传输。

### Claude 说连接器是自定义的或无法确认

从**[连接器目录](https://claude.ai/directory)**移除并重新添加连接器，或要求您的组织中的所有者或主要所有者这样做。

### 发送失败或您停止了它

在重试前检查应用。文件可能已到达。

### 文件无法从您的手机完成上传

在文件完成上传之前，请保持 Claude 在屏幕上打开，不要让屏幕关闭。

## 在 Team 和 Enterprise 计划上管理文件传输

### 启用文件传输

发送和保存文件默认都是关闭的。所有者和主要所有者可以启用其中一个或两个：

1. 导航到**组织设置 > 连接器**。

2. 在**文件传输**下，启用**上传文件到连接器**、**从连接器下载文件**或两者。

3. 要求用户启动新聊天或 Claude Code 会话。

每个设置适用于整个组织。您已阻止的连接器工具保持阻止状态。在聊天中，成员还需要在**组织设置 > 功能**中启用聊天和协作统一。

## 合规记录

在启用了合规 API 的 Enterprise 计划上，发送的文件通常记录在其活动源中。保存的文件可能不会被记录。详细了解**[访问合规 API](https://support.claude.com/en/articles/13015708-access-the-compliance-api)**。

### 无法使用文件传输的组织

某些组织无法使用文件传输，包括：

- 使用 HIPAA 设置、零数据保留、客户管理的加密密钥、访问透明度或 IP 允许列表的组织

- 其默认工作区将数据保留在美国外的组织

- 为 FERPA 设置的组织和 Claude for Teachers 账户

允许推理钩子的组织无法使用发送文件功能。

### 如果连接器无法接收文件会发生什么

从**[连接器目录](https://claude.ai/directory)**移除并重新添加连接器。之后检查谁有权访问它，因为移除它可能会重置该权限。
