# 在 Claude 中使用技能

技能通过为 Claude 提供专业知识和工作流程的访问权限来扩展其功能。本指南展示如何在 Claude 中启用、发现和使用技能。

技能适用于免费版、专业版、最大版、超级版、团队版和企业版计划的用户。此功能需要**[启用代码执行](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude#h_1c99382190)**。技能也可在 Claude Code 中使用，并对所有使用代码执行工具的 API 用户处于测试阶段。

## 前置条件

**对于企业版计划：**所有者必须检查**[组织设置 > 插件和技能](https://claude.ai/admin-settings/skills)**中的“策略”选项卡中是否同时启用了**代码执行和文件创建**以及**技能**。所有者还可以上传技能以在整个组织范围内配置它们——这些技能会自动为所有用户显示。在组织级别启用技能后，个人成员可以在**[自定义 > 技能](https://claude.ai/customize/skills)**中切换示例技能、访问已配置的技能以及上传自己的个人技能。

**对于团队版计划：**此功能在组织级别默认启用。启用后，个人成员可以在**[自定义 > 技能](https://claude.ai/customize/skills)**中切换示例技能并上传自己的技能。

**对于免费版、专业版、最大版和超级版计划：**您可以在**[自定义 > 技能](https://claude.ai/customize/skills)**中启用示例技能并上传自己的技能。

---

## 如何启用技能

1. 对于团队版/企业版计划：导航到**[组织设置 > 插件和技能](https://claude.ai/admin-settings/skills)**，点击“策略”选项卡，并确保同时启用了**云代码执行和文件创建**以及**技能**。

2. 对于个人免费版、专业版、最大版和超级版计划：导航到**设置 > 功能**并确保启用了**代码执行和文件创建**（在更新的设置布局中称为**创建和编辑文件**）。

3. 转到**[自定义 > 技能](https://claude.ai/customize/skills)**。

4. 根据需要切换各个技能的开关。

## 在整个组织范围内配置技能

团队和企业组织的所有者可以为所有用户配置技能。这些技能会在您的个人技能列表中显示，带有团队指示符——您可以根据偏好切换它们的开关。有关为您的组织配置技能的信息，请参阅**[为您的组织配置和管理技能](https://support.claude.com/en/articles/13119606-provisioning-and-managing-skills-for-your-organization#h_4dea113421)**。

## 使用 Anthropic 技能

Anthropic 提供多个内置技能，可供所有用户使用，包括：

- 增强的 Excel 电子表格创建和操作

- 专业 Word 文档创建

- PowerPoint 演示文稿生成

- PDF 创建和处理

启用**代码执行和文件创建**后，Claude 会在相关时自动使用这些工具。您无需显式调用它们——Claude 会根据您的请求确定何时需要每项技能。

例如，如果您要求 Claude“创建关于第三季度结果的 PowerPoint 演示文稿，”Claude 会在启用该功能的情况下自动使用 PowerPoint 技能。

## 添加和使用自定义技能

您还可以创建和上传自己的技能来教 Claude 您的特定工作流程：

1. 按照技能结构创建技能（有关详细说明，请参阅**[如何创建自定义技能](https://support.claude.com/en/articles/12512198-creating-custom-skills)**）。

2. 将您的技能文件夹打包为 ZIP 文件。

3. 导航到**[自定义 > 技能](https://claude.ai/customize/skills)**。

4. 要添加自定义技能，请点击“+”按钮，然后点击“+ 创建技能。”

5. 选择“上传技能。”

6. 上传包含您的技能文件夹的 ZIP 文件。

7. 您的技能将出现在您的技能列表中，可以切换开关。

**注意：**您上传的自定义技能在您分享之前对同事不可见。管理员可以看到它们的名称和分享状态，但看不到它们的文件。在团队版和企业版计划上，您可以分享技能（请参阅下面的**分享技能**），或为您的组织配置技能。了解更多关于**[为您的组织配置技能](https://support.claude.com/en/articles/13119606-managing-skills-as-an-admin#h_4dea113421)**的信息。

## 分享技能

在团队版和企业版计划上，您可以与特定同事和小组分享您创建的技能。要使技能对整个组织可用，请改为发布它。技能分享在聊天和 Cowork 中都有效。

**注意：****技能分享**切换对团队版计划和未设置技能偏好的企业版计划默认开启。对于具有 HIPAA 就绪或其他受管制配置的组织，技能和技能分享默认关闭，管理员可以启用它们。**与组织分享**和**与小组分享**切换也默认关闭。所有者必须导航到**[组织设置 > 插件和技能](https://claude.ai/admin-settings/skills)**，点击“策略”选项卡，并启用至少一个切换，“分享”按钮才会出现。如果您的组织使用自定义角色，您的角色还必须启用**与小组分享技能**功能。如果您看不到分享选项，请与您的组织所有者联系。

要分享技能：

1. 导航到**[自定义 > 技能](https://claude.ai/customize/skills)**。

2. 找到您创建的技能。

3. 点击它旁边的三点菜单 (...)，然后选择“分享。”

4. 选择与谁分享：

  - **特定人员：**输入名称或电子邮件以直接分享。分享会创建一个链接，为与其分享的任何人打开该项目。该技能会在每个收件人的技能列表中显示，在他们启用之前呈灰色，并显示您的名称作为所有者。

  - **一个小组（仅限企业版计划）：**与您的组织已设置的小组分享。该技能会在每个小组成员的技能列表中显示，在他们启用之前呈灰色。需要**与小组分享**切换。

5. 点击“分享。”

共享技能是只读的。收件人可以启用和使用该技能，但无法编辑其内容。如果您稍后更新该技能，收件人会在下次使用时自动获得更新版本。您可以随时移除某人的访问权限，如果他们离开组织，访问权限会自动移除。

## 将技能发布到您的组织

在团队版和企业版计划上，您可以将您创建的技能提交到您的组织库，以便组织中的任何人都可以安装它。分享会将技能提供给特定人员或小组，您保持对其的控制。发布会将其交给您的组织。

要发布技能：

1. 导航到**[自定义 > 技能](https://claude.ai/customize/skills)**。

2. 打开您想要发布的技能。

3. 点击“发布到组织。”

4. 如果您的组织需要审核，请选择您希望如何提供该技能：可安装、默认安装或必需。如果需要，请为审核者添加发布说明，然后提交。

如果您的组织需要审核，所有者（或有权审核请求的人员）会在技能发布前检查它。您选择的提供方式是一个建议。审核者会看到它被预选，可以更改它，他们还会选择谁获得该技能：所有人或特定群组。您可以在等待期间继续使用和编辑您的副本，也可以撤回提交。该技能显示其状态：待处理、请求更改（附带审核者的备注）或已发布。批准后您会收到电子邮件。如果您的组织不需要审核，该技能会发布到库中，您组织中的所有人都可以安装。如果您的组织启用了安全扫描，该技能在通过扫描前不会列出给其他人，通常需要几分钟。

发布后，该技能由您的组织管理。要更新它，请再次发布。新版本会经过相同的审核，所有使用该技能的人都会保持在已批准的版本上，直到更新获得批准。

## 使用与您共享的技能

在 Team 和 Enterprise 计划中，您在 **[自定义 > 技能](https://claude.ai/customize/skills)** 中的技能列表分为三个部分：

- **个人技能：**您创建或上传的技能。

- **与您共享：**同事直接与您共享的技能。这些技能默认关闭，直到您打开它们。

- **组织技能：**发布到您的组织的技能以及您的所有者为您配置的技能。您从目录中安装这些技能，而不是从列表中启用它们。

### 启用直接与您共享的技能

1. 在您的技能列表的 **与您共享** 部分中找到该技能。

2. 打开它。

您可以随时关闭该技能，或者如果您不需要它，可以从列表中完全删除它。

### 从您的组织目录中安装技能

1. 在 Cowork 中，单击左侧边栏中的 **自定义**，然后单击 “+” 按钮打开目录。

2. 单击 **技能** 选项卡。

3. 找到您想要的技能并单击 “安装。”

您从目录中安装的技能可以关闭，这会将它们从您的边栏中移除。它们仍保留在目录中，以便您稍后可以重新启用它们。有关浏览目录的更多信息，请参阅 **[在一个目录中浏览技能、连接器和插件](https://support.claude.com/en/articles/14328846-browse-skills-connectors-and-plugins-in-one-directory)**。

## 在 Microsoft 365 加载项中使用技能

您在 Claude 设置中启用的技能也可在 Claude for Excel、PowerPoint、Word 和 Outlook 加载项中使用。Claude 在您工作时自动应用相关技能——您无需单独调用它们。

**加载项中的触发工作原理：**

- 在边栏中键入 `/` 以查看可用技能并选择一个（例如 `/debug` 或 `/deck-check`）。

- 或自然地描述您的任务——Claude 会识别何时适用某个技能并使用它。

Claude 会根据其所在的界面调整技能。研究技能可能在 Cowork 中生成 Word 文档，但在 Excel 中生成详细的数据分解。某些技能在某个界面上的效果可能比其他界面更好。如果您允许 Claude 跨应用工作，Claude 可以协调另一个应用来应用该技能。如果您使用特定的 Excel 或 PowerPoint 模板构建技能，Claude for Excel 和 PowerPoint 可以将该模板精确加载到当前打开的文件中。

## 在 Claude Code 中使用技能

您在 Claude 设置中启用的技能也会在您使用同一 Claude 账户登录时加载到终端中的 Claude Code 中。这包括您创建或打开的技能以及您的所有者为您的组织配置的技能。它需要 Claude Code v2.1.273 或更高版本。

在 Claude Code 中运行 `/skills` 以查看它们在 **claude.ai sync** 下列出。

- Claude Code 会话启动时技能会同步，然后大约每 10 分钟检查一次更改。

- 同步是单向的。它从您的 Claude 账户读取，永远不会更改其中的任何内容。

- 当 Claude Code 使用 API 密钥登录或在 Amazon Bedrock 等云提供商上运行时，技能不会同步。

要停止技能同步，请在您的 Claude Code 设置中将 `syncClaudeAiSkills` 设置为 `false`。在 Claude Code 文档中了解更多关于 **[同步技能的行为](https://code.claude.com/docs/en/skills#how-synced-skills-behave)**。

## 管理您的技能

### 查看您的技能

您的所有技能都列在 **[自定义 > 技能](https://claude.ai/customize/skills)** 中。您可以看到：

- Anthropic 技能（由 Anthropic 创建、测试和维护）

- 您上传的自定义技能

- 每个技能的启用或上传时间

- 每个技能的简要描述

### 启用/禁用您的技能

使用其旁边的开关打开或关闭任何技能。禁用的技能将不可用于 Claude。

### 下载自定义技能

要保存您创建或上传的自定义技能的副本：

1. 导航到 **[自定义 > 技能](https://claude.ai/customize/skills)**。

2. 在您的技能列表中找到该技能并单击它以查看详细信息。

3. 单击切换开关旁边的 “...” 按钮，然后选择 “下载。”

当您将个人账户迁移到 Team 或 Enterprise 组织时，自定义技能不会移动，因此请在迁移前下载您想保留的任何技能。有关更多信息，请参阅 **[迁移时会移动什么](https://support.claude.com/en/articles/9267400-move-your-personal-claude-account-to-a-team-or-enterprise-organization#h_4e63ef6e87)**。

### 删除自定义技能

要删除您上传的自定义技能：

1. 导航到 **[自定义 > 技能](https://claude.ai/customize/skills)**。

2. 在您的技能列表中找到该技能并单击它以查看详细信息。

3. 使用右上角的切换开关禁用该技能。

4. 要完全删除自定义技能，请点击切换开关旁边的 “...” 按钮，然后选择 “删除”：

## 隐私和安全详情

对于团队和企业计划，组织所有者可以通过组织设置为所有用户配置技能。如果所有者启用了共享，个人可以与同事共享技能，或者如果所有者启用了发布，可以将其发布到组织。在所有其他计划中，每个人都将技能上传到自己的账户。

请注意，技能可能包含或指示 Claude 安装第三方软件包和软件供 Claude 在完成任务时使用。有关 Claude 容器环境的详情，请参阅 **[我们关于 Claude 容器环境的指南](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude#h_0ee9d698a1)**，以及 **[API 文档](https://docs.claude.com/en/docs/agents-and-tools/tool-use/code-execution-tool#containers)**中关于 API 容器环境的内容。

**注意：**如果您使用企业计划且您的组织已启用技能扫描，您上传或编辑的每个第三方技能都会在运行前检查是否存在恶意内容。大多数扫描在大约一到两分钟内完成。如果技能被阻止，您无法使用它，直到您修复被标记的问题并重新上传。了解更多关于 **[技能和插件扫描](https://support.claude.com/en/articles/15927065)**的信息。

### 使用技能的主要风险是什么？

最重大的风险是提示注入（允许 Claude 被操纵执行意外操作）和数据泄露（由恶意软件包代码或提示注入数据泄露引起）。我们已实施多项缓解措施来应对这些风险。有关更多信息，请参阅 **[我们关于代码执行安全考虑的指南](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude#h_0ee9d698a1)**。

**重要：**仅从可信来源安装技能。

从不太可信的来源（包括同事共享的来源）安装技能时，请在启用前进行审查。首先阅读技能中包含的文件内容以了解其功能，特别注意代码依赖项和捆绑的资源（如图像或脚本）。同样，请注意技能中指示 Claude 连接到可能不受信任的外部网络源的说明或代码。

## 故障排除

### 技能部分不可见

确保在 **[设置 > 功能](https://claude.ai/settings/capabilities)**（免费、专业、最大、超级）或 **[组织设置 > 插件和技能](https://claude.ai/admin-settings/skills)**中的 “策略” 标签（团队、企业）中启用代码执行。然后导航到 **[自定义 > 技能](https://claude.ai/customize/skills)**来访问您的技能。技能需要代码执行环境才能运行。

### Claude 未使用技能

- 验证技能在 **[自定义 > 技能](https://claude.ai/customize/skills)**中已打开。

- 检查技能的描述字段是否清楚地说明了何时应使用它。

- 确保技能的说明清晰且结构良好。

- 尝试在您的请求中更加明确（例如，“使用我的品牌指南技能来创建演示文稿”）。

### 无法创建或上传技能

在团队和企业计划中，组织所有者可以关闭用户的技能创建功能。如果缺少创建或上传技能的选项，您的组织可能已关闭 **用户创建的技能**，或者在具有自定义角色的企业计划中，您的角色可能不包括 **创建技能**功能。您仍然可以启用和使用所有者配置的技能。如果您需要创建自己的技能，请联系您的组织所有者。

### 技能灰显

如果技能显示为灰显，代码执行可能在组织级别（对于团队和企业计划）或个人级别被禁用。请与您的组织所有者联系（团队、企业），或确保在 **[设置 > 功能](https://claude.ai/settings/capabilities)**（免费、专业、最大、超级）中启用代码执行。

### 上传错误

上传失败的常见原因：

- ZIP 文件超过大小限制

- 技能文件夹名称与技能名称不匹配

- 缺少必需的 skill.md 文件

- 技能名称或描述中包含无效字符

### 尝试共享技能时组不出现

该组需要由组织所有者启用 **与此组共享资源**可见性设置。如果您期望看到的组缺失，请联系您的组织所有者。

### 共享按钮不可见

**技能共享**切换在团队计划和未设置技能偏好的企业计划中默认启用。对于具有 HIPAA 就绪或其他受管制配置的组织，技能和技能共享默认关闭，管理员可以启用它们。**与组织共享**和 **与组共享**切换也默认关闭。所有者必须导航到 **[组织设置 > 技能](https://claude.ai/admin-settings/skills)**并启用至少一个切换，“共享”按钮才会出现。如果您的组织使用自定义角色，您的角色还必须启用 **与组共享技能**功能。如果您看不到共享选项，请与您的组织所有者联系。

### “发布到组织”按钮不可见

您的组织的 **发布**设置可能已关闭，或该技能可能不是您创建的。您无法发布与您共享的技能、Anthropic 的内置技能或您从组织库安装的技能。如果这是您自己的技能且您看不到该按钮，请与您的组织所有者联系。

## 最佳实践

**从简单开始。**在创建自定义技能之前，先从 Anthropic 的预构建技能开始，了解它们的工作原理。

**具体明确。**编写自定义技能时写清楚的描述。具体的描述告诉 Claude 何时调用您的技能。

**测试您的技能。**上传自定义技能后，使用几个不同的提示进行测试，以确保其按预期工作。

**按目的组织。**为不同的目的创建单独的技能，而不是创建一个旨在做所有事情的单一技能。
