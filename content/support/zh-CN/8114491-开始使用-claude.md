# 开始使用 Claude

## Claude 是什么？

Claude 是由 Anthropic 构建的大型语言模型 (LLM)。它经过训练，可以成为一个有帮助、诚实和无害的助手，具有对话式的语气。

## 如何访问 Claude

您可以通过多个平台访问 Claude：

- **网页**：访问 **[claude.ai](https://claude.ai/)** 在网络浏览器中与 Claude 聊天。

- **桌面**：**[下载 Claude Desktop](https://claude.ai/download)** 用于 Mac 或 Windows。

- **移动设备**：下载 Claude iOS 或 Android 版本，在您的移动设备上聊天。

## 支持的地区

您必须在我们的 **[支持地区](https://support.claude.com/en/articles/8461763-where-can-i-access-claude)** 之一才能访问 Claude。

## 使用 Claude 有年龄要求吗？

您必须至少 18 岁才能使用我们的服务。

## 如何与 Claude 交谈

### 什么是提示词？

您使用 **提示词** 与 Claude 交流。最好的方法是像与同事或朋友交谈一样自然而随意地与 Claude 交谈。您的提示词可以从简单问题到复杂请求：

- **简单问题**："我如何在房间里挂一个相框？"

- **复杂请求**：多步骤项目、分析、创意写作、编码或技术任务。

### 使用 Claude 聊天界面

在聊天界面中输入您的提示词，然后点击提交按钮开始与 Claude 的对话。您可以点击左下角的 "+" 按钮或输入 "/" 来查看其他选项和命令：

## 了解 Claude 的功能

### 我在与哪个模型交谈？

您当前聊天的模型显示在您的文本输入下方（在网页和桌面上）或屏幕顶部（在移动设备上）。您可以点击您正在使用的模型来打开模型选择器并切换到另一个可用模型。

您还可以选择 Claude 在每个响应中投入多少努力，以及它是否使用扩展思考。了解更多关于 **[更改模型、努力和思考设置](https://support.claude.com/en/articles/8664678)** 的信息。

### 我可以用不同的语言与 Claude 聊天吗？

Claude 在英语方面有广泛的训练，在许多其他常见语言中表现良好。它还具有用不常见语言交流的一些能力，并对编程语言有广泛的了解。

有关在您的设置中选择语言的说明，请参阅 **[如何用您喜欢的语言使用 Claude](https://support.claude.com/en/articles/10769299-how-to-use-claude-in-your-preferred-language)。**

### 是否有使用限制或聊天长度限制？

使用免费 Claude 计划时，存在基于会话的使用限制，每五小时重置一次。此外，您可以发送的消息数量将根据需求而异，我们可能会施加其他类型的使用限制以确保所有用户的公平访问。当您达到限制或您的提示词超过可用上下文窗口时，Claude 会通知您。

有关使用和长度限制的更多信息，请参阅 **[使用和长度限制如何工作？](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work)**

### 我如何增加我的使用限制？

我们还提供多个付费订阅，提供额外的使用。有关更多信息，请参阅我们的 **[计划和定价页面](https://claude.com/pricing)**。

### 我可以从另一个 AI 提供商导入我的对话历史吗？

不，目前无法从另一个 AI 提供商将对话历史导入到 Claude 中。但是，Free、Pro、Max 和 Ultra 用户可以使用内存导入功能将其他 AI 提供商的内存转移到 Claude 中。有关更多信息，请参阅 **[从 Claude 导入和导出您的内存](https://support.claude.com/en/articles/12123587-import-and-export-your-memory-from-claude)**。

## 入门提示

1. **从简单开始**：从直接的问题开始，以熟悉 Claude 的响应方式。

2. **具体明确**：您的请求越具体，Claude 就能更好地帮助您。

3. **迭代**：不要犹豫，改进您的提示词或提出后续问题。

4. **探索**：尝试不同类型的任务 - 从让 Claude 回答基本问题到将其用作更复杂项目的协作伙伴。
