本文介绍如何使用 **[Claude Cowork](https://claude.com/product/cowork)**，它将 Claude Code 的智能体功能扩展到编码之外的知识工作领域。

## 什么是 Claude Cowork？

Claude Cowork 使用与 Claude Code 相同的智能体架构，无需终端。Claude 不是一次响应一个提示，而是可以承担复杂的多步骤任务并代表您执行。

使用 Cowork，您可以描述一个结果，然后离开，之后回来查看完成的工作——格式化的文档、组织的文件、综合的研究等。Cowork 在云中远程运行您的会话，因此您的会话和文件与您的 Claude 账户一起保存，并跟随您在桌面、Web 和移动设备上使用。聊天和 Cowork 现在共享一个主页，因此将任务交给 Claude 与进行对话从同一消息框开始。使用计划任务，Claude 可以自动为您完成工作。使用项目，您可以将相关任务组织到具有自己的文件、链接、说明和记忆的持久工作区中。

**重要提示：**

- 由于 Cowork 的智能体性质和互联网访问，它具有独特的风险。

- Cowork 遵守您当前的网络出口权限。

  - **重要提示：**网络出口权限不适用于网页获取或 **[网页搜索](https://support.claude.com/en/articles/10684626-enabling-and-using-web-search)** 工具或 MCP，包括 Chrome 中的 Claude。网页获取在服务器端运行，仅限于搜索结果和您共享的 URL。

  - Team 或 Enterprise 计划所有者可以在 **[组织设置 > 功能](https://claude.ai/admin-settings/capabilities)** 中为 Cowork 和聊天关闭网页搜索，或通过 **[组织设置 > Chrome 中的 Claude](https://claude.ai/admin-settings/browser-extension)** 为 Chrome 中的 Claude 关闭。

- 您可以控制 Cowork 任务，并可以随时使用"删除"选项删除任务（单击任务旁边的

有关使用 Cowork 的 Team 和 Enterprise 组织的重要限制和注意事项，请参阅 **[Team 和 Enterprise 计划的 Cowork](https://support.claude.com/en/articles/13455879-cowork-for-team-and-enterprise-plans)**。

### 主要功能

- **随处工作：**云中的会话跟随您的 Claude 账户。在一个设备上启动任务，从另一个设备上指导它，并在任何地方获取完成的输出。请参阅 **[在 Web、桌面和移动设备上使用 Claude Cowork](https://support.claude.com/en/articles/15520349)**。

- **无需您的工作继续进行：**在云中的会话中，当您关闭笔记本电脑或离开时，Claude 会继续工作。

- **与聊天共享记忆：**在云中的会话中，Claude 从它已经从您的聊天中记住的内容开始，Cowork 任务中出现的内容会回到聊天中。要运行单个任务而不使用记忆，请在发送第一条消息之前在"+"菜单中关闭

- **直接本地文件访问：**在桌面上，Claude 可以读取和写入您的本地文件，无需手动上传或下载。

- **子智能体协调：**Claude 将复杂工作分解为较小的任务，并协调并行工作流来完成它们。

- **专业输出：**生成精美的可交付成果，如具有工作公式的 Excel 电子表格、PowerPoint 演示文稿和格式化文档。

- **就地编辑草稿：**当 Claude 起草 Markdown 文档时，突出显示要更改的文本，单击"使用 Claude 编辑"，然后输入您的请求。Claude 在您标记的位置进行编辑，无需在任务线程中描述该部分。

- **长期运行的任务：**在长时间内处理复杂任务，而不会因对话超时或上下文限制而中断您的进度。

- **计划任务：**创建并保存任务，您可以让 Claude 按需运行或按您选择的频率自动运行。计划任务在云中运行，无需设备在线。

- **电子表格和演示文稿：**Cowork 可以生成电子表格和幻灯片，可以使用 Claude for Excel 和 PowerPoint 进一步编辑。

- **项目：**将相关任务分组到具有自己的文件、上下文、说明和记忆的工作区中。请参阅 **[在 Cowork 中使用项目组织任务](https://support.claude.com/en/articles/14116274-organize-your-tasks-with-projects-in-cowork)**。

- **浏览器操作：**对于涉及网站的任务，Claude 可以打开网站、阅读页面、点击、输入和填充表单。在桌面上，Claude 默认使用内置于 Claude Desktop 应用中的浏览器，无需安装任何内容。如果您已经使用 Claude in Chrome，Claude 会在您自己的浏览器中工作，您可以随时在 **[设置 > Cowork](https://claude.ai/settings/cowork)** 中更改您的首选浏览器。您也可以直接在 Chrome 侧边栏中运行 Cowork 会话。在 **[在 Claude Cowork 中使用内置浏览器](https://support.claude.com/en/articles/16607400)** 和 **[Chrome 中的 Claude 入门](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome)** 中了解更多信息。

## Claude Cowork 如何运行您的任务

Cowork 在云中运行您的任务。Claude 的工作在 Anthropic 的服务器上以隔离环境运行，您的会话和文件保存到您的 Claude 账户。当您关闭笔记本电脑时工作会继续，您可以从任何设备打开同一会话。

当任务需要计算机上的内容（如本地文件或浏览器）时，Claude 通过该计算机上的 Claude Desktop 应用访问它。当您在 Cowork 中启动任务时，Claude：

1. 分析您的请求并创建计划。

2. 在需要时将复杂工作分解为子任务。

3. 在 Anthropic 服务器上的隔离环境中运行代码和 shell 命令。

4. 在适当时协调多个并行工作流。

5. 将完成的输出交付到您的会话，您可以在其中预览和下载它们。

您在整个过程中保持对 Claude 计划和执行内容的可见性，因此您可以在重要时进行指导，或让 Claude 独立运行。

## 开始

### 要求

- **付费 Claude 订阅：**Cowork 仅适用于付费 Claude 计划（Pro、Max、Ultra、Team、Enterprise）。

- **对于本地文件访问、浏览器使用和计算机使用：**macOS 或 Windows 的 **[Claude Desktop 应用](https://support.claude.com/en/articles/10065433-installing-claude-desktop)**，打开并连接。这些功能访问计算机上的内容，因此即使您的会话在云中运行，它们也需要该应用。

- **活跃的互联网连接：**在整个会话中需要。

## 启动 Cowork 会话

**注意：**如果您的消息框不显示"聊天"和"Cowork"选项，说明您拥有新的 Claude 体验。跳过第 2 步，因为每个对话都可以承担 Cowork 任务。

聊天和 Cowork 共享一个主页。要在任何设备上启动会话：

1. 在 claude.ai 网页版、Claude 桌面应用或 Claude 移动应用中打开 Claude。

2. 在消息框中选择"协作"。

3. 描述您希望 Claude 完成的任务。

4. 查看 Claude 的方法，然后让它运行。

**注意：**即使桌面应用关闭或计算机处于睡眠状态，会话也会继续运行。如果您的任务使用本地文件、浏览器或计算机，请保持桌面应用打开，以便 Claude 可以访问它们。

## 任务期间的预期情况

当 Claude 在协作中处理任务时：

- **进度指示器**显示 Claude 在每一步正在做什么。

- **透明度：**Claude 展示其推理和方法，以便您可以跟进。

- **引导：**您可以随时介入以纠正方向或在任务中途提供额外指导。

- **随处检查：**在另一个设备上打开同一会话以监控进度、回答 Claude 的问题或重定向工作。

- **并行工作：**对于复杂任务，Claude 可能会协调多个子代理同时工作。

- **删除保护：**使用协作时，Claude 需要您的明确许可才能永久删除任何文件。您将看到权限提示，需要选择"允许"才能让 Claude 执行删除任务。

任务可能会根据复杂性运行较长时间。您可以监控进度或离开，在 Claude 完成时返回。

**手动批准（手动）**，以前称为"在行动前询问"。Claude 暂停并请求批准操作。您查看每个请求并选择允许或拒绝。

**自动批准（自动）。**Claude 继续工作而不停止询问每一步。相反，Claude 审查每个操作的安全性（例如检查数据外泄或**[提示注入](https://support.claude.com/en/articles/13364135-use-claude-cowork-safely)**），并自动阻止它认为不安全的任何内容。当操作被阻止时，Claude 会寻找更安全的方式来完成任务或暂停并直接询问您。如果 Claude 不断遇到阻止，它会切换回为每一步请求您的许可。

在将自动模式设为 Claude Code 的默认值之前，我们进行了内部测试和第三方红队测试。我们使用这些发现来加强自动模式在所有产品中的工作方式。它为您提供让 Claude 不间断工作的速度，同时具有"跳过所有批准"所没有的保护层：每个操作在发生前仍会被审查。*当然，没有防御是完美的，没有模式可以替代您的判断。对于有真实后果的工作——金钱、以您的名义发送的消息、重要文件——请保持密切关注并审查 Claude 所做的事情，或考虑切换回"手动批准"。*

自动模式适用于您所有现有的连接器、插件、内置浏览器、Chrome 中的 Claude 和一些协作操作，如获取网站。

**跳过所有批准（跳过）**，以前称为"在不询问的情况下行动"。Claude 不暂停询问，没有任何内容自动检查其操作。仅当您完全信任任务中涉及的每个操作、连接器、文件、应用等时才使用此选项。

您可以设置 Claude 自动运行或按需运行的任务。要安排任务，请在任何 Cowork 任务中输入 `/schedule`。您也可以点击左侧边栏中的"已安排"来查看、创建和管理您的定期任务。

## 使用限制

多步骤任务（如运行代码、创建文件或使用您连接的应用和浏览器的任务）比快速提问使用更多的配额。Claude 采取的每一步都会使用令牌。

如果您经常达到使用限制，请尝试：

- 将相关工作分组到一个任务中，而不是多个任务。

- 为不相关的工作开始新对话，这样 Claude 就不会携带额外的上下文。

- 告诉 Claude 您只需要快速答案，而不是文件或完成的可交付成果。

- 在 **[设置 > 使用情况](https://claude.ai/settings/usage)** 中检查您的使用情况。

如需更多信息，请参阅 **[使用限制最佳实践](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)**。

## 权限和安全

Cowork 采用分层保护运行：

- **会话隔离：**Claude 的工作在 Anthropic 服务器上的隔离环境中运行，与您的计算机和网络分离。Claude 编写的 Shell 命令和代码在该环境内运行。隔离保护您的计算机；它不会改变 Claude 可以通过您授予的访问权限读取或执行的操作。

- **受控文件和网络访问：**Claude 只能读取和写入您连接的文件夹中的文件，网络访问遵循您配置的出站设置。

**重要：**Claude 可以访问您授予其权限访问的本地文件，并可以代表您采取真实操作。在允许 Claude 继续之前，请查看其计划的操作，特别是在处理敏感文件时。

权限的工作方式与聊天相同。您可以控制：

1. 您 **[连接到 Claude 的 MCP](https://claude.ai/settings/connectors)** 以及它们请求权限的频率。

2. **[Claude 的互联网访问](https://claude.ai/settings/capabilities)**

在将访问权限扩展到 Claude 的默认设置之外之前，请仔细评估您对 MCP 或网站的信任程度。

## 示例用例

Cowork 专为受益于文件访问和扩展执行时间的复杂多步骤工作而设计。以下是一些示例：

### 文件和文档管理

- **组织文件：**"按类型和日期组织我的下载文件夹"— Claude 可以将数百个文件分类到分类文件夹中。

- **处理收据：**将收据放在文件夹中，并要求 Claude 创建格式化的费用报告。

- **批量重命名：**使用一致的模式（如 YYYY-MM-DD 格式）重命名文件。

### 研究和分析

- **研究综合：**将网络搜索、文章、论文和笔记中的信息合并成连贯的报告或摘要。

- **成绩单分析：**从会议记录、访谈或讲座录音中提取主题、要点和行动项。

- **个人知识综合：**分析您的笔记、日志或研究文件，以发现您可能遗漏的模式、主题和联系。

### 文档创建

- **带公式的电子表格：**生成具有工作 VLOOKUP、条件格式和多个选项卡的 Excel 文件，而不仅仅是需要修复的 CSV。

- **演示文稿：**从粗略笔记或会议记录创建幻灯片。

- **来自混乱输入的报告：**将语音备忘录和零散笔记转换为精美文档。

### 数据和分析

- **统计分析：**对您的数据文件进行异常值检测、交叉制表和时间序列分析。

- **数据可视化：**使用您的数据生成图表。

- **数据转换：**清理、转换和处理数据集。

如需更详细的示例，请参阅我们的 **[用例](https://claude.com/resources/use-cases)** 并按"Cowork"类别筛选。

## 故障排除

### 启动 Cowork 时，我看到"正在设置 Claude 的工作区"；这是什么意思？

此消息是预期的，表示 Cowork 正在更新到最新版本以应用任何修复和改进。

### Claude 停止处理我的任务

对于本地会话（在 Pro、Max 和 Ultra 计划上，**[您在 10 月 6 日之前在计算机上启动的任务](https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile#h_f951c27c48)**），请确保在整个任务期间 Claude Desktop 应用保持打开状态。如果应用被关闭或您的计算机进入睡眠状态，会话可能已结束。云中的会话会在后台继续运行；从任何设备打开会话以检查其进度。

### 我的使用限额消耗得很快

多步骤任务比快速提问消耗更多的使用配额。将相关工作分组到一个任务中，为不相关的工作开始新对话，并在 **[设置 > 使用情况](https://claude.ai/settings/usage)** 中检查您的使用情况。在 **[使用限额最佳实践](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)** 中了解更多信息。
