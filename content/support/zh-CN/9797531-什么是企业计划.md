# 什么是企业计划？

**[企业计划](https://claude.com/solutions/enterprise)**专为需要高级安全性、合规控制和可扩展AI的组织设计，可跨团队使用。它包含**[团队计划](https://support.claude.com/en/articles/9266767-what-is-the-team-plan)**中的所有功能，以及额外的安全和合规功能。企业计划定价与团队计划不同：座位费仅涵盖访问权限，所有使用费按API费率单独计费。

有关企业计划定价的更多信息，请参阅**[我们的定价页面](https://claude.com/pricing/enterprise)**。

企业计划有两种方式可用：

- **[自助服务](https://claude.ai/create/enterprise?utm_source=support&utm_medium=article&utm_content=enterprise-plan_self-serve_intro)** — 直接在线购买，无需销售人员参与。

- **[销售协助](https://claude.com/contact-sales?utm_source=support&utm_medium=article&utm_content=enterprise-plan_contact-sales_intro)** — 与我们的销售团队合作，获得高级选项和专属支持。

**重要提示：**如果您的组织目前使用**聊天**和**聊天 + Claude Code**座位，或**标准**和**高级**座位，请参阅本文末尾的相关部分，了解特定于您计划的信息。

## 企业计划包含什么？

企业计划包含团队计划中的所有功能，以及以下内容：

- **安全功能**，确保您组织数据的安全性和合规性，包括：

  - **审计日志：**捕获有关用户操作、系统事件和数据访问的关键信息。

  - **跨域身份管理系统 (SCIM)**

  - **自定义数据保留控制**

  - **合规API：**以编程方式访问Claude使用数据，包括活动日志、聊天历史记录和文件内容，具有按用户和时间范围的筛选功能。

  - **分析API：**以编程方式访问您组织的聚合参与度和采用指标。

  - **客户管理的加密密钥：**在您自己的云提供商中配置加密密钥，由您的组织控制，并让Anthropic使用它来保护您团队在Claude中的聊天、项目和文件。

  - **仅限美国推理：**将您组织的推理保持在美国境内。

- **基于使用量的定价**

  - 座位费仅涵盖平台访问权限，不包含任何使用费。Claude、Claude Code和Cowork的所有使用费按标准API费率单独计费，基于您的团队实际消耗的量。没有每座位使用限制，也没有包含的代币额度。

  - 管理员可以在组织和个人用户级别设置支出限制以管理成本。

- **工作场所工具连接器**

  - 将Claude连接到Google Drive、Gmail、Google Calendar、GitHub、Microsoft 365和Slack，以搜索和检索来自现有文档、电子邮件、日历和团队通信的上下文，无需手动上传。

- **HIPAA就绪**

  - 符合条件的组织可以启用HIPAA就绪配置，并从组织设置中接受BAA。了解更多关于**[HIPAA就绪企业计划](https://support.claude.com/en/articles/13296973-hipaa-ready-enterprise-plans)**的信息。

## 定价

企业计划使用单一座位类型，按用户每月定价，按年计费。座位费为每个用户提供在网络、桌面和移动设备上访问Claude的权限，以及Claude Code和Cowork。

**座位费不包含使用费。**您的团队使用的每个代币（在聊天、Claude Code或Cowork中）都按标准API费率计费，费用在座位成本之上。有关您计划的使用费计费方式的完整详情，请参阅**[我的企业计划如何计费？](https://support.claude.com/en/articles/11526368-how-am-i-billed-for-my-enterprise-plan)**

价格和计划可能会根据Anthropic的决定而改变。

## 企业计划有使用限制吗？

基于使用量的企业计划（包括上述单一企业座位）**没有计划或座位级别的使用限制**。使用费根据实际消耗计费，而不是限制在固定金额。

如果您的组织使用的是具有标准和高级座位的基于座位的计划，则使用限制适用。有关详情（包括如何在这些计划上启用使用额度），请参阅下面的**[标准和高级座位部分](#h_f8351870fb)**。

### 使用量如何在团队中应用？

在基于使用量的企业计划中，没有代币额度可分配。相反，每个团队成员的使用量都会被计量并按API费率计费给组织。一个人的大量使用不会减少其他人可用的内容，因为首先没有分配任何内容。如果您需要成本可预测性，管理员可以在组织或用户级别设置支出限制。

## 自助服务与销售协助企业计划

自助服务和销售协助企业计划都包含相同的功能和相同的座位定价。区别在于您购买、支付和管理计划的方式：

|                   | **自助服务**                                                                                                                         | **销售协助**                                                                                                                                |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **购买方式**          | **[在线](https://claude.ai/create/enterprise?utm_source=support&utm_medium=article&utm_content=enterprise-plan_self-serve_intro)** | 通过我们的**[销售团队](https://claude.com/contact-sales?utm_source=support&utm_medium=article&utm_content=enterprise-plan_contact-sales_intro)** |
| **最少座位数**         | 20                                                                                                                               | 50                                                                                                                                      |
| **支付方式**          | 信用卡、ACH\*                                                                                                                        | 信用卡†、ACH、发票                                                                                                                             |
| **接受的货币**         | 仅USD                                                                                                                             | 支持多种货币                                                                                                                                  |
| **使用费计费**         | 预先购买的额度                                                                                                                          | 按月后付计费                                                                                                                                  |
| **HIPAA就绪 / BAA** | 可用                                                                                                                               | 可用                                                                                                                                      |

*新的自助服务企业组织可以在注册时选择ACH银行转账、信用卡或借记卡。从团队计划升级的组织在升级时使用信用卡，之后可以在**[组织设置 > 计费](https://claude.ai/admin-settings/billing)**中切换到ACH银行转账。

†对于50,000美元或以上的销售协助发票，仅提供银行转账（ACH或电汇）。

**何时联系销售：**如果您的组织需要发票、专属客户成功管理或使用USD以外的货币支付，请联系我们的**[销售团队](https://claude.com/contact-sales)**来设置销售协助企业计划。

## 如何获得企业计划

### 自助服务企业计划

访问**[claude.ai/create/enterprise](https://claude.ai/create/enterprise)**直接购买企业计划。您可以使用信用卡或ACH银行转账（仅USD）支付。

**关于ACH银行转账**

新的自助服务企业组织可以选择通过ACH银行转账而不是信用卡支付。ACH是一种推送式支付方式，这意味着您从银行的界面启动转账，将资金发送到Anthropic的虚拟银行账户号码（VBAN）。您在创建组织时选择支付方式，可以随时在**[组织设置 > 计费](https://claude.ai/admin-settings/billing)**中的ACH银行转账、信用卡或借记卡之间切换。

以下是关于ACH支付的注意事项：

- **激活时间：**如果您选择ACH作为支付方式，您的计划在我们收到付款后才会激活，这可能需要长达五个工作日。

- **无自动充值额度：**ACH支付不支持自动充值。要设置额度自动充值，您可以向账户添加信用卡。

- **订阅和额度：**ACH组织可以通过ACH支付其订阅发票和额度购买。如果您使用ACH购买额度，在付款结算前，额度不会添加到您的账户。

- **添加座位：**如果您增加座位数，我们将为额外座位生成发票，但新座位可以立即使用。

- **从团队升级：**从团队计划升级的组织在升级期间使用信用卡支付。升级完成后，您可以在**组织设置 > 计费**中切换到ACH。

### 销售协助企业计划

**[联系我们的销售团队](https://claude.com/contact-sales)**讨论您组织的需求。

### AWS Marketplace

企业计划也可通过**[AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-nnvi6wff6ef6m)**获得。

如果您的组织目前使用团队计划，并且有兴趣升级到企业计划，请参阅本文了解更多信息：**[将您的组织从团队迁移到企业](https://support.claude.com/en/articles/13779868-migrate-your-organization-from-team-to-enterprise)**。

## 使用聊天和聊天 + Claude Code座位的组织信息

**注意：**目前使用聊天和聊天 + Claude Code座位的基于使用量的企业组织将无法在下一个合同续期后继续使用此计费模式。

一些现有的基于使用量的企业组织目前有两种座位类型：**聊天**和**聊天 + Claude Code**。如果您在**[组织设置 > 成员](https://claude.ai/admin-settings/members)**中看到这些座位类型，本部分适用于您。

您当前的座位类型和定价将保持不变，直到下一个合同续期。续期时，您的计划将自动过渡到上述单一企业座位模式——所有用户将转移到包含Claude Code访问权限的全包**企业座位**，**按用户每月定价**。

有关您当前计划上座位管理工作原理的详情，请参阅**[在企业计划上购买和管理座位](https://support.claude.com/en/articles/13393991-purchasing-and-managing-seats-on-enterprise-plans#h_2673e097fb)**。

## 使用基于座位的企业计划的组织信息

**注意：**目前使用具有标准和高级座位的基于座位的企业计划的组织将无法在下一个合同续期后继续使用此计费模式。

一些企业组织使用较旧的基于座位的计划，该计划使用**标准**和**高级**座位，具有每座位使用限制，而不是上述基于使用量的模式。如果您在导航到**[组织设置 > 成员](https://claude.ai/admin-settings/members)**时看到"标准"和"高级"座位，本部分适用于您。

基于座位的企业计划没有改变；您的座位类型、使用限制和使用额度选项将保持不变，直到您迁移到当前的基于使用量的计费模式。有关您计划上使用额度工作原理的详情，请参阅**[管理团队和基于座位的企业计划的使用额度](https://support.claude.com/en/articles/12005970-)**。

如果您有兴趣迁移到当前的基于使用量的模式，请联系您的Anthropic联系人或**[我们的销售团队](https://claude.com/contact-sales)**。
